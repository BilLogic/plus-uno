## Usage

AI chat is the one way to ask AI about the page in front of you. Pick the mode for the size of the ask.

<DocsTable>
<thead>
<tr><th>Mode</th><th>When to use</th></tr>
</thead>
<tbody>
<tr><td>Popup</td><td>The default. A quick ask that keeps the page in view.</td></tr>
<tr><td>Panel</td><td>Ongoing work beside the page. The Frame docks it, or opens it over the Page on a Blanket when there is no room.</td></tr>
<tr><td>Full screen</td><td>Long answers that need room. It covers the window.</td></tr>
</tbody>
</DocsTable>

AI chat applies the six AI rules from the AI overview.

1. **One AI identity, unnamed.** The chat is called AI chat and carries the AI icon. It has no persona name or avatar.
2. **Every answer is marked.** Each reply is an AI message, which leads with the AI icon.
3. **Fallibility, once.** "AI can make mistakes. Check important info." sits under the prompt input, never on each message.
4. **Sources when it draws on data.** A reply that used records lists them under the message: `respond` returns `{ text, sources }` instead of text.
5. **People confirm actions.** The chat proposes changes; anything that changes data waits for the person's confirm.
6. **Feedback on every answer.** Each reply offers thumbs up and thumbs down, and `onFeedback` receives the reply with its rating. The rating stays on the reply as chat moves between modes.

### Storybook variant

`variant="storybook"` is the chat in the Storybook docs. The docs' floating button opens it through its AI agent action, so the chat's own button is left out with `launcher={false}`: the popup floats above the bottom right corner instead. `respond` may return `{ text, sources }`, and the sources list under the answer, opening in `linkTarget`. The docs' answerer calls a server-side function that answers from the design-system index and holds the credentials, so none reaches the browser; when it errors or is rate limited, the chat searches the site's pages and the component index instead and says so.

## Parts

1. **Button.** A primary circle Icon button with the AI icon, at the bottom right of the Page. It is the one way in, and it hides while chat is open in the Panel or full screen.
2. **Header.** The AI icon, the title and the controls: clear chat, switch mode (popup and Panel trade places), full screen, more and close. The Storybook variant carries clear chat, move to Panel and close.
3. **Conversation.** The person's messages on the sunken fill, and each reply as an AI message with its sources and thumbs.
4. **Prompt starters** (optional). Offered while the conversation is empty, from `starters`.
5. **Prompt input.** Where the person writes. While a reply is coming, its send button becomes Stop.
6. **Fallibility line.** One line under the prompt input.

The same surface fills every mode; the mode only changes which header controls show and where the surface sits.

## Best practices

### Use the popup for quick asks.

A popup keeps the page in view. For ongoing work it covers the page and loses context: move it to the Panel.

### Use the Panel beside the page.

The Panel docks next to the work. For a quick ask it takes more room than the question needs.

### Use full screen for long work.

Full screen gives long answers room. A docked Panel squeezes them.

## Accessibility

- The button is named by `title`, AI chat by default, and so is the Panel's complementary landmark unless `panelLabel` names it.
- The conversation is a log that announces new messages politely.
- Every reply carries one AI icon named "AI", so no answer reads as a person's to a screen reader.
- The thumbs are a group named "Rate this answer". A rated thumb is pressed, and a status line confirms the rating.
- The popup without the button (`launcher={false}`) takes focus in its prompt input on open, and Escape closes it.
- Full screen is a dialog named by `title`, and focus moves into it.
