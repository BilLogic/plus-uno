## When to use

Use `ColumnRangeChart` for a minimum and maximum per category, such as daily
available hours, shortest and longest session per subject, or lowest and
highest score per class.

For one value per category, use `BarChart`. For two distinct moments such as
before and after, use `DumbbellChart`. For spans on a timeline, use
`XRangeChart`. For a full distribution with quartiles and outliers, use
`BoxPlotChart`.

Vertical by default; set `horizontal` for long category labels.

## Data shape

`categories` is an array of strings. `data` is an array of `{ low, high }` (both
required) in `categories` order. `height` defaults to 400; `horizontal` defaults
to `false`.

```jsx
<ColumnRangeChart
    yAxisLabel="Session length (min)"
    categories={['Math', 'Science', 'Reading', 'Writing']}
    data={[
        { low: 25, high: 60 },
        { low: 30, high: 55 },
        { low: 20, high: 45 },
        { low: 30, high: 50 },
    ]}
/>
```

## Color and accessibility

- **Single series color.** Every column uses categorical slot 1 with no per-column color override.
- **Position and end labels carry the values.** Both ends sit on a shared axis and print bare numbers, so the chart reads without hue. Include the unit in `yAxisLabel`, such as `"Hour"` or `"Session length (min)"`.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Because there is no legend and the series is named `"Range"`, state what is measured in `yAxisLabel` and the surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`ColumnRangeChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Availability could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No availability set" description="Hours appear once a tutor sets their availability." />
    : <ColumnRangeChart categories={categories} data={data} yAxisLabel="Hour" />}
```
