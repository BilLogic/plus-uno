## Usage

Use `Facts` to show a few facts about one thing, such as a school's name and
the date it was created, when the reader only needs to read them.

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For a value the reader can select and copy from a field, use `TextField` with `isReadOnly`.
- For facts about many things in rows, use `Table`.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **List.** A `dl` in two columns: the labels, then the values.
2. **Label.** A `dt` in the subtle text ink.
3. **Value.** A `dd` in the default text ink.

## Best practices

### Give each `Facts` label one value.

`Facts` keys each row by its label, so a repeated label collides and drops a row. Put several values for one label in that label's value.

### Keep a `Facts` list free of controls.

A `Facts` list is plain text and takes no focus. For a value the reader edits or copies from a field, use `TextField` with `isReadOnly`.

</div>

## Accessibility

- **Paired for assistive technology.** The `dl`, `dt` and `dd` elements tell screen readers which value belongs to which label.
- **Contrast.** Both inks come from text tokens that pass on the surface in every color mode.

</div>

- `TextField`: use when the reader needs to select and copy the value from a field, with `isReadOnly`.
- `Table`: use when the facts describe many things, one per row.
