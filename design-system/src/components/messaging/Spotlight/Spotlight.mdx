## Anatomy

1. **`SpotlightTarget`** wraps the element the callout points at and shares its
   anchor with the `Spotlight` beside it through a `SpotlightProvider`.
2. **Header** holds the headline and, when `dismissible`, the close button —
   the dialog's first focusable element.
3. **Media**, when passed, sits above the body.
4. **Body** is the `children` text.
5. **Footer** holds an optional `stepCount` and up to two `SpotlightAction`s,
   the secondary one first.

## When to use

Use `Spotlight` to call out one feature the first time someone can use it —
pointing at a new button, a changed control, a place to start. It is a single
step or a short, explicit sequence with a `stepCount`, not an ongoing help
system.

For a message that stays on the page until resolved, use `SectionMessage` or
`Banner` instead. For a short note tied to one field or value, use
`InlineMessage`.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Wrap the target and the callout in one `SpotlightProvider`.

`SpotlightTarget` and `Spotlight` share an anchor through context, so both
need to sit inside the same provider. Pass `target` directly only when the
anchor comes from outside that tree.

```jsx
<SpotlightProvider>
    <SpotlightTarget>
        <Button text="Create" />
    </SpotlightTarget>
    <Spotlight headline="Create a new board" onDismiss={() => setSeen(true)}>
        Click here whenever you want to start something new.
    </Spotlight>
</SpotlightProvider>
```

### Dismiss it once, and remember that it was seen.

`isOpen` is yours to control. Store whatever "seen" state applies — a user
preference, a session flag — so the same spotlight does not reopen on every
visit.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **A dialog, not a tooltip.** The callout is a `Popover.Popup` with a title
  and a description, read together when it opens.
- **The dismiss control is the first focusable element.** Tab reaches it
  before the body or the actions, so closing never requires finding the
  target again.
- **Escape closes it.** Dismissing with Escape or the close button calls
  `onDismiss`, same as pressing it directly.

</div>

## Related

- For a message that explains one field or value inline, use `InlineMessage`.
- For a message scoped to a page or section, use `Banner` or `SectionMessage`.
