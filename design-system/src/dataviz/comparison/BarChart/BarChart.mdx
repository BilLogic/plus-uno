## When to use

Use `BarChart` to compare or rank values across categories, such as enrollment
per subject, average score per class or sessions per weekday. Sort bars from
most to least when ranking.

For change over time, use `LineChart`. For parts of one total, use
`StackedBarChart`, `PieChart` or `DonutChart`. For a value against a target, use
`BulletChart`.

Prefer **vertical** columns for short labels and fewer than seven categories.
Prefer **horizontal** bars (`horizontal`) for long labels, many categories or a
ranking.

## Data shape

`categories` is an array of strings. `series` is an array of `{ name, data }`,
with one number per category in `categories` order. Omit `color` on a series to
assign one automatically.

```jsx
<BarChart
    yAxisLabel="Enrolled students"
    categories={['Math', 'Science', 'History', 'Art']}
    series={[
        { name: '2023', data: [50, 40, 35, 60] },
        { name: '2024', data: [65, 55, 45, 70] },
    ]}
/>
```

## Color and accessibility

- **Automatic series color.** One series uses `--ds-chart-brand`; two or more follow the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1 without skipping. Past six series, group the smallest categories into "Other".
- **Length carries the value.** Color only separates series, so the chart reads without hue. Keep the series count low enough for the legend to name each one.
- **Start the baseline at zero.** A truncated axis exaggerates small differences.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`BarChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : series.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <BarChart categories={categories} series={series} />}
```

## Related

- For the same categories measured over time, use `LineChart`.
- For parts of one total rather than separate values, use `StackedBarChart`.
- For a value against a target, use `BulletChart`.
- For a ranked list where the bar is a thin stem, use `LollipopChart`.
