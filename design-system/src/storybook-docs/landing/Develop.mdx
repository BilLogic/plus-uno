<FoundationSection title="Start here">

- Run `npm install` and `npm run dev` to open Storybook at `localhost:4200`.
- Check `design-system/agent-views/components/index.md` or run `npm run ds -- find <query>` before creating a component.
- Import public components from `@/components` and patterns from `@/patterns`, never from a deep folder path.
- Style with `--ds-*` and role tokens from <DocsLink id="foundations-tokens-color">Tokens</DocsLink>, never literal values.
- Build new interactive behavior on <DocsLink id="tech-stack-base-ui">Base UI</DocsLink>, styled with tokens.

</FoundationSection>

<FoundationSection title="Pages">

Start a new page from a template in <DocsLink id="templates-overview">Templates</DocsLink>: place a <DocsLink id="templates-page">Page</DocsLink> inside a <DocsLink id="templates-frame">Frame</DocsLink> and fill it with <DocsLink id="templates-section">Sections</DocsLink>.

</FoundationSection>

<FoundationSection title="Generators and checks">

- `npm run regenerate` runs the generators in dependency order, then updates ratchets. Never hand-edit generated files.
- `node scripts/sync-storybook-sort.mjs` regenerates the sidebar order from `storybook.taxonomy.json`.
- `npm run check:harness` runs the repo's static checks and reports stale generated files.
- `npm run check:storybook-categories` checks that sidebar sections, component folders and story titles match the taxonomy.
- `DocumentedContract.stories.jsx` mounts every documented prop and variant in a real browser during Storybook test runs.

</FoundationSection>
