## Usage

Use `AvatarGroup` for a short set of people that would crowd a line: the
attendees of a session, the members of a team. Past `max`, the rest fold into
a `+n` menu, reachable by name.

Use plain `Avatar` elements, not `AvatarGroup`, where there is room to name
each person beside their picture.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Avatars.** Up to `max`; when people overflow, `max` minus one plus the `+n`. Each the group's size and shape, overlapping by a quarter.
2. **Ring.** A surface-colored ring around each avatar that separates neighbors.
3. **Overflow.** A gray `+n` button that opens a menu of the people left out, by name.

## Best practices

### Let the group set the size and shape.

`AvatarGroup` passes its `size` and `shape` to every `Avatar` child, so the
row stays even even when a child sets its own.

<DoDontPair
    doExample={<AvatarGroup label="Attendees" max={3}><Avatar name="Jane Park" /><Avatar name="Sam Lee" /><Avatar name="Ana Ruiz" /><Avatar name="Li Wei" /></AvatarGroup>}
    doCaption="The group sets one size and shape for every child."
    dontExample={<AvatarGroup label="Attendees" max={3}><Avatar name="Jane Park" size={24} /><Avatar name="Sam Lee" size={40} shape="square" /><Avatar name="Ana Ruiz" /></AvatarGroup>}
    dontCaption="Children that set their own size and shape, which the group ignores."
/>

### `max` counts the `+n` in.

Five people with `max={5}` show all five; a sixth pushes one into `+2` —
`max` is the most avatars the row ever shows, the `+n` included.

<DoDontPair
    doExample={<AvatarGroup label="Attendees" max={3}><Avatar name="Jane Park" /><Avatar name="Sam Lee" /><Avatar name="Ana Ruiz" /></AvatarGroup>}
    doCaption="Three people fit in max 3, with no +n."
    dontExample={<AvatarGroup label="Attendees" max={3}><Avatar name="Jane Park" /><Avatar name="Sam Lee" /><Avatar name="Ana Ruiz" /><Avatar name="Li Wei" /></AvatarGroup>}
    dontCaption="A fourth person shows two avatars and +2, because the +n takes a slot."
/>

### Keep the group short.

Use it for a handful of people. For a roster, link to the list instead of folding sixty names behind `+n`.

<DoDontPair
    doExample={<AvatarGroup label="Attendees" max={4}><Avatar name="Jane Park" /><Avatar name="Sam Lee" /><Avatar name="Ana Ruiz" /><Avatar name="Li Wei" /><Avatar name="Max Cho" /><Avatar name="Zoe Tan" /></AvatarGroup>}
    doCaption="A handful, with the rest behind the +n."
    dontExample={<AvatarGroup label="Attendees" max={2}><Avatar name="Jane Park" /><Avatar name="Sam Lee" /><Avatar name="Ana Ruiz" /><Avatar name="Li Wei" /><Avatar name="Max Cho" /><Avatar name="Zoe Tan" /></AvatarGroup>}
    dontCaption="Folding most of a roster behind +n: link to the list instead."
/>

## Accessibility

- **Name the group.** `label` names the group for assistive technology —
  "Session attendees" — the same way `Avatar`'s `label` names a person.
- **The `+n` is a named button.** It reads "+3, 3 more people", opens a menu
  of the hidden people by name, reached with Tab and closed with Escape.
- **Every shown avatar keeps its own name.** The group changes `size` and
  `shape`, never an avatar's accessible name.
