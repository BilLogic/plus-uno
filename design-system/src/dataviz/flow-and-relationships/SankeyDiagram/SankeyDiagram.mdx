## When to use

Use `SankeyDiagram` when a quantity splits and merges across five to seven
one-way stages, such as referral source → first session → subject or tutor hours
flowing into subjects. Avoid backward loops (use `DependencyWheel` for two-way
flows).

For stages that only narrow without branching, use `FunnelChart`. For unweighted
connections, use `NetworkGraph` or `ArcDiagram`. For comparing totals, use
`BarChart`.

## Data shape

`data` is an array of `[from, to, weight]` rows. Because nodes are keyed by
name, spell each node name identically across rows.

```jsx
<SankeyDiagram
    data={[
        ['School referral', 'First session', 120],
        ['Family referral', 'First session', 60],
        ['First session', 'Math', 110],
        ['First session', 'Reading', 50],
        ['First session', 'No second session', 20],
    ]}
/>
```

## Color and accessibility

- **Per-node color.** Nodes cycle through the [categorical order](?path=/docs/data-visualizations-color--docs) from `--ds-chart-categorical-1` (repeating past eight), and links inherit their source node's color.
- **Width and labels carry the reading.** Node heights, link widths and inline node labels let the chart read without hue; exact amounts are in the tooltip.
- **Avoid thin slivers.** Fold minor flows into an `"Other"` node so links remain visible and hoverable.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`SankeyDiagram` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Student flow could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="The flow appears after students book their first session." />
    : <SankeyDiagram data={data} />}
```

## Related

- For stages that only ever narrow, use `FunnelChart`.
- For relationships with no amount attached, use `NetworkGraph` or `ArcDiagram`.
- For flows that run both ways between a set of items, use `DependencyWheel`.
- For composition at one moment rather than flow between stages, use `TreemapChart`.
