## When to use

Use `RadarChart` to show a profile across three to eight measures on one shared
scale, such as a tutor's five SMART competencies, a student's skills across
subjects, or one tutor against the cohort average. Keep to two or three series
and never mix units.

Because angled spokes and polygon areas are hard to compare precisely, use
`BarChart` when exact values matter. For two values per measure read as a gap,
use `DumbbellChart`. For change over time, use `LineChart`.

## Data shape

`categories` is an array of spoke names. `series` is an array of
`{ name, data, color, dashStyle }`, with one number per category in `categories`
order. `height` defaults to 400 (or `'100%'` to fill its container).
`chartSpacing` is `[top, right, bottom, left]`.

```jsx
<RadarChart
    filled
    yAxisMax={5}
    categories={['Social-emotional', 'Mastering content', 'Advocacy', 'Relationships', 'Technology tools']}
    series={[
        { name: 'Maya', data: [4, 5, 3, 5, 4] },
        { name: 'Cohort average', data: [3.5, 4, 3.5, 4, 3], dashStyle: 'Dash' },
    ]}
/>
```

## Color and accessibility

- **Automatic series color.** One series uses `--ds-chart-brand`; two or more follow the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1 unless overridden by `color`.
- **Subject-tinted spoke labels.** `categoryColors` tints spoke labels from an array in category order or an object keyed by name. Use `--ds-chart-smart-*` (`SMART` in the palette) for the five SMART competencies.
- **Distance from center carries the value.** Add a non-color cue when comparing series: `filled` fills the first series, and `dashStyle` dashes comparison lines.
- **Name icon-only spokes nearby.** `categoryIcons` replaces text labels with icons, so name the categories in surrounding copy.
- **Percent-only data labels.** `showDataLabels` appends `%` to every value; enable it only for percentages.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`RadarChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Competencies could not load.</SectionMessage>
    : series.length === 0 ? <EmptyState spacing="compact" header="No ratings yet" description="Competencies appear after a session is reviewed." />
    : <RadarChart categories={categories} series={series} />}
```

## Related

- For the same measures read as values rather than as a shape, use `BarChart`.
- For two values per measure read as a gap, use `DumbbellChart`.
- For measures that change over time, use `LineChart`.
- For one score against a target per measure, use `BulletChart`.
