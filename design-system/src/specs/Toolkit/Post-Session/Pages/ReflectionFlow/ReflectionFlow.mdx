**End-to-end interactive prototype** — not a Figma page frame.

Use this when you need to click through the full tutor journey in one place:
Session Info → Student(s) → Session → Self (optional) → Form Feedback (optional) → submit / Save & Exit modals.

Individual **Pages** docs (Session Info, Student, Session, Self, Form Feedback) are **single-step visual specs** for Figma page masters. Prefer those when checking layout/copy for one step. Prefer Reflection Flow when checking navigation, cadence flags, cancellation, and confirmation modals together.

The hi-fi prototype app (`prototypes/post-session-reflection`) mounts this same orchestrator.
