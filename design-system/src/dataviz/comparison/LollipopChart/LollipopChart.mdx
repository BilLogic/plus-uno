## When to use

Use `LollipopChart` to rank many categories on one measure: scores by student,
average rating by tutor, lesson views by lesson. Sort the data from most to
least before passing it in; the chart keeps the order it is given.

For a few categories, or more than one series, use `BarChart`. For two values
per category, such as before and after, use `DumbbellChart`. For a low-to-high
span per category, use `ColumnRangeChart`.

The chart is horizontal by default, which suits long names. Set `horizontal` to
`false` for short labels laid out as columns.

## Data shape

`categories` is an array of strings. `data` is an array of numbers, one per
category, in the same order. `height` defaults to 400; `horizontal` defaults to
`true`.

```jsx
<LollipopChart
    yAxisLabel="Average rating"
    categories={['Maya', 'Jordan', 'Priya', 'Luis', 'Ana', 'Sam']}
    data={[4.9, 4.7, 4.6, 4.4, 4.1, 3.8]}
/>
```

## Color and accessibility

- **One color for every dot.** The chart draws a single series in categorical slot 1 and takes no per-point color, so it cannot highlight one category. Call out the item that matters in the surrounding text.
- **Position carries the value.** Dots read without hue; the stems make each one easy to trace back to its label.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. There is no legend, so the axis title from `yAxisLabel` is the only name for the measure. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`LollipopChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Ratings could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState size="compact" header="No ratings yet" description="Ratings appear after students review a session." />
    : <LollipopChart categories={categories} data={data} yAxisLabel="Average rating" />}
```
