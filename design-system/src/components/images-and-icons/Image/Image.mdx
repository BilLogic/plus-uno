## Usage

Use `Image` for a bitmap — a photo, a screenshot, an illustration exported as
a raster. For a square picture of a school, a tool or a lesson, use `Tile`
instead. For a typed glyph standing in for a kind of thing, use `Object`.

## Parts

1. **Picture.** An `img`, with a `picture` and a dark source when `srcDark` is set.
2. **Size.** `fluid` fills its container's width and keeps the ratio; `fixed` keeps its natural size.

## Best practices

### Pass `srcDark` instead of swapping `src` yourself.

The dark variant is a second `<source>` inside a `<picture>`, matched by
`prefers-color-scheme`. The browser picks it before paint, so there is no
flash of the light image on a dark system.

<DoDontPair
    doExample={<Image src="https://placehold.co/160x90" srcDark="https://placehold.co/160x90/111/eee" alt="" />}
    doCaption="One image with a dark variant, picked before paint."
    dontExample={<Image src="https://placehold.co/160x90" alt="" />}
    dontCaption="A light image alone on a dark surface."
/>

### `alt` defaults to empty, which marks the image decorative.

Set `alt` to real text only when the image carries information nothing else
on the page already states. A caption beside the image, or a heading above
it, usually means `alt=""` is correct.

<DoDontPair
    doExample={<div><Image src="https://placehold.co/160x90" alt="" /><p>Week 3 attendance, by session.</p></div>}
    doCaption="Empty alt where a caption already says it."
    dontExample={<div><Image src="https://placehold.co/160x90" alt="Image" /><p>Week 3 attendance, by session.</p></div>}
    dontCaption="Alt text that says nothing, or repeats the caption beside it."
/>

### Size the container, not the image.

Use `fluid` and let the container set the width, so one image works from phone to desktop. Reach for `fixed` only for a picture that must stay at its natural size.

<DoDontPair
    doExample={<div style={{ width: '50%' }}><Image src="https://placehold.co/320x180" alt="" /></div>}
    doCaption="Fluid, so the container sets the width."
    dontExample={<div style={{ width: '50%' }}><Image src="https://placehold.co/320x180" alt="" size="fixed" /></div>}
    dontCaption="Fixed in a narrow container: the picture overflows it."
/>

</div>

## Accessibility

- **Decorative by default.** `alt=""` hides the image from assistive
  technology — appropriate when a caption or heading nearby already says
  what it shows.
- **Meaningful images need real alt text.** Describe what the image
  communicates, not what it depicts pixel for pixel.
- **The dark swap has no accessibility impact.** It is a media query on the
  `<picture>` element, not a state change a screen reader needs to track.
