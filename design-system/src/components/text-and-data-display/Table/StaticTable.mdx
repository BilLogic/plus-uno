## Usage

Use `StaticTable` for a grid people only read: a record, a summary, a rate
card. A table people sort, filter, select or page is a Dynamic table.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Head cell.** A label with an optional type icon.
2. **Row.** Cells in a band; rest, highlighted, selected or disabled.
3. **Cell.** Text, a number, an icon or any node, with optional secondary text and a leading slot.
4. **Summary row.** One calculation per column, muted, with no rule under it.

## Best practices

- **Per-cell control** — pass `{ content, align, emphasis, overflow, secondary, leading, state, loading, colSpan, className }` instead of a bare value. `align` is `text`, `number` or `icon`.
- **Row size** — `size` is `32`, `40` or `48` (default 40), from the `--size-row-*` tokens. Cell padding is `--size-table-cell-pad-x` and `--size-table-cell-pad-y`.
- **Long text** truncates to one line with an ellipsis and shows the full text in a tooltip; pass `overflow: 'wrap'` for a cell that should wrap.
- **One title column** — `titleColumn` is the index of the column that names the record.
- **No hover, no sort.** `StaticTable` renders `Table` with `hover` forced off. Nothing in it reaches for the Dynamic table's sorting, selection or paging.

## Accessibility

- **It is a real table.** Headers are `th` in a `thead`, so a screen reader announces the column for each cell.
- **Rows are not controls.** Nothing in a Static table takes focus; a table people interact with is a Dynamic table.
- **State is not color alone.** A selected row sets `aria-selected`, a disabled row `aria-disabled`.
- **Truncated text keeps its full value.** A cell that ends in an ellipsis shows the whole text in a tooltip.
