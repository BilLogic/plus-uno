## Usage

Place `AiSources` under its AI message with one `{ title, href, type }` per source.
Duplicate addresses appear once; no sources renders nothing. The toggle shows
the count and starts closed.

Inside a frame, pass `target`, such as `_top`, to open links outside it.
Without `target`, external links open in a new window.

</div>
