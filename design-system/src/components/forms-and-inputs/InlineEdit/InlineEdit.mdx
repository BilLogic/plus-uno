## When to use

Use `InlineEdit` for a value that is read far more often than it is changed and
that can be saved on its own: a title, a name or a short note on a record or a
profile page.

Use `TextField` inside a form, where a Save button submits every field together. An
inline edit saves when it is confirmed and has no say in the form's submit, so
placing one in a form leaves two ways to save. Use a subtle `TextField` where
leaving the field should save with no buttons at all.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Keep the read view to plain text.

The whole read view is one button. A link or a button inside it cannot be
reached or pressed, so put those beside it.

```jsx
// Incorrect: a link inside the read view.
<InlineEdit readView={() => <a href="/profile">{name}</a>} ... />

// Correct.
<InlineEditableTextfield label="Name" value={name} onConfirm={setName} />
```

### Let the parent hold the value.

`defaultValue` is what the edit view starts with each time it opens. Update it
in `onConfirm`, or the next edit starts from the old value.

### Say why a value was refused.

Return the reason from `validate`, in the words a tutor would use. A refused
value leaves the editor open, so the person can fix it without retyping.

### Leave the editor open for long text.

Set `keepEditViewOpenOnBlur` where a stray click would publish an unfinished
thought, and keep the buttons so there is a clear way out.

</div>

## Accessibility

- **The read view is a button.** It is named by the label and the text ("Display
  name Ada Lovelace") and described as "Edit" (`editLabel`).
- **Focus follows the editor.** Opening it puts the caret in the field. Enter,
  the check or Escape returns focus to the read view. Leaving the field
  confirms and leaves focus where the person sent it.
- **Enter confirms and Escape cancels.** In a multi-line edit view, Enter adds a
  line and Cmd or Ctrl and Enter confirms.
- **Refusals are announced.** The message is in the field's caption with
  `role="alert"`, and the field is `aria-invalid`.
- **The buttons are named.** The check and the cross are icon-only, named by
  `confirmLabel` and `cancelLabel`.

</div>

## Related

- For a field in a form, use `TextField`.
- For editing in place with no buttons, use `TextField` with `appearance="subtle"`.
- For several lines edited in place, use `TextArea` with `appearance="subtle"`.
