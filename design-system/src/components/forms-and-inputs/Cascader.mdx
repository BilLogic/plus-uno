## Anatomy

<ol>
    <li><strong>Field</strong>: shows the placeholder, or the chosen path joined with " / ".</li>
    <li><strong>Caret</strong>: the field's trailing icon, a caret-down.</li>
    <li><strong>Menu</strong>: the open list, holding one or more columns.</li>
    <li><strong>Column</strong>: one per level. Its rows are options.</li>
    <li><strong>Row with children</strong>: ends in a caret-right. The selected fill marks the path so far.</li>
    <li><strong>Leaf row</strong>: has no caret. Choosing it commits the path and closes the menu.</li>

## For developers

- **<code>onChange</code> fires only on a leaf.** Choosing a branch opens the next column and reports nothing, so a partial path is never a value. If a branch is a legitimate answer, give it a child that says so, such as "All of Scotland".
- **Label it the ordinary way.** <code>id</code> lands on the input, so a label pointing at it names the field. <code>aria-label</code> works too, because extra props go to the same input.
- **A falsy option value falls through to the text.** The value is read as <code>value</code>, then <code>text</code>, then <code>label</code>, so a value of 0 or an empty string resolves to the label. Use non-empty string values.
- **Hover previews; the keyboard walks.** Down opens the menu. Up and Down walk a column. Right opens the child column and steps into it, and Left goes back to the row that opened it. Enter commits a leaf, and Escape closes the menu and returns focus to the field. Disabled options are stepped over.

## When to use

Use a Cascader when every answer is one leaf and each level narrows the next, as school, then grade, then class. Its value is the whole path, root to leaf. It cannot stop at a parent or hold more than one.

- **The answer is always one leaf.** If stopping at a parent is a valid answer, or the answer is a set, use [Tree select](?path=/docs/components-forms-and-inputs-tree-select--docs).
- **Keep columns short.** Each column is a scrolling list the pointer travels down, so keep levels few and lists short.
- **Show the whole path in the field.** Once filled, the field reads the path joined with " / ", so people can check every level without opening the menu again.
- **For a flat list**, use [Select](?path=/docs/components-forms-and-inputs-select--docs) for 5 to 15 values, and [Radio](?path=/docs/components-forms-and-inputs-radio--docs) for fewer than 5.

</div>

## Accessibility

- **The field says what it opens.** It has the role combobox with a listbox popup, an expanded state, and a link to the menu while it is open.
- **Each column is a named listbox.** The first is "Options". The rest are named for the row that opened them, so a screen reader user hears which branch they are inside rather than a second unnamed list.
- **One tab stop, and it moves with you.** The open menu holds a single tab stop on the highlighted row, so Tab leaves the menu and the arrow keys walk it.
- **Escape closes it and gives focus back to the field.** So does choosing a leaf. Nothing strands focus in a menu that is no longer there.
- **Disabled options are skipped.** Arrow keys step over them, so a keyboard user never lands somewhere that will not respond.
