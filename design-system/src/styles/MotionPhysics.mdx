<FoundationSection title="Springs">

A spring has no fixed duration. It is pulled toward its target and settles when it arrives, so it can be interrupted, reversed and handed the speed of a hand at any moment. Linear motion is the one exception: it is for things that follow time or the pointer one to one.

<FoundationSubsection title="Three families">

Pick the family by the property that changes. The page header on scroll is `linear` too: its small title, actions and tabs follow the scroll position one to one and stay put when scrolling stops.

<FoundationSubsection title="How quick and how bouncy">

A spring has two settings: stiffness (how quick it is) and damping ratio (how bouncy it is). At ratio 1 it lands on its target and stays; at 0.8 it passes by about 1.5%; at 0.6 by about 9.5%. Each time is given twice: to 90% (when the motion reads as arrived) and to settled (within 1% of the target).

</FoundationSubsection>

<FoundationSubsection title="Modes and tokens">

Elsewhere in the docs a token drops its `motion.` prefix (`spatial.fast`), and "Expressive `spatial.fast`" means that token in Expressive mode. All tokens are mass 1. Figma has no motion tokens; a Figma prototype uses the nearest spring with Smart Animate, splitting any move into x then y.

<SpringTokenTable />

**Productive** is the mode for everything. **Expressive** is switched on for one container at a time (`data-motion="expressive"`) for these moments only:

- **Finish:** every completed reflection. The confirmation Flag lands with one overshoot on Expressive `spatial.fast`.
- **Milestone:** onboarding complete, first session done, a student's goal reached, term start and term end. The one card in the hero entrance is Expressive. A goal shows once per person: the student sees it the moment it happens, the tutor the next time they open that student.

Inside an Expressive container, controls, fields, page transitions and data marks stay Productive. This is the only list of Expressive moments; other pages point here.

**The shake** is the one other bounce. A blocked submit shakes its container once: a loose spring (stiffness 1187.5, damping 15, mass 1) kicked sideways at 420 px/s, peaking at 9 px after 40 ms. It is one pattern used by Modal, a field with its own button and InlineEdit, not a token.

<FoundationSubsection title="Exits">

Two questions decide how something leaves.

1. **Can it come back?** If yes (a floating Panel, the Sidebar, a docked Panel), it reverses its entrance one speed faster (`fast` stays `fast`) and settles at the edge.
2. **If it is gone for good, who started it?**
   - **The system** (a Flag timing out): `spatial.exit`, aimed 3.8 times past the edge so it leaves at full speed.
   - **The person, with a click** (a close button, a deleted row): `appearance.fast` in place; surrounding rows close the gap on `spatial.fast`.
   - **The person, with a flick:** `spatial.exit` started from the hand's velocity.

An exit is shorter than its entrance and lands without a bounce. A floating layer may shrink 2% as it fades (a Modal to 98%).

<Canvas of={PhysicsStories.Exits} sourceState="none" />

</FoundationSubsection>

<FoundationSubsection title="Loops">

`motion.loop` is an undamped spring that swings as a sine wave (one cycle every 1.2 s). A three-pulse typing Progress indicator runs the same loop, each pulse an eighth of a cycle behind the one before; turning damping back on settles it at rest.

- A loop runs only while work runs (loading, thinking, typing) and stops the moment the work ends.
- A decorative loop stops by 5 s, and every loop has a pause.
- In Reduced mode a loop becomes a static label, such as "Thinking".

</FoundationSubsection>

<FoundationSection title="Velocity">

What a hand moves keeps the hand's speed.

- **Dragging, splitters, swipes and scrubbing run a live spring** started from the release velocity (projected rest = velocity ÷ 1000 × 0.998 ÷ 0.002; 3 px slop before drag starts, pointer capture, `touch-action: none`).
- **Opening, closing and selecting use the token as CSS.** There is no velocity to carry.
- **Past a limit, it resists, then returns** with the hand's speed (√overshoot × 4 px, returning on `spatial.fast`).
- **A throw is decided by where it would land,** and shows an armed state before release so the person can still take it back.

<FoundationSection title="Weight">

Weight in PLUS is chosen by token, never by mass (every token is mass 1).

<FoundationSubsection title="Size and carry">

Bigger things travel on slower tokens (`fast`, `default`, `slow`). Something dragged follows the pointer on a spring: a tag or name stays right under the pointer on `spatial.fast`; a card trails slightly on `spatial.default` and settles a beat after the drop. Neither bounces: weight shows as lag, never wobble.

<Canvas of={PhysicsStories.Carry} sourceState="none" />

</FoundationSubsection>

<FoundationSubsection title="What it costs">

A destructive action gets friction, not slower motion: deleting something that cannot be undone asks for a confirmation Modal while keeping its normal motion token.

</FoundationSubsection>

</FoundationSection>

<FoundationSection title="Damping">

These four share `spatial.default`'s stiffness and differ only in damping ratio. Productive motion uses ratio 1 everywhere; Expressive uses 0.8 and, for small things thrown with energy, 0.6. Every token stays at 0.6 or above so it never rings.

<Canvas of={PhysicsStories.Damping} sourceState="none" />

<FoundationSubsection title="Damping at a limit">

Dragged past where it can go, a surface moves by √overshoot × 4 px and springs back on `spatial.fast` on release.

<FoundationSection title="Choosing a spring">

Size and distance set the speed. How often it happens decides whether it travels.

<RefTable
    head={['How often', 'What moves']}

        ['Once a session', 'It travels on its size’s token'],

- A page never cuts.
- From the keyboard, controls and Popups open with no animation; layers and pages keep their motion.
- Focus rings never animate.

<FoundationSection title="One spring, five ways">

One token, written for each target it ships to (`damping = 2 × ratio × √(stiffness × mass)`, `response = 2π ÷ √stiffness`). Because CSS cannot repeat a generated `linear()` easing, `motion.loop` ships in CSS as an alternating 600 ms half-cycle sine curve.

<OneSpringFiveWays />

</FoundationSection>

<FoundationSection title="In code">

CSS reads a semantic token as a `linear()` easing plus its settle time. Components bind `--ds-motion-*` semantics only, never a `--motion-spring-*` primitive.

```css
transition: transform var(--ds-motion-spatial-default-duration) var(--ds-motion-spatial-default);
```

JS motion (drag, throw, interruption, height) reads `SPRINGS`:

```js
import { animate } from 'motion';
import { SPRINGS } from '@/tokens/ladder/springs.generated.js';

animate(panel, { x: 0 }, SPRINGS['spatial.default'].productive);
```
