<Title />
A tag names a subject, a focus area, a person, an agent or a team: anything
that is not a number or a changing condition. It is outlined and a status is
filled, so a reader tells a category from a meaning without reading the words.
A row of tags is a Tag group, which owns the gaps, the wrapping, the alignment
and the disabled state.

## For developers

Disabled comes from the field, not from a prop. A field or Tag group wraps its
tags in the context provider, and `useTagContext()` reads the same value from
inside a custom tag.

```jsx
<TagContext.Provider value={{ isDisabled: true }}>
    <Tag behavior="removable" onRemove={drop}>Grade 4</Tag>
</TagContext.Provider>
```

`TAG_COLORS` lists the ten colors for a picker, and `resolveTagColor` turns a
name, including the deprecated alias, into the color Tag draws.

## When to use

Use a tag for a subject, a focus area, a person, an agent or a team. To pick
between the labels, ask in this order:

- **Is it a number?** Use Count.
- **Is it the condition something is in, and can that condition change?** Use Status.
- **Is it a value the system proposes?** Use Suggestion.
- **Otherwise,** use Tag.

For several tags in a row, use Tag group. For a labeled field where a person
picks, creates and removes tags, use Tag input.

Four rules shape how a tag is used:

- **Color is a category, not a status.** A color names a category on the border and the swatch. A meaning that can change is a Status.
- **Pick the behavior, not the look.** Choose read-only, removable, selectable or link. A count is for selectable tags only.
- **Name who owns it with a type.** Person, agent and team lead with a 16 avatar. Leave the avatar out, or let it fail, and initials stand in without moving the tag.
- **Lift a tag onto an image with the elevated option.** It is for read-only and link tags only, because a value is edited off the image.

Two rules belong to the field and the group:

- **Disable the field, not the tag.** A disabled field or Tag group says so once, and every tag inside follows.
- **Let the group own the gaps.** A tag sets no margin. Put more than one tag in a Tag group, which sets the 8 gap and wraps the row or collapses it behind +n.

</div>

## Accessibility

- **Removable:** the tag is a span with one button in it, because a button inside a button is invalid. The × is named from the label, such as "Remove Science". Pass a remove label when the label is not text.
- **Selectable:** the tag publishes its pressed state, so selection is not carried by color alone. Selected also changes the border to the full hue.
- **Link with a ×:** two tab stops, the link and then the ×. Pressing the × never follows the link.
- **Saving:** announced once as "Saving". The × and a link stay focusable but do nothing until the save lands.
- **Focus:** a 2px ring, 2px outside the tag. On an elevated tag the gap is filled in the surface color, so the ring reads on a dark picture.
- **Disabled:** a disabled tag takes no focus and is announced as disabled.
- **Clipped label:** the full text stays in a tooltip that hover and keyboard focus both reach.
- **Swatch and avatar:** decoration, hidden from assistive technology. The tag's words name the person, agent or team.
- **Contrast:** the label is the neutral text token on every color, so the color never decides whether the words can be read.
