## Usage

Give it a `menu`, normally a `Calendar`, where a person changes the date in place: the
tag becomes the trigger of a `Popup`. Leave `menu` off where nobody changes the date there.

Use `DateTag` for a due or event date beside the thing it belongs to: an
assignment, a session, a report. Write `children` as people say the date, such as "Due tomorrow" or "2 days overdue", never a raw timestamp. `DateTag`'s outline, icon and three
appearances are reserved for dates.

### Appearance guidance

The app derives `appearance` from the date and a due-soon window it defines.

## Alternatives

- For a date inside a form that a Save button submits, use `DatePicker`.
- For a workflow condition such as "Completed" or "Needs review", use `StatusTag`.
- For a category or subject or person, use `Tag`.
- For a numeric count, use `CountTag`.

## Parts

1. **Icon.** Fixed by the appearance: a calendar for neutral, a clock for warning and a triangle for danger. It is decoration; the date says the rest.
2. **Date.** One short string, set by the app: "Due tomorrow", "Mar 4".
3. **Outline.** An inset border, so the height stays exact. A date tag has no fill.
4. **Chevron.** With a `menu` only: `angle-down`, and `angle-up` while the popup is open.

## Best practices

### Reserve danger for overdue dates.

The app picks the appearance from the date and its due-soon window, never from taste. Danger means the date has passed; a far-off date stays neutral.

<DoDontPair
    doExample={<FigureRow><span>Overdue</span><DateTag appearance="danger">2 days overdue</DateTag></FigureRow>}
    doCaption="Danger when it is overdue."
    dontExample={<FigureRow><span>Due later</span><DateTag appearance="danger">Due next month</DateTag></FigureRow>}
    dontCaption="Danger on a date far in the future."
/>

### Use warning for dates that are close.

Warning tells people the date is near, before it turns overdue.

<DoDontPair
    doExample={<FigureRow><span>Due tomorrow</span><DateTag appearance="warning">Due tomorrow</DateTag></FigureRow>}
    doCaption="Warning when it is due soon."
    dontExample={<FigureRow><span>Due tomorrow</span><DateTag>Due tomorrow</DateTag></FigureRow>}
    dontCaption="Neutral hides that it is due soon."
/>

### Show one date tag per row.

A row carries one date; extra tags compete for attention.

<DoDontPair
    doExample={<FigureRow><span>Session</span><DateTag>Due Nov 12</DateTag></FigureRow>}
    doCaption="One date per row."
    dontExample={<FigureRow><span>Session</span><DateTag>Due Nov 12</DateTag><DateTag appearance="warning">Due tomorrow</DateTag><DateTag appearance="danger">2 days overdue</DateTag></FigureRow>}
    dontCaption="Several dates in one row."
/>

### Add a calendar where the date changes in place.

Give the tag a `menu` holding a `Calendar` where a person moves a date in the row.
Elsewhere, leave it a label.

<DoDontPair
    doExample={<FigureRow><span>Session 12</span><DateTag appearance="warning" menu={<span>Calendar</span>} aria-label="Due date, Session 12: Due tomorrow">Due tomorrow</DateTag></FigureRow>}
    doCaption="A calendar where the date is moved in the row."
    dontExample={<FigureRow><span>Session 12</span><DateTag appearance="warning" menu={<span>Calendar</span>} aria-label="Due tomorrow">Due tomorrow</DateTag></FigureRow>}
    dontCaption="A name that does not say which field or record."
/>

### Leave the tag a label where nobody changes the date.

Without a `menu` it renders a `span` with no role and no click handler: `onClick`,
`role` and `tabIndex` are dropped with a console warning in development. The one
time it takes focus is when its text is truncated, so a keyboard user can still
reach the tooltip holding the full date.

## Accessibility

- **Without a menu, not a control.** No role, no tab stop, no click handler: assistive
  technology reads it as plain text beside whatever it labels.
- **A button with a menu.** With a `menu` it is a `button` with `aria-haspopup` and
  `aria-expanded`. Its name is the `aria-label`, "field, record: date".
- **Keyboard.** Enter and Space open the popup, and Escape closes it and returns
  focus to the tag.
- **Truncated text stays reachable.** When the label is clipped, the tag
  takes a tab stop and its full text is available as a tooltip on hover or
  focus.
- **The icon is decorative.** It is `aria-hidden`; the appearance's meaning
  lives in the text, not the icon alone.
