## Usage

Use `SearchField` to find a record in a list by typing. To pick a value, use
`Select`; to narrow by a category, use `FilterButton`.

Results show in the results area, never under the field: the count in the table
or results header, and the no-matches message in the table body.

Pick the mode by where the answer lands:

- `active` (default): the rows you hold filter as you type, through `onValueChange`.
- `basic`: the search runs on Enter through `onSearch`, for a search too heavy to run on every keystroke.
- `focused`: a panel under the field, for jumping straight to a record from anywhere. It lists `recent` searches on focus, matches grouped by type while typing, then a "See all" row. The panel is the one exception to the rule above: its rows sit under the field.

The panel's last row is a slot: pass a `SearchFieldAction` child, such as "Create student", and it joins the keyboard order.

`isCollapsible` starts the field as an icon button; `defaultOpen` starts it open. The field's own words are props, so a translation or a product term can replace them: `clearLabel` ("Clear search"), `panelLabel` ("Suggestions"), `recentLabel` ("Recent searches"), `noMatchesLabel` ("No matches for") and `seeAllLabel` ("See all results for").

## Parts

1. **Scope filter** (optional). A compact select before the field, with All first and selected.
2. **Field.** A text field, 40 at default spacing and 32 at compact.
3. **Search icon.** Before the text; a spinner takes its place while results load.
4. **Clear button.** After the text once it holds any.

## Best practices

### Name the scope in the placeholder.

<DoDontPair
    doExample={<SearchField placeholder="Search students" />}
    doCaption="The placeholder says what is searched."
    dontExample={<SearchField placeholder="Search" />}
    dontCaption="A bare verb leaves the scope unsaid, and the label is hidden."
/>

### Pass compact in a bar.

A view bar or top bar holds 32-high controls, so pass `spacing="compact"`.

### Collapse only where the bar is tight.

Use `isCollapsible` when the bar keeps quiet until search is needed. Elsewhere
leave the field open.

## Accessibility

- **The hidden label still names the field.** The accessible name is the placeholder, or `label` when given.
- **The collapsed icon button is named** by the same words, and its tooltip shows them.
- **The scope filter has its own name**, "Search scope" unless `scopeLabel` says otherwise.
- **In `focused` the input is the combobox.** Focus stays in it and the highlighted row is its `aria-activedescendant`; the panel is a named listbox.
- **Loading is announced** through the spinner's status text.
