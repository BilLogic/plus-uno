# ADR-041: Motion is springs on four tiers (2026-11-12)

**Decision.** Every motion value in PLUS is a spring. Bezier curves and fixed
durations retire; ADR-038's duration and easing roles are superseded for motion
(its space, size, radius and type half stands). The plan is `scripts/lib/tokens/plan.mjs`,
generated by `npm run generate:design-tokens` like every other family.

**Tiers.**
- **Primitives:** raw springs, mass 1, named by stiffness with the damping ratio
  appended as `-r<percent>` only when it is not 1: `880`, `440`, `190`, `3800`,
  `1600`, `800`, `800-r60`, `380-r80`, `200-r80`, `25` (exit), `27-r0` (loop).
  `--motion-spring-<name>`. A component never reads one.
- **Semantics:** `motion.spatial.{fast,default,slow}`, `motion.appearance.{fast,default,slow}`,
  `motion.spatial.exit`, `motion.loop`, `linear`. `--ds-motion-<family>-<speed>` holds a
  `linear()` easing sampled from the spring; `-duration` beside it holds its settle time.
  The values are the motion table in the motion docs, fixed.
- **Patterns and components:** the motion registry, one row per template, pattern and
  component, naming its enter, exit and change by semantic (tickets after #2209).

**Expressive** is one container attribute, `data-motion="expressive"`. It re-declares
the spatial semantics that differ (`fast`, `default`, `slow`) and nothing else, so no
component names a mode.

**Reduced** is one block under `prefers-reduced-motion`: every spatial semantic becomes
the `appearance.fast` fade, in the final place and size, never 0 ms. It covers Expressive
containers, so Reduced wins. No component writes its own reduced branch.

**Loops.** CSS cannot repeat a generated `linear()`, so `motion.loop` is a sine half cycle
(600 ms) that the component alternates.

**JS.** `springs.generated.js` holds a `motion`-package config per semantic
(`stiffness`, `damping = 2 x ratio x sqrt(stiffness x mass)`, `mass`) from the same table.

**Figma holds no motion tokens.** Prototypes use the nearest spring as a proxy. The Figma
payload gains no motion variable.

**Why.** A spring takes a hand's velocity and survives interruption; a curve does neither.
One table then serves CSS, JS and docs. The motion docs hold the reasoning and the rulings.

**Sampling.** `design-system/src/tokens/spring.js` samples the analytic response to at most 40
points within 0.3% of it. Tests read each emitted easing back and check 90% time, settle
time (within 10 ms) and overshoot against the table.

**The first pass is gone.** The first-pass duration and easing tokens, their
Foundations page and their guideline were deleted with the harness wiring (#2219); every
component reads a `--ds-motion-*` semantic.
