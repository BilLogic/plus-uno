# Prompt-spec — Tutor shout-outs board · wireframes (Stitch)

**Confirmed brief:** Goal = align stakeholders on layout before any build ·
Artifact = static wireframes, 3 screens · Fidelity = Visual low-mid
(wireframe-clean, real copy), Interaction none (static), Scope 3 screens ·
Won't include = moderation UI, notifications, profile pages.

## Screens (layout settled in the ASCII pass — follow it)

1. **Board, populated** — header "Shout-outs" + primary button "Give one";
   card list, each card: tutor name, message (2–3 lines), poster + relative
   time; "load older" link at the bottom.
2. **Board, empty** — same header; centered message "No shout-outs here yet.
   Know a great tutor?" with the same primary button.
3. **Compose** — back link, title "Give a shout-out"; tutor search field
   (dropdown affordance), message textarea, primary button "Post shout-out".

## Copy (use verbatim — no lorem)

Card 1: To Ms. Alvarez, from Jamie, 2d — "Explained fractions three ways until
it clicked. Legend." · Card 2: To Mr. Okafor, from staff, 5d — "Covered two
extra shifts this week."

## Out of scope — do not draw

Moderation/report controls · notification badges · tutor profile pages ·
any nav chrome beyond back links.
