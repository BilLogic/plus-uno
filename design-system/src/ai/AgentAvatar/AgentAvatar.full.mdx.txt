## When to use

Use `AgentAvatar` wherever the agent speaks or acts: a message in a chat, a
suggested edit, a line in an activity list. Use `Avatar` for a person.

## Usage notes

### The hexagon is for agents only.

<DoDont>
    <Do caption="An agent is a hexagon and a person is a circle, so the two are told apart before anyone reads a name.">
        <span style={{ display: 'inline-flex', alignItems: 'center', gap: 'var(--element-inline-lg)' }}>
            <AgentAvatar label="PLUS AI" size={32} />
            <Avatar name="Jane Park" size={32} />
        </span>
    </Do>
    <Dont caption="Do not give a person a hexagon, or an agent a circle. The shape is how the two are told apart.">
        <span style={{ display: 'inline-flex', alignItems: 'center', gap: 'var(--element-inline-lg)' }}>
            <Avatar label="PLUS AI" icon="wand-magic-sparkles" size={32} />
            <Avatar name="Jane Park" shape="square" size={32} />
        </span>
    </Dont>
</DoDont>

### Lead with the agent.

When an agent acted for a person, show the agent at 32 and the person at 16,
offset 2 from its lower corner. The larger mark says who did the work.

```jsx
// Incorrect: the person is larger than the agent that acted.
<Avatar name="Jane Park" size={32} />
<AgentAvatar label="PLUS AI" size={16} />

// Correct: the agent leads.
<AgentAvatar label="PLUS AI" size={32} />
<Avatar name="Jane Park" size={16} />
```

### Name it.

`label` is required. An agent avatar with no name is a shape a screen reader
cannot say.

## Accessibility

- **One image with a name.** The avatar is `role="img"` and `label` is its name.
- **The glyph is decoration.** It is hidden from assistive technology.
- **Contrast.** The glyph is `--ds-text-inverse` on `--ds-ai-background-bold`,
  which pass in every color and contrast mode.
- **Shape is not the only signal.** Where it matters, pair the avatar with a
  name or an `AI label`, so the distinction does not rest on shape alone.
