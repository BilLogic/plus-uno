<FoundationSection title="Drawing rules">

- Paint with design-system tokens only: color, stroke and corner. The kit follows light and dark on its own.
- Draw skeleton bars where text would sit. Put the words in the caption beside the drawing.
- Keep one scale per set and equal margins around every drawing, balanced by eye.
- Give each drawing one accent, and place it on the subject.
- A drawing shows a concept no component can render. A screen a component can render is a live story.

</FoundationSection>

<FoundationSection title="Primitives">

Each primitive takes a position, a size and an `accent` flag. The top drawing is neutral and the bottom one is accented.
