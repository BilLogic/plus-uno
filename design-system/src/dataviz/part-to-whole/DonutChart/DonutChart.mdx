## When to use

Use `DonutChart` for a single headline number that is a share of something:
modules completed, sessions done against the term's target, SMART competencies
a tutor has passed. The ring shows the share at a glance; the center states it
exactly. It also fits a small split of two to five parts when a total or label
belongs in the middle.

For a split with labeled slices and a legend, use `PieChart`. For one value
against a target that must be read precisely, use `BulletChart`. For a value
on a dial with a min and max, use `GaugeChart`. For more than five parts, or
comparing several donuts side by side, use `BarChart`.

## Data shape

`segments` is an array of `{ value, color, label }`. `value` and `color` are
required; `label` names the segment in the tooltip. Segments draw in the order
given.

```jsx
import { BRAND, CHROME } from '@/dataviz/palette';

<DonutChart
    value="18/24"
    label="Sessions this term"
    segments={[
        { value: 18, color: BRAND, label: 'Completed' },
        { value: 6, color: CHROME.track, label: 'Remaining' },
    ]}
/>
```

## Color and accessibility

- **You pick every color.** `color` is required on each segment and the chart assigns none of its own. For progress, fill the done part with `BRAND` (`--ds-chart-brand`) and the remainder with `CHROME.track` (`--ds-background-neutral`). For a split, sort segments from most to least and give each the next `CATEGORICAL` slot in order, never skipping one.
- **The center text carries the value.** Arc length shows the share, but the exact figure lives in `value`. Write the number there; do not leave the ring to speak alone.
- **Without a legend, segment names are hover-only.** For a split of three or more parts, name the parts in the text around the chart or use `PieChart`, which labels each slice.
- **Keep it to five segments or fewer.** Arcs on a thin ring are even harder to compare than pie slices.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation through the segments. Do not wrap it in `aria-hidden`; that would hide the keyboard proxies. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`DonutChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the size of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={228} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Progress could not load.</SectionMessage>
    : segments.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="Progress appears after a session is logged." />
    : <DonutChart value={value} label={label} segments={segments} />}
```
