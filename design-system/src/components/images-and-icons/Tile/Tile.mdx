## Usage

Use `Tile` wherever a small square picture stands for a thing: a tool's logo in
a list of integrations, a school's crest beside its name, a lesson's thumbnail,
or an icon marking the kind of item in a row. Putting all of them in one frame
keeps them the same size and shape wherever they appear.

Use an icon on its own when it sits inline with text and needs no frame. Use
`Avatar` for a person: people are round, and a tile is square.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Square.** The Media size of the step, 16 to 48, with a radius of a quarter of its size.
2. **Content.** An icon, a logo or an image. An icon is inset to the Font Awesome size of the same step; an image covers the square.
3. **Border.** Optional, drawn inside the square so the tile keeps its size.

## Best practices

### Pick the content, then the color.

Icons take `appearance` and `color`. Logos take a ground color only, since the
logo keeps its own. Images cover the whole tile, so color does not apply.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Tile icon="book-open" appearance="bold" color="blue" /><Tile icon="book-open" /></div>}
    doCaption="Icons take appearance and color; logos keep their own."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Tile content="logo" src="https://placehold.co/48" appearance="bold" /></div>}
    dontCaption="A bold appearance on a logo, which does nothing."
/>

### Colors are categories.

`color` takes the Tag color set: plain names, never a status. Keep one color per kind of
item across the app, or leave tiles gray.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Tile icon="book-open" color="blue" /><Tile icon="book-open" color="blue" /></div>}
    doCaption="One color for each kind of item, across the app."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Tile icon="book-open" color="blue" /><Tile icon="book-open" color="magenta" /></div>}
    dontCaption="The same kind of item in two colors."
/>

### Give a logo its own ground.

Logos default to white. Set a ground color only to match a surface; never recolor the logo.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Tile content="logo" src="https://placehold.co/48" /></div>}

    dontCaption="A bold ground on the logo, which keeps its own."
/>

## Accessibility

- **Decorative by default.** A tile usually sits beside a name that already
  says what it is, so it is hidden from assistive technology
  (`aria-hidden="true"`) unless it has a `label`.
- **`label` makes it one image with a name.** The tile becomes `role="img"`
  with that name, and the picture inside it stays hidden, so the square is
  announced once. Give a tile a label whenever it stands alone, such as a
  logo with no name beside it.
- **Not a control.** A tile has no hover or focus state. To make one clickable,
  wrap it in a button or link that carries the accessible name.
