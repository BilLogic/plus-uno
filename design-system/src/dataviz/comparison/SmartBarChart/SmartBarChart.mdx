## When to use

Use `SmartBarChart` for a small set of percentages read at a glance: share of
students at each grade, session attendance by weekday, completion by unit. The
track behind each column shows how far it is from 100%, so the chart reads as
"how full" rather than "how much".

For values that are not percentages, or that need an axis to read exactly, use
`BarChart`. For a value against a target, use `BulletChart`. For parts of one
total, use `StackedBarChart` or `DonutChart`.

Keep category labels short. The axis is sized for a letter or a day initial,
which is what the stories use.

## Data shape

`data` is an array of `{ letter, height, color }`, all three required. `height`
is a numeric string from 0 to 100; `letter` labels the column; `color` fills it.
The chart's own `height` prop is its pixel height and defaults to 200.

```jsx
import { BRAND } from '@/dataviz/palette';

<SmartBarChart
    height={200}
    data={[
        { letter: 'M', height: '72', color: BRAND },
        { letter: 'T', height: '85', color: BRAND },
        { letter: 'W', height: '64', color: BRAND },
        { letter: 'T', height: '90', color: BRAND },
        { letter: 'F', height: '48', color: BRAND },
    ]}
/>
```

## Color and accessibility

- **You assign every color.** The chart has no default, so `color` is required on each item. For one measure across categories, give every column `--ds-chart-brand` (`BRAND`). For ordered groups such as grades, use one hue from `sequentialRamp`, the strongest step on the biggest value, as the Overview story does.
- **Fill height carries the value.** Color adds nothing the height does not already say, so the chart reads without hue. Do not use color alone to flag a column as good or bad.
- **No axis, no printed values.** The exact number is only in the tooltip. When readers need the number, put it in the surrounding text or use `BarChart`.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. Single letters make thin point labels, so say what each letter stands for nearby. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`SmartBarChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={200} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Attendance could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No attendance yet" description="Attendance appears after a session is logged." />
    : <SmartBarChart data={data} />}
```
