## When to use

Use `ComboChart` when a count (columns) and a rate (line) belong together, such
as weekly sessions held alongside attendance rate, or monthly active tutors
alongside average session rating.

When all series share one unit, use `LineChart` or `BarChart` so a dual axis
does not create false crossings. For ranked causes with a cumulative line, use
`ParetoChart`. For a value against a target, use `BulletChart`.

## Data shape

`categories` is an array of period labels. `barData` and `lineData` (all three
required; pass `[]` for an unused side) are arrays of `{ name, data, color, yAxis }`.
Set `yAxis: 1` on a line series to plot it against the secondary axis; `height`
defaults to 300.

```jsx
<ComboChart
    primaryAxisLabel="Sessions held"
    secondaryAxisLabel="Attendance (%)"
    categories={['Wk 1', 'Wk 2', 'Wk 3', 'Wk 4', 'Wk 5']}
    barData={[{ name: 'Sessions', data: [120, 134, 128, 142, 150] }]}
    lineData={[{ name: 'Attendance', data: [86, 88, 84, 90, 92], yAxis: 1 }]}
/>
```

## Color and accessibility

- **Sequential categorical assignment.** `barData` series take [categorical slots](?path=/docs/data-visualizations-color--docs) starting at slot 1 (even for a single column series), and `lineData` continues from the next free slot.
- **Shape and explicit axis labels.** Columns and lines stay distinct without hue, while multiple series of the same kind rely on color. Include units in `primaryAxisLabel`, `secondaryAxisLabel` and series names so each series maps clearly to its axis.
- **Known gap.** Line marker rings and the secondary axis title use Highcharts defaults and marker fills are white rather than chart tokens, so they do not adapt to color mode.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Series colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`ComboChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Attendance could not load.</SectionMessage>
    : categories.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="Sessions and attendance appear once a week is logged." />
    : <ComboChart categories={categories} barData={barData} lineData={lineData} />}
```
