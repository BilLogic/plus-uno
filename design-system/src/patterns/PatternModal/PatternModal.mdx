The modal pattern is the dialog shell: a header with the title and close button, a body slot and a footer slot, placed in an `Overlay` that carries the scrim. Its width is a step of the screen grid and its height hugs or fills to the screen less 128. It draws the overlay pair, `--ds-surface-overlay` with `--ds-shadow-overlay`, as the Modal component does, with Modal/pad 16, Modal/stack-md 16 and Modal/radius 12. The pattern is drawn inline here; for a real dialog with focus management, use the core Modal component.
