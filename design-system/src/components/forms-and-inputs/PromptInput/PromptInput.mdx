## Usage

Use `PromptInput` as the one place a person writes to the AI — a chat panel,
a feature that drafts from a free-text ask. For a plain multi-line field with
no AI behavior (no send-on-Enter, no loading state), use `TextArea` instead.

`PromptInput` does not carry the fallibility line. `AiChat` shows it once
under its input; any other consumer shows the same line under the field itself.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Attachments** (optional). A row of staged files above the text.
2. **Start slot** (optional). One quiet control before the text, such as an attach button.
3. **Text area.** Grows from one line to five, then scrolls. Named by `label`.
4. **Actions** (optional). Extra controls beside the send button.
5. **Send.** A compact primary icon button; while loading it becomes Stop.

## Best practices

### Keep the field visible while generating.

The loading state shows progress inside the field. Pair `isLoading` with `onStop` rather than disabling the field: the question stays in view, and Stop stays reachable.

<DoDontPair
    doExample={<PromptInput label="Message to AI chat" defaultValue="Summarize Maya's last two sessions" isLoading onStop={() => {}} />}
    doCaption="The loading state shows progress inside the field."
    dontExample={<PromptInput label="Message to AI chat" placeholder="Ask about a student, a session or a lesson" isLoading onStop={() => {}} />}
    dontCaption="A field emptied while generating loses the question."
/>

### Show focus while typing.

Focus tells the user the field accepts input. The field draws its own focus ring; never remove it with custom styles.

### Hint at what can be asked.

<DoDontPair
    doExample={<PromptInput label="Message to AI chat" placeholder="Ask about a student, a session or a lesson" />}
    doCaption="The placeholder hints at what can be asked."
    dontExample={<PromptInput label="Message to AI chat" placeholder="Type here" />}
    dontCaption="The placeholder describes the control."
/>

### Leave the field enabled when idle.

A disabled field blocks follow-up questions.

<DoDontPair
    doExample={<PromptInput label="Message to AI chat" placeholder="Ask about a student, a session or a lesson" />}
    doCaption="An idle field takes the next question."
    dontExample={<PromptInput label="Message to AI chat" placeholder="Ask about a student, a session or a lesson" isDisabled />}
    dontCaption="A disabled idle field blocks the next question."
/>

### Send only real text.

`onSubmit` fires only when there is text to act on: never for an empty, disabled or loading field, and never on a mid-composition Enter.

```jsx
<PromptInput
    label="Message to AI chat"
    placeholder="Ask anything about this session…"
    isLoading={isGenerating}
    onSubmit={sendMessage}
    onStop={cancelGeneration}
/>
```

## Accessibility

- **`label` is required** and is the field's only accessible name — there is
  no visible label by default.
- **Send and Stop are both labeled buttons**, each with its own
  `aria-label`, not just an icon.
- **Enter-to-send follows the platform convention for composed text**:
  Shift+Enter inserts a line break, and an in-progress IME composition never
  triggers a send.
