## When to use

Use `BubbleChart` when three measures of the same records belong together:
sessions per week against average rating, sized by student count per tutor;
attendance against grade average, sized by class size. The third measure is
read roughly, so use it for "bigger or smaller", not exact amounts.

For two measures with nothing to size by, use `ScatterChart`. For sizes alone
with no axes, use `PackedBubbleChart`. When the size value needs exact
comparison, give it its own `BarChart`.

## Data shape

`data` is an array of series, each `{ name, data }`, where `data` holds
`[x, y, z]` triples. The labels default to "X Axis", "Y Axis" and "Size", so
always set all three. `height` defaults to 400.

```jsx
<BubbleChart
    xAxisLabel="Sessions per week"
    yAxisLabel="Average rating"
    zAxisLabel="Students"
    data={[
        { name: 'Math tutors', data: [[6, 4.6, 12], [9, 4.2, 18], [4, 4.8, 7]] },
        { name: 'Reading tutors', data: [[5, 4.5, 9], [8, 4.7, 15], [3, 4.1, 5]] },
    ]}
/>
```

A series may carry its own `color`; leave it out and the chart assigns one.

## Color and accessibility

- **Color is assigned for you.** One series takes `--ds-chart-brand`. Two or more take the categorical order, slot 1 first, never skipping a slot. Keep to two or three series; bubbles crowd faster than dots.
- **Position and size carry the values.** Color only tells series apart. Area is the weakest of the three encodings: readers can rank bubbles but cannot judge their ratio.
- **No size legend.** The chart does not draw a key for bubble size, so say what size means in the header or description; the tooltip gives the exact value under `zAxisLabel`.
- **Overlap.** The 70% fill keeps a bubble behind another visible, but many large bubbles still hide each other. Drag-to-zoom helps a reader pull a cluster apart.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`BubbleChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Tutor stats could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState size="compact" header="No tutor stats yet" description="Stats appear after a tutor's first week of sessions." />
    : <BubbleChart data={data} xAxisLabel="Sessions per week" yAxisLabel="Average rating" zAxisLabel="Students" />}
```

## Related

- For two measures with no third to size by, use `ScatterChart`.
- For sizes grouped into clusters with no axes, use `PackedBubbleChart`.
- For density rather than individual points, use `HeatmapChart`.
- For a weight shown as column width instead of bubble area, use `VariwidthChart`.
