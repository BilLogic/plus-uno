## What it is

Sorting changes one column at a time, and the arrow moves to the sorted column. Paging always shows the range, such as “1–25 of 340”. Selection adds a checkbox to every row and a select-all box to the header, which turns indeterminate when only some rows are chosen. Bulk actions appear in the Section header above the table, never inside it.

Colors follow the toolbar’s Color mode and Contrast switches.

</div>

<div className="sb-ds-doc-section">

## Which table?

Pick the type from what people do with the rows. Rows they only read are a Static table. Rows they sort, filter, select, page or act on are a Dynamic table. Rows that nest under other rows are a Tree table, and nesting wins even when the table is interactive.

The <a href="?path=/docs/foundations-patterns-table--docs">table pattern</a> shows how a table sits in a Section, with its pagination and empty-state slots.

## States

First load shows skeleton rows. Later loads, after a sort, a page change or a filter, keep the old rows dimmed under a spinner, so the layout does not jump and nothing reads as gone. When rows are missing, a message row says why and offers the next step. The header stays visible in every state.

## When to use

Use a Dynamic table when any of these apply: sort, filter, select (including bulk actions), paginate, expand rows, row actions, a frozen column, or loading and empty states. Hover, pressed, focus and selected rows live here and in Tree tables.

- For records people only read, use a Static table.
- For rows that nest under other rows, use a Tree table.

</div>

## Accessibility

- **Name the select-all box.** The head row checkbox is “Select all rows”, and it is indeterminate when only some rows are chosen.
- **Name each row’s controls.** A row checkbox and a More actions button carry the row’s name in their labels.
- **Do not mark selection with color alone.** A selected row shows a checked box as well as the fill.
- **Announce the selection.** The bulk bar in the Section header says how many rows are selected.
- **Make the scroll region reachable.** A region that scrolls takes keyboard focus, and the focus ring is drawn inside it.
- **Say where people are in the pages.** The range, such as “1–25 of 340”, sits beside the pager.
- **Keep contrast.** Text, rules and fills keep their contrast in every Color mode and Contrast setting.
