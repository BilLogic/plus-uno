## For developers

- **Rating is always controlled.** It holds no state, so pass <code>value</code> and an <code>onChange</code> that receives the number, not an event. Without a handler the icons are clickable and nothing changes.
- **It is not a form field.** There is no input behind it, so nothing is submitted and <code>name</code> is not used. Carry the value yourself, for example in a hidden input.
- **The label is a span**, because no form control exists for a label element to point at. The row is named by <code>aria-labelledby</code>, and <code>id</code> lands on the row.

## When to use

Use Rating for a single score out of five: the end of a session, a piece of feedback, a quick judgment made in one gesture. Five icons read at a glance, and five is the whole scale.

- **Use it for a quick judgment, not a precise score.** If the exact number matters, ask for it with [Number input](?path=/docs/components-forms-and-inputs-number-input--docs).
- **Caption the ends when the scale is not obvious.** Name what one and five mean, such as "Poor" and "Great".
- **Ask the follow-up only after a rating.** The follow-up prompt appears once a value is chosen. Keep it to one short prompt, such as "What could be better?".
- **For a labeled scale of options**, use [Choice group](?path=/docs/components-forms-and-inputs-choice-group--docs) laid out inline.
- **For a position on a span**, use [Range](?path=/docs/components-forms-and-inputs-range--docs).

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **It is one value out of five, and says so.** The row is a radio group and each icon is a radio named "Rate 1" through "Rate 5". The chosen value is in the accessibility tree, not only in the fill color.
- **Give it a label.** The label names the row. Without one the row falls back to the generic name "Rating", which says nothing when a page carries two of them. The comments caption is not a substitute.
- **One tab stop, arrow keys within it.** Tab reaches the group once, landing on the chosen icon or the first when none is chosen. Arrow keys, Home and End move the value.
- **Moving the selection changes it.** There is no "focused but not chosen" state, so a keyboard user cannot browse the scale without setting it.
- **Disabled stays announced.** The icons keep their role and value, are announced as unavailable, and drop out of the tab order.
- **Required marks the label only.** The asterisk is decoration, and nothing blocks a submit.
