## When to use

Use `DropdownMenu` for a trigger that opens a list of actions or navigation
links. Its rows are the public Menu family: `Section`, `ButtonItem`,
`LinkItem` and `CustomItem` (also drawn by `MenuGroup` on its own, for a
menu that does not float). For picking one value from a list of options, use
`Select` instead — a dropdown menu is for actions, a select is for a value.

`trigger` is the element that opens it, `children` are its rows. `isOpen` and
`onOpenChange` make it controlled; left uncontrolled it opens and closes on
its own. `placement` and `shouldFlip` govern where it opens and whether it
flips when there isn't room. `spacing` is `cozy` (40px rows, the default) or
`compact` (32px). `loading` swaps the rows for a spinner while its options are
still being fetched.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### A row closes the menu unless it opts out.

```jsx
// Picking "Rename" closes the menu — the common case for an action list.
<DropdownMenu trigger={<Button text="Actions" iconAfter={<i className="fa-solid fa-chevron-down" />} />}>
    <ButtonItem onClick={onRename}>Rename</ButtonItem>
    <ButtonItem onClick={onArchive}>Archive</ButtonItem>
</DropdownMenu>

// A toggle row that should stay open across repeated picks carries
// `data-keep-open`, as a multi-select tag or filter row does.
<ButtonItem onClick={toggleStarred} isSelected={starred} data-keep-open="true">
    Starred
</ButtonItem>
```

### A static row never closes the menu.

A `CustomItem` with no `component` override (its default, `div`) renders a row
that only says its words: nothing to press, nothing to focus, and it leaves
the menu open — the same contract `MenuGroup` itself uses for a row that is
not a control.

### Nested menus are not yet built.

Base UI's own Menu has submenu parts, but the public Menu family has no
submenu-trigger row of its own yet — out of scope for this pass.

</div>

## Accessibility

- **The trigger announces the menu.** Base UI Menu's trigger carries
  `aria-haspopup="menu"` and an `aria-expanded` that tracks the open state.
- **Arrow keys move between rows**, Enter and Space pick the row at the
  cursor, and Escape closes the menu and returns focus to the trigger.
- **A disabled row is out of the tab order** and cannot be picked.
