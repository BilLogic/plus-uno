## When to use

Use `XRangeChart` for schedules and time spans across people or resources, such
as weekly tutor sessions, blocked availability, class exam windows or lesson
plan durations. Gaps show free time and overlaps show clashes.

For ordered milestones without duration, use `TimelineChart`. For low-to-high
ranges without a time axis, use `ColumnRangeChart`. For capacity used over time
as a quantity, use `AreaChart`.

## Data shape

`categories` names the rows top to bottom. `data` is an array of
`{ start, end, y, name, color }`, where `start` and `end` are millisecond
timestamps, `y` indexes into `categories`, and `name` and `color` are optional.
`height` defaults to 400.

```jsx
const day = 24 * 60 * 60 * 1000;
const monday = Date.UTC(2026, 8, 7);

<XRangeChart
    categories={['Maya (Lincoln Middle)', 'Jordan (Roosevelt K-8)', 'Priya (North High)']}
    data={[
        { start: monday, end: monday + day, y: 0, name: 'Lincoln Middle group' },
        { start: monday + day * 2, end: monday + day * 3, y: 0, name: 'Roosevelt K-8 1:1' },
        { start: monday, end: monday + day * 2, y: 1, name: 'North High group' },
        { start: monday + day, end: monday + day * 4, y: 2, name: 'Session prep' },
    ]}
/>
```

## Color and accessibility

- **Per-row color.** Bars take the [categorical color](?path=/docs/data-visualizations-color--docs) for their row index `y` (repeating past eight) unless overridden by `color`. When using a status `color` (for example, a canceled session), include the status in `name` as well.
- **Position and labels carry the reading.** Row labels, bar endpoints and bar `name`s convey who, when and what without hue.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`XRangeChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>The schedule could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions scheduled" description="Sessions appear here once tutors are booked." />
    : <XRangeChart categories={categories} data={data} />}
```
