## Usage

- **Is it a number?** Count tag.
- **Is it the condition something is in, and can that condition change?** Status tag.
- **Otherwise** (a subject, a focus area, a person, a category): Tag.

Who set the value no longer decides. A tag is outlined and a status is filled,
so a reader tells a category from a meaning without reading the words.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Lead, optional.** Nothing by default. A 10 swatch (`swatchBefore`), an icon (`elemBefore`), or for a person, an agent or a team a 16 avatar.
2. **Label.** Neutral text; the hue never colors the words.
3. **Trailing metric.** Optional on a selectable tag: a compact Count tag, such as a filter's result count.
4. **Remove button.** Optional, with the 2px focus ring on the button itself and a name that says what it removes.

## Best practices

### Use one color per category.

A color names a category; changing it inside one category reads as a different one.

<DoDontPair
    doExample={<div style={{ display: 'flex', flexWrap: 'wrap', alignItems: 'center', gap: 'var(--inline-md)' }}><Tag color="blue">Algebra</Tag><Tag color="blue">Geometry</Tag><Tag color="blue">Fractions</Tag></div>}
    doCaption="One color for one category."
    dontExample={<div style={{ display: 'flex', flexWrap: 'wrap', alignItems: 'center', gap: 'var(--inline-md)' }}><Tag color="blue">Algebra</Tag><Tag color="green">Geometry</Tag><Tag color="orange">Fractions</Tag></div>}
    dontCaption="Rainbow inside one category."
/>

### Keep color for a category, never a status.

Pick a color per category and keep it stable, or leave every tag gray. A condition that can change is a Status tag.

<DoDontPair
    doExample={<div style={{ display: 'flex', flexWrap: 'wrap', alignItems: 'center', gap: 'var(--inline-md)' }}><Tag color="blue">Biology</Tag><Tag color="blue">Chemistry</Tag></div>}
    doCaption="A stable color for a category."
    dontExample={<Tag color="green">Passed</Tag>}
    dontCaption={'Green reads as "went well" beside anything red.'}
/>

### Show selection with the selected state.

Selection is a state of the tag, never a new color.

<DoDontPair
    doExample={<Tag isSelected onClick={() => {}}>Algebra</Tag>}
    doCaption="Selected state."
    dontExample={<Tag color="green">Algebra</Tag>}
    dontCaption="A new color for selected."

### Add a swatch only when color is the way to find the tag.

A plain tag is its outline and neutral words. Turn on `swatchBefore` for a tag that is a legend entry or a color-coded filter, where the reader matches the square to a chart or a key. An icon in `elemBefore` is for when the icon carries meaning of its own.

### Let the props pick the kind of tag.

```jsx
// Read-only, the default: a value on show.
<Tag>Grade 4</Tag>

// Removable: a value the person can take out.
<Tag isRemovable onAfterRemoveAction={drop}>Grade 4</Tag>

// Selectable: a filter or an answer chip, with its result count.
<Tag isSelected={on} onClick={toggle} trailingMetric={12}>Science</Tag>

// Link, and a link with a separate ×.
<Tag href="/sites/lincoln-middle">Lincoln Middle</Tag>
<Tag href="/sites/lincoln-middle" isRemovable onAfterRemoveAction={drop}>Lincoln Middle</Tag>
```

`isSelected` is a boolean on purpose: `false` is an unselected toggle, and
leaving it out is a tag that is not selectable. `trailingMetric` is for
selectable tags only; anywhere else it is ignored with a warning.

### Use the type for who, not for what.

Person, agent and team tell people who something belongs to; topics stay plain.

<DoDontPair
    doExample={<div style={{ display: 'flex', flexWrap: 'wrap', alignItems: 'center', gap: 'var(--inline-md)' }}><Tag type="person">Ava Reyes</Tag><Tag type="agent" color="purple">Coach</Tag><Tag type="team">Math team</Tag></div>}
    doCaption="Types name the owner."
    dontExample={<div style={{ display: 'flex', flexWrap: 'wrap', alignItems: 'center', gap: 'var(--inline-md)' }}><Tag>Ava Reyes</Tag><Tag>Coach</Tag><Tag>Math team</Tag></div>}
    dontCaption="Plain tags hide the owner."
/>

`avatar` takes an image source or a node. Leave it out, or let it fail, and
initials stand in without moving the tag. On a plain tag it is ignored with a
warning.

### Lift a tag onto an image with `isElevated`.

```jsx
// A subject on a lesson thumbnail, 8 from the corner.
<Tag color="blue" isElevated>Lincoln Middle</Tag>
<Tag href="/lessons/42" color="magenta" isElevated>Open lesson</Tag>
```

Read-only and link only: a value is edited off the image. On a removable or
selectable tag `isElevated` is ignored with a warning.

### Disable one tag, or the whole field.

`isDisabled` disables one tag. A field or group that is disabled says so once,
and every tag inside follows:

```jsx
<Tag isDisabled>Grade 4</Tag>

<TagContext.Provider value={{ isDisabled: true }}>
    <Tag isRemovable onAfterRemoveAction={drop}>Grade 4</Tag>
</TagContext.Provider>
```

`useTagContext()` reads the same value from inside a custom tag.

### Let the group own the gaps.

`Tag` sets no margin of its own. A row of tags is a `TagGroup`, which sets
`gap` once for the set.

## Accessibility

- **A removable tag is not itself a control.** The × is, and a button inside a
  button is invalid, so the tag is a `span` with one button in it.
- **The × is named from the label.** It announces `Remove Science`;
  `removeButtonLabel` overrides that when the label is not text.
- **Selectable publishes `aria-pressed`**, so the state is not only visible.
  Selected also changes the border to the full hue, so it does not rest on a
  change of lightness alone. A selectable tag given `aria-expanded` is a button
  that opens something, such as TagGroup's `+n`: it publishes the expanded
  state and no `aria-pressed`.
- **A link with a × is two tab stops**, link then ×, and pressing the × never
  follows the link.
- **Saving is announced once.** The spinner is hidden; a status region beside
  the tag, outside its name, says "Saving". The × and a link stay focusable
  but do nothing until the save lands.
- **A × needs a name.** When the label is not text, pass `removeButtonLabel`, or the
  × is named only "Remove" and development warns.
- **An elevated tag's focus ring has a surface gap.** The 2px between the tag
  (or a link's ×) and the ring is filled in the surface color, so the ring
  reads on a dark picture.
- **Disabled tags take no focus, and say they are disabled.** They come from
  `isDisabled` or a disabled field. A selectable tag is a native disabled button, announced as
  disabled. Every other tag is a span, which has no disabled state a screen
  reader announces, so it ends with visually hidden text and is read as
  "Science, disabled".
- **A clipped label keeps its full text** in a tooltip that hover and keyboard
  focus both reach. On a control the control carries it; on a plain tag the
  label takes focus while, and only while, it is clipped.
- **The swatch and the avatar are decoration** and are hidden from assistive
  technology; an avatar image has empty alt text. The tag's words name the
  person, agent or team, so the initials are never read out or folded into the
  ×'s name.
