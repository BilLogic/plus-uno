# Logos

PLUS has one logo: a logomark, with or without the wordmark. Use the `Logo` component (`@/components`); never redraw it.

## Rules

- Sizes are fixed steps: 60, 96, 132, 192 and 224. The minimum is 60; never scale an instance by hand.
- Color options: colored on light surfaces (the default), filled on a bold or dark ground, outlined on photos and busy grounds. Filled and outlined are white.
- Clear space is half the logomark's height on every side, measured from the logomark.
- Never stretch, crop, rotate, recolor, nest in a container or add effects.
- One Logo per view. Partner and tool logos go in a Tile, never in the Logo set.
- Alt text: "PLUS" where the logo alone names the product, empty beside a visible PLUS title, "PLUS home" when it links home.
