## Usage

Use `UserAvatar` for the current user's identity in the topbar or in a row that names a person. For a person who is not the signed-in user, or a picture-only avatar, use `Avatar`.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Initial.** A round pill with the first letter of the name, in `--ds-background-brand-subtlest`. Hidden from assistive technology.
2. **Name.** Truncates with an ellipsis (at the label maximum width in the compact spacing) and keeps the full name in its `title`.
3. **Role.** A Status tag with the text "Lead" for a lead tutor; other types show none.
4. **Counter.** Optional, a danger-subtler pill with the notification count.

## Best practices

### Pick `spacing` by where it sits.

`compact` fits the 32 topbar. `default` fits table rows. The name truncates with an ellipsis, at the label maximum width in `compact`, and keeps the full name in its `title`.

```jsx
<UserAvatar spacing={topbar ? 'compact' : 'default'} name={user.name} firstChar={user.name[0]} type="lead tutor" counterValue={3} />
```

### Pass `onClick` to make it clickable.

Without it the avatar is a static line. With it, the row shows the pointer, takes focus, and presses on Enter and Space. When the click opens a menu or navigates, wrap the avatar in the button or link that owns that behavior instead, so the control carries its own name and expanded state.

## Accessibility

- **A clickable row is a button.** With `onClick` it has `role="button"`, a tab stop, and a 2px focus ring. `state="disabled"` sets `aria-disabled` and removes the tab stop.
- **The initial is decorative.** The pill is hidden from assistive technology; the name carries the meaning.
- **The role is text.** The Lead tag is a Status tag with visible text, not color alone.
