## Usage

Use `Suggestion` when the system proposes a value and a person decides whether
to take it: an AI-suggested focus area beside the ones already chosen, or a
suggested question beside a chat box. Put it in the row where the accepted
value will land, after the tags already there.

Use `Tag` for a value that is already in the field. Use `Button` for an action
that is not a proposed value, and `AiLabel` to mark content the agent has
already produced.

</div>

## Parts

1. **Glyph.** A plus for an <code>insert</code> suggestion, a sparkles wand for a <code>prompt</code>. It says which kind of proposal this is.
2. **Label.** The proposed value or prompt, short.
3. **Edge.** Dashed, in the discovery border: the system proposed it, the person has not accepted it.

## Best practices

### The field decides what happens next.

`onAccept` hands back the value (insert) or the text (prompt). The suggestion
does not change itself; the field that owns the value adds a Tag, sends the
message or fills the text box, and stops offering the suggestion.

```jsx
// Incorrect: a Tag styled as a suggestion is not a button, so nobody can
// accept it with a keyboard.
<Tag color="purple">Relationships</Tag>

// Correct: insert hands back the value; the field turns it into a Tag.
<Suggestion label="Relationships" value="focus-relationships" onAccept={addFocusArea} />

// Correct: prompt hands back the text to send or fill.
<Suggestion type="prompt" label="Summarize" text="Summarize this session" onAccept={send} />
```

### Keep the words short.

A suggestion sits in a tag row, so its label is a value's name, not a
sentence. For a prompt, pass the full words as `text` and a short `label`.

### Disable one suggestion, or the field.

`isDisabled` disables one suggestion. A disabled field or `TagGroup` disables
every suggestion in it through `TagContext`, the same value a Tag reads, so a
suggestion is disabled with the tags beside it.

```jsx
<Suggestion label="Ratios" isDisabled onAccept={add} />

<TagGroup label="Focus areas" isDisabled={!canEdit}>
  <Tag color="blue">Fractions</Tag>
  <Suggestion label="Ratios" onAccept={add} />
</TagGroup>
```

## Accessibility

- **A real button.** It takes focus, and Enter or Space accepts it.
- **Disabled is a disabled button.** It keeps its name, is announced as
  disabled, is skipped by Tab, and never calls `onAccept`.
- **Named for what pressing it does.** An insert suggestion is announced as
  `Add {label}, suggested`, so a screen-reader user knows pressing it adds a
  value. A prompt is not added to anything, so it is announced as
  `{label}, suggested`.
- **The glyph is decorative.** The plus and the sparkle wand are hidden from
  assistive technology; the name already says what the suggestion does.
- **Focus is a ring, not a fill**: a 2px Focus Ring 2px outside the edge, so
  focus never reads as pressed.
