## What it is

The Section header above the table carries the title and any action that leaves the rows as they are, such as Export, so the table never has a toolbar of its own. Search, filters, view tabs, a bulk bar or a pager make it a Dynamic table.

The feel is quiet. The header is 12px and muted, with a stronger rule under it. Rows are flat, with hairline rules between them and no zebra striping. One title column is emphasized, numbers align to the end, and rows rest, with highlighted as the only other row state.

Colors follow the toolbar’s Color mode and Contrast switches.

</div>

## Which table?

Pick the type from what people do with the rows. Rows they only read are a Static table. Rows they sort, filter, select, page or act on are a Dynamic table. Rows that nest under other rows are a Tree table, and nesting wins even when the table is interactive.

The <a href="?path=/docs/foundations-patterns-table--docs">table pattern</a> shows how a table sits in a Section, with its pagination and empty-state slots.

## Variants

### Frame

Plain is the default on a page: the table spans its section with no outer frame, and its first and last cells are flush with the section edge. Use framed when the table sits beside other content and needs its own edge, such as inside a modal body.

<DocsCanvasShell description={<>Plain and framed.</>}>
    <DsCanvasQuiet of={StaticTableStories.FrameVariants} />
</DocsCanvasShell>

### Row size

Rows are 32, 40 or 48 tall at minimum. Pick by how much each row holds, not by screen width: small for dense admin lists, medium for most tables, large when rows hold avatars or two lines.

<DocsCanvasShell description={<>The three row heights.</>}>
    <DsCanvasQuiet of={StaticTableStories.RowSizeVariants} />
</DocsCanvasShell>

### Cells

A cell is text or a slot. Text cells can add a muted second line, wrap, or carry the title emphasis. The leading slot puts an avatar, an icon or a Status before the text.

### Groups and expandable rows

A group row heads the rows that share a value, such as a week or a status, with the count beside it. Group rows alone keep the table static. An expandable row opens a detail panel under it, and makes the table a Dynamic table.

### Summary

The summary row closes the table, muted, with one calculation per column. A Static table never pages, so it has no footer. When the rows need a pager, use a Dynamic table, whose footer shows the range and the pager.

</div>

## States

Static table rows rest, or are highlighted to mark a new or changed row. Hover, pressed, focus, selected and disabled rows belong to the Dynamic and Tree tables. States use the tokens’ own steps. Hovered and pressed are the neutral subtle background steps, selected is the selected background across the whole row with no edge bar, and highlighted is the warning background. Focus is always a 2px focus ring drawn inside the cell or row, so a sticky header or the scroll container never clips it, and it never adds a fill.

## When to use

Use a Static table for records people read and compare, with nothing to do to the table itself.

- For a table people sort, filter, select, page or expand, use a Dynamic table.
- For rows that nest under other rows, use a Tree table.
- For a list of records with no columns to line up, use List group.
- For one item among many, use Card.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **Give every column a heading.** A column heading cell names its column for every cell below it.
- **Label controls that sit in cells.** A checkbox column needs a label on each box. An icon button names its row: “More actions for Ava Lee”.
- **Show truncated text in full.** A truncated cell shows its full value in a tooltip on hover and focus. Wrap the text people must read in full.
- **Do not mark state with color alone.** A highlighted row needs words or an icon beside it. An error cell carries its icon and a message.
- **Keep the focus ring visible.** It is drawn inside the cell or row, so scrolling and sticky headers never clip it.
- **Keep contrast.** Text, rules and fills keep their contrast in every Color mode and Contrast setting.
