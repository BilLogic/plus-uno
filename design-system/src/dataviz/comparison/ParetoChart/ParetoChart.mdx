## When to use

Use `ParetoChart` to isolate the few causes behind most of an outcome, such as
support tickets by issue type, missed sessions by reason or topics where
students struggle most. Read across from 80% on the right axis to see which
causes account for the majority.

For a ranking without a running total, use `BarChart` or `LollipopChart`. For
unordered shares of a total, use `PieChart` or `TreemapChart`. For drop-off
through ordered stages, use `FunnelChart`.

Sort `data` from largest to smallest before passing it in; the chart preserves
input order, and the cumulative line is only meaningful when descending.

## Data shape

`categories` is an array of strings. `data` is an array of numbers in
`categories` order, sorted largest to smallest. The chart computes the
cumulative line automatically. `height` defaults to 400.

```jsx
<ParetoChart
    yAxisLabel="Missed sessions"
    categories={['Schedule conflict', 'Tech issue', 'Illness', 'No notice', 'Other']}
    data={[42, 25, 12, 7, 4]}
/>
```

## Color and accessibility

- **Fixed colors.** Columns use categorical slot 1 and the cumulative line uses slot 2; no color is assigned per column.
- **Shape separates the series.** Columns and the line sit on separate axes and read without hue.
- **Two axes, two units.** The left axis is a count and the right is a percentage; name the count in `yAxisLabel` to keep them distinct.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Because the legend names series only as `"Values"` and `"Cumulative"`, state what is counted in the surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`ParetoChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Missed sessions could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No missed sessions" description="Reasons appear when a session is marked missed." />
    : <ParetoChart categories={categories} data={data} yAxisLabel="Missed sessions" />}
```

## Related

- For the ranked bars without the cumulative line, use `BarChart`.
- For the cumulative share as parts of one whole, use `TreemapChart` or `PieChart`.
- For a drop-off through ordered stages rather than ranked causes, use `FunnelChart`.
- For columns and a line on any two measures, use `ComboChart`.
