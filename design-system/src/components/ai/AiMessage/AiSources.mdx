## Usage

Place `AiSources` under its AI message with one `{ title, href, type }` per source.
Duplicate addresses appear once; no sources renders nothing. The toggle shows
the count and starts closed.

Inside a frame, pass `target`, such as `_top`, to open links outside it.
Without `target`, external links open in a new window.

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For the reply the sources belong to, use `AiMessage`, which draws sources under a finished answer for you.
- For a single link in running text, use `Link`.

</div>

<div className="sb-ds-doc-section">

## Best practices

### Pass AiSources one entry per record an answer read.

An answer built from sessions, students or reports lists each one with a
`title`, an `href` and a `type`, so a person can open what the AI read. An
answer that read nothing passes none, and nothing renders.

### Title a source by its record, not its address.

Write "Session notes, Oct 24" with the type "Session". A bare address tells a
tutor nothing about what the answer drew on.

</div>
