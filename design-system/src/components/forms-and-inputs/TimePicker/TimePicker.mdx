## When to use

Use `TimePicker` for a time of day alone — a reminder time, a recurring
slot's start. For a date alone, use `DatePicker`; for a date and a time
together, use `DateTimePicker`.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### The field always reports a 12-hour value.

`onChange` fires with a string like `"02:30 PM"` regardless of how `value`
was given. A 24-hour `value` passed in is accepted and split into the hour
and period this control shows, but what it hands back is always 12-hour.

```jsx
<TimePicker value={time} onChange={setTime} />
```

### AM/PM is a separate control from the typed text.

The field itself has no notion of which half of the day it is — typing sets
the hour and minute, and the AM/PM toggle beside it sets the period
independently, reporting immediately with whichever half of the time is
already set.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **There is no `label` prop.** Name the field with `aria-label` or
  `aria-labelledby`, forwarded straight to the input a screen reader lands
  on, same as `aria-describedby` and `data-*`.
- **The AM/PM toggle is a real button inside a menu**, reachable and
  operable by keyboard like any other PLUS dropdown.
- **An invalid typed time keeps the typed text** rather than silently
  reverting, so the person can see and correct what they entered.

</div>
