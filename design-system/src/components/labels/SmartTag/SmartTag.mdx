## Usage

Use `SmartTag` wherever training content, a tutor's strengths or a feedback
item is tagged by SMART area. For a category that is not a SMART subject, use
`Tag` directly: `SmartTag` exists only to fix the color and icon per subject,
not to add new behavior.

## Parts

1. **Subject icon.** Fixed per subject: a heart, a book, a bullhorn, a handshake, a laptop. It is decoration.
2. **Label.** The subject's own name unless the context needs other words.
3. **Edge and ground.** The subject's hue on the border and the swatch, with neutral text, exactly as Tag draws a color.

## Best practices

### Keep the subject's own name.

The label defaults to the subject name; a long rewrite breaks the one-line tag. Override it with `children` or `text` only when the surrounding content needs a shorter or longer phrasing.

<DoDontPair
    doExample={<SmartTag subject="social-emotional" />}
    doCaption="The subject name."
    dontExample={<SmartTag subject="social-emotional">Social-emotional learning and wellbeing</SmartTag>}
    dontCaption="A long custom label."
/>

### Show each subject once.

Repeating a subject adds nothing; a row lists the different subjects.

<DoDontPair
    doExample={<div style={{ display: 'flex', flexWrap: 'wrap', alignItems: 'center', gap: 'var(--inline-md)' }}><SmartTag subject="social-emotional" /><SmartTag subject="mastering-content" /></div>}
    doCaption="Distinct subjects."
    dontExample={<div style={{ display: 'flex', flexWrap: 'wrap', alignItems: 'center', gap: 'var(--inline-md)' }}><SmartTag subject="social-emotional" /><SmartTag subject="social-emotional" /><SmartTag subject="social-emotional" /></div>}
    dontCaption="The same subject three times."
/>

### Keep the icon with its label.

The icon is part of the subject's identity, so it is never dropped. A plain `Tag` in the subject's color loses it.

<DoDontPair
    doExample={<SmartTag subject="technology-tools" />}
    doCaption="Icon and label."
    dontExample={<Tag color="brown">Technology tools</Tag>}
    dontCaption="Label without the icon."
/>

### Write the current spelling.

`socio-emotional` and `relationships` are accepted and map to
`social-emotional` and `relationship`. Write new code with the current
spelling; the aliases exist for content written before it changed.

</div>

## Accessibility

- **Inherits `Tag`'s accessibility.** Selection, removal and link behavior
  are unchanged; see `Tag`'s own Accessibility section for the full
  contract.
- **The subject icon is decorative.** It is `aria-hidden`; the subject's name
  is carried by the visible label, not the icon.
