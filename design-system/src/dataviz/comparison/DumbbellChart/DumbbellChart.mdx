## When to use

Use `DumbbellChart` when the gap between two values is the story: pre-test
against post-test score per student, start against current level per skill,
first-week against latest attendance per school. Sort by gap size and the
biggest movers rise to the top.

For one value per category, use `LollipopChart`. For a continuous span with no
two distinct moments, use `ColumnRangeChart`. For the two values read as
separate bars, use `BarChart` with two series. For more than two points per
category, use `LineChart`.

The chart is horizontal by default, which suits names. Set `horizontal` to
`false` for short labels laid out as columns.

## Data shape

`categories` is an array of strings. `data` is an array of `{ low, high }`, both
required, one per category in the same order. `lowLabel` and `highLabel` name the
two ends. `height` defaults to 400; `horizontal` defaults to `true`.

```jsx
<DumbbellChart
    lowLabel="Pre-test"
    highLabel="Post-test"
    yAxisLabel="Score"
    categories={['Maya', 'Jordan', 'Priya', 'Luis']}
    data={[
        { low: 45, high: 82 },
        { low: 65, high: 92 },
        { low: 58, high: 78 },
        { low: 80, high: 88 },
    ]}
/>
```

## Color and accessibility

- **Color tells the two ends apart.** The high dot and the connector take categorical slot 1, the low dot slot 2. The colors are fixed and cannot mark a gain against a loss.
- **The legend does not name the colors separately.** Its one entry reads "Pre-test → Post-test" in one swatch, so a reader matches dot to end by color alone. Say which end is which in the surrounding text, or rely on the tooltip.
- **Position carries the values.** Both dots sit on a shared axis, so the gap reads as a length without hue.
- **Keep `low` and `high` consistent.** Put the same measure in the same field for every row, such as pre-test in `low`. When a row declines, only the order of the two colors shows it, so call declines out in the surrounding text.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`DumbbellChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a post-test is logged." />
    : <DumbbellChart categories={categories} data={data} lowLabel="Pre-test" highLabel="Post-test" />}
```
