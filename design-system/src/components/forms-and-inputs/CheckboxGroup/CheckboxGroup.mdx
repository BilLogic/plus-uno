## Usage

Use `CheckboxGroup` for one question where a person may pick several answers — or none — from a short list visible all at once. It mirrors `RadioGroup` on `Fieldset`, owning the `legend`, the array `value`, and a single group `error` so each option stays a plain `Checkbox`.

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For a single standalone confirmation or a select-all tree, use `Checkbox`.
- For mutually exclusive answers where only one may be chosen, use `RadioGroup`.
- For a long list of multi-select options, use `Select` with `isMulti`.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Legend.** The question. It names the `<fieldset>` and carries the required marker.
2. **Options.** Checkboxes in a stacked list, an inline row, bordered `card` rows, or 224px `tile` cards.
3. **Tile checkbox and illustration.** When `appearance` is `tile`, each tile centers its decorative `illustration`, `label`, and `description`, and anchors its `Checkbox` at the top end so multi-select is clear before clicking.
4. **Reveal.** Optional content under an option, shown while that option is selected.
5. **Error.** One message under the group, tied to the `<fieldset>` with `aria-describedby`.

## Best practices

### Name the question with a legend.

The `legend` tells people what the checkboxes answer and names the `<fieldset>` for assistive technology.

<DoDontPair
    doExample={<CheckboxGroup name="do-cbg-legend" legend="Which subjects can you tutor?" options={['Math', 'Reading', 'Science']} />}
    doCaption="A visible legend names the question."
    dontExample={<CheckboxGroup name="dont-cbg-legend" aria-label="Which subjects can you tutor?" options={['Math', 'Reading', 'Science']} />}
    dontCaption="Checkboxes with no visible question."
/>

### Reserve choice tiles for one big question with two to four pictured options.

Use `appearance="tile"` when a step asks one focal question with two to four options and every option carries an `illustration`. Keep ordinary form lists and sets of five or more options in `plain` or `card`.

<DoDontPair
    doExample={
        <CheckboxGroup
            name="do-cbg-tile"
            legend="Which areas do you want to practice?"
            appearance="tile"
            options={[
                { value: 'content', label: 'Mastering content', description: 'Concept fluency.', illustration: <Illustration character="mastering-content" size={48} /> },
                { value: 'advocacy', label: 'Student advocacy', description: 'Self-advocacy skills.', illustration: <Illustration character="advocacy" size={48} /> },
            ]}
        />
    }
    doCaption="Two pictured options for one focal question."
    dontExample={
        <CheckboxGroup
            name="dont-cbg-tile"
            legend="Available days"
            appearance="tile"
            options={['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday']}
        />
    }
    dontCaption="An ordinary list without illustrations drawn as tiles."
/>

### Explain an error once under the group.

Pass `error` on `CheckboxGroup` so one message explains what to fix, rather than repeating an error under every box.

<DoDontPair
    doExample={<CheckboxGroup name="do-cbg-error" legend="Which subjects can you tutor?" options={['Math', 'Reading']} isRequired error="Select at least one subject." />}
    doCaption="One error explains what to select."
    dontExample={<CheckboxGroup name="dont-cbg-error" legend="Which subjects can you tutor?" options={['Math', 'Reading']} isRequired isInvalid />}
    dontCaption="Invalid borders with no explanation."
/>

</div>

## Accessibility

- **Native `<fieldset>` grouping.** `Fieldset` wires the `legend` to name the group so screen readers announce the question when entering the checkboxes.
- **Standard checkbox keyboard behavior.** `Tab` moves between checkboxes in the group and `Space` toggles the focused checkbox, in plain, card and tile appearances alike.
- **Decorative illustrations.** In `tile` appearance, `illustration` is marked `aria-hidden="true"` so each tile is announced by its `label`, `description` (`aria-describedby`), and checked state.
- **One error, announced once.** `error` renders a single `role="alert"` message linked to the `<fieldset>` via `aria-describedby`.

## Related

- `Checkbox`: use when there is a single confirmation or a parent-child select-all list.
- `RadioGroup`: use when only one option may be chosen.
- `Select`: use when the list is too long to show all at once, with `isMulti`.
- `Fieldset`: use when grouping mixed form controls under a legend.
