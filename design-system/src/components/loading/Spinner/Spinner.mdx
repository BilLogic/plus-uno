## Usage

Use `Spinner` when the wait is short, indeterminate, and the user has nothing
to do but wait: a submit in flight, a panel fetching on open. It says
"working", and that is all it says.

### Appearance guidance

<thead>
<tr><th>Appearance</th><th>When to use</th></tr>
</thead>
<tbody>
<tr><td>Inherit</td><td>The default. The ring takes the surrounding text color, so it matches a label, a panel or a disabled control.</td></tr>
<tr><td>Invert</td><td>On a bold or colored background.</td></tr>
</tbody>
</DocsTable>

## Parts

1. **Ring.** A circle with one side open, turning. Its stroke is an eighth of the diameter.
2. **Label.** Visually hidden text read as a status, "Loading" unless `label` names more.

## Best practices

### Size the spinner to its container.

A small control takes the 16 spinner; a large one dwarfs the label it replaces.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Spinner size={16} /><span>Saving notes</span></div>}
    doCaption="16 spinner in a small control."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Spinner size={48} /><span>Saving notes</span></div>}
    dontCaption="48 spinner in a small control."
/>

### Use invert on dark surfaces.

Inherit takes the text color around it; on a dark ground use invert so it
stays visible. There is no color prop: a spinner is not a status color.

<DoDontPair
    doExample={<div style={{ display: 'inline-flex', padding: 'var(--pad-y-lg) var(--pad-x-md)', borderRadius: 'var(--radius-md)', backgroundColor: 'var(--ds-background-neutral-bold)' }}><Spinner appearance="invert" /></div>}
    doCaption="Invert on a dark surface."
    dontExample={<div style={{ display: 'inline-flex', padding: 'var(--pad-y-lg) var(--pad-x-md)', borderRadius: 'var(--radius-md)', backgroundColor: 'var(--ds-background-neutral-bold)' }}><Spinner /></div>}
    dontCaption="Inherit on a dark surface."
/>

### One spinner per wait.

Several spinners on one view compete for attention; show one for the whole load.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Spinner /></div>}
    doCaption="A single spinner."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Spinner /><Spinner /><Spinner /></div>}
    dontCaption="A spinner on every block."
/>

### Show a busy button with its own loading state.

<DoDontPair
    doExample={<Button appearance="primary" text="Save notes" isLoading />}
    doCaption="isLoading puts the spinner inside the button and blocks it."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Button appearance="primary" text="Save notes" /><Spinner size={16} /></div>}
    dontCaption="A loose spinner beside a button that can still be pressed."
/>

### Say what is loading when a wait runs long.

After a few seconds a spinner stops reading as "working" and starts reading
as "stuck".

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Spinner size={16} /><span>Loading session plans</span></div>}
    doCaption="Text beside the spinner names the wait."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Spinner size={16} /></div>}
    dontCaption="A bare spinner as the only sign of a long wait."
/>

## Accessibility

- **It announces itself as a status.** `role="status"` is the default, with a
  visually hidden label: "Loading" unless `label` names something more
  specific.
- **A status region is only announced when it changes.** A spinner rendered
  into a region that was already on the page is announced; one that arrives
  with a whole new screen usually is not. If the wait matters, put the live
  region where it will still be there afterwards and swap its contents.
- **Say what is loading, if it is not obvious.** "Loading" beside a form is
  fine. "Loading" as the only thing on a page is not; override `label` with
  something more specific.
- **Reduced motion is handled.** The rotation slows under
  `prefers-reduced-motion: reduce` rather than stopping outright, so the ring
  still reads as working.

</div>

## Related

- For a wait whose length is known, use `ProgressBar`. A determinate bar
  answers "how much longer", which a spinner never can.
- For content loading into a layout that already has a shape, use `Skeleton`:
  it holds the shape and does not flash. A spinner is for when there is no
  shape yet.
- For a result once the wait ends, use `SectionMessage` or `Flag`.
- For a button that is busy, set its `isLoading`; the `Button` draws its own spinner.
- For a wait under about 300ms, show nothing. The spinner appears and
  vanishes as a flicker, which reads as a glitch rather than as work.
