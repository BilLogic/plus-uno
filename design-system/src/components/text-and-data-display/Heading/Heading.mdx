## Usage

Use `Heading` for every heading in the product: a page title, a section
header, a card title. Never style plain text to look like a heading: a
sighted-only "heading" breaks navigation by heading for anyone using
assistive technology.

## Parts

1. **Text.** Set in the text style of <code>size</code>, from xxlarge to xxsmall.
2. **Tag.** Follows the ambient heading level, or <code>as</code> when given.
3. **Color.** Default ink, inverse ink on a dark ground, or the warning inverse ink.

## Best practices

Nest content in a `HeadingContextProvider`, or rely on the one a pattern like `Section` already provides, and `Heading` picks `h1` to `h6` from how deep it sits. Pass `size` for the look; reach for `as` only to break that link on purpose.

### Choose `size` for the look.

`size` is required, and it is separate from the tag the context picks.

<DoDontPair
    doExample={<Heading size="xsmall">Student progress</Heading>}
    doCaption="Pass the size the spot needs and let the level pick the tag."
    dontExample={<Heading as="h5" size="xsmall">Student progress</Heading>}
    dontCaption="Pick a tag to get a size, which breaks the outline."
/>

### Use `as="div"` for a label that is not a heading.

<DoDontPair
    doExample={<Heading as="div" size="xxsmall">Section label</Heading>}
    doCaption="Heading style with no heading meaning."
    dontExample={<Heading size="xxsmall">Section label</Heading>}
    dontCaption="A real heading that screen reader users meet in the outline."
/>

### Let the ground set the ink.

<DoDontPair
    doExample={<div style={{ background: 'var(--ds-text)', padding: 'var(--pad-x-md)' }}><Heading as="div" size="xlarge" color="color.text.inverse">On a dark ground</Heading></div>}

## Accessibility

- **The tag is the real heading level**, not a visual effect: a screen
  reader's "jump to heading" list is built from the actual tag, which is why
  nesting through `HeadingContextProvider` matters more than it looks.
- **`as` can break the outline if misused.** Overriding the tag to something
  that isn't `h1`–`h6` (like `div` or `span`) removes it from the heading
  outline entirely: correct for a styled label, wrong for an actual section
  title.
- **Match the ink to the ground.** Pass
  `color.text.inverse` or `color.text.warning.inverse` when the heading sits
  on a dark ground; the token resolves the right ink in every color mode.
