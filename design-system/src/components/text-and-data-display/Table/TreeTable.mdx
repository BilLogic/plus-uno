## Usage

Use a Tree table for records that nest — a curriculum of units and lessons, a
folder of sessions. For a flat list, use the Static or Dynamic table instead.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Head cell.** A label, as in the other tables.
2. **Chevron.** 12 tall in a 24 hit area, leading a parent's title cell; a spinner while children load.
3. **Indent.** One `--table-indent` step per level, up to three levels.
4. **Count.** An optional count beside a parent's name.
5. **Message row.** Under an open parent that is loading or has nothing in it.

## Best practices

Use a tree table for records that nest, up to three levels, where every level shares the same columns.

### Keep every column at every level.

<DoDontPair
    doExample={<TreeTable head={treeHead} items={treeItems} label="Schools" defaultExpandedIds={['a']} />}
    doCaption="Each level indents one step and keeps both columns."
    dontExample={<TreeTable head={treeHead} items={[{ id: 'a', cells: ['Lincoln Middle'], children: [{ id: 'a1', cells: ['Grade 7 · Math'] }] }]} label="Schools" defaultExpandedIds={['a']} />}
    dontCaption="Levels that drop a column, so the type column goes ragged."
/>

### Load children late for a long tree.

<DoDontPair
    doExample={<TreeTable head={treeHead} items={lazyItems} label="Schools" loadChildren={() => [{ id: 'b1', cells: ['Kindergarten · Reading', 'Class'] }]} />}
    doCaption="`hasChildren` with `loadChildren` fetches a branch the first time it opens."
    dontExample={<TreeTable head={treeHead} items={lazyItems} label="Schools" />}
    dontCaption="`hasChildren` with nothing to load them, so the branch opens onto the empty message."
/>

### Leave the row press for rows without controls.

`shouldExpandOnClick` never fires from a button or link in the row. A row that carries controls reads better with the chevron alone.

<DoDontPair
    doExample={<TreeTable head={treeHead} items={treeItems} label="Schools" shouldExpandOnClick />}
    doCaption="A row of plain text opens on a press anywhere."
    dontExample={<TreeTable head={treeHead} items={[{ id: 'a', cells: [<a key="l" href="#schools">Lincoln Middle</a>, 'School'], children: [{ id: 'a1', cells: ['Grade 7 · Math', 'Class'] }] }]} label="Schools" shouldExpandOnClick />}
    dontCaption="A link in the row, where a press means two things."
/>

## Accessibility

- **A treegrid.** Each row carries `aria-level`, `aria-posinset` and `aria-setsize`, and a parent `aria-expanded`, so depth and state are announced.
- **One tab stop.** Arrow keys move, open and close rows; Home and End jump to the ends; Enter toggles.
- **The chevron is a pointer target only.** It is `aria-hidden`; the keyboard route is the arrow keys on the row.
- **Loading is busy.** A parent whose children are loading is `aria-busy`.

</div>
