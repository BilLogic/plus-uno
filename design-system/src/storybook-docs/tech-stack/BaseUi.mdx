<FoundationSection title="What it is for">

`@base-ui/react` supplies open and closed state, focus management, keyboard navigation and ARIA roles. PLUS styles Base UI's `data-*` state attributes with `--ds-*` tokens.

</FoundationSection>

<FoundationSection title="What wraps it">

Each interactive component wraps its own Base UI part: <DocsLink id="components-overlays-and-layering-popup">Popup</DocsLink>, <DocsLink id="components-overlays-and-layering-tooltip">Tooltip</DocsLink>, <DocsLink id="components-messaging-modal-dialog">Modal dialog</DocsLink>, <DocsLink id="components-navigation-tabs">Tabs</DocsLink>, <DocsLink id="components-forms-and-inputs-checkbox-checkbox">Checkbox</DocsLink>, <DocsLink id="components-forms-and-inputs-radio-radio">Radio</DocsLink>, <DocsLink id="components-forms-and-inputs-radio-radio-group">Radio group</DocsLink>, <DocsLink id="components-forms-and-inputs-radio-choice-grid">Choice grid</DocsLink>, <DocsLink id="components-forms-and-inputs-toggle">Toggle</DocsLink>, <DocsLink id="components-forms-and-inputs-range">Range</DocsLink>, <DocsLink id="components-forms-and-inputs-rating">Rating</DocsLink>, <DocsLink id="components-layout-and-structure-accordion">Accordion</DocsLink>, <DocsLink id="components-forms-and-inputs-dropdown-menu">Dropdown menu</DocsLink>, <DocsLink id="components-forms-and-inputs-fieldset">Fieldset</DocsLink> and <DocsLink id="components-messaging-spotlight">Spotlight</DocsLink>, plus the internal field frame (`FieldFrame`) and the <DocsLink id="templates-frame">Frame</DocsLink> and <DocsLink id="ai-ai-chat">AI chat</DocsLink> patterns.

</FoundationSection>

<FoundationSection title="What not to do">

- Do not import `@base-ui/react` in product code. Use the PLUS component, or propose one.
- Do not hand-write open state, focus trapping or arrow-key handling. Build new interactive components on a Base UI part.
- Do not style a part with literal values. Use <DocsLink id="foundations-tokens-color">tokens</DocsLink>.

</FoundationSection>
