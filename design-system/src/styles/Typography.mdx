PLUS sets text in three families of style: **Heading**, **Body** and
**Metric**. There are seven Heading sizes, three Body sizes and three Metric
sizes, following Atlassian's type scale, with Lato for headings and metrics
and Merriweather Sans for body text. Pick a style by where the text sits on
the page, not by how big it should look. The older registers (Display, H1–H6
and the B1–B3 body styles) are legacy, and new work never applies them.

### Type scale

Each style is one token that sets the weight, size, line height and family at
once: `font: var(--heading-medium)`. In Figma, each style is a text style whose
every property is bound to a variable, so a later change edits a variable and
never a component.

### Heading levels

Headings step down one size per nesting level, and containers use a fixed
title size.

### Labels

Button and tab labels are `--body-default` at `--type-weight-medium` (500).
There is no separate button style, as in Atlassian. In Figma, changing the
weight of a styled text node drops its style, so a label carries no text style
and binds four variables instead: Font size/0875, Line height/125, Family/body
and Weight/medium.

### Code

`--code` sets code samples, token names and property values in Source Code
Pro, at 0.875em of the text around it, so a code span follows its paragraph's
size. In Figma docs the style is Code/default, 12/16.

### Usage

**Step one size per nesting level.** The page title is `--heading-large` 24
(h1), a section `--heading-medium` 20 (h2), a subsection `--heading-small` 16
(h3). Never skip a step; there is nothing below a subsection. Containers have
fixed titles: a modal's is `--heading-medium` 20, and a card's, a popup's and a
flag's is `--heading-xsmall` 14, over a `--body-default` description.

<Canvas of={TypographyStories.OneStepPerLevel} sourceState="none" />

**Take the tag from where the heading sits.** One h1 per page. A modal's title
is the dialog's h1, named by `aria-labelledby`. A card title is tagged one
level below its section. A title hidden by a tabs-only header keeps its level,
visually hidden. Group labels (`--heading-xxsmall` 12) name a menu group or a
head cell and are never headings.

**Keep xxlarge and xlarge for heroes.** `--heading-xxlarge` 32 and
`--heading-xlarge` 28 are for heroes, empty states and metric-heavy dashboards
only, never for a page title.

**Body/default runs the interface.** Every control label is 14/20, which is
what sets the 24 and 32 Item heights. `--body-large` is for reading text, such
as lessons and help articles. `--body-small` is for meta text, Tag, Status,
Count and tooltips.

**Numbers take Metric.** Stat cards and counts use `--metric-large` 28,
`-medium` 24 or `-small` 16, as plain text, never as headings.

**Change the token, not the text.** Never type a size, and never detach a
style.

### Accessibility

- Heading tags follow the page's outline, not the size: one h1 per page, and
  no skipped levels. The style and the tag are chosen separately.
- Body text is never under 12, and running text uses `--body-default` 14 or
  `--body-large` 16.
- Sizes are in rem, so text scales with the browser's font size setting.
  Never fix a line's height in pixels around text.
- Text color comes from the text tokens in **Color**, which clear 4.5:1 on
  every surface.
</div>

### Legacy registers

Display, Headline (H1–H3), Title (H4–H6) and the Body registers are
deprecated. Existing components keep them until they are rebuilt. Use this
map to move text onto the live scale.
