## When to use

Use `PackedBubbleChart` for an overview of how big things are within groups:
enrollment per course grouped by subject, tutors per specialty, lessons per
category in the content library. It suits a summary card where the reader
wants the biggest items to stand out, not a precise ranking.

For exact comparison, use `BarChart`. For parts of one total, use
`TreemapChart`. For bubbles placed on real axes, use `BubbleChart`. For the
overlap between groups rather than their sizes, use `VennDiagram`.

## Data shape

`data` is an array of groups, each `{ name, data }`, where `data` holds items
as `{ name, value }`. `height` defaults to 500; `splitSeries` defaults to `true`.

```jsx
<PackedBubbleChart
    data={[
        { name: 'CMU', data: [{ name: 'Lincoln Middle', value: 250 }, { name: 'Roosevelt K-8', value: 180 }] },
        { name: 'Pitt', data: [{ name: 'North High', value: 220 }, { name: 'South High', value: 200 }] },
        { name: 'Duquesne', data: [{ name: 'Riverside Academy', value: 300 }, { name: 'Jefferson Elementary', value: 150 }] },
    ]}
/>
```

The size range is fixed at 0 to 1,000, so values above 1,000 all draw at the
largest size and values far below it draw small. Keep the data inside that range.

</div>

## Color and accessibility

- **One color per group.** Groups take the categorical order, slot 1 first. Every item in a group shares its color, so color names the group and size carries the value. Past six groups, fold the smallest into "Other".
- **Area is a weak encoding.** Readers can pick out the biggest bubble but cannot judge one as twice another. Put exact numbers in a table or a `BarChart` beside it if they matter.
- **Labels drop out.** Bubbles at 50 or under carry no label, so a reader sees them only by color and position; the tooltip is the only place their name appears.
- **Label ink is fixed.** Bubble labels are drawn in black rather than a text token, so they do not adapt to dark mode or pick an ink by contrast. Check the chart in dark mode before shipping it there.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`PackedBubbleChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={500} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No enrollment yet" description="Courses appear once students enroll." />
    : <PackedBubbleChart data={data} />}
```
