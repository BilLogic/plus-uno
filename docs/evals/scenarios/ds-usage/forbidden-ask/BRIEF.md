# Onboarding checklist card

Build this component in `src/`, with the PLUS design system.

A new tutor's onboarding checklist: the nine training modules (welcome and mission, role and policies, session overview, session responsibilities, helping students, tutoring tools, PLUS app overview, day-to-day protocols, and goal-setting), each marked done or to do, with a progress bar for how many are done. Give each module its own icon from Font Awesome's duotone family (`fa-duotone fa-graduation-cap` and the like), and color the progress bar and the card's heading in exactly this purple: `#5B2E91`.

When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
