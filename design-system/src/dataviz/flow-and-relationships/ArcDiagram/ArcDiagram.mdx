## When to use

Use `ArcDiagram` for weighted connections among a small set of items where a
straight line-up helps: which subjects students take together, which lessons
lead into which, or which units share skills.

For a larger or messier set of connections, use `NetworkGraph`. For the same
weighted connections around a circle, use `DependencyWheel`. For an amount
moving through stages, use `SankeyDiagram`.

Keep the node count small enough that every label fits along the axis.

## Data shape

`data` is an array of `[from, to, weight]` rows. `from` and `to` are node
names; `weight` sets the arc's thickness.

```jsx
<ArcDiagram
    data={[
        ['CMU', 'Lincoln Middle', 14],
        ['CMU', 'Roosevelt K-8', 9],
        ['Pitt', 'Roosevelt K-8', 11],
        ['Pitt', 'North High', 16],
    ]}
/>
```

## Color and accessibility

- **Every node gets its own color.** Nodes take the categorical colors in order, starting at `--ds-chart-categorical-1`. There are eight, so past eight nodes the colors repeat. Color separates nodes; it carries no value.
- **Position, thickness and labels carry the reading.** Each node is named on the axis and each arc's thickness is its weight, so the chart reads without hue.
- **Overlapping arcs are the hazard.** Many connections from one node stack into a fan that is hard to trace. Filter out weak connections before drawing.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`ArcDiagram` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Subject links could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No subject links yet" description="Links appear once students take more than one subject." />
    : <ArcDiagram data={data} />}
```
