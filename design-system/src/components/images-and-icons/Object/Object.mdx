## Usage

Use an `Object` icon (`TaskIcon`, `BugIcon`, `IdeaIcon`, `PullRequestIcon`,
`ProjectIcon` or `PageIcon`) beside the name of the record it represents — a
task in a list, a bug in a reference, a page in a breadcrumb. Each kind is its
own fixed Font Awesome Free glyph (`size` is `12` or `16`, and `label` defaults
to the kind's name unless `label=""` marks it decorative) — there is no `icon`
prop to swap it for another kind.

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For a larger square picture of a school or tool or lesson, use `Tile`.
- For a general-purpose Font Awesome Free glyph, use `Icon`.
- For a bitmap photo or screenshot, use `Image`.
- For a person or an agent, use `Avatar`.

</div>

## Best practices

### Pick the component for the kind.

`TaskIcon`, `BugIcon`, `IdeaIcon`, `PullRequestIcon`, `ProjectIcon` and
`PageIcon` each draw a fixed glyph. Reach for the component that names the
record rather than passing a custom glyph name.

<DoDontPair
    doExample={<FigureRow><TaskIcon label="" /><span>Fix the broken sync</span></FigureRow>}
    doCaption="The Task glyph beside the task name."
    dontExample={<FigureRow><BugIcon label="" /><span>Fix the broken sync</span></FigureRow>}
    dontCaption="The Bug glyph on a task."
/>

### Override `label` only when the default name does not fit.

Each kind defaults its accessible name to its kind ("Task", "Bug"). Set
`label=""` when the kind is already stated in visible text beside it, so
assistive technology does not hear it twice.

<DoDontPair
    doExample={<FigureRow><TaskIcon label="" /><span>Task: fix the sync</span></FigureRow>}
    doCaption="An empty label when the kind is written beside it."
    dontExample={<FigureRow><TaskIcon /><span>Task: fix the sync</span></FigureRow>}
    dontCaption="Both the default name and the visible kind, so it reads twice."
/>

### Keep the glyph at its kind and put status in `StatusTag`.

Each kind has one glyph and color. Do not swap the glyph to indicate workflow state; pair it with `StatusTag`.

<DoDontPair
    doExample={<FigureRow><TaskIcon /><span>Fix the sync</span><StatusTag appearance="success">Done</StatusTag></FigureRow>}
    doCaption="The kind stays a Task; the status goes in a Status tag."
    dontExample={<FigureRow><TaskIcon /><BugIcon /><span>Fix the sync</span></FigureRow>}
    dontCaption="A second glyph to hint at a status."
/>

## Accessibility

- **Named by default.** Each icon's default `label` makes it `role="img"`
  with that name, read by assistive technology.
- **Decorative with an empty label.** `label=""` sets `aria-hidden="true"`
  and drops the accessible name, for use beside visible text that already
  names the kind.
