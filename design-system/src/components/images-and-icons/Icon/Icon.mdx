<Title />
An icon is a single Font Awesome Free glyph in a square box exactly its size:
12, 16 or 24. The box has no padding, so the icon lines up with the text beside
it and the parent decides the space around it. There is no Icon component in
code: you write the glyph as an `i` element and size it with a token.

## What to write

Write the glyph with a Font Awesome Free class, and set its size and color from
tokens. Icon colors follow the toolbar's Color mode and Contrast switches, so
check an icon in each mode.

```jsx
<i
    className="fa-solid fa-calendar-days"
    aria-hidden="true"
    style={{ fontSize: 'var(--icon-md)', color: 'var(--ds-icon-subtle)' }}
/>
```

- **No Icon component.** There is no `Icon` export and no props. The class names, the size token and the color token are the whole API.
- **Hide it from assistive technology.** Add `aria-hidden="true"` whenever words beside the icon say what it means.
- **Put a name on an icon used alone.** Give the control that holds it an `aria-label`.

</div>

<div className="sb-ds-doc-section">

## Anatomy

1. **Box.** A square exactly the size: 12, 16 or 24. Nothing inside it pads the glyph.
2. **Glyph.** The Font Awesome glyph named in the class, centered. Its font size equals the box and its line height is 1, so it never grows taller than the box.
3. **Color.** `--ds-icon-subtle` by default. Override it on the element with an icon color token.

</div>

## Sizes

<DocsCanvasShell description={<>12, 16 and 24. Pick the size from the text beside it.</>}>
    <DsCanvasQuiet of={IconStories.Sizes} />

Use **md 16** by default. It sits beside 14 and 16 text. Use **sm 12**
sparingly, for chevrons, small text, field validation and small components.
**lg 24** is the largest icon. Anything bigger is decorative and goes in a Tile.

## Styles

<DocsCanvasShell description={<>Solid is the default. Regular reads lighter. Brands holds product logos.</>}>
    <DsCanvasQuiet of={IconStories.Styles} />

Use **solid** by default. Use **regular** for a quieter version of the same
glyph. **Brands** holds product logos such as `figma`, `notion` and `slack`, and
only brand names render in it.

## Color

<DocsCanvasShell description={<>The default color and four others. Each is a token that changes with the color mode.</>}>

An icon has no states of its own. Hover, pressed, focus and disabled belong to
the control around it, and that control sets the icon color with a token.

## Rules

- **Font Awesome Free only.** Use `fa-solid`, `fa-regular` or `fa-brands`. Pro families and names (`fa-light`, `fa-thin`, `fa-sharp`, `fa-duotone`) are not licensed here and render as a blank box.
- **One size per row.** Icons in a list share a size so the labels line up.
- **Colors come from tokens.** Never write a hex value or a `--color-*` name for an icon.

## When to use

Use an icon to mark an action or a kind of thing next to words, or alone for a
well-known action in a tight space.

- For a mark larger than 24, or an icon on a colored square, use **Tile**.
- For an action people press, use **Button**, and keep icon-only buttons for in-row actions.
- For a picture or a logo, use **Image** or **Tile**.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **A labeled icon is decorative.** Hide it with `aria-hidden="true"`, because the words beside it already carry the meaning.
- **An icon alone needs a name.** Give the button or link that holds it an `aria-label` that says what the action does.
- **Color is never the only signal.** A danger icon sits beside words that say what went wrong.
- **Contrast.** Icon colors are tokens built to meet contrast on the surfaces they are meant for. Check an icon in the toolbar's high-contrast mode.

</div>
