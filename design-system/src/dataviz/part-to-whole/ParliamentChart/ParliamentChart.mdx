## When to use

Use `ParliamentChart` when a total is a modest count (a few dozen to a few
hundred) of individual units where each dot represents one person or seat, such
as cohort students by grade, council seats or school tutors by certification
level.

When individual units do not matter, use `PieChart` or `StackedBarChart`. For
exact count comparisons, use `BarChart`. For nested groups, use `SunburstChart`.

## Data shape

`data` is an array of `{ name, value, color }` (`name` and whole-number `value`
required; `color` optional). Sort `data` from most to least before passing it in
so group and color order match size order.

```jsx
<ParliamentChart
    data={[
        { name: 'Grade 8', value: 22 },
        { name: 'Grade 7', value: 17 },
        { name: 'Grade 6', value: 11 },
    ]}
/>
```

## Color and accessibility

- **Color by position.** Groups without `color` follow the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1. Past six groups, fold the smallest into "Other" so adjacent hues stay distinct.
- **Keep labels and legend.** Because equal-sized dots differ only by hue in the arc, group labels and legend counts provide the non-color reading.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`ParliamentChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>The cohort could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No students yet" description="Students appear once they join the cohort." />
    : <ParliamentChart data={data} />}
```
