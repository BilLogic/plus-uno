## When to use

Use `VariwidthChart` when a per-category value needs its weight beside it:
average score per subject sized by enrollment, average rating per tutor sized
by number of reviews. It keeps a high score from a small group from looking as
important as one from a large group.

For equal-width columns where only height matters, use `BarChart`. For parts
of a total sized by area, use `TreemapChart`. For three measures on two real
axes, use `BubbleChart`. For the spread within each category, use
`BoxPlotChart`.

## Data shape

`data` is an array of `{ name, y, z, color }`. `name`, `y` and `z` are
required; `color` is optional. `height` defaults to 400.

```jsx
<VariwidthChart
    xAxisLabel="Subject"
    yAxisLabel="Average score"
    data={[
        { name: 'Math', y: 85, z: 120 },
        { name: 'Science', y: 78, z: 90 },
        { name: 'Reading', y: 92, z: 30 },
        { name: 'History', y: 70, z: 80 },
    ]}
/>
```

## Color and accessibility

- **Each column takes a color.** Columns run through the categorical order, slot 1 first. The axis already names each column, so these colors identify nothing; past six columns they move into the overflow slots, and past eight they repeat. To keep one hue, give every item the same `color`, such as `var(--ds-chart-brand)`.
- **Height and width carry the values.** Neither depends on hue. Height reads well; width reads only roughly, and there is no width axis, so say what width means in the header or description.
- **Area is not a total.** A wide, short column and a narrow, tall one can cover the same area. Readers will compare area anyway, so use this chart only when height times width means something.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`VariwidthChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <VariwidthChart data={data} xAxisLabel="Subject" yAxisLabel="Average score" />}
```
