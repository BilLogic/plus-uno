## When to use

Use `HeatmapChart` to surface patterns across two category axes, such as
sessions by weekday and hour, students by SMART competency or tutor availability
by day and slot.

For exact values, use a table. For one measure over time, use `LineChart`. For
individual points, use `ScatterChart`. For one dimension, use `HistogramChart`.

## Data shape

`xCategories` and `yCategories` are arrays of strings. `data` is an array of
`[x, y, value]` triples indexing into those arrays. `height` defaults to 400.

```jsx
<HeatmapChart
    xCategories={['Mon', 'Tue', 'Wed', 'Thu', 'Fri']}
    yCategories={['3pm', '4pm', '5pm']}
    data={[
        [0, 0, 12], [0, 1, 30], [0, 2, 18],
        [1, 0, 15], [1, 1, 34], [1, 2, 22],
        [2, 0, 10], [2, 1, 28], [2, 2, 25],
        [3, 0, 14], [3, 1, 36], [3, 2, 20],
        [4, 0, 8],  [4, 1, 19], [4, 2, 11],
    ]}
/>
```

## Color and accessibility

<RefTable
    head={['Ramp', 'Prop', 'Tokens and rules']}
    rows={[
        ['Sequential (default)', <><C>hue</C> (default <C>blue</C>; supports blue, teal, green, lime, yellow, orange, red, magenta, purple, gray, brown)</>, <>Four even stops from lowest to highest: <C>{'--ds-background-accent-{hue}-subtler'}</C>, <C>{'--ds-chart-{hue}-bold'}</C>, <C>{'--ds-chart-{hue}-bolder'}</C>, <C>{'--ds-chart-{hue}-boldest'}</C> (darker in light mode, lighter in dark mode).</>],
        ['Diverging', <><C>{'diverging={[low, high]}'}</C> (overrides <C>hue</C>)</>, <>Seven stops: low hue <C>boldest</C> down to <C>bold</C>, midpoint <C>--ds-background-accent-gray-subtler</C>, high hue <C>bold</C> up to <C>boldest</C>. Orange and blue stay distinct under color-vision deficiency; never pair red with green.</>],
    ]}
/>

- **Scale bounds.** By default the ramp spans the data's lowest and highest values. Set `min` and `max` to compare heatmaps on a shared scale; for a diverging ramp, set them equidistant around the baseline because the midpoint lands halfway between `min` and `max`, not at zero.
- **Live mode resolution.** The chart resolves token values for the color bar and updates automatically when color mode or contrast changes.
- **Keep cell labels on.** Because equal-sized cells encode value by shade alone, leave `showDataLabels` on whenever cells fit text; each label picks `--ds-text` or `--ds-text-inverse` for contrast.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`HeatmapChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Session activity could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="Activity appears after the first week of sessions." />
    : <HeatmapChart xCategories={days} yCategories={hours} data={data} />}
```
