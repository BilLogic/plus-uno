# Session history page

Build this page in `src/`, with the PLUS design system.

> **PRD excerpt.** Tutors need one page that lists their past sessions so they can find a session to reflect on. Each row shows the date, the student or group name, the subject, the session length, and a status: *Reflected*, *Reflection due*, or *Missed*. A tutor can filter by status and search by student name. The page has a title, a short line saying how many sessions are listed, and a primary action, *Export*, at the top right. When a tutor has more than 20 sessions, the list pages.

Use realistic sample data (at least 8 sessions). When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
