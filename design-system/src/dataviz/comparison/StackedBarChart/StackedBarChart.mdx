## When to use

Use `StackedBarChart` when both the total and its makeup matter: sessions per
day split into 1-on-1 and group, tutoring hours per week split by activity.
The bottom segment shares a baseline across columns, so it compares well; the
segments above it do not, so put the part that matters most at the bottom.

For separate values with no total, use `BarChart`. For one total split into
parts, with no categories to compare, use `PieChart` or `DonutChart`. For
composition moving through time as a continuous shape, use `AreaChart`.

Keep it to a few segments. Each one above the first is read against a moving
baseline, and the chart has no legend to name them.

## Data shape

`dates` is an array of category labels. `data` is an array of columns, one per
date, each `{ segments }`. A segment is `{ value, height, color, textColor }`:
`height` is a numeric string that sets the segment's size, `value` is the label
printed on it, and `color` and `textColor` are optional. The segment at index 0
in every column belongs to the same series, and so on up the stack.

```jsx
<StackedBarChart
    height={300}
    dates={['Mon', 'Tue', 'Wed', 'Thu', 'Fri']}
    data={[
        { segments: [{ value: '12', height: '12' }, { value: '30', height: '30' }] },
        { segments: [{ value: '18', height: '18' }, { value: '24', height: '24' }] },
        { segments: [{ value: '9', height: '9' }, { value: '33', height: '33' }] },
        { segments: [{ value: '15', height: '15' }, { value: '27', height: '27' }] },
        { segments: [{ value: '6', height: '6' }, { value: '20', height: '20' }] },
    ]}
/>
```

`height` and `value` are independent: the chart draws one and prints the other
without checking that they agree. Keep them the same number unless the label is
deliberately a different unit. `yLabels` is accepted but not used.

</div>

## Color and accessibility

- **Color follows stack position.** A segment without a `color` takes the categorical order by its index: the bottom segment slot 1, the next slot 2. Give the same segment the same color in every column, or leave `color` out and let the order do it.
- **Label ink is picked for you.** Each segment label takes the text color that reads best on its fill in the current color mode. Set `textColor` only to override that.
- **Height carries the value, the label confirms it.** Color is the only thing that tells segments apart, and there is no legend. Name the segments in the surrounding header or a caption, and keep the count low.
- **Upper segments are hard to compare.** Only the bottom segment sits on a shared baseline. When the parts matter more than the total, use `BarChart` with one series per part instead.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. Series are announced as "Segment 1", "Segment 2", so the surrounding text has to say what each one is. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`StackedBarChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Sessions could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="Sessions appear after one is logged." />
    : <StackedBarChart dates={dates} data={data} height={300} />}
```

## Related

- For categories compared against each other rather than composed, use `BarChart`.
- For one total broken into parts with no categories, use `PieChart` or `TreemapChart`.
- For composition changing over time, use `AreaChart` or `StreamgraphChart`.
- For a running total built from gains and losses, use `WaterfallChart`.
