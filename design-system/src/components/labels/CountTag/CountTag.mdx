## When to use

Use `CountTag` for a number on its own: unread messages on a nav item, results on a
tab, errors in a section header, a notification on a bell.

- **Is it a number?** Count tag.
- **Is it the condition something is in, and can that condition change?** Status tag.
- **Otherwise** (a subject, a person, a category): Tag.

`spacing="compact"` (16) is for use inside a label: Status tag nests it through its
`count` prop, and Tag nests it on a selectable tag.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Keep most counts quiet.

Subtle neutral is the default. Bold asks for action now, so use at most one bold
count per area.

```jsx
// Incorrect — every tab shouts, so none of them does.
<CountTag value={4} isBold appearance="danger" />
<CountTag value={12} isBold appearance="info" />

// Correct — quiet by default, bold only where something needs doing now.
<CountTag value={12} />
<CountTag value={3} isBold appearance="danger" label="3 errors" />
```

### Let the component decide zero and overflow.

```jsx
// Incorrect — the caller re-implements what Count tag already does.
{unread > 0 && <CountTag value={unread > 99 ? '99+' : unread} />}

// Correct — hidden at 0, capped at max.
<CountTag value={unread} />
```

### Use inverse on filled buttons and dark surfaces.

Inverse is a solid white badge with dark text, so it passes contrast on any fill.
On a light surface it barely separates from the page; use subtle there.

</div>

## Accessibility

- **A dot needs a name.** It has no number, so `label` is its accessible name,
  exposed as an image with that name. Without one it is announced as nothing,
  and the component warns in development.
- **A label turns a digit into information.** "Messages 4" is ambiguous; with
  `label="4 unread"` a screen reader hears "Messages 4 unread", while the badge
  still shows 4.
- **The count is not a control.** It is a `span` that sits inside buttons, tabs
  and nav items; whatever is pressable is the thing around it.
- **Contrast.** Subtle uses each appearance's (Text) color, and bold warning uses the
  Warning Container pair because warning with white text fails AA. Inverse
  is a solid white badge with dark text, so it clears AA on any fill, including
  a primary button.

</div>
