## When to use

Use `FunnelChart` for a process of five to seven stages where each step is a
subset of the one before, ordered largest to smallest — such as tutor
onboarding, student enrollment or assessment completion.

For stages that do not strictly shrink, use `BarChart`. For flows that split
into multiple branches, use `SankeyDiagram`. For drop-off ranked by cause, use
`ParetoChart`.

## Data shape

`data` is an array of `{ name, y, color }` (`name` and `y` required) in process
order.

```jsx
<FunnelChart
    data={[
        { name: 'Applied', y: 640 },
        { name: 'Completed training', y: 410 },
        { name: 'Matched with students', y: 300 },
        { name: 'Led a first session', y: 260 },
    ]}
/>
```

## Color and accessibility

- **Per-stage color.** Stages follow the [categorical order](?path=/docs/data-visualizations-color--docs) from `--ds-chart-categorical-1` (repeating past eight) unless overridden by `color`. Colors separate adjacent stages and do not encode magnitude.
- **Labels carry the values.** Every stage prints its name and count, which is essential near the fixed-width neck. State conversion percentages in surrounding copy when drop-off rates matter.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`FunnelChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Onboarding progress could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No applicants yet" description="Stages fill in as tutors apply and complete training." />
    : <FunnelChart data={data} />}
```

## Related

- For stages that do not have to shrink, use `BarChart`.
- For flow that splits and rejoins rather than narrowing, use `SankeyDiagram`.
- For the same drop-off ranked by cause, use `ParetoChart`.
- For quantities ordered largest to smallest without a process behind them, use `PyramidChart`.
