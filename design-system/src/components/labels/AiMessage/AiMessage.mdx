## Usage

Use `AiMessage` for every reply an assistant writes: in the AI chat, in a panel,
anywhere text comes from the model. Show `thinking` from the moment a message is
sent until the first text arrives, `streaming` while text arrives, then
`complete`.

### Status guidance

## Parts

1. **AI icon.** The small AI icon at 16, named "AI", centered on the first line, so no answer reads as a person's.
2. **Text.** The body style, keeping the reply's line breaks. With <code>parts</code>, text parts and other parts in order; <code>renderPart</code> draws a part that is not text.
3. **Caret.** Streaming only: a thin bar after the last character, blinking.
4. **Typing indicator.** Thinking only: three pulsing dots in place of the text.
5. **Sources** (optional). Complete only: a "Sources" heading, one row per source with its title as a link and its type beside it, and a toggle past three.
6. **Feedback** (optional). Complete only, with <code>onFeedback</code>: thumbs up and down and a quiet thanks beside them.

## Best practices

### Stream the answer, then settle.

The streaming state shows the answer arriving. Show the state, never a blank:
the typing indicator holds the place until the first text, then text streams
in, then the message settles to `complete`.

<DoDontPair
    doExample={<div style={{ display: 'flex', flexDirection: 'column', gap: 'var(--stack-lg)' }}><AiMessage status="thinking" /><AiMessage status="streaming" text="Maya has the steps for adding fractions, but in word" /></div>}
    doCaption="The typing indicator, then the streaming state, shows the answer arriving."
    dontExample={<AiMessage text="Maya has the steps for adding fractions, but in word" />}
    dontCaption="Partial text shown as finished hides that it is still being written."
/>

### List the sources whenever an answer draws on records.

An answer built from sessions, students or reports passes them as `sources`,
so a person can open what the AI read. A general answer that read nothing
shows no list.

<DoDontPair
    doExample={<AiMessage text="Ava attended 12 of 14 sessions this term." sources={[{ title: 'Session notes, Oct 24', href: '#session-1024', type: 'Session' }, { title: 'Ava Thompson', href: '#student-ava', type: 'Student' }]} />}
    doCaption="The records the answer read, listed under it."
    dontExample={<AiMessage text="Ava attended 12 of 14 sessions this term." />}
    dontCaption="An answer from records with nothing to open."
/>

### Offer feedback on every finished answer.

Pass `onFeedback` wherever an answer is shown. The thumbs appear only once the
reply is complete, so a streaming answer is never rated on partial text. A
second press on the same thumb clears it; thumbs down opens an optional comment
that can be skipped.

<DoDontPair
    doExample={<AiMessage text="Ava attended 12 of 14 sessions this term." onFeedback={() => {}} />}
    doCaption="Thumbs under a finished answer."
    dontExample={<AiMessage text="Ava attended 12 of 14 sessions this term." />}
    dontCaption="A finished answer with no way to rate it."
/>

</div>

## Accessibility

- **Marked as AI.** The AI icon at the start of every reply is an image named
  "AI", so a screen reader hears whose answer it is. Don't add a second icon
  beside the message.
- **Sources are a named list.** The list is named by its "Sources" heading,
  and the toggle past three says how many more and carries `aria-expanded`.
- **Thumbs are buttons, not toggles.** They sit in a group named "Rate this answer".
  Thumbs down opens a popup, so neither thumb carries `aria-pressed`; the chosen one
  is described as "Selected". A polite status names each rating ("Thanks. Marked
  as a good answer."), so a change of mind is heard too. No animation.
- **Busy while arriving.** A streaming message is marked `aria-busy`, so a
  screen reader waits for the finished text. A typed-out reply carries its full
  text for assistive technology and hides the character-by-character copy.
- **Announced indicator.** The typing indicator is a status named "AI is writing";
  its dots are hidden from assistive technology.
- **Reduced motion.** The caret and dots stop animating, and typed-out text
  shows at once.
