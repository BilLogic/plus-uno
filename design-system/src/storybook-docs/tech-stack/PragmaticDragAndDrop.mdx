<FoundationSection title="What it is for">

`@atlaskit/pragmatic-drag-and-drop` handles dragging and dropping elements. Drag in PLUS runs on it and nothing else.

</FoundationSection>

<FoundationSection title="What wraps it">

No PLUS component wraps it yet; only the Storybook motion demos use it. The first component that needs drag wraps it and is listed here.

</FoundationSection>

<FoundationSection title="What not to do">

- Do not add another drag library.
- Do not import it in product code. Wait for the wrapping component.
- Do not make drag the only way to reorder; keep a keyboard path.

</FoundationSection>
