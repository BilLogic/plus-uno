## When to use

Use `NetworkGraph` to show connections with no fixed order or hierarchy: how
topics in a subject connect, which students tutor each other, or which tutors
share students.

For a strict hierarchy, use `OrganizationChart` or `TreegraphChart`. For a small
set of items in a fixed order, use `ArcDiagram`. For connections that carry an
amount, use `SankeyDiagram` or `DependencyWheel`.

Past about 50 nodes the graph turns into a hairball; filter to the part of the
network the question is about.

## Data shape

`data` is an array of `[from, to]` pairs of node names. `nodes` is optional: an
array of `{ id, color }`, where `id` matches a name used in `data`.

```jsx
<NetworkGraph
    data={[
        ['Fractions', 'Ratios'],
        ['Ratios', 'Percentages'],
        ['Fractions', 'Decimals'],
        ['Decimals', 'Percentages'],
        ['Ratios', 'Proportions'],
    ]}
    nodes={[{ id: 'Fractions', color: 'var(--ds-chart-categorical-2)' }]}
/>
```

## Color and accessibility

- **One color by default.** Every node takes the series color, `--ds-chart-categorical-1`, unless `nodes` gives it its own `color`. Use a categorical token for that, and only to mark a group that matters to the question.
- **Labels and links carry the reading.** Each node is named and each connection is a line, so the graph reads without hue. If you color node groups, say what each color means in the surrounding text; the chart has no legend.
- **The layout moves.** The simulation keeps nodes in motion as it settles, and the arrangement can differ between renders. Do not refer to a node by where it sits.
- **Dense graphs fail.** Overlapping labels and crossing links are the main hazard; fewer nodes is the fix.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`NetworkGraph` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={500} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Topic map could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No connections yet" description="Topics connect once lessons reference each other." />
    : <NetworkGraph data={data} />}
```
