<FoundationSection title="Overview">

The <DocsLink id="components-images-and-icons-icon">Icon</DocsLink> component renders a single glyph; components with icon slots (`Button`'s `iconBefore` and `iconAfter`) pass the glyph name through `Icon` (`fa-regular fa-<name>`, falling back to `fa-solid` where Font Awesome Free has no regular weight). A React node in place of the name renders as given.

```jsx
<Icon name="calendar-days" size={16} color="subtle" />
<Button appearance="primary" text="Add tutor" iconBefore="plus" />
```

</FoundationSection>

<FoundationSection title="Principles">

<FoundationSubsection title="Use one recognized symbol per meaning">
Pick the plainest glyph most people read the same way (calendar for dates, bell for notifications, gear for settings) and keep one glyph per meaning across the product.

<Canvas of={IconsStories.OneGlyphOneMeaning} />
</FoundationSubsection>

<FoundationSubsection title="Pair icons with text labels">
A label states what the icon does and names it for screen readers. Leave an icon unlabeled only for a familiar action in a tight space, and give the control an accessible `label` in code.

<Canvas of={IconsStories.PairWithLabels} />
</FoundationSubsection>

</FoundationSection>

<FoundationSection title="Sizes: 12, 16 and 24">

Icons ship at three sizes bound to `Size/Icon` tokens. `--fa-width: 1em` is set globally so every glyph fills its square box without adding line height. Chevrons are always 12. Add breathing room with spacing tokens, never a larger icon size.

<Canvas of={IconsStories.Sizes} />

<FoundationSection title="Above 24, use a Tile">

24 is the top of the icon scale. A larger mark, tool logo or empty-state symbol belongs in a <DocsLink id="components-images-and-icons-tile">Tile</DocsLink>, which sets its size, radius and fill together.

<Canvas of={IconsStories.LargerMeansTile} />

</FoundationSection>

<FoundationSection title="Font Awesome Free and color tokens">

Use Font Awesome Free 7.2 only: `fa-solid`, `fa-regular` and `fa-brands` (such as `fa-brands fa-figma` and `fa-brands fa-github`). Pro families (`fa-light`, `fa-thin`, `fa-sharp`, `fa-duotone`) and Pro-only names are unlicensed and render blank, so check a glyph name against the Free set first. Regular is the default weight; solid is used where Free has no regular glyph. Where one set of icons needs a glyph Free draws only in solid, that one glyph is solid and the rest stay regular. Always use current glyph names rather than legacy aliases (`calendar-days`, not `calendar-alt`).

<Canvas of={IconsStories.Families} />

Color icons with `--ds-icon-*` tokens (`--ds-icon-success`, `--ds-icon-danger`, or the text color beside the icon), never a raw hex value.

<Canvas of={IconsStories.Colors} />

</FoundationSection>

Before proposing a new glyph through Intake, verify that no existing glyph fits, that it will not conflict with another icon in the same view, and that a text label alone would not be clearer. A design lead approves new glyphs. Zoom has no Font Awesome Free glyph: a Zoom link is not an icon, and partner and tool marks go in a `Tile`, never in `Logo`.

<FoundationSection title="Do and don't">

<FoundationSubsection title="Use Free families and Free names only">

Solid, regular and brands are licensed here, including brand glyphs.

Do: Free families (fa-regular, fa-solid, fa-brands) render everywhere.

Don't: Pro families (fa-light, fa-thin, fa-sharp, fa-duotone) render blank.

<Canvas of={IconsStories.FreeFamiliesOnly} />

</FoundationSubsection>

<FoundationSubsection title="Use 16 by default, 12 sparingly">

Icons are 16 beside body text. Keep 12 for chevrons, validation and compact parts.

Do: A 16 icon leads the label; the trailing chevron is 12.

Don't: A 12 leading icon is too small beside 14 body text.

<Canvas of={IconsStories.IconSizingInControls} />

</FoundationSubsection>

<FoundationSubsection title="Use a symbol people recognize">

Pick the glyph most people read the same way.

Do: A bell for notifications.

Don't: A gear reads as settings, so it misleads here.

<Canvas of={IconsStories.RecognizableSymbols} />

</FoundationSubsection>

</FoundationSection>

<FoundationSection title="Accessibility">

- Decorative icons and icons beside a visible text label carry `aria-hidden="true"`.
- Icon-only controls (`IconButton`) require a concise `label` prop so screen readers announce the action.
- `--ds-icon-*` tokens clear the 3:1 non-text contrast bar against their paired surfaces (<DocsLink id="foundations-visual-color">Color</DocsLink>).

</FoundationSection>
