## The four answers

Pick by what the text is. Wrap when it must be read whole; truncate when the room is fixed and the full text can be reached; fold a list; page a table.

## Key cases

<ComponentExample of={OverflowStories.TruncatedTags} title="A tag" description="A Tag stops at its maxWidth, 180 by default, and a Status tag at 200. A clipped tag becomes a tab stop so its Tooltip opens on focus." />

<ComponentExample of={OverflowStories.TruncatedCell} title="A cell" description="A table cell stays one line and ends in an ellipsis. A short cell in the same column is not a tab stop and has no Tooltip." />

The three cases below are Planned <PlannedTag />: no component carries them yet.

- **The breadcrumb middle.** Five or more levels fold the middle into a "…" that opens a menu of the hidden levels. The Breadcrumb never wraps.
- **An open item in the Sidebar.** Named by when and who, "4:00 PM · Ms. Ortiz", with the school in the Tooltip. Three show, then "Show n more".
- **A file name.** The one mid-line truncation: a file name or an id keeps its start and its end, because the end tells them apart.

## Usage

Use Overflow whenever a value may be longer than the space it has. The answer follows the element, so the same text behaves the same way on every page, and the full text is always reachable.

## Alternatives

- For a long paragraph, let it wrap; a paragraph is read, not scanned.
- For a trail too long to show, follow Navigation; the Breadcrumb's fold is described there.
- For more views than fit a row of pills, fold the extra pills into "More"; Navigation describes the views.
- For more controls than fit a bar, the extras go into the More icon button, five controls at most.
- For narrowing a long list of rows instead of folding it, follow <a target="_top" href="./?path=/docs/patterns-filtering--docs">Filtering</a>.

## Best practices

### Wrap titles, headers, labels, errors and notifications.

<RuleTag kind="automatic" />

They must be read whole, so they take more lines. Nothing that tells a person what something is, or what went wrong, is ever clipped.

<DoDontPair
    doExample={<WrappedSectionTitle />}
    doCaption="A long Section title takes a second line."
    dontExample={<ClippedSectionTitle />}
    dontCaption="A clipped Section title: the one thing that names the content is the one thing cut."
/>

### Truncate cells, tags and names at the end, on one line.

<RuleTag kind="automatic" />

An ellipsis stands for three or more characters. A cell stays one line. Mid-line truncation is only for file names and ids, where the end tells them apart; it is Planned <PlannedTag />. Truncating from the front is not used.

### Open the full text in a Tooltip only when it is clipped.

<RuleTag kind="automatic" />

The Tooltip opens on hover and on focus, and the clipped element becomes a tab stop only while it is clipped. Never the browser's `title` attribute. An unclipped value has no Tooltip.

<DoDontPair
    doExample={<ClippedCellOpensText />}
    doCaption="A clipped cell opens its full text in a Tooltip."
    dontExample={<ClippedCellNoText />}
    dontCaption="A clipped cell with nothing to open: the rest of the text cannot be read."
/>

### Make a bare ellipsis open a menu.

<RuleTag kind="review" />

A "…" that stands for hidden items, such as the breadcrumb middle, is a button that opens them. A "…" at the end of a value is not a control.

### Fold a list behind Show n more and page a table.

<RuleTag kind="review" />

"Show n more" carries the count and "Show less" closes; both are Planned <PlannedTag />. A Tag group folds into +n today. A table pages in its footer instead of growing. No gradients, fades or inner scroll.

<DoDontPair
    doExample={<ShowMoreWithCount />}
    doCaption="A button under the list that names how many more it holds, and the list grows in place."
    dontExample={<FadedList />}
    dontCaption="A fade over the list, hiding how much is there."
/>

## Accessibility

- The full text is always in the DOM, so a screen reader hears all of it whether or not it is clipped.
- A clipped element is a tab stop so a keyboard user can reach the Tooltip; an unclipped one is not.
- The +n button of a Tag group names how many tags it holds, "+3 more tags", and opens a menu the arrow keys move through.
- The breadcrumb's "…" button is named "Show hidden levels" <PlannedTag />.
- "Show n more" announces the new count when the list expands <PlannedTag />.
