<Title>Page</Title>
Page is a tokenized container with a fill, an elevation, a pad and a radius, and a slot for your content. A level is a fill and its shadow together, so a Page never wears one without the other. The frame draws its own content box the same way, and you can also use Page alone for any block that needs a level.

The examples on this page follow the **Color mode** switch in the toolbar. In dark, a level gets lighter as it rises.

## Usage

Use Page for a block that needs a fill at one of the four levels. The frame draws its own content box with the same fill and edge, so a page does not place a Page inside it. For the page frame, use <a href="?path=/docs/patterns-frame-frame--docs">Frame</a>.

## Parts

1. **Page.** The container. It carries the level's fill and shadow, the pad and the radius.
2. **Title** (optional). A Page that holds a whole page can carry the page's one h1, at Heading/large 24, above the content.
3. **Content.** The slot. Sections go here.

In the frame, the content box is a 12-column grid with a 16 gutter, capped at 1232 (reading 864) and never under 720. In Figma the Page part has one property, width, with the values content and reading; code sets it on the Frame.

### States

A Page has no states of its own: it does not respond to hover, press or focus, and it is never disabled.

## Best practices

### Keep the Page pad on every side.

Content stays 24 from the edge, so nothing touches the chrome.

<DoDontPair
    doExample={<div style={backdrop}><Page padding="md">{slotContent('Section')}</Page></div>}
    doCaption="Keep the Page pad on all sides."
    dontExample={<div style={backdrop}><Page padding="none">{slotContent('Section')}</Page></div>}
    dontCaption="Run content to the Page edge."
/>

### Put sections in the content column.

Sections stack inside the column and share its width.

<DoDontPair
    doExample={<div style={backdrop}><Page padding="md"><div style={stack}>{slotContent('Section')}{slotContent('Section')}</div></Page></div>}
    doCaption="Stack sections in one column."
    dontExample={<div style={backdrop}><Page padding="md"><Page padding="md" border>{slotContent('Section')}</Page></Page></div>}
    dontCaption="Nest a Page inside a Page."
/>

### Match the width to the content.

Use the reading width for prose and the content width for grids and tables. A Page takes its width from where it sits, so set it on the Frame: `width="reading"`.

### Use Card for one object.

<DoDontPair
    doExample={<div style={backdrop}><HeadingLevelContext.Provider value={4}><PatternCard title="Next session" padding="sm">{slotContent('Thursday · 4:30 PM')}</PatternCard></HeadingLevelContext.Provider></div>}
    doCaption="A Card, raised and ready to fill, with its title in the header."
    dontExample={<div style={backdrop}><Page level="raised" padding="sm" radius="md"><p style={{ margin: 0, font: 'var(--body-default)' }}>Next session</p>{slotContent('Thursday · 4:30 PM')}</Page></div>}
    dontCaption="A raised Page with a hand-made title drifts from the Card pattern."
/>

## Accessibility

- A Page has no role of its own. Use `as="main"` for the page's content box and `as="section"` for a labeled block.
- Pass `title` on the page's own Page only. It renders the page's one h1, and Sections inside it open at h2.
- Text on a Page uses `--ds-text` at every level, in every color mode.
- In light increased contrast the default Page draws its edge ring, so it stays distinct from the frame behind it.
