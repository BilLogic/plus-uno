## When to use

Use `StreamgraphChart` for a high-level view of how a mix of categories rises
and falls over time, such as subject enrollment across a year or session types
over a term.

When exact readings matter, use `LineChart`. For composition on a fixed zero
baseline, use `AreaChart` with `stacking`. For composition at a single moment,
use `TreemapChart` or `DonutChart`.

## Data shape

`categories` is an array of period labels. `series` is an array of
`{ name, data }` with one number per period in `categories` order. `height`
defaults to 400.

```jsx
<StreamgraphChart
    categories={['Sep', 'Oct', 'Nov', 'Dec', 'Jan', 'Feb']}
    series={[
        { name: 'Math', data: [120, 140, 155, 150, 170, 185] },
        { name: 'Reading', data: [90, 95, 100, 98, 110, 118] },
        { name: 'Science', data: [45, 52, 60, 58, 66, 72] },
    ]}
/>
```

## Color and accessibility

- **Color by series order.** Layers take the [categorical order](?path=/docs/data-visualizations-color--docs) starting at slot 1 (even for one series; per-series `color` is ignored). Past six series, group the smallest into "Other".
- **Legend and tooltip carry exact values.** Because layers have no inline labels, patterns or value axis, keep the layer count low and provide exact figures in the tooltip or surrounding text.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`StreamgraphChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment could not load.</SectionMessage>
    : series.length === 0 ? <EmptyState spacing="compact" header="No enrollment yet" description="Subjects appear once students enroll." />
    : <StreamgraphChart categories={categories} series={series} />}
```
