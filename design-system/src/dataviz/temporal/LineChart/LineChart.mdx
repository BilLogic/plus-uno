## When to use

Use `LineChart` for trends across evenly spaced periods, such as average score
over a semester, weekly sessions completed or monthly active students. Keep to
four or five lines so crossings remain easy to follow.

For unordered categories, use `BarChart`. When the quantity under the line
matters or parts stack into a total, use `AreaChart`. For two units on one
chart, use `ComboChart`. For a compact trend beside a number with no axes, use
`Sparkline`.

## Data shape

`data` is an array of `{ name, data, categories, color }` series, with period
labels passed on the first series' `categories` (there is no separate
`categories` prop). `height` defaults to 300. Omit `color` to assign one
automatically.

```jsx
<LineChart
    xAxisLabel="Week"
    yAxisLabel="Average score (%)"
    yDomain={[0, 100]}
    yTicks={[0, 25, 50, 75, 100]}
    data={[
        { name: 'Cohort A', data: [62, 66, 71, 74, 78], categories: ['Wk 1', 'Wk 2', 'Wk 3', 'Wk 4', 'Wk 5'] },
        { name: 'Cohort B', data: [58, 60, 65, 70, 72] },
    ]}
/>
```

## Color and accessibility

- **Automatic series color.** One line uses `--ds-chart-brand`; two or more follow the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1 without skipping. Past six series, group the smallest into "Other" or split the chart.
- **Keep line count low.** Because every line uses the same solid stroke and circle marker, crossings rely on color and the legend; name key lines in surrounding text when needed.
- **Set `yDomain` deliberately.** Without `yDomain` the axis fits the data, which can exaggerate small changes; pass the full range for scores and percentages.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`LineChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <LineChart data={data} />}
```
