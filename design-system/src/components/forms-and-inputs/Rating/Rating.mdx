## Usage

Use a rating for a single satisfaction score out of five: the end of a session, a piece of feedback, a quick judgment the person makes in one gesture. Five items is the whole scale; there is no other length.

`variant` chooses what the row says about itself: `comments` puts one caption under the row, `numeric` puts 1 to 5 above each item. `icon` is `star` or `thumbs-up`.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Label.** Text above the row that names the rating. A required marker follows it.
2. **Items.** Five 32 circles, each drawing a 16 icon. Items up to the score are filled.
3. **Number.** In the numeric variant, 1 to 5 above each item.
4. **Caption.** In the comments variant, one line under the row.

## Best practices

### It is always controlled.

```jsx
// Incorrect: the component holds no state. Without an onChange the items are
// clickable and nothing ever changes.
<Rating label="How was the session?" />

// Correct: onChange receives the number, not an event.
<Rating label="How was the session?" value={score} onChange={setScore} />
```

### It submits its value under `name`.

A hidden input carries the score with its form, so `name` is how a server reads it.

```jsx
<form onSubmit={submit}>
    <Rating name="score" label="Rating" value={score} onChange={setScore} />
</form>
```

### Give it a `label`.

<DoDontPair
    doExample={<Rating label="How was the session?" value={3} onChange={() => {}} />}
    doCaption="A label names the row, so a page with two ratings tells them apart."
    dontExample={<Rating value={3} onChange={() => {}} />}

## Accessibility

- **It is one value out of five, and says so.** The row is a `radiogroup` and each item is a `radio` carrying `aria-checked` and an `aria-label` of "Rate 1" through "Rate 5". The chosen value is in the accessibility tree, not only in the fill color.
- **One tab stop, arrow keys within it.** Tab reaches the group once, landing on the checked item, or the first when nothing is checked; Left/Right, Up/Down, Home and End move the value. Enter and Space still activate an item directly.
- **Moving the selection is changing it.** An arrow key calls `onChange`, so a keyboard user cannot browse the scale without setting it. That is the usual radio-group behavior.
- **Disabled stays announced.** The items keep their role, label and `aria-checked` and take `aria-disabled`, and drop out of the tab order.
- **The label is a `span`, deliberately.** There is no form control for a `label` element to point at, so the label has an id and the row is named by `aria-labelledby`.
- **`isRequired` marks the label and requires the group.** The asterisk follows the label and is read as "required"; the group carries the native required constraint.
