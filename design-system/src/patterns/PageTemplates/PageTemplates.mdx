A page template is the whole page every screen starts from: the topbar, the sidebar and the surface that holds the page's content. It sets the screen width, the grid and the content width once, and everything inside moves with it. The default frame is for pages people move among. The focused frame is for one task, with no sidebar.

### When to use

Start every page from a page template. Pick the frame by the kind of work the page holds.

- **Default frame.** The person moves among pages: browse, compare, come back. It keeps the sidebar and the breadcrumb.
- **Focused frame.** One task that takes more than a screen or a few minutes. The person finishes or leaves it, and the rest of the app would only distract. Writing a session note, setting up a session and reviewing an import are focused tasks.
- **For a short decision, use Modal.** A confirmation, a rename or a few fields that keep the page behind them in view belong in a modal. A form that scrolls for long or has sections is a focused page.
- **For a panel that needs the page in view, use Drawer.** The details of a row or a set of filters open in a drawer over the template.

- **Content grid** (blue in Figma). It belongs to the surface and has 12 columns with a 16 gutter.

Rules for the focused frame:

- **One task per page.** Name the task in the title ("Add a session note"), not the app area.
- **Back and Close.** If both would go to the same place, keep Close only.
- **Actions in the footer.** End-aligned, the primary last, one primary at most.
- **Sections only in the surface.** Never put a sidebar, a card grid or a table toolbar beside them.

### Usage

- **Two rows.** The topbar runs across the full width, 32 high with no padding of its own. Under it, the sidebar and the surface sit 8 apart.
- **Container pad.** 8 on top, right and bottom. On the left it is 8 while the sidebar floats and 0 once it docks.
- **Sidebar.** 240 wide, from the screen edge to the surface. It docks from 1024.
- **Surface pad.** 16 below 1440 and 24 from 1440. The grid margin is the same token.
- **Content cap.** 1232. With the sidebar docked it binds from a 1528 screen, and past that the margins grow.
- **Content minimum.** 720. Narrower, the surface scrolls sideways and the topbar stays.
- **Set the mode on the template, never inside it.** Sections, Cards and Tables inherit the mode and never carry one of their own.

#### Slots, not variants

A slot is a region left open for real content. The pattern owns the layout, the spacing and the size, and the slot holds what the feature needs.

- **Keep the slot wrapper** and replace the placeholder inside it. A slot is a place for content, not a placeholder to delete.
- **Slots, not variants.** If a layout is duplicated to handle a variation, that layout needs a slot.
- **Slots live in** Card (header, body, footer), Modal (body, footer), Section (content, side, actions, tabs) and the page templates (the surface). A table is never a slot shell.

#### Build a real page

A page is built from the top down out of patterns. A Sessions page is a surface that holds a page header, a row of metric cards and a table under a header with tabs.

1. **Surface container.** The topbar, the sidebar and the surface around the page. The template sets the layout mode once for everything inside.
2. **Section header, level page.** The page title, description and page-level actions. One per page.
3. **Card, size sm.** Metric tiles. A card shows one piece of information, with the header turned off when the body carries its own title.
4. **Section header, tabs type.** The tabs are the header's bottom row. They replace a separate tab group above the table.
5. **Table.** A plain table directly under the header, with no card around it and no toolbar of its own.

### Accessibility

- **Landmarks.** The topbar is the banner, the surface is the one `main`, and the focused footer is a named footer (`Page actions`).
- **One page title.** The page has one `h1`. In the default frame it is visually hidden and the breadcrumb shows the place. In the focused frame it is the visible title in the topbar.
- **Focus order.** In the focused frame it is Back, Close, the content, then the actions. In the default frame the sidebar toggle comes first, then the page.
- **Names.** Back and Close are buttons with names, and Close keeps its name when the title truncates. Name the Close button for the task, such as "Close note".
- **Sidebar.** The toggle reports whether the sidebar is open. Hover is never the only way in: the toggle opens and docks it from the keyboard, and Escape closes a floating sidebar.
- **Drawer.** It is a dialog named by its title. It moves focus inside, keeps Tab there and returns focus to its trigger.
- **Color.** The frame, the surface and the title use color roles, so they hold their contrast in Light, Dark and increased contrast.

### For developers

The page template is `PageLayout`, which fills `Frame` with the PLUS topbar and sidebar. `frame="focused"` fills it with the focused topbar, the reading surface and the footer. There is no mode prop in code: the layout tokens switch on the viewport width, so the screen picks the mode. A page that needs the reading cap in the default frame composes `Frame` with `width="reading"`. Figma's `drawer?` toggle is the `drawer` prop: pass it the props of `PatternDrawer` and the template renders the Drawer over the page. The page holds the open state and passes it as `open`.
