<Title />
A suggestion is a value the system proposes that a person can accept, such as
an AI-suggested focus area or a suggested question beside a chat box. It is a
button, not a label: it has the height, padding and radius of a Tag, so it
sits in the tag row where the accepted value will land.

## For developers

The accept handler hands back the value (insert) or the text (prompt), and the
suggestion does not change itself. The field that owns the value adds a Tag,
sends the message or fills the text box, and stops offering the suggestion.

```jsx
// Insert hands back the value; the field turns it into a Tag.
<Suggestion label="Relationships" value="focus-relationships" onAccept={addFocusArea} />

// Prompt hands back the text to send or fill.
<Suggestion type="prompt" label="Summarize" text="Summarize this session" onAccept={send} />
```

Inside a disabled Tag group, a suggestion reads the same context a Tag does
and is disabled with the tags beside it.

```jsx
<TagGroup label="Focus areas" disabled={!canEdit}>
  <Tag color="blue">Fractions</Tag>
  <Suggestion label="Ratios" onAccept={add} />
</TagGroup>
```

## When to use

Use a suggestion when the system can propose a value a person may accept. Offer
one where a likely value exists but the person decides, such as an AI-suggested
focus area or a suggested question beside a chat box. Once the value is set, it
is a Tag. To say only where content came from, use AI label.

- **Put it where the value will land.** Place it in the tag row, after the tags already there. Suggestions always sit at the end of a Tag group, after +n, and are never counted or hidden.
- **Let the field decide what happens next.** The field that owns the value adds a Tag, sends the message or fills the text box, and stops offering the suggestion.
- **Keep the words short.** A suggestion is a value's name, not a sentence. For a prompt, pass the full words as the text and a short label.
- **Disable the field, not the suggestion.** There is no disabled prop. A disabled field or Tag group disables every Tag and Suggestion in it.

</div>

## Accessibility

- **A real button.** It takes focus, and Enter or Space accepts it.
- **Disabled is a disabled button.** It keeps its name, is announced as disabled, is skipped by Tab and never calls the accept handler.
- **Named for what pressing it does.** An insert suggestion is announced as "Add Ratios, suggested", so a screen-reader user knows pressing it adds a value. A prompt adds nothing, so it is announced as "Summarize, suggested".
- **The glyph is decoration.** The plus and the sparkle wand are hidden from assistive technology, since the name already says what the suggestion does.
- **Focus is a ring, not a fill.** A 2px ring, 2px outside the edge, so focus never reads as pressed.
- **Contrast:** the label and glyph use the discovery text and icon tokens, never a literal color.
