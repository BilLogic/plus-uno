<FoundationSection title="What AI UI is">

AI UI is the layer of the design system for moments where the AI is at work: a tutor asking for a session summary, a draft being written, a suggested focus area. It uses the same tokens, type and components as the rest of PLUS, and adds a small set of its own so a person can always tell what the AI made and what a person made.

</FoundationSection>
