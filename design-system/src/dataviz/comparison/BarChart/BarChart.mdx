## When to use

Use `BarChart` to compare values across categories: enrollment per subject,
average score per class, sessions per day of the week. It also ranks — sort the
bars from most to least and the order does the reading for you.

For the same value moving through time, use `LineChart`. For parts of one
total, use `StackedBarChart`, `PieChart` or `DonutChart`. For a value against
a target, use `BulletChart`.

Prefer **vertical** columns for short labels and fewer than seven categories.
Prefer **horizontal** bars (`horizontal`) for long labels, many categories or a
ranking.

## Data shape

`categories` is an array of strings. `series` is an array of `{ name, data }`,
where `data` holds one number per category, in the same order as `categories`.

```jsx
<BarChart
    yAxisLabel="Enrolled students"
    categories={['Math', 'Science', 'History', 'Art']}
    series={[
        { name: '2023', data: [50, 40, 35, 60] },
        { name: '2024', data: [65, 55, 45, 70] },
    ]}
/>
```

A series may carry its own `color`; leave it out and the chart assigns one.

## Color and accessibility

- **Color is assigned for you.** One series takes `--ds-chart-brand`. Two or more take the categorical order, slot 1 first, never skipping a slot. Past six series, group the smallest categories into "Other".
- **Bar length carries the value.** Color only tells series apart, so the chart reads without hue. Keep the series count low enough that the legend can name each one.
- **Keep the baseline at zero.** A truncated axis makes a small difference look large.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`BarChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : series.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <BarChart categories={categories} series={series} />}
```
