## When to use

Use `StreamgraphChart` for an overview of how a mix changes: which subjects
grow in enrollment across a year, which session types rise and fall over a
term. It works for a broad story with a few layers, read at a glance.

For values someone needs to read or compare precisely, use `LineChart`: the
streamgraph has no value axis. For composition on a fixed zero baseline, use
`AreaChart` with `stacking`. For composition at one moment, use `TreemapChart`
or `DonutChart`.

## Data shape

`categories` is an array of period labels. `series` is an array of
`{ name, data }`, where `data` holds one number per period, in the same order
as `categories`.

```jsx
<StreamgraphChart
    categories={['Sep', 'Oct', 'Nov', 'Dec', 'Jan', 'Feb']}
    series={[
        { name: 'Math', data: [120, 140, 155, 150, 170, 185] },
        { name: 'Reading', data: [90, 95, 100, 98, 110, 118] },
        { name: 'Science', data: [45, 52, 60, 58, 66, 72] },
    ]}
/>
```

`height` defaults to 400.

## Color and accessibility

- **Color follows series order.** Layers take the categorical colors in order, slot 1 first, even when there is only one; a series `color` is ignored. Past six series, group the smallest into "Other".
- **Color is the only thing naming a layer.** Layers carry no labels or patterns, so the legend and the tooltip do the identifying. Keep to a few layers the legend can name.
- **Thickness is hard to judge.** With no axis and every layer floating on the ones beside it, only the overall shape reads reliably. Put exact figures in the tooltip or in text, never in the reader's estimate.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`StreamgraphChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment could not load.</SectionMessage>
    : series.length === 0 ? <EmptyState size="compact" header="No enrollment yet" description="Subjects appear once students enroll." />
    : <StreamgraphChart categories={categories} series={series} />}
```
