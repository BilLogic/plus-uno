## When to use

Use `AreaRangeChart` when the spread matters as much as the level: the lowest
and highest session score each week, the expected score band across a term,
the earliest and latest session start each day. A widening band says results
are getting less consistent.

For a single value over time, use `LineChart`. For a fill down to zero, use
`AreaChart`. For low-to-high ranges across categories rather than time, use
`ColumnRangeChart`.

The chart draws one band and nothing else. It does not draw the midpoint or a
second series, so if the reader needs the average too, say it in the text
beside the chart.

## Data shape

`data` is an array of `[x, low, high]` triples, one per point, in x order.
There is no `categories` prop, so the x axis shows numbers: index weeks or
months from zero and name the unit in `xAxisLabel`.

```jsx
<AreaRangeChart
    xAxisLabel="Week of term"
    yAxisLabel="Session score (%)"
    data={[
        [1, 52, 78], [2, 55, 80], [3, 58, 84], [4, 61, 85], [5, 60, 88],
    ]}
/>
```

`height` defaults to 400. The legend is off, since there is only one series.

## Color and accessibility

- **One color, always.** The band takes `--ds-chart-brand`. There is no `color` prop and no second series to tell apart.
- **Position carries the values.** The top and bottom edges are the high and low; the fill only shows the span between them. Without an outline, the edges are the fill's boundary alone, so read exact values from the tooltip.
- **Name the range in words.** The chart has no legend, so the surrounding header or caption must say what the low and high are, such as "Lowest and highest score each week".
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`AreaRangeChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Score ranges could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Ranges appear after a week of sessions is logged." />
    : <AreaRangeChart data={data} yAxisLabel="Session score (%)" />}
```

## Related

- For the level alone, as a line, use `LineChart`.
- For a fill down to zero rather than between two bounds, use `AreaChart`.
- For low-to-high ranges across categories rather than time, use `ColumnRangeChart`.
- For the full spread of values in each group, with quartiles, use `BoxPlotChart`.
