Size roles set how tall or wide a part is: a control, a table row, an icon, a
label, a picture, a field. PLUS has one size scale, used through six roles.
Pick the role, then its size. You never type a height or width.

### Accessibility

- Every control is at least 24 tall, and 32 everywhere outside a table row or
  an inline toolbar, so it stays an easy target.
- An icon never sets the height of the line it sits in: its box is exactly
  its size. A control with only an icon still needs a name.
- A Tag whose label is cut short shows the full label in a tooltip, on hover
  and on focus.
</div>
