## When to use

Use `VennDiagram` for overlap across two or three groups, such as students
tutored in both Math and Reading, tutors certified in multiple SMART
competencies, or students in both fall and spring cohorts. Past three sets,
overlaps cannot all be drawn to scale.

For group sizes without overlap, use `PieChart` or `TreemapChart`. For
membership across many groups, use `HeatmapChart`. For links between individual
items, use `NetworkGraph`.

## Data shape

`data` is an array of `{ sets, value, name }` (`sets` and `value` required):
list each single set, then each overlap. A single set's `value` is the full
circle including overlaps, not the exclusive portion. `height` defaults to 400.

```jsx
<VennDiagram
    data={[
        { sets: ['Math'], value: 42, name: 'Math' },
        { sets: ['Reading'], value: 35, name: 'Reading' },
        { sets: ['Math', 'Reading'], value: 12, name: 'Math and Reading' },
    ]}
/>
```

## Color and accessibility

- **Automatic set colors.** Each single-set circle takes the next slot in the [categorical order](?path=/docs/data-visualizations-color--docs) starting at slot 1; overlaps blend where circles cross.
- **Label every region.** Pass `name` on every entry so labels and tooltips identify each circle and intersection without hue. Because area is judged roughly, include exact counts in `name` or surrounding copy when they matter.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

</div>

## States

`VennDiagram` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No enrollment yet" description="Overlaps appear once students enroll in more than one subject." />
    : <VennDiagram data={data} />}
```

## Related

- For the sizes of the groups rather than their overlap, use `PieChart` or `TreemapChart`.
- For membership across many groups, use `HeatmapChart`.
- For relationships between individual items rather than sets, use `NetworkGraph`.
- For group sizes clustered without overlap, use `PackedBubbleChart`.
