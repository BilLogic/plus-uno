## When to use

Use `BulletChart` when each metric has a goal on a 0 to 100 scale, such as
weekly session completion rate, program attendance or a SMART competency
benchmark. Stacking metrics lets readers scan for bars that fall short of their
ticks.

For values without a target, use `BarChart`. For one headline value against a
target on a dial, use `GaugeChart`. For progress toward a target over time, use
`LineChart`.

Every metric must be a percentage or a score out of 100 because the scale is
fixed at 0 to 100.

## Data shape

`categories` is an array of row labels. `data` is an array of `{ y, target }` in
the same order. `height` defaults to 200; allow roughly 60 to 80 px per row.

```jsx
<BulletChart
    height={250}
    categories={['Session completion', 'Attendance', 'Reflection rate']}
    data={[
        { y: 78, target: 85 },
        { y: 92, target: 90 },
        { y: 64, target: 75 },
    ]}
/>
```

## Color and accessibility

- **Fixed colors.** Bars use `--ds-chart-brand`, targets use `--ds-chart-gray-boldest`, and bands use the danger, warning and success backgrounds; no color is assigned per row.
- **Position carries the value.** Bar length and tick position on the shared axis show distance from the goal without hue.
- **Unlabeled status bands.** The red and green bands carry no printed labels and are easily confused under color-vision deficiency. State what the bands mean in surrounding text and never rely on them alone to flag a row.
- **Fixed band thresholds.** Thresholds stay at 60 and 80 for every row. If a metric uses different thresholds, put it in its own chart or in `BarChart`.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`BulletChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={250} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Goals could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No goals set" description="Progress appears once a target is set." />
    : <BulletChart categories={categories} data={data} height={250} />}
```
