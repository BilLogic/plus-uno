## When to use

Use `ParliamentChart` when the total is a modest count of real units and
seeing each one matters: the students in a tutoring cohort by grade, the seats
on a student council, the tutors at a school by certification level. A dot
per person keeps the numbers human.

For a split where the units do not matter, use `PieChart` or
`StackedBarChart`. For counts that must be compared precisely, use `BarChart`.
For groups within groups, use `SunburstChart`.

## Data shape

`data` is an array of `{ name, value }`, one object per group. `value` is a
whole count of units.

```jsx
<ParliamentChart
    data={[
        { name: 'Grade 8', value: 22 },
        { name: 'Grade 7', value: 17 },
        { name: 'Grade 6', value: 11 },
    ]}
/>
```

An item may carry its own `color`; leave it out and the chart assigns one.
Groups draw in the order given, so sort `data` from most to least before you
pass it.

## Color and accessibility

- **Color is assigned by position.** Each group without a `color` takes the categorical order: slot 1 for the first item, slot 2 for the second. Sort first so the order of the colors matches the order of the sizes.
- **Color is what tells groups apart in the arc.** Dots are the same shape and size, so adjacent groups differ only by hue. The group labels and the legend counts are the non-color encoding; keep both. Past six groups, adjacent hues get hard to tell apart, so group the smallest into "Other".
- **Keep the total modest.** A few dozen to a few hundred dots; past that, dots shrink until they stop reading as units.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation through the groups. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`ParliamentChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>The cohort could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No students yet" description="Students appear once they join the cohort." />
    : <ParliamentChart data={data} />}
```
