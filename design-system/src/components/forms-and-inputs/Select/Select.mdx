## Usage

Use `Select` for a list too long to show all at once, or when typing to
filter helps more than scanning — a tutor roster, a list of schools. For a
handful of options visible all at once, use `RadioGroup` instead. For
options arranged in a hierarchy, use `TreeSelect` or `Cascader`.

</div>

## Parts

1. **Field.** The box that shows the value, or the placeholder, and a chevron.
2. **Label.** Names the field. A required marker follows it.
3. **List.** The options, in a popup under the field. Groups carry a heading.
4. **Caption.** Helper text, or the error that replaces it.

## Best practices

### Pick the mode by the answer.

`isMulti` shows picks as Tags and checkboxes in the list; `selectAll` and `maxSelections` apply to it only. `isSearchable` filters by typing, and `isCreatable` adds a "Create" row when nothing matches. `clearable` defaults to on with `isMulti` and off for a required single select.

### Chain `dependsOn` for fields that filter each other.

Pass the parent's `{ value, label }` as `dependsOn` on the child. The child
disables itself and explains why until the parent has a value, and clears
itself the moment the parent's value changes — no manual wiring needed beyond
passing the parent's current state down.

```jsx
<Select label="School" options={schools} value={school} onChange={setSchool} />
<Select
    label="Teacher"
    options={teachersFor(school)}
    value={teacher}
    onChange={setTeacher}
    dependsOn={{ value: school, label: 'a school' }}
/>
```

### Use `commitOnClose` for a filter bar, not a form field.

A form's multi-select should fire `onChange` on every pick, so other UI can
react immediately. `commitOnClose` is for the opposite case — a filter panel
where firing once, on close, avoids re-querying on every checkbox click.

### Reach for `loadOptions` once a list is genuinely large or server-backed.

`recent` and `suggested` only change the order past 50 static options;
`loadOptions` is for a list too large to ship as a static array at all.

## Accessibility

- **A real combobox.** The field is `role="combobox"` with
  `aria-expanded`/`aria-controls`/`aria-activedescendant` tracking the open
  list and its highlighted row.
- **The label is linked, or named explicitly.** Pass `label` for a visible
  one, or `aria-label`/`aria-labelledby` when there isn't a visible label.
- **Keyboard parity with a native select.** Arrow keys, Enter and Escape
  open, move through and close the list; Backspace removes the last Tag in a
  multi-select with an empty filter; Delete clears the field when
  `clearable`.
- **A waiting dependent field says why.** `dependsOn`'s disabled state pairs
  with a caption ("Choose a school first"), not silence.
