## Usage

Use `Avatar` wherever a person or an agent is named in a row, a thread or a
list of attendees. Use `AvatarGroup` for a short set of people that would crowd
a line: the attendees of a session, the members of a team.

Use `Tile` for a school, a tool or a lesson: a square picture of a thing, not
a face. Use `UserAvatar` for the signed-in user in the topbar, with the name,
role and notification counter beside the initial.

</div>

## Parts

1. **Face.** The picture when it loads; otherwise the initials, then the icon, then a plain person glyph.
2. **Frame.** A circle for a person; a square for a team or an agent, with a radius of a quarter of its size.
3. **Presence dot.** Optional, a quarter of the avatar's size at the bottom right, ringed in the surface color.

## Best practices

### Circle for people, square for teams and agents.

Keep one shape per kind within a list, so the shape tells a person from an
agent at a glance.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Avatar name="Jane Park" /><Avatar shape="square" icon="robot" label="Study bot" /></div>}
    doCaption="A circle for a person, a square for an agent."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Avatar shape="square" name="Jane Park" /><Avatar icon="robot" label="Study bot" /></div>}
    dontCaption="A person in a square and an agent in a circle."
/>

### Keep the name beside bare initials.

Two people can share initials. The name is what tells them apart, so drop it
only where the person is named nearby.

### Let the group set the size.

`AvatarGroup` passes its `size` and `shape` to every avatar, so the row stays
even.

```jsx
<AvatarGroup label="Session attendees" max={5}>
    {people.map((p) => <Avatar key={p.id} name={p.name} src={p.photo} />)}
</AvatarGroup>
```


### A color is a category, not a status.

Keep one color per kind of person, or leave avatars blue. Green, yellow and red belong to the presence dot, so a green avatar reads as "online".

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Avatar name="Jane Park" /><Avatar name="Sam Lee" /></div>}
    doCaption="One color for all people, or one per kind."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Avatar name="Jane Park" color="green" /><Avatar name="Sam Lee" color="yellow" /></div>}
    dontCaption="Green and yellow read as online and away."
/>

### Show presence only where it helps.

Use the dot in a list a person scans for who is around. Leave it off a byline or a comment, where presence is not the question.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Avatar name="Jane Park" status="online" /><span>Jane Park</span></div>}
    doCaption="The dot in a list that is scanned for who is around."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Avatar name="Jane Park" status="online" size={16} /></div>}
    dontCaption="A dot on a tiny byline, where presence is not the question."
/>

## Accessibility

- **Decorative by default.** An avatar with no `name` or `label` is hidden from
  assistive technology (`aria-hidden="true"`), for use beside a name that
  already says who it is.
- **A name makes it one image.** With a `name` or `label` it becomes
  `role="img"` with that name. A `status` is added to the name ("Jane Park,
  online"), since the dot's color alone says nothing to a screen reader.
- **The group is a named group.** Give `AvatarGroup` a `label`. The `+n` is a
  button named by its count ("+3, 3 more people"); it opens a menu of the
  hidden people by name, reached with Tab and closed with Escape.
- **Not a control.** An avatar has no hover or focus state of its own. To make
  one clickable, wrap it in a button or link that carries the name.
