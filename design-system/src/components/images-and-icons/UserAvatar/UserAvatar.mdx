## When to use

Use `UserAvatar` for the current user's identity in the topbar or in a row that names a person. For a person who is not the signed-in user, or a picture-only avatar, use `Avatar`.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Pick `spacing` by where it sits.

`compact` fits the 32 topbar. `default` fits table rows. The name truncates at the label maximum width and keeps the full name in its `title`.

```jsx
<UserAvatar spacing={topbar ? 'compact' : 'default'} name={user.name} firstChar={user.name[0]} type="lead tutor" counterValue={3} />
```

### Pass `onClick` to make it clickable.

Without it the avatar is static. With it, the avatar shows the clickable look.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **The initial is decorative.** The pill is hidden from assistive technology; the name carries the meaning.
- **The role is text.** The Lead tag is a Status tag with visible text, not color alone.

</div>

<div className="sb-ds-doc-section">

## Related

- For a picture or initials alone, use `Avatar`.
- For several people, use `AvatarGroup`.
- For the role tag, see `StatusTag`.
