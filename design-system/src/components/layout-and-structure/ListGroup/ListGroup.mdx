## When to use

Use `ListGroup` for a flat, bordered list of like things — a set of links, a set
of actions, or rows of content. An item renders as an `a` if given `href`, a
`button` if given `onClick` or `action`, and a `div` otherwise.

It is not for picking a value. A list of options under a field is the option
list that Select and TagInput open; for a few options in a form, use
`ChoiceGroup`.

`flush` removes the outer border for a list inside another surface; `horizontal`
lays the rows in a row.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### `style` on an item is a color variant, not inline CSS.

It takes `primary`, `success`, `danger` and the rest, and is turned into a class
name. An object passed there produces a class name built from `[object Object]`,
and there is no inline-style prop on the item — put the CSS in a `className`.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **A list of links and buttons is walked with Tab.** Each actionable row is
  its own tab stop, as links and buttons are anywhere else.
- **Disabled rows.** A disabled `button` item gets the real `disabled`
  attribute; a disabled link loses its `href` and takes `tabIndex={-1}`.
- **A row that only looks clickable is not.** Without `href`, `onClick` or
  `action` the item renders as a `div` — no focus, no Enter. If it does
  something, give it one of the three.

</div>

<div className="sb-ds-doc-section">

## Related

- For picking one option or several in a form, use `Select`, or `ChoiceGroup`
  for fewer than five options. Both carry the keyboard pattern a list of
  options needs.
- For rows that navigate a section of the app, use `SidebarTab` or `NavPills`.
- For tabular data with more than one column per row, use `Table`.

</div>
