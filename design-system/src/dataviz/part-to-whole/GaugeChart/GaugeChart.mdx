## When to use

Use `GaugeChart` for one key figure that sits on a known scale: a course
completion rate, the share of sessions a tutor attended, an average student
satisfaction score out of 100. One or two gauges on a dashboard draw the eye to
the number that matters most.

Use it sparingly. For several of these figures at once, use `BarChart`; a row
of dials is harder to scan than a column of bars. For a value against a
target that must be read precisely, use `BulletChart`. For a completion share
with room for a label in the middle, use `DonutChart`. For the same figure over
time, use `LineChart`.

## Data shape

`value` is a single number. `min` and `max` set the scale; `label` says what
the number is.

```jsx
<GaugeChart value={82} min={0} max={100} label="Sessions attended (%)" />
```

The value shows as given, with no unit added. Put the unit in `label`.

## Color and accessibility

- **One color, brand by default.** The fill is `--ds-chart-brand` unless you pass `color`. The fill does not change color as the value moves; it stays the color you set.
- **Status needs words, not just hue.** When the value is a status, pass a status chart color (`STATUS.success`, `STATUS.warning`, `STATUS.danger` from the palette) and say the status in `label` or the surrounding text. Color alone will not reach every reader.
- **Arc length carries the value, and the number confirms it.** The value is always printed under the arc, so the gauge reads without hue.
- **Keep the scale honest.** A `min` above zero makes a small value look large; set it only when the scale truly starts there.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, a per-point label, and keyboard navigation to the value. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting.

## States

`GaugeChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Attendance could not load.</SectionMessage>
    : value == null ? <EmptyState spacing="compact" header="No sessions yet" description="Attendance appears after a session is logged." />
    : <GaugeChart value={value} label="Sessions attended (%)" />}
```
