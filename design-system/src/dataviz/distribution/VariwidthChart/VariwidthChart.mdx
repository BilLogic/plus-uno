## When to use

Use `VariwidthChart` when a category value needs its weight alongside it, such
as average score per subject sized by enrollment or average tutor rating sized
by review count.

For equal-width columns, use `BarChart`. For parts of a total sized by area,
use `TreemapChart`. For three measures on two axes, use `BubbleChart`. For
spread within each category, use `BoxPlotChart`.

## Data shape

`data` is an array of `{ name, y, z, color }` (`name`, `y` and `z` required;
`color` optional). `height` defaults to 400.

```jsx
<VariwidthChart
    xAxisLabel="Subject"
    yAxisLabel="Average score"
    data={[
        { name: 'Math', y: 85, z: 120 },
        { name: 'Science', y: 78, z: 90 },
        { name: 'Reading', y: 92, z: 30 },
        { name: 'History', y: 70, z: 80 },
    ]}
/>
```

## Color and accessibility

- **Per-column color.** Columns cycle through the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1 (overflowing past six and repeating past eight). Because the axis already names each column, pass `color: 'var(--ds-chart-brand)'` on every item if you prefer one hue.
- **Height and width carry the values.** There is no width axis, so state what column width represents in the header or description.
- **Ensure height × width is meaningful.** Readers naturally compare column areas, so use this chart only when the product of height and width makes sense.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`VariwidthChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <VariwidthChart data={data} xAxisLabel="Subject" yAxisLabel="Average score" />}
```
