Frame is the app frame: a full-width Topbar above a row that holds the sidebar and the page. Every value is a token, and values read Medium, Large and X-Large where the layout mode changes them.

### When to use it

Use Frame for every page of the app. It owns the frame sizes and the sidebar's behavior, so a page only supplies its Topbar, its sidebar and its content.

For a whole page with the PLUS Topbar and sidebar already filled in, start from a page template. For a bare fill and elevation, use **Page**. For a region inside the content, use **Section**.

### Anatomy

1. **Topbar** is a part. It holds the sidebar toggle, the breadcrumb and the account, in a row 32 high with no fill of its own. The toggle sits 8 from the left, flush to the top at every width.
2. **Page** is a part. It is the rounded content box on `--ds-surface`, with the pad and radius from the table below.
3. **Content** is the slot where Sections go. It is a 12-column grid, centered and capped at 1232.
4. **Sidebar** is a part. It holds the logo, Home, then the sidebar sections. It docks from 1024 and floats over the page below that.

An optional footer row sits directly under the page, with no gap, lined up with it. A focused page puts its actions there.

The Topbar, Sidebar and Page have their own pages. This page covers how the frame places them.

### Variants and states

#### sidebar = auto

The sidebar follows the width. At Medium (768) it is closed and the toggle shows the bars icon. At Large and X-Large it docks, 240 wide, and the toggle shows angles-left. Clicking the toggle docks a closed sidebar at any width and closes a docked one.

Docked below 1024, the page is narrower than the content minimum of 720, so it scrolls sideways while the Topbar stays put. Crossing 1024 returns the sidebar to that width's default.

### Accessibility

- The sidebar is a landmark named by `sidebarLabel`, "Sidebar" by default. Name it differently when a page has two.
- The toggle is a button. Its name says what a press does: "Close sidebar" while docked, "Open sidebar" otherwise. It reports whether the sidebar is showing, and it points at the sidebar while it is open.
- A peeked sidebar closes on Escape, and focus returns to the toggle. A control that handles its own Escape, such as a menu, keeps it.
- Opening a modal from the floating sidebar returns focus to the toggle when the modal closes, because the trigger left with the sidebar.
- Pass `contentAs="main"` so the page has one main landmark.
- In light increased contrast the page draws its edge ring in `--ds-border-surface`, so it stays distinct from the frame behind it.
