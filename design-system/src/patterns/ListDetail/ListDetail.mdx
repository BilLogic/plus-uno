<Title>List and detail</Title>
List and detail is a page layout that opens a record beside its list. The list takes 7 of the Page's 12 columns and the detail, a Section with a subtle fill, takes 5. Next and previous sit in the detail's header, so a supervisor can work down a queue without going back to it.

The examples on this page follow the **Color mode** switch in the toolbar.

### When to use it

Use it for a queue a person works through: Admin › Compliance, Admin › Reflections. The detail is for a decision that takes a glance or a short form. Heavy work, such as the recording review, gets its own page: put "Open full review" in the detail's footer.

<div className="sb-ds-doc-section">

### Anatomy

1. **List** is a Section, usually holding a table or rows. It takes 7 columns.
2. **Detail** is a Section with the subtle fill. It takes 5 columns.
3. **Next and previous** sit at the end of the detail's header.
4. **Back link** appears only when the detail replaces the list.

</div>

<div className="sb-ds-doc-section">

### Behavior

The layout measures the Page's content, not the window, and holds the split from **960**.

- **At 960 or more**, both show. Selecting another record updates the detail in place.
- **Below 960**, the detail replaces the list and a back link returns to it. With no record open, the list fills the row.
- **With the Panel open**, pass `listDetail` to the Frame. The Frame collapses the Sidebar first, so the content keeps 960 beside a docked Panel. If it cannot, the split gives way as above.
