## When to use

Use `PromptStarters` to offer a few things a person could ask an AI feature,
before they've typed anything — an empty chat, a fresh reflection, a blank
prompt field. Once a conversation is underway, use `Suggestion` directly for
a single follow-up prompt instead of a full row of starters.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### `onSelect` decides what happens — the component never sends on its own.

The common pattern is putting the starter's `text` into a `PromptInput` so a
person can read and edit it before sending, not sending it immediately on
their behalf.

```jsx
<PromptStarters
    label="Suggested prompts"
    starters={[
        { id: 'summarize', label: 'Summarize this session', text: 'Summarize what happened in this session.' },
        { id: 'next-steps', label: 'Suggest next steps', text: 'What should the tutor focus on next?' },
    ]}
    onSelect={(starter) => setDraft(starter.text)}
/>
```

### An empty list renders nothing.

Don't guard the component with your own conditional — passing an empty
`starters` array already renders nothing, with no empty group left behind.

</div>

## Accessibility

- **A named group.** The row is `role="group"` with `label` as its accessible
  name, required so assistive technology announces the set together.
- **Each chip is `Suggestion`'s own control.** Keyboard reach, focus and the
  accept action all follow `Suggestion`'s accessibility contract.

</div>
