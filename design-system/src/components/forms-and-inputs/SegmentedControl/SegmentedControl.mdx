## Usage

Use `SegmentedControl` to change how the same content is shown: Table or Cards, Day, Week or Month, Form or Code. The choice applies at once and there is no apply step. Exactly one segment is selected.

```jsx
<SegmentedControl
    label="Format"
    value={format}
    onChange={setFormat}
    options={[
        { value: 'table', label: 'Table', icon: 'table-list', isIconOnly: true },
        { value: 'cards', label: 'Cards', icon: 'grip', isIconOnly: true },
    ]}
/>
```

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For switching between sections of a page, each with its own content, use `Tabs`.
- For a row of related actions that each do something, use `ButtonGroup`.
- For one answer in a form that is saved with the form, use `RadioGroup`.
- For more than five choices, use `Select`.

</div>

## Parts

1. **Track.** A neutral fill that holds the segments, inset by 2.
2. **Segments.** Text, an icon with text, or an icon alone. Each is a toggle button.
3. **Indicator.** One raised surface under the selected segment. It slides to the new segment when the choice changes.

## Best practices

### Switch the view of one thing, not the thing itself.

Every segment shows the same content a different way.

<DoDontPair
    doExample={<SegmentedControl label="Format" defaultValue="table" options={[{ value: 'table', label: 'Table' }, { value: 'cards', label: 'Cards' }]} />}
    doCaption="Table and Cards show the same students."
    dontExample={<SegmentedControl label="Students" defaultValue="students" options={[{ value: 'students', label: 'Students' }, { value: 'sessions', label: 'Sessions' }]} />}
    dontCaption="Students and Sessions are different content. Use Tabs."
/>

### Keep it to two to five segments.

A longer list is a menu. Six is the limit when every segment is icon-only.

### Name the group and every icon-only segment.

`label` names the group for assistive technology. An icon-only segment needs its own `label`, which is its accessible name and its Tooltip.

### Make the labels parallel and short.

<DoDontPair
    doExample={<SegmentedControl label="Calendar range" defaultValue="week" options={[{ value: 'day', label: 'Day' }, { value: 'week', label: 'Week' }, { value: 'month', label: 'Month' }]} />}
    doCaption="Every label is a noun of the same kind."
    dontExample={<SegmentedControl label="Calendar range" defaultValue="week" options={[{ value: 'day', label: 'Day' }, { value: 'week', label: 'Show all' }, { value: 'month', label: 'Choose' }]} />}
    dontCaption="A noun, a phrase and a verb in one control."
/>

### Fit a narrow container with `shouldFitContainer`.

The segments share the width equally instead of hugging their labels. Labels that still do not fit end in an ellipsis; see [Overflow](?path=/docs/patterns-states-overflow--docs).

## Accessibility

- **A group of toggle buttons.** The control is `role="group"` named by `label`, and each segment is a button with `aria-pressed`. It is not a radiogroup or a tablist, because choosing a segment changes a view in place and does not move to another page region.
- **Keyboard.** Tab enters the control on the selected segment. Arrow keys move focus between segments and wrap at the ends. Space or Enter selects the focused segment.
- **One always selected.** Pressing the selected segment keeps it selected.
- **Icon-only.** The `label` is the accessible name, and the Tooltip shows on hover and on keyboard focus.
- **Reduced motion.** The indicator does not slide; the selected segment takes its fill at once.
