## Usage

Use `MenuGroup` for an always-visible list of actions or destinations — the
content of a sidebar section, a settings list, a dropdown's body once it's
open. For the popup mechanics that open and close a menu, see `Popup`;
`MenuGroup` is the list inside it, not the popup itself.

</div>

## Parts

1. **Group.** The scrollable `menu` the sections sit in; `density` sets the row height.
2. **Section.** A titled run of rows; `hasSeparator` draws a divider above it.
3. **Row.** A `ButtonItem`, `LinkItem` or `CustomItem` with an optional leading icon, a label, a description and a trailing icon.

## Best practices

### Pick the item kind for what the row does.

`ButtonItem` performs an action in place, `LinkItem` navigates to an `href`,
and `CustomItem` wraps a caller's own component for anything else — a label
around a checkbox, a row that isn't a button or a link at all.

```jsx
<MenuGroup>
    <Section title="Account">
        <LinkItem href="/settings">Settings</LinkItem>
        <ButtonItem onClick={signOut}>Sign out</ButtonItem>
    </Section>
</MenuGroup>
```

### `CustomItem`'s wrapper only shows up when `component` isn't a `div`.

With the default `div`, the row itself carries `role="menuitem"`. With a
different `component`, that role moves to an unstyled wrapper so the inner
element keeps its own native semantics (a `label`, for instance) while the
menu still sees an allowed child.

### Group rows by what they have in common.

Two to five sections of a few rows each scan faster than one long list. Title a section when its purpose is not obvious from its rows, and separate it when it changes kind, such as moving from navigation to actions.

### Keep the description to one line.

A description clarifies a row; it does not carry the row. If it needs two lines, the label is the problem.

## Accessibility

- **A real `menu` with arrow keys.** `MenuGroup` is `role="menu"`; Arrow Down
  and Arrow Up move focus between enabled items and wrap at the ends. Buttons
  and links are tab stops; a `CustomItem` rendered as a `div` is reached by the
  arrow keys only when the caller gives it a tab stop. The group does not yet
  collapse the items into one tab stop.
- **Sections are named groups.** A `Section` with a `title` is
  `role="group"` with `aria-labelledby` pointing at that title.
- **Disabled items leave the tab order.** `isDisabled` removes a `LinkItem`'s
  `href` and tab stop, and sets `aria-disabled` on every item kind.
- **`isSelected` is `aria-current`**, read by assistive technology as the
  active choice, independent of visual selection styling.
