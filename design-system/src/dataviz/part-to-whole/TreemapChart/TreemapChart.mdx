## When to use

Use `TreemapChart` for a flat split with more parts than a pie can hold where
the largest shares matter most, such as tutoring hours by subject, library
resources by type or sessions by school.

For nested levels, use `SunburstChart`. For two to five parts, use `PieChart` or
`DonutChart`. For exact ranking or comparison, use `BarChart`.

## Data shape

`data` is an array of `{ name, value, color }` (`name` and raw `value`
required; `color` optional when `colorByPoint` is on).

```jsx
<TreemapChart
    data={[
        { name: 'Math', value: 1240 },
        { name: 'Reading', value: 860 },
        { name: 'Science', value: 520 },
        { name: 'Writing', value: 310 },
        { name: 'Other', value: 140 },
    ]}
/>
```

- **Area and labels carry the value.** Small slivers are hard to compare and may not fit a label, so rely on the tooltip for exact figures.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`TreemapChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Tutoring hours could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No hours yet" description="Hours appear after a session is logged." />
    : <TreemapChart data={data} />}
```

## Related

- For two to five parts, use `PieChart` or `DonutChart`.
- For parts nested inside parts, use `SunburstChart`.
- For values that must be ranked or compared precisely, use `BarChart`.
- For the structure of a hierarchy without sizes, use `TreegraphChart`.
