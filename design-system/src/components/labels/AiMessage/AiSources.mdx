## Usage

Place `AiSources` under the AI message it belongs to, and pass one `{ title, href, type }` per source the answer read. With no sources it renders nothing. Inside a frame, pass `target` (such as `_top`) so the links leave it; without it, outside links open in a new window.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- The list is named by its "Sources" heading.
- The toggle is a button that reports `aria-expanded`.
