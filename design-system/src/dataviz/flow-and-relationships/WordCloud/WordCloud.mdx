## When to use

Use `WordCloud` for a quick, impressionistic read of open text: words students
use in session feedback, themes in tutor session notes, or answers to an
open-ended survey question.

It is a shape, not a measurement. When the counts matter, or two words need
comparing, use `BarChart`. For terms grouped by category as well as sized, use
`PackedBubbleChart`. For which terms appear together, use `NetworkGraph`.

Filter out common words (the, and, of) before passing the data, and keep to
the top 50 to 100 words.

## Data shape

`data` is an array of `{ name, weight }`. Both are required: `name` is the word,
`weight` its count.

```jsx
<WordCloud
    data={[
        { name: 'Patient', weight: 42 },
        { name: 'Encouraging', weight: 35 },
        { name: 'Clear', weight: 28 },
        { name: 'Prepared', weight: 19 },
        { name: 'Fun', weight: 12 },
    ]}
/>
```

## Color and accessibility

- **Color is decoration here.** Words take the categorical colors in order, starting at `--ds-chart-categorical-1`, and repeat past eight. The color says nothing about the word or its count; do not describe it as a category.
- **Size is the only encoding, and a weak one.** Long words take up more space than short words of the same weight, so a long word looks more common than it is. Give the exact counts in the tooltip, a table or the surrounding text when they matter.
- **Too many words become illegible.** The smallest words drop below a readable size first.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`WordCloud` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Feedback could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No feedback yet" description="Words appear after students rate a session." />
    : <WordCloud data={data} />}
```
