# Prompt-specs

Where low/mid-fidelity **prompt-spec** deliverables live once written —
`uno-prototype`'s output for every spec-handoff route (flow map · wireframe ·
concept image · storyboard · interactive proof).

**Naming:** `<slug>-<deliverable>.md` — e.g. `session-coverage-flow-map.md`,
`resource-search-interactive.md`.

**Why here rather than `docs/plans/`:** a prompt-spec is a design artifact that
exits to `uno-review` with an artifact manifest, not an implementation plan.
`docs/plans/` belongs to `ce:plan`. Live agent runs (2026-08-02) put specs in
three different places because no doc named one — this is that name.

Not built by `build:all`; these are text handed to an external tool, not code.
