## Usage

Use `NotificationItem` for updates that arrived over time: in the Inbox <a target="_top" href="./?path=/docs/patterns-notifications--docs">Notifications</a> panel, in a recent-updates card on Home, or on a full notifications page. Every row says who, what, where and when in two compact lines and opens its destination as one link.

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For a passing confirmation of an action that just finished, use `Flag`.
- For something to read or act on inside part of a page, use `SectionMessage`.
- For a condition that holds across a whole surface, use `Banner`.

</div>

## Parts

1. **Actor (`actor` at `start`).** A `32px` (`--image-md`) `Avatar` for a person or `Tile` for the system. Hidden from the link's accessible name because `title` already says who acted.
2. **Title (`title` at `label`).** Who and what on `--body-default` in `--ds-text`, promoted to `--type-weight-medium` while `unread` is true.
3. **Meta (`meta` at `description`).** Context and relative time separated by a middle dot (`"Sessions · 2m"`) on `--body-small` in `--ds-text-subtle`.
4. **Unread indicator and action (`end`).** An `8px` (`--count-tag-dot-size`) dot in `--ds-background-brand-bold` paired with visually hidden `"Unread"`, replaced on hover and keyboard focus by a compact `"Mark as read"` `IconButton` when `onMarkRead` is provided.

## Best practices

### Keep the whole row a single link.

Put the destination on `href` and never nest links inside `title` or `meta`. A single link gives one clear target for pointers and one stop per row for keyboard users.

<DoDontPair
    doExample={(
        <NotificationItem
            actor={<Avatar name="Ana Ruiz" size={32} />}
            title="Ana Ruiz moved Thursday's session"
            meta="Sessions · 2m"
            unread
            href="#do-one-link"
            onClick={(event) => event.preventDefault()}
            onMarkRead={() => {}}
        />
    )}
    doCaption="One link opens the session; Mark as read sits beside it as a sibling button."
    dontExample={(
        <NotificationItem
            actor={<Avatar name="Ana Ruiz" size={32} />}
            title="moved a session"
            meta="2m"
            unread
            href="#dont-vague"
            onClick={(event) => event.preventDefault()}
        />
    )}
    dontCaption="Missing actor name and context forces opening the notification to tell who and where."

### Pair Avatar for people and Tile for the system.

Circles represent people; rounded squares represent tools, reminders and system events.

## Accessibility

- **One link per row.** `NotificationItem` renders a single `<a>` element for the row and keeps the `"Mark as read"` `IconButton` as a sibling outside the link so interactive controls never nest.
- **Unread state announced in words.** The unread dot is `aria-hidden="true"` and paired with visually hidden `"Unread"` inside the link, so assistive technology announces unread status without relying on color or shape.
- **No duplicate actor announcement.** `actor` sits in an `aria-hidden="true"` start slot because `title` names who acted.
- **Keyboard-reachable Mark as read.** Focusing the row link triggers `:focus-within`, revealing `"Mark as read"` as the next Tab stop.
