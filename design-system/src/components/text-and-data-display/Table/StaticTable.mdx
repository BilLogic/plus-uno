## Parts

1. **Head cell.** A label with an optional type icon.
2. **Row.** Cells in a band; rest, highlighted, selected or disabled.
3. **Cell.** Text, a number, an icon or any node, with optional secondary text and a leading slot.
4. **Summary row.** One calculation per column, muted, with no rule under it.

## Best practices

A static table is a fixed grid people read. It has no hover, sort or paging; for those, use the Dynamic table.

### Right-align numbers.

<DoDontPair
    doExample={<StaticTable headers={rosterHeaders} rows={[['Jul 3', 'Priya Nair', { content: '$32.00', align: 'number' }], ['Jul 9', 'Marcus Lee', { content: '$6.50', align: 'number' }]]} />}
    doCaption="Numbers align by their digits, so the amounts line up."
    dontExample={<StaticTable headers={[{ text: 'Session date', width: '30%' }, { text: 'Student', width: '40%' }, { text: 'Amount', width: '30%' }]} rows={[['Jul 3', 'Priya Nair', '$32.00'], ['Jul 9', 'Marcus Lee', '$6.50']]} />}
    dontCaption="Left-aligned numbers do not line up."
/>

### Name the record in one column.

<DoDontPair
    doExample={<StaticTable headers={rosterHeaders} titleColumn={1} rows={[['Jul 3', 'Priya Nair', { content: '$32.00', align: 'number' }], ['Jul 9', 'Marcus Lee', { content: '$6.50', align: 'number' }]]} />}
    doCaption={<><code>titleColumn</code> marks the one column that names the row.</>}
    dontExample={<StaticTable headers={rosterHeaders} rows={[[{ content: 'Jul 3', emphasis: 'title' }, { content: 'Priya Nair', emphasis: 'title' }, { content: '$32.00', align: 'number', emphasis: 'title' }]]} />}
    dontCaption="Emphasis on every cell, so nothing stands out."
/>

### Keep a cell to one line.

<DoDontPair
    doExample={<div style={{ width: 360 }}><StaticTable headers={[{ text: 'Student' }, { text: 'Note' }]} rows={[['Priya Nair', 'Needs a longer session on fractions and ratios this week']]} /></div>}
    doCaption="Long text truncates with an ellipsis and shows in full in a tooltip."
    dontExample={<div style={{ width: 360 }}><StaticTable headers={[{ text: 'Student' }, { text: 'Note' }]} rows={[['Priya Nair', { content: 'Needs a longer session on fractions and ratios this week', overflow: 'wrap' }]]} /></div>}
    dontCaption="Every cell wrapped, so rows grow uneven."
/>

## Accessibility

- **It is a real table.** Headers are `th` in a `thead`, so a screen reader announces the column for each cell.
- **Rows are not controls.** Nothing in a Static table takes focus; a table people interact with is a Dynamic table.
- **State is not color alone.** A selected row sets `aria-selected`, a disabled row `aria-disabled`.
- **Truncated text keeps its full value.** A cell that ends in an ellipsis shows the whole text in a tooltip.
