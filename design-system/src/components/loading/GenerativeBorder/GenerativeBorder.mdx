## When to use

Use `GenerativeBorder` only while PLUS AI is generating into a piece of content, one ring per piece. It is never decoration, and two must not nest. For other waits, use `Spinner` or `Skeleton`.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Wrap the content and toggle `isActive`.

```jsx
<GenerativeBorder isActive={isGenerating} radius="radius-100">
    <Card>{draft}</Card>
</GenerativeBorder>
```

### Match `radius` to the wrapped content.

The wrapper is as wide as its parent, so set the width of the thing it surrounds.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **`aria-busy` says content is changing.** The wrapper sets it from `isActive`; the ring itself is decorative and hidden from assistive technology.
- **Motion respects the user.** The segments turn slowly while active and hold still under reduced motion.

</div>

<div className="sb-ds-doc-section">
