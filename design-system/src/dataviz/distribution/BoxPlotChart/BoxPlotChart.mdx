## When to use

Use `BoxPlotChart` to compare how spread out a measure is across groups: test
scores by class, session length by subject, tutor ratings by school. It shows
whether groups differ in their middle and in how far they stretch, which an
average alone hides.

For the full shape of one distribution, use `HistogramChart`. For a plain
low-to-high span with no quartiles, use `ColumnRangeChart`. For one value per
group, use `BarChart`; for change over time, use `LineChart`.

Box plots assume readers know what a quartile is. For a general audience, add
a line of copy saying what the box and whiskers mean.

## Data shape

`categories` is an array of strings. `data` holds one array per category, in
the same order: `[low, q1, median, q3, high]`. The chart draws the numbers it is
given; compute them before passing them in. `height` defaults to 400.

```jsx
<BoxPlotChart
    yAxisLabel="Session length (min)"
    categories={['Math', 'Reading', 'Science']}
    data={[
        [20, 32, 41, 50, 62],
        [18, 28, 35, 44, 55],
        [25, 34, 40, 48, 58],
    ]}
/>
```

There is one series and no outlier points. If the low and high are trimmed
(say, to the 5th and 95th percentiles), say so in the description.

## Color and accessibility

- **One color.** Box, stem and whiskers take `--ds-chart-categorical-1`; there is only one series, so color names nothing and the chart reads without hue.
- **Position carries the values.** Every number is read off the value axis, and the median line contrasts with the box fill rather than relying on hue.
- **Keep the groups few.** Past about ten boxes, the category labels crowd and comparison gets hard; split the chart or filter.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

</div>

## States

`BoxPlotChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <BoxPlotChart categories={categories} data={data} yAxisLabel="Test score" />}
```
