## When to use

Use `AiMessage` for every reply an assistant writes: in the AI chat, in a panel,
anywhere text comes from the model. Show `thinking` from the moment a message is
sent until the first text arrives, `streaming` while text arrives, then
`complete`.

## Usage notes

### Show the state, not a blank.

```jsx
// Incorrect: nothing appears until the whole reply is ready.
{reply ? <AiMessage text={reply} /> : null}

// Correct: the typing indicator holds the place, then text streams in.
<AiMessage status={reply ? 'streaming' : 'thinking'} text={reply} />
```

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **Busy while arriving.** A streaming or thinking message is marked
  `aria-busy`, so a screen reader waits for the finished text.
- **Announced indicator.** The typing indicator is a status named "AI is writing";
  its dots are hidden from assistive technology.
- **Reduced motion.** The caret and dots stop animating, and typed-out text
  shows at once.
