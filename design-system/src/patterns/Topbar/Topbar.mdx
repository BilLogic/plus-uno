<Title>Topbar</Title>
The Topbar is the top row of the page frame, 32 high. It holds the sidebar toggle at the start, the page's breadcrumb in the middle, and Help Center and the account at the end. It is a part of the surface container and sits in the frame's topbar slot.

The examples on this page follow the **Color mode** switch in the toolbar.

### When to use it

Use the Topbar in the surface container's topbar slot, so every page has the same toggle, trail and account in the same place. The frame owns the sidebar state and hands it to the Topbar, so there is one toggle.

The trail is always a Breadcrumb and never plain text, so the current page truncates and Help Center and the avatar stay whole at 768. For the account, use the User avatar. For a heading inside the page, use a **Section header**, not the Topbar.

### Anatomy

1. **Start** is the left area, padded 8 on the left so the toggle sits at the container pad. Docked, it is 240 wide. Otherwise it hugs the toggle and pads 12 before the breadcrumb.
2. **Sidebar toggle** is a primary tonal icon-only Button at 32.
3. **Middle** is a Breadcrumb that fills what is left. It stays on one line, and its crumbs end in an ellipsis rather than wrap.
4. **Help Center** is a secondary text icon Button with the circle-question icon.
5. **User avatar** is the account: an initial, a name and a role, at size md.

Help Center and the avatar sit 12 apart and 12 after the breadcrumb.

### Accessibility

- The toggle is a button with a name that changes with the state: "Close sidebar" while docked, "Open sidebar" otherwise. It reports whether the sidebar is showing.
- Help Center is an icon-only button, so it carries the name "Help Center".
- The breadcrumb is a navigation landmark, and its last item is the current page.
- The toggle, Help Center and the avatar are each 32 high.
