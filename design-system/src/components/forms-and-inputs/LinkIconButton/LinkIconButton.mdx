## Usage

Use a link icon button when an icon alone opens another page or site and space is limited, such as the Help Center link in the top bar. For an icon that acts on the current page, use Icon button. For a link with a label, use Link button.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Container.** An anchor drawn as a square button: 32 at default spacing and 24 at compact. `shape="circle"` rounds it.
2. **Icon.** A Font Awesome Free glyph at 16.
3. **Label.** Not drawn. It is the accessible name and the tooltip, and says where the link goes.

## Best practices

### Keep space between link icon buttons.

Leave a gap so neighboring link icon buttons read as separate targets.

<DoDontPair
    doExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><LinkIconButton href="#help" icon="circle-question" label="Open Help Center" /><LinkIconButton href="#settings" icon="gear" label="Open settings" /><LinkIconButton href="#notifications" icon="bell" label="Open notifications" /></div>}
    doCaption="A clear gap between link icon buttons."
    dontExample={<div style={{ display: 'flex', gap: 0 }}><LinkIconButton href="#help" icon="circle-question" label="Open Help Center" /><LinkIconButton href="#settings" icon="gear" label="Open settings" /><LinkIconButton href="#notifications" icon="bell" label="Open notifications" /></div>}
    dontCaption="Link icon buttons touching."
/>

### Say where the link goes.

The `label` is the accessible name and the tooltip. Name the destination:
"Open Help Center", not "Link" or a bare "Help". The label is never drawn, so
the difference shows only on hover, on focus and to a screen reader.

```jsx
// Incorrect: says nothing about the destination.
<LinkIconButton href="/help" icon="circle-question" label="Link" />

// Correct.
<LinkIconButton href="/help" icon="circle-question" label="Open Help Center" />
```

### Keep it square.

Link icon buttons stay 32 or 24 square, and round only in top navigation
(`shape="circle"`). Link icon button has no prop to fill its container; never
stretch one to fill a row.

### A link goes somewhere; a button does something.

If the icon acts on the current page, use Icon button. Navigation uses a link icon button so assistive technology announces a link and it can be opened in a new tab.

### Pick a glyph people know.

Use the glyph people already read as that destination.

<DoDontPair
    doExample={<LinkIconButton href="#help" icon="circle-question" label="Open Help Center" />}
    doCaption="A question mark reads as help."
    dontExample={<LinkIconButton href="#help" icon="star" label="Open Help Center" />}
    dontCaption="A star does not read as the Help Center."
/>

### Give each destination its own glyph.

Do not reuse one glyph for several links in the same area.

<DoDontPair
    doExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><LinkIconButton href="#help" icon="circle-question" label="Open Help Center" /><LinkIconButton href="#settings" icon="gear" label="Open settings" /></div>}
    doCaption="Help Center and settings each have their own glyph."
    dontExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><LinkIconButton href="#help" icon="link" label="Open Help Center" /><LinkIconButton href="#settings" icon="link" label="Open settings" /></div>}
    dontCaption="One link glyph for two destinations."
/>

</div>

## Accessibility

- `label` is required and says where the link goes. A missing label fails `check:icon-button-name`.
- It has no disabled state. Disabled links leave the tab order and do not say why; use validation and error messages instead.
- `target="_blank"` adds `rel="noopener noreferrer"`; say so in the label if it opens a new tab.
- The focus ring is 2px in `--ds-border-focused`. Never remove it.
