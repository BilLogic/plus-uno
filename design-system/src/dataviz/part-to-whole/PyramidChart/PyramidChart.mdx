## When to use

Use `PyramidChart` for a short series of levels where each is smaller than the
one beneath it and the shape itself tells the story: students referred, then
enrolled, then attending weekly, then meeting their goal; tutors in training,
then certified, then leading sessions.

For stages that narrow from top to bottom, use `FunnelChart`. For levels with
no built-in order, or values that must be compared precisely, use `BarChart`.
For parts of one total with no levels, use `PieChart`.

## Data shape

`data` is an array of `{ name, value }`, one object per band. List it from the
base up, largest first.

```jsx
<PyramidChart
    data={[
        { name: 'Referred', value: 1200 },
        { name: 'Enrolled', value: 840 },
        { name: 'Attending weekly', value: 510 },
        { name: 'Met their goal', value: 230 },
    ]}
/>
```

Values print with thousands separators and no decimals.

## Color and accessibility

- **Color is assigned by position.** The chart sets no colors of its own and takes no per-item `color`, so bands draw from the theme's categorical order, base first.
- **Labels carry the value.** Every band is labeled with its name and number, so the chart reads without hue. Band size is hard to judge by eye, since a band's width changes along its height; read the labels, not the shape, for exact figures.
- **Keep it short.** Four to six levels keep the bands tall enough for their labels.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation through the bands. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`PyramidChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No students yet" description="Levels appear after the first referral." />
    : <PyramidChart data={data} />}
```
