# Student roster table

Build this view in `src/`, with the PLUS design system.

A table of a tutor's students: name with avatar, grade, school, last session date, and attendance rate. The table sorts by name and by last session. Build all four states and add a small control at the top to switch between them for review: **loading** (data on its way), **empty** (no students yet, with a way to invite one), **error** (the roster failed to load, with a retry), and **loaded** (at least 10 students).

When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
