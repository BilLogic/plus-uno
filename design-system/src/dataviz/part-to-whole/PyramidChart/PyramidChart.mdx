## When to use

Use `PyramidChart` for four to six ordered levels where each tier is smaller
than the one beneath it, such as students referred → enrolled → attending weekly
→ meeting their goal, or tutors in training → certified → leading sessions.

For stages narrowing top to bottom, use `FunnelChart`. For unordered levels or
exact comparisons, use `BarChart`. For parts of a total without levels, use
`PieChart`.

## Data shape

`data` is an array of `{ name, value }`, ordered from the base up (largest
first).

```jsx
<PyramidChart
    data={[
        { name: 'Referred', value: 1200 },
        { name: 'Enrolled', value: 840 },
        { name: 'Attending weekly', value: 510 },
        { name: 'Met their goal', value: 230 },
    ]}
/>
```

## Color and accessibility

- **Color by position.** Bands take the theme's [categorical order](?path=/docs/data-visualizations-color--docs) from the base up, with no per-item `color` override.
- **Labels carry exact figures.** Because tapered band widths distort visual area, rely on the printed name and number labels rather than shape or hue.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

</div>

## States

`PyramidChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No students yet" description="Levels appear after the first referral." />
    : <PyramidChart data={data} />}
```
