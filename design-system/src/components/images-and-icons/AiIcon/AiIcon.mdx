## Usage

Use `AiIcon` for AI actions. For other actions, use a plain Font Awesome Free glyph.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Glyph.** A Font Awesome Free shape for the action: generate, ask, rewrite, summarize, plan, suggest or stop generating.
2. **Sparkle.** One four-point sparkle at the top right, with a gap cut around it. Generate is the sparkle alone; stop generating has none.
3. **Size.** 12 (generate and stop generating only), 16 or 24.

## Best practices

### Pair it with visible text, or give it a `label`.

Without `label` the icon is hidden from assistive technology.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><AiIcon name="summarize" label="Summarize" /><span>Summarize</span></div>}
    doCaption="The icon beside the verb it stands for."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><AiIcon name="summarize" /></div>}
    dontCaption="A bare icon with no text and no label, so it has no name."
/>

### Pick `name` from the set.

`generate`, `ask`, `rewrite`, `summarize`, `plan`, `suggest` and `stop-generating`.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><AiIcon name="ask" label="Ask" /><AiIcon name="rewrite" label="Rewrite" /><AiIcon name="plan" label="Plan" /></div>}
    doCaption="One icon for each action it names."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><AiIcon name="ask" label="Rewrite" /><AiIcon name="ask" label="Plan" /></div>}
    dontCaption="One icon reused for different actions."
/>

### Use it for AI actions only.

An AI icon marks something generative. Use a plain Font Awesome icon for an action that is not.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><AiIcon name="generate" label="Generate" /><span>Generate</span></div>}
    doCaption="The sparkle marks something generative."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><AiIcon name="generate" label="Download" /><span>Download</span></div>}
    dontCaption="The sparkle on an action that is not AI."
/>

## Accessibility

- **Labeled or hidden.** With `label` the icon is `role="img"` named by it. Without, it is `aria-hidden`.
- **Color follows the text.** It fills with `currentColor`, so it keeps contrast with its surroundings.
