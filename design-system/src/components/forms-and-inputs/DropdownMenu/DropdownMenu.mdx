## Usage

Use a dropdown menu for a trigger that opens a list of actions or navigation links. Its rows are the public Menu family: Section, Button item, Link item and Custom item. For picking one value from a list of options, use Select: a dropdown menu is for actions, a select is for a value.

`trigger` is the element that opens it, `children` are its rows. `isOpen` and `onOpenChange` make it controlled; left uncontrolled it opens and closes on its own. `placement` and `shouldFlip` govern where it opens and whether it flips when there is no room. `spacing` is `cozy` (40 rows, the default) or `compact` (32). `loading` swaps the rows for a spinner while its options are still being fetched.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Trigger.** Any element that opens the menu, usually a Button with a chevron.
2. **Menu.** A floating list 4px from the trigger, on the raised surface.
3. **Rows.** Button items, Link items or Custom items, 40 tall at cozy and 32 at compact.
4. **Section title and separator** (optional). Group related rows.

## Best practices

### A row closes the menu unless it opts out.

```jsx
// Picking "Rename" closes the menu: the common case for an action list.
<DropdownMenu trigger={<Button text="Actions" iconAfter={<i className="fa-solid fa-chevron-down" />} />}>
    <ButtonItem onClick={onRename}>Rename</ButtonItem>
    <ButtonItem onClick={onArchive}>Archive</ButtonItem>
</DropdownMenu>

// A toggle row that should stay open across repeated picks carries
// `data-keep-open`, as a multi-select tag or filter row does.
<ButtonItem onClick={toggleStarred} isSelected={starred} data-keep-open="true">
    Starred
</ButtonItem>
```

### A static row never closes the menu.

A Custom item with no `component` override (its default, `div`) renders a row that only says its words: nothing to press, nothing to focus, and it leaves the menu open.

### Use a menu for actions and a select for a value.

Rows that set a value belong in a Select, which shows the chosen value on its trigger. A dropdown menu's rows do something: rename, archive, share.

### Group related items and keep destructive ones last.

Order items by task and put Delete at the bottom, away from the common actions.

<DoDontPair
    doExample={<div inert aria-hidden="true"><MenuGroup minWidth="var(--width-1500)"><ButtonItem>Rename</ButtonItem><ButtonItem>Duplicate</ButtonItem><ButtonItem>Archive</ButtonItem><ButtonItem>Delete</ButtonItem></MenuGroup></div>}

### Start each item with a verb, in sentence case.

Verb-first labels read as actions. All caps and noun-only labels slow scanning.

<DoDontPair
    doExample={<div inert aria-hidden="true"><MenuGroup minWidth="var(--width-1500)"><ButtonItem>Rename</ButtonItem><ButtonItem>Duplicate</ButtonItem><ButtonItem>Archive</ButtonItem></MenuGroup></div>}
    doCaption="Verb first, sentence case."
    dontExample={<div inert aria-hidden="true"><MenuGroup minWidth="var(--width-1500)"><ButtonItem>NAME</ButtonItem><ButtonItem>COPY</ButtonItem><ButtonItem>FILE</ButtonItem></MenuGroup></div>}
    dontCaption="All caps and noun-only labels."
/>

### Keep item labels short and distinct.

One or two words each. Long, near-identical labels make the choice harder and wrap.

<DoDontPair
    doExample={<div inert aria-hidden="true"><MenuGroup minWidth="var(--width-1500)"><ButtonItem>Rename</ButtonItem><ButtonItem>Duplicate</ButtonItem><ButtonItem>Archive</ButtonItem></MenuGroup></div>}
    doCaption="Short, distinct labels."
    dontExample={<div inert aria-hidden="true"><MenuGroup minWidth="var(--width-1500)"><ButtonItem>Archive this session now</ButtonItem><ButtonItem>Archive this session later</ButtonItem><ButtonItem>Archive this session today</ButtonItem></MenuGroup></div>}
    dontCaption="Long, near-identical labels."
/>

### Nested menus are not yet built.

The public Menu family has no submenu-trigger row of its own yet. Flatten the choices or use sections.

## Accessibility

- **The trigger announces the menu.** Its trigger carries `aria-haspopup="menu"` and an `aria-expanded` that tracks the open state.
- **Arrow keys move between rows**, Enter and Space pick the row at the cursor, and Escape closes the menu and returns focus to the trigger.
- **A disabled row is out of the tab order** and cannot be picked.
- **Disabled is not color alone:** the row sets `aria-disabled`.
