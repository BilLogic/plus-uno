## Usage

Pass the icon's name to the component that shows it. Where no component takes the name, draw the glyph yourself:

```jsx
import { iconClass } from '@/lib/icon';

<i className={iconClass('calendar-days')} aria-hidden="true" />
```

`iconClass(name)` returns `fa-regular fa-<name>` where Font Awesome Free has a regular weight, and `fa-solid fa-<name>` where it does not. Use the current name: an alias such as `calendar-alt` is not in the regular list, so it draws solid. Only the Free families draw: `fa-solid`, `fa-regular` and `fa-brands`.

## Parts

1. **Glyph.** An `i` element with the family and name classes, sized by an icon size token and colored by an icon color token.

### States

An icon has no state of its own: hover, pressed, focus and disabled belong to the control around it.

## Accessibility

- A glyph is decoration: draw it with `aria-hidden="true"`, and let the words beside it, or the control's label, carry the meaning.
- An icon-only control is named by its `label`, as Icon button is.
