## When to use

Use `TreegraphChart` for non-people hierarchies, such as subject → topic →
lesson, prerequisite chains or session decision paths.

For reporting lines, use `OrganizationChart`. For hierarchies sized by value,
use `TreemapChart` or `SunburstChart`. For graphs with multiple parents or
cycles, use `NetworkGraph`.

## Data shape

`data` is a flat array of `{ id, parent, name }`: unique `id` (required),
`parent` set to the parent's `id` (omitted on roots), and `name` for the label.

```jsx
<TreegraphChart
    data={[
        { id: 'math', name: 'Math' },
        { id: 'fractions', parent: 'math', name: 'Fractions' },
        { id: 'ratios', parent: 'math', name: 'Ratios' },
        { id: 'equivalent', parent: 'fractions', name: 'Equivalent fractions' },
        { id: 'unit-rates', parent: 'ratios', name: 'Unit rates' },
    ]}
/>
```

## Color and accessibility

- **Depth-based color.** Colors mark tree depth rather than individual nodes; levels, links and labels carry the hierarchy without hue.
- **Check label legibility across modes.** Node labels use `--ds-text` without an outline on colored fills, so verify legibility in both light and dark modes.
- **Avoid wide crowding.** Many siblings at one level squeeze labels; collapse branches or split the tree.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`TreegraphChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={500} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Topic tree could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No topics yet" description="Topics appear once a subject's lessons are added." />
    : <TreegraphChart data={data} />}
```
