## When to use

Use `HeatmapChart` to find patterns across two sets of categories: sessions by
weekday and hour, students by SMART competency, tutor availability by day and
time slot. It suits questions like "when are we busiest" or "which skills lag",
where the shape matters more than any one number.

For exact values, use a table. For one measure over time, use `LineChart`. For
individual points rather than a grid, use `ScatterChart`. For one dimension
rather than two, use `HistogramChart`.

## Data shape

`xCategories` and `yCategories` are arrays of strings. `data` is an array of
`[x, y, value]`, where `x` and `y` are indexes into those arrays. `height`
defaults to 400.

```jsx
<HeatmapChart
    xCategories={['Mon', 'Tue', 'Wed', 'Thu', 'Fri']}
    yCategories={['3pm', '4pm', '5pm']}
    data={[
        [0, 0, 12], [0, 1, 30], [0, 2, 18],
        [1, 0, 15], [1, 1, 34], [1, 2, 22],
        [2, 0, 10], [2, 1, 28], [2, 2, 25],
        [3, 0, 14], [3, 1, 36], [3, 2, 20],
        [4, 0, 8],  [4, 1, 19], [4, 2, 11],
    ]}
/>
```

## Color and accessibility

- **A sequential ramp by default.** `hue` (default `blue`) picks one of the chart hues: blue, teal, green, lime, yellow, orange, red, magenta, purple, gray or brown. The ramp runs through four tokens, evenly spaced: `--ds-background-accent-{hue}-subtler` for the lowest value, then `--ds-chart-{hue}-bold`, `--ds-chart-{hue}-bolder` and `--ds-chart-{hue}-boldest` for the highest. Each step sits further from the surface than the last, so the biggest value is darker in light mode and lighter in dark.
- **A diverging ramp on request.** `diverging={[low, high]}` takes two different hues and overrides `hue`. It builds seven steps: the low hue from `boldest` down to `bold`, the neutral midpoint `--ds-background-accent-gray-subtler`, then the high hue from `bold` up to `boldest`. Orange and blue stay apart under every common color-vision deficiency; never pair red with green.
- **The ramp spans the data.** The lowest value takes the lightest step and the highest the strongest, not rounded ticks. Set `min` and `max` to fix the scale, so two heatmaps compare on the same ramp. For a diverging ramp, set them an equal distance either side of the baseline: the midpoint lands halfway between `min` and `max`, not at zero.
- **Resolved per color mode.** The color bar blends between its stops, so it needs real colors, not token references. The chart reads each token's current value and reads them again whenever the color mode or contrast setting changes.
- **Labels pick their ink.** Each cell label takes `--ds-text` or `--ds-text-inverse`, whichever contrasts more with that cell.
- **Color is the only encoding.** Cells are all the same size, so the value lives in shade alone. Keep `showDataLabels` on wherever the grid is large enough; with labels off, readers who cannot tell the tones apart get only the tooltip.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`HeatmapChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Session activity could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="Activity appears after the first week of sessions." />
    : <HeatmapChart xCategories={days} yCategories={hours} data={data} />}
```
