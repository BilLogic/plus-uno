## Usage

Use Search when a person is looking for rows by what they are called, inside the Section they are looking at. Search narrows as you type; it is not a filter, so it keeps its own icon before the filters and never shares a count with them. Server-backed lists narrow the same way through <a target="_top" href="./?path=/docs/components-forms-and-inputs-popup-select--docs">Popup select</a>'s `loadOptions`, 50 at a time.

## Best practices

### Narrow the rows as the person types.

<RuleTag kind="review" />

No submit, no results page. The table under the bar narrows and the count updates in words: "2 of 6 students". Loading, empty and no-match states happen inside the table, so the view bar stays usable.

### Grow the Search icon into the field and shrink it back when empty.

<RuleTag kind="review" />

The field stays open while it holds text. Leaving an empty field shrinks it back to the icon. The icon sits before the filters, at the height every bar control shares. The animated grow and shrink are Planned <PlannedTag />.

### Clear on Esc and close on a second Esc.

<RuleTag kind="review" />

The first Esc empties the text and keeps the field; the second closes it and returns focus to the icon. The in-field button is named "Clear search".

### Name the scope in the placeholder and the accessible name.

<RuleTag kind="review" />

"Search students", never "Search…". There is no visible label; the icon and the placeholder say what is searched.

<DoDontPair
    doExample={<TextField label="Search students" isLabelHidden placeholder="Search students" spacing="compact" />}
    doCaption="The placeholder names the scope."
    dontExample={<div style={{ display: 'flex', gap: 'var(--inline-md)', alignItems: 'center' }}><TextField label="Search" isLabelHidden placeholder="Search…" spacing="compact" /><Button text="Go" spacing="compact" /></div>}
    dontCaption={'"Search…" with a Go button: the scope is unnamed and the rows wait for a press.'}
/>

### Keep the search across views.

<RuleTag kind="review" />

Switching pills keeps the text, so a person can compare views on one name. "Reset filters" clears the search too. Leaving the page clears it <PlannedTag />.

### Name what was searched when nothing matches.

<RuleTag kind="review" />

The empty state replaces the table whole and says what matched nothing. See <a target="_top" href="./?path=/docs/patterns-states-empty--docs">Empty</a>.

## Accessibility

- The icon button is named "Search students"; the field takes the same name, so a screen reader hears the scope either way.
- The count is a polite live region that announces "2 of 6 students" as the rows narrow.
- Tab enters the field; Esc clears, then closes; closing returns focus to the icon.
- Focus stays in the field when the list empties; it never jumps to the empty state.
