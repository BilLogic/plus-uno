<FoundationSection title="The categorical order">

Multi-series charts assign colors in slot order from <C>--ds-chart-categorical-1</C> through <C>-8</C>. Slots 7 and 8 are overflow for charts past six series, which you should usually avoid by grouping smaller categories into "Other". See [Color](?path=/docs/foundations-visual-color--docs) for how the sequence is constructed.

</FoundationSection>

<FoundationSection title="Reads the same without hue">

Lightness alternates across the categorical sequence, so the order still holds when desaturated.

<Canvas of={ColorStories.CategoricalGrayscale} sourceState="none" />

</FoundationSection>

<FoundationSection title="Separators">

Lightness alternation identifies *which series* a mark belongs to; a separator (a gap or <C>--ds-border-inverse</C> stroke between touching marks) shows *where one mark ends and the next begins*. Include both so marks stay distinct without hue or across close tones.

<Canvas of={ColorStories.SeparatorCompare} sourceState="none" />

</FoundationSection>
