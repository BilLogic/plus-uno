<Title>Sidebar</Title>
The sidebar is the app's side navigation: a header with the logo, the top-level items, then sections. A section is a group label, its items and an optional divider, and every item is a Sidebar tab. It is a part of the surface container. In code, the foundation is `PatternSidebar` and `Sidebar` fills it with the PLUS content for each role.

The examples on this page follow the **Color mode** switch in the toolbar.

### When to use it

Use the sidebar for the app's top-level destinations. Content comes from one config per role: a tutor sees Home, Training and Toolkit, and a supervisor adds Admin. Never draw a second sidebar for a role.

A label truncates at one line. It never wraps or widens the 240 sidebar.

For a place inside a page, use **Tabs**. For one destination on its own, use a link. For the row itself, see the **Sidebar tab** component.

### Anatomy

1. **Header** is the logo, padded 6 and 8. It sits outside the scroller, so it stays put.
2. **Body** holds the top-level items, then the sections. Past the frame's height it scrolls inside the sidebar.
3. **Section label** is a 12 semibold group name, padded 6 and 12. It names a group and is not a heading.
4. **Item** is a Sidebar tab: at least 32 high, a 16 icon, a label that truncates, and the description, elemAfter and actionsOnHover slots.
5. **Divider** is optional, after a section: a Divider inset 12.

Rows sit 4 apart, and the sidebar pads 8 at the sides.

### Open tabs

An opened record, such as a session or a student, becomes a temporary tab under the item it belongs to. Several can be open at once, and each one can be closed. They are open records, not nested pages. Toolkit › Sessions and Toolkit › Students use them first.

#### Parts

1. **Parent** is the item as an accordion. Its chevron is a disclosure button that hides and shows the tabs, and the list opens on its own when a tab is opened. The label still opens the item's own page. On hover or focus it shows "Close all".
2. **Tab** has two parts side by side: a 28 thread column, and a surface that is a Sidebar tab without an icon. The title truncates. A live session shows a green Count dot named "Live". On hover or focus it shows a close button named "Close" plus the title.
3. **Show more** is the row after the 5 most recent tabs, "Show N more", in the subtlest text color.
4. **Thread** is the line that ties the tabs to their parent. It hangs from the parent row and runs unbroken beside every tab. It ends at the last row in a rounded elbow. The last row is "Show N more" when it shows. The thread never changes with the row's state.

#### Open tab states

Rest, hover, pressed, selected, selected and hovered, and focus all draw on the tab's surface. The thread stays the same in every state.

#### Rules

- Opening a record adds its tab under the item it belongs to and selects it.
- Closing the selected tab selects its parent.
- The 5 most recent tabs show, then "Show N more". A selected tab older than the five still shows, after them.
- Tabs are session-scoped. They survive a reload and clear at sign-out or when the browser session ends.
- Tabs never change routing or deep links. Each record keeps its own route, and the tab links to the page that already shows it. Never duplicate a record's detail to make a tab.

#### For developers

Keep the tabs with `useOpenTabs`, and call `clearOpenTabs()` at sign-out. Nothing in the model reads or writes the URL.

```jsx
import PatternSidebar, { useOpenTabs } from '@/patterns/Sidebar';

const tabs = useOpenTabs();
// Wherever a page opens a record:
tabs.open('sessions', { id: 's1', title: 'Hogwarts · Tue, Sep 9', href: '/toolkit/sessions', status: 'live' });

<PatternSidebar
    items={items}
    sections={sections}
    activeId={tabs.selectedId}
    openTabs={tabs.byParent}
    onTabSelect={(tab) => tabs.select(tab.id)}
    onTabClose={(tab) => tabs.close(tab.id)}
    onTabsCloseAll={(item) => tabs.closeAll(item.id)}
/>
```

### Accessibility

- The sidebar is a navigation landmark. <code>label</code> names it, "Main" by default.
- A section label names a <code>role="group"</code>. It is not a heading, so the sidebar adds no headings to the page outline.
- The selected item carries <code>aria-current="page"</code>. A disabled item is announced and skipped by Tab.
- An external link opens a new tab and says so to a screen reader.
- Tab reaches each row in order, and the focus ring is 2px in <code>--ds-border-focused</code>, drawn 2px outside the row.
- A parent's chevron is a button with an expanded state, and it points at the list it shows. Its name reads "Sessions tabs", for example.
- Each tab's close button is named "Close" plus the title. Delete or Backspace closes the focused tab.
- A live tab's dot is named "Live", so the row is announced as live.
- Hover-only controls, such as the close button and Close all, also appear on focus.
