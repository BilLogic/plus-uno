## Usage

Use `ProgressTracker` when each step of a journey has its own name people
need to see and, often, jump back to — a multi-page form, a setup flow, a
reflection with named sections. When position alone is enough and the steps
have no names to show, use `ProgressIndicator` instead.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Marker.** A dot for unvisited, current and disabled steps; a success check for a visited step.
2. **Label.** One line, truncating with an ellipsis.
3. **Step.** A link, a button or plain text, with <code>aria-current="step"</code> on the current one.
4. **Rule.** A hairline joining horizontal steps.

## Best practices

### An item's status and its action are set separately.

`status` alone decides how a step looks. Give any non-`disabled` item an `href` or `onClick` to make it reachable; without either, it renders as plain text even if its status says it can be revisited.

```jsx
<ProgressTracker
    items={[
        { id: 'info', label: 'Session information', status: 'visited', onClick: goTo('info') },
        { id: 'reflection', label: 'Student reflection', status: 'current' },
        { id: 'feedback', label: 'Form feedback', status: 'disabled' },
    ]}
/>
```

### Let people go back to a step they finished.

Give a `visited` step an action so it can be reopened. Leave a step that cannot be reached yet `disabled`.

<DoDontPair
    doExample={<ProgressTracker label="Do: reachable visited step" items={[
        { id: 'a', label: 'Session information', status: 'visited', onClick: () => {} },
        { id: 'b', label: 'Student reflection', status: 'current' },
        { id: 'c', label: 'Form feedback', status: 'disabled' },
    ]} />}
    doCaption="A finished step opens again; a step not yet reachable is disabled."
    dontExample={<ProgressTracker label="Don't: visited step with no action" items={[
        { id: 'a', label: 'Session information', status: 'visited' },
        { id: 'b', label: 'Student reflection', status: 'current' },
        { id: 'c', label: 'Form feedback', status: 'unvisited', onClick: () => {} },
    ]} />}
    dontCaption="A finished step is plain text, while a step not yet ready can be opened."
/>

### Keep labels short.

One line per step, a few words. A long label truncates with an ellipsis.

<DoDontPair
    doExample={<ProgressTracker label="Do: short labels" items={[
        { id: 'a', label: 'Information', status: 'visited', onClick: () => {} },
        { id: 'b', label: 'Reflection', status: 'current' },
        { id: 'c', label: 'Feedback', status: 'unvisited' },
    ]} />}
    doCaption="Each label names the task in a word or two."
    dontExample={<ProgressTracker label="Don't: long labels" items={[
        { id: 'a', label: 'Information about the session you just taught', status: 'visited', onClick: () => {} },
        { id: 'b', label: 'Your reflection on how the student did', status: 'current' },
        { id: 'c', label: 'Feedback on the form you filled out', status: 'unvisited' },
    ]} />}
    dontCaption="Sentence-length labels that cut off mid-word."
/>

### Use the vertical orientation when the row will not fit.

Stack the steps in a narrow column such as a sidebar; keep the row when there is width for it.

<DoDontPair
    doExample={<div style={{ width: 'calc(var(--control-sm) * 7)' }}><ProgressTracker label="Do: vertical in a narrow column" orientation="vertical" items={[
        { id: 'a', label: 'Information', status: 'visited', onClick: () => {} },
        { id: 'b', label: 'Reflection', status: 'current' },
        { id: 'c', label: 'Feedback', status: 'unvisited' },
    ]} /></div>}
    doCaption="Vertical steps in a narrow column, each label readable."
    dontExample={<div style={{ width: 'calc(var(--control-sm) * 7)' }}><ProgressTracker label="Don't: row in a narrow column" items={[
        { id: 'a', label: 'Information', status: 'visited', onClick: () => {} },
        { id: 'b', label: 'Reflection', status: 'current' },
        { id: 'c', label: 'Feedback', status: 'unvisited' },
    ]} /></div>}
    dontCaption="A row squeezed into a narrow column, so every label truncates."
/>

### A `disabled` item takes neither a link nor a button, whatever is passed.

This keeps a step someone cannot reach yet from being focusable or clickable, regardless of what `href` or `onClick` the caller supplies.

## Accessibility

- **A named landmark.** The tracker is a `nav` with `label` as its accessible
  name ("Progress tracker" by default), and its steps are an ordered list.
- **The current step is `aria-current="step"`.** Screen readers announce it
  as the one in progress.
- **Reachable steps are real links or buttons.** Tab reaches any non-`disabled`
  step that carries `href` or `onClick`; `disabled` steps are marked
  `aria-disabled` and are not in the tab order.

</div>
