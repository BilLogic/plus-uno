# Escalation review

Build this two-page flow in `src/`, with the PLUS design system.

Tutors escalate a session from their session reflection, and a supervisor reviews each one. **The list page** shows every escalation: the tutor's name, affiliation (*CMU*, *Pitt* or *Duquesne*), the date reported, the priority (blank until set, then *Low*, *Medium* or *High*) and the status (*Open* or *Closed*), open ones first. Choosing a row opens **the detail page** for that escalation: the tutor, the date, the tutor's reflection text, a control to set the priority, and a closure note, which is required to close it. Closing returns to the list with that row now *Closed* and its priority shown; leaving the detail page any other way changes nothing. Each page has its own address, so the browser's back and forward buttons move between them. Use realistic sample data (at least 8 escalations, some already closed).

When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
