## Usage

The Sidebar builds every row from its config, so a page passes `groups` to the Sidebar rather than placing rows. Reach for `SidebarTab` for a row of the same shape outside the Sidebar. Leave `state` on `enabled` or `selected`: the stylesheet draws hover and focus.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Icon.** A 16 Font Awesome Free glyph, hidden from assistive technology.
2. **Label.** Body/default, truncated with an ellipsis.
3. **Description** (optional). A second line in Body/small.
4. **Trailing slot** (optional). A count, a badge or a status.
5. **Actions** (optional). Controls beside the row, shown on hover and focus.

## Accessibility

- A row with `onClick` is a button: Enter and Space activate it. A row with `href` is a link.
- The selected row carries `aria-current="page"`, so selection never rests on the fill alone.
- An external link announces "(opens in a new tab)".
