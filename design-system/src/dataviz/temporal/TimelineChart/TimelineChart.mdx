## When to use

Use `TimelineChart` for a short sequence of milestones in order, such as a
student's path from application to completion, tutor onboarding steps or
program term phases.

Because events sit at equal spacing with no time scale, use `XRangeChart` when
durations or time gaps matter. For a measured value over time, use `LineChart`.
For stages with drop-off counts, use `FunnelChart`.

## Data shape

`data` is an array of `{ name, label, description }` in chronological order
(`name` required; `label` defaults to `name` and `description` to `''`).
`height` defaults to 400.

```jsx
<TimelineChart
    data={[
        { name: 'Matched', label: 'Matched with tutor', description: 'Placed in a Math group' },
        { name: 'First session', label: 'First session', description: 'Baseline SMART check-in' },
        { name: 'Midpoint', label: 'Midpoint review', description: 'Goals revisited with the tutor' },
        { name: 'Wrap-up', label: 'Term wrap-up', description: 'Final progress report shared' },
    ]}
/>
```

## Color and accessibility

- **Decorative event color.** Events cycle through the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1 (wrapping past eight) with no per-event `color` prop; order and text carry the meaning without hue.
- **Keep labels concise.** Because colliding labels are hidden rather than repositioned, keep copy short and event counts modest, or increase `height`.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`TimelineChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Milestones could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No milestones yet" description="Milestones appear as the student moves through the program." />
    : <TimelineChart data={data} />}
```
