## When to use

Use `SmartBarChart` for a small set of percentages read at a glance, such as
student share by grade, weekday attendance or unit completion. Each column's
track marks 100%, so the chart reads as "how full" rather than "how much".

For non-percentage values or exact axis readings, use `BarChart`. For a value
against a target, use `BulletChart`. For parts of one total, use
`StackedBarChart` or `DonutChart`.

Keep category labels to a single letter or day initial, which the axis is sized
for.

## Data shape

`data` is an array of `{ letter, height, color }` (all required): `height` is a
numeric string from `0` to `100`, `letter` labels the column, and `color` fills
it. The chart's `height` prop sets its pixel height (default 200).

```jsx
import { BRAND } from '@/dataviz/palette';

<SmartBarChart
    height={200}
    data={[
        { letter: 'M', height: '72', color: BRAND },
        { letter: 'T', height: '85', color: BRAND },
        { letter: 'W', height: '64', color: BRAND },
        { letter: 'T', height: '90', color: BRAND },
        { letter: 'F', height: '48', color: BRAND },
    ]}
/>
```

## Color and accessibility

- **Caller-assigned color.** `color` is required on every item. Use `BRAND` (`--ds-chart-brand`) for one measure across categories, or one hue from `sequentialRamp` (strongest step on the largest value) for ordered groups such as grades.
- **Fill height carries the value.** The chart reads without hue; never use color alone to flag a column as good or bad.
- **Hover-only numbers.** With no axis or data labels, exact values appear only in the tooltip. State key numbers in surrounding text or use `BarChart`.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Explain single-letter category labels in nearby text, and name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`SmartBarChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={200} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Attendance could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No attendance yet" description="Attendance appears after a session is logged." />
    : <SmartBarChart data={data} />}
```
