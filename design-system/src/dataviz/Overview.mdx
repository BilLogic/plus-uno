<FoundationSection title="Color do and don't">

<DoDont>
    <Do caption="Stay within five or six series so each keeps its categorical slot and legend label." code={`<BarChart

<DoDont>
    <Do caption="Use categorical colors to separate categories, and reserve state colors for state values." code={`<BarChart
    height={200}
    categories={['Math', 'Science', 'History']}
    series={[
        { name: 'Online', data: [40, 55, 30] },
        { name: 'In person', data: [52, 48, 41] },
    ]}
/>`}>
        <Story of={OverviewStories.CategoriesOnly} />
    </Do>
    <Dont caption="Do not mix categorical and state colors: one series reads as success and the other as nothing." code={`<BarChart
    height={200}
    categories={['Math', 'Science', 'History']}
    series={[
        { name: 'Online', data: [40, 55, 30], color: 'var(--chart-categorical-2)' },
        { name: 'In person', data: [52, 48, 41], color: chartPalette.STATUS.success },
    ]}
/>`}>
        <Story of={OverviewStories.CategoryAndStateMixed} />
    </Dont>
</DoDont>

- **Never rely on color alone.** Pair every series or state with a label, shape, pattern or table. Where a chart type leans on color, add a direct label.
- **Keep text off chart fills.** Place labels beside marks. When a label must sit on a fill, such as a heatmap cell, use <C>--ds-text</C> or <C>--ds-text-inverse</C>, whichever contrasts.
- **Sort categories from most to least.** Ordered sets such as grades or stages take one hue's sequential ramp, strongest tone on the largest value.
