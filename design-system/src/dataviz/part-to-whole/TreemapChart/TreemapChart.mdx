## When to use

Use `TreemapChart` when a total splits into more parts than a pie can hold and
the big parts matter most: tutoring hours by subject across a district,
library resources by type, sessions by school. Area makes the largest parts
obvious at a glance, and the rectangle uses space well on a dashboard.

`TreemapChart` takes one flat level of parts. For parts nested inside parts,
use `SunburstChart`. For two to five parts, use `PieChart` or `DonutChart`.
For values that must be compared or ranked precisely, use `BarChart`; area is
harder to judge than length.

## Data shape

`data` is an array of `{ name, value }`, one object per tile. Values are raw
amounts; the chart sizes each tile against the total.

```jsx
<TreemapChart
    data={[
        { name: 'Math', value: 1240 },
        { name: 'Reading', value: 860 },
        { name: 'Science', value: 520 },
        { name: 'Writing', value: 310 },
        { name: 'Other', value: 140 },
    ]}
/>
```

With `colorByPoint`, an item may carry its own `color`; leave it out and the
chart assigns one.

</div>

## Color and accessibility

- **Two ways to color.** With `colorByPoint`, each tile without a `color` takes the categorical order by position: slot 1 for the first item, slot 2 for the second. Sort `data` from most to least so the first slots land on the biggest tiles. With `colorByPoint={false}`, color repeats the value on a sequential ramp of `hue` (blue by default), the strongest tone on the biggest tile, and the ramp is resolved for the current color mode.
- **Area and labels carry the value.** Color either separates tiles or restates their size, so the chart reads without hue. The weak spot is small tiles: thin slivers are hard to compare and leave little room for a label, so the exact value is only in the tooltip.
- **Past six tiles, stop using categorical color.** Slots 7 and 8 exist for overflow only. With many tiles, prefer the sequential ramp, or group the smallest parts into "Other".
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation through the tiles. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`TreemapChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Tutoring hours could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState size="compact" header="No hours yet" description="Hours appear after a session is logged." />
    : <TreemapChart data={data} />}
```
