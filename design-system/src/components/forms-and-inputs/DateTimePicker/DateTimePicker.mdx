## When to use

Use `DateTimePicker` when a date and a time are one answer — a session's
start, a deadline. For a date with no time, use `DatePicker` alone; for a
time with no date, use `TimePicker` alone.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### `onChange` reports the date, the time and the combined moment.

Each field's change calls `onChange` with `{ date, time, utc }` — `date` and
`time` are the two fields' own display values, and `utc` is the ISO moment
once both halves are set, computed from `timeZone`. Store `utc`; show
`date`/`time` back to the person who typed them.

```jsx
<DateTimePicker
    label="Session start"
    dateValue={date}
    timeValue={time}
    onChange={({ date, time, utc }) => {
        setDate(date);
        setTime(time);
        setStartUtc(utc);
    }}
/>
```

### `label` names the whole field, not either input.

`htmlFor` points at the date input (or the time input, with `showDate`
false), but the label's text is read as the group's accessible name — both
the date and time inputs are additionally named off the "Date"/"Time"
section headings. `isLabelHidden` only hides the label visually; it is
still rendered and still names the group.

### A time-zone mismatch adds the other person's time, it doesn't replace yours.

`otherTimeZone` only changes the caption when it differs from the viewer's
own zone, and then it adds the other person's time rather than converting
the field itself — the fields always show the viewer's local time.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **One group, two named inputs.** The wrapper is `role="group"` named by
  `label`; the date and time inputs are each named by that label plus their
  own section heading, so a screen reader announces "Session start, Date"
  and "Session start, Time".
- **Validation and the time-zone caption are both wired through
  `aria-describedby`**, composed with anything already passed in rather than
  overwriting it.
- **`isLabelHidden` never removes the accessible name** — only its visible
  text.

</div>
