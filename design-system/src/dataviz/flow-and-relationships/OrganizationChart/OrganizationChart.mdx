## When to use

Use `OrganizationChart` for reporting lines between people or roles: the
program team, which lead tutors supervise which tutors, or who a support
request escalates to.

For a hierarchy that is not people, like subject to topic to lesson, use
`TreegraphChart`. For a hierarchy sized by a value, use `TreemapChart` or
`SunburstChart`. For relationships that are not a tree, use `NetworkGraph`.

Each box shows a name only. When the reader needs titles, contact details or
photos, build the structure from components instead.

## Data shape

`data` is an array of `[from, to]` pairs: the manager first, then the person who
reports to them. Boxes are created from the names, so every name must be unique.
Two people with the same name merge into one box.

```jsx
<OrganizationChart
    data={[
        ['Program Director', 'Lead Tutor, Math'],
        ['Program Director', 'Lead Tutor, Reading'],
        ['Lead Tutor, Math', 'Priya S.'],
        ['Lead Tutor, Math', 'Marcus T.'],
        ['Lead Tutor, Reading', 'Dana K.'],
    ]}
/>
```

## Color and accessibility

- **Color marks depth, not identity.** The top row is `--ds-chart-categorical-1` with `--ds-text-inverse` labels, the second row `--ds-chart-categorical-2`, the third `--ds-chart-categorical-3`. Every box is outlined in `--ds-chart-categorical-1`. There is no per-person color.
- **Position carries the structure.** Rows and lines show the hierarchy, so the chart reads without hue; the level colors repeat what position already says.
- **Wide trees overflow.** Many people on one row shrink the boxes until labels truncate. Split a large organization into one chart per team, or raise `height` for deep trees.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`OrganizationChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={500} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Team structure could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No team members yet" description="The structure appears once tutors are assigned to a lead." />
    : <OrganizationChart data={data} />}
```
