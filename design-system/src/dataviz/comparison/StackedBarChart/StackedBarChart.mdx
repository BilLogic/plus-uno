## When to use

Use `StackedBarChart` when both the category total and its makeup matter, such
as daily sessions split into 1-on-1 and group or weekly tutoring hours by
activity. Place the most important part at the bottom so it shares the zero
baseline; keep to a few segments since upper segments sit on moving baselines
and there is no legend.

For separate values without a total, use `BarChart`. For a single total split
into parts, use `PieChart` or `DonutChart`. For continuous composition over
time, use `AreaChart`.

## Data shape

`dates` is an array of category labels. `data` is an array of `{ segments }`,
one per date. Each segment is `{ value, height, color, textColor }`: `height`
(numeric string) sets the size, `value` sets the printed label, and `color` and
`textColor` are optional. Matching segment indexes across columns form a series.

```jsx
<StackedBarChart
    height={300}
    dates={['Mon', 'Tue', 'Wed', 'Thu', 'Fri']}
    data={[
        { segments: [{ value: '12', height: '12' }, { value: '30', height: '30' }] },
        { segments: [{ value: '18', height: '18' }, { value: '24', height: '24' }] },
        { segments: [{ value: '9', height: '9' }, { value: '33', height: '33' }] },
        { segments: [{ value: '15', height: '15' }, { value: '27', height: '27' }] },
        { segments: [{ value: '6', height: '6' }, { value: '20', height: '20' }] },
    ]}
/>
```

Keep `height` and `value` equal unless the printed label intentionally uses a
different unit; the chart does not verify that they match. `yLabels` is accepted
but unused.

## Color and accessibility

- **Color by stack position.** Segments without `color` take the [categorical order](?path=/docs/data-visualizations-color--docs) by index (bottom segment slot 1, next slot 2). Keep segment colors consistent across columns.
- **Automatic label ink.** Segment labels automatically pick the contrasting text token for their fill in the active color mode unless overridden by `textColor`.
- **No legend.** Because color alone distinguishes segments and series announce as `"Segment 1"`, `"Segment 2"`, name each segment in the surrounding header or caption.
- **Upper segments are hard to compare.** When comparing parts matters more than the total, use a grouped `BarChart`.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`StackedBarChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Sessions could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="Sessions appear after one is logged." />
    : <StackedBarChart dates={dates} data={data} height={300} />}
```

## Related

- For categories compared against each other rather than composed, use `BarChart`.
- For one total broken into parts with no categories, use `PieChart` or `TreemapChart`.
- For composition changing over time, use `AreaChart` or `StreamgraphChart`.
- For a running total built from gains and losses, use `WaterfallChart`.
