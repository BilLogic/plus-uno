# Content

What a tutor, student or school reads inside the app. A button label is as much
a component decision as its padding, so the rules sit with the design system.
Each file mirrors one human page in Storybook (Brand › Content) and the two
change together.

| Reach for | When the copy is |
|-----------|------------------|
| [voice-and-tone.md](voice-and-tone.md) | Choosing how it sounds, or how that shifts for the reader |
| [language.md](language.md) | Any word, name, sentence, date, time or number |
| [messages.md](messages.md) | An error, warning, success, info, empty or discovery message |

**Not this folder:** how *agents* write — commit messages, PRDs, Slack replies,
long-form articles. That is `docs/conventions/`.
