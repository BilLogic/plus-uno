## When to use

Use `EmptyState` when a view, panel, card or table has no content yet, in place
of a blank area or a bare "No results". It carries a picture, a header, one line
and one primary action.

<DocsTable>
    <thead>
        <tr><th>Prop</th><th>Type</th><th>What it does</th></tr>
    </thead>
    <tbody>
        <tr><td><code>header</code></td><td>node</td><td>What this view is, as a heading.</td></tr>
        <tr><td><code>description</code></td><td>node</td><td>One line on what goes here and what to do.</td></tr>
        <tr><td><code>image</code></td><td>node</td><td>Picture slot, such as an Illustration.</td></tr>
        <tr><td><code>icon</code></td><td>string</td><td>A Font Awesome Free solid name, used when there is no image.</td></tr>
        <tr><td><code>primaryAction</code></td><td>node</td><td>One filled Button.</td></tr>
        <tr><td><code>secondaryAction</code></td><td>node</td><td>An optional outlined Button.</td></tr>
        <tr><td><code>spacing</code></td><td>default | compact</td><td>A view or panel, or a table body or card.</td></tr>
    </tbody>
</DocsTable>

Use `default` for a view or panel and `compact` inside a Table or Card. Use an
SectionMessage, not an EmptyState, for a failure.

## Usage notes

### Invite; do not apologize.

```jsx
// Incorrect: apologetic, and no way forward.
<EmptyState header="Sorry, nothing to show" />

// Correct: says what goes here and offers the action.
<EmptyState
    header="No students yet"
    description="Add a student to start planning sessions."
    primaryAction={<Button text="Add student" appearance="primary" />}
/>
```

### One primary action.

```jsx
// Incorrect: two filled buttons compete.
<EmptyState primaryAction={<Button text="Add" appearance="primary" />} secondaryAction={<Button text="Import" appearance="primary" />} />

// Correct: the second action is outlined.
<EmptyState primaryAction={<Button text="Add" appearance="primary" />} secondaryAction={<Button text="Import" />} />
```

### Fill a Table with it, not around it.

```jsx
// Incorrect: a bare string.
<Table headers={headers} rows={[]} emptyState="No students" />

// Correct: the header stays and the EmptyState takes the body.
<Table headers={headers} rows={[]} emptyState={<EmptyState spacing="compact" header="No students yet" />} />
```

## Accessibility

- **A real heading.** The header is one level below the section that holds the
  EmptyState, so it joins the page outline.
- **Decorative picture.** The image and icon are hidden from screen readers; the
  words carry the meaning.
- **Contrast.** Header and description use the text roles, which pass in every
  color mode.
- **Reflow.** The text wraps inside a 480 wide column, and long words break.
