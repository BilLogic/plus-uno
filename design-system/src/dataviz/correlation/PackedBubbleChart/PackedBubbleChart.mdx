## When to use

Use `PackedBubbleChart` for a quick overview of relative sizes within groups,
such as course enrollment by subject, tutors per specialty or library lessons by
category.

For exact comparison, use `BarChart`. For parts of one total, use
`TreemapChart`. For bubbles plotted on two axes, use `BubbleChart`. For overlap
between groups, use `VennDiagram`.

## Data shape

`data` is an array of `{ name, data }` groups, where `data` holds
`{ name, value }` items. Keep values within the fixed 0 to 1,000 size range so
bubbles above 1,000 do not all clamp to the maximum size. `height` defaults to
500; `splitSeries` defaults to `true`.

```jsx
<PackedBubbleChart
    data={[
        { name: 'CMU', data: [{ name: 'Lincoln Middle', value: 250 }, { name: 'Roosevelt K-8', value: 180 }] },
        { name: 'Pitt', data: [{ name: 'North High', value: 220 }, { name: 'South High', value: 200 }] },
        { name: 'Duquesne', data: [{ name: 'Riverside Academy', value: 300 }, { name: 'Jefferson Elementary', value: 150 }] },
    ]}
/>
```

## Color and accessibility

- **One color per group.** Groups follow the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1. Past six groups, fold the smallest into "Other".
- **Area is a rough encoding.** Readers can spot the largest bubble but cannot judge exact ratios; pair with a table or `BarChart` when exact numbers matter.
- **Thresholded labels.** Bubbles at 50 or under carry no label, so their names appear only in the tooltip.
- **Fixed black label ink.** Bubble labels draw in black rather than a text token and do not adapt to dark mode; verify legibility before shipping in dark mode.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Series colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`PackedBubbleChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={500} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No enrollment yet" description="Courses appear once students enroll." />
    : <PackedBubbleChart data={data} />}
```
