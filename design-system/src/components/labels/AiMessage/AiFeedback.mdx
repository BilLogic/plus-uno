## Usage

Place `AiFeedback` under a finished AI message. Leave `value` unset to let it hold the rating, starting from `defaultValue`, or pass `value` to own it. `onFeedback` receives `{ rating }` on a press, with `rating` set to `up`, `down` or null, and `{ rating: 'down', comment }` when a comment is sent.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- The two thumbs are buttons named "Good answer" and "Bad answer". Both are toggle buttons and report `aria-pressed`, true on the chosen one. Thumbs down is not the comment popup's trigger, so it never reports `aria-expanded`: the popup opens after the pick, anchored to the thumb, focus moves into it, and focus returns to the thumb on close.
- A rating, and a change of rating, is confirmed in a status message a screen reader hears.
