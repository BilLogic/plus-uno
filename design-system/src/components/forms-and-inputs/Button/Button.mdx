## When to use

Use `Button` for anything the user *does*: submit, confirm, open a dialog, run an
export, dismiss a step. It is the only component in `actions` that carries a
click handler of its own, and it is the element the rest of the system composes
when it needs an action — `Modal`, `Card` and `Jumbotron` all render `Button`
from their `primaryButton` / `secondaryButton` props.

Use it for navigation too, but pass `href`: the component forwards `href` and
`target` to the underlying element, which renders an anchor. That keeps
middle-click and "open in new tab" working, which a click handler on a `button`
does not.

</div>

## Usage notes

### Loading is not a substitute for feedback.

```jsx
// Incorrect — the label goes transparent, so for a ten-second export the
// button reads as an empty box for ten seconds.
<Button text="Export report" loading={isExporting} />

// Correct — keep the label, and say what is happening next to it.
<Button text="Export report" disabled={isExporting} />
{isExporting && <Spinner />}
```

### `style` carries two vocabularies; only one of them means severity.

`success`, `warning` and `danger` say something happened. The five SMART
domains — `social-emotional`, `mastering-content`, `advocacy`, `relationship`,
`technology-tools` — are subject colors, and a button wearing one is about
that domain, not about an outcome. The props table lists all thirteen values
side by side; the enum does not tell you which half you are in.

```jsx
// Incorrect — advocacy is the color of a curriculum domain. Nothing about it
// says "this deletes something".
<Button text="Delete session" style="advocacy" />

// Correct — severity from the semantic set, domain color where the button is
// genuinely about that domain.
<Button text="Delete session" style="danger" />
<Button text="Open advocacy plan" style="advocacy" />
```

## Accessibility

- **Icon-only sizing.** With no `text` and no children the component adds
  `plus-btn--icon-only`, which sets a square box: 32×32 at `medium` and 24×24
  at `small`. `large` is deprecated and draws 32×32 like `medium`. No size
  meets the 44×44 minimum in
  `design-system/guidelines/foundations/accessibility.md`, so leave room
  around an icon-only button, and give it a text label where touch matters.
- **Icon-only naming.** A string `leadingVisual` / `trailingVisual` renders as
  `<i aria-hidden="true">`, so an icon-only button has no accessible name unless
  you pass `aria-label` or the `title` prop.
- **Loading.** `loading` sets `disabled` and `aria-disabled`, drops the click
  handler, and the stylesheet paints the label transparent while a CSS spinner
  runs. Nothing is announced. If the wait matters to a screen-reader user, put
  the status in a live region beside the button.
- **Disabled.** `disabled` sets both the native attribute and `aria-disabled`.
  A natively disabled button leaves the tab order, so any explanation of *why*
  it is disabled must live outside the button, where it can still be reached.
- **Pass-through.** Unrecognized props are spread onto the rendered element, so
  `aria-pressed`, `aria-expanded`, `aria-controls` and `aria-describedby` all
  work without a wrapper.

### An icon-only button needs a name and needs room.

```jsx
// Incorrect — no text and no children means icon-only, which renders 32×32
// at the default medium size with no accessible name at all.
<Button leadingVisual="trash" style="danger" />

// Correct — the name is supplied by hand, and where touch matters the
// button carries its label too.
<Button leadingVisual="trash" style="danger" aria-label="Delete session" />
<Button leadingVisual="trash" style="danger" text="Delete session" />
```

### A group of buttons is not a selection control.

```jsx
// Incorrect — `active` is a class. Nothing announces which one is chosen.
<Button text="Week" active={range === 'week'} onClick={() => setRange('week')} />
<Button text="Month" active={range === 'month'} onClick={() => setRange('month')} />

// Correct — extra props are spread onto the element, so state can be declared.
<Button text="Week" active={range === 'week'} aria-pressed={range === 'week'}
        onClick={() => setRange('week')} />
```
