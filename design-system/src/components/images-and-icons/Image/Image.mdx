## Usage

Use `Image` for a bitmap — a photo, a screenshot or a raster graphic — especially when it has a dark-mode asset to swap via `srcDark`.

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For a square picture of a school or tool or lesson, use `Tile`.
- For a typed glyph standing in for a kind of record, use `Object`.
- For a person or an agent's picture or initials, use `Avatar`.
- For a vector PLUS character, use `Illustration`.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Picture.** An `img`, wrapped in `<picture>` with a dark `<source>` when `srcDark` is set.
2. **Size.** `fluid` fills its container's width and keeps the aspect ratio; `fixed` keeps its natural size.

## Best practices

### Pass `srcDark` instead of swapping `src` yourself.

The dark variant is a second `<source>` inside a `<picture>`, matched by
`prefers-color-scheme`. The browser picks it before paint, so there is no
flash of the light image on a dark system.

<DoDontPair
    doExample={<Image src={sessionSummaryLight} srcDark={sessionSummaryDark} alt="" />}
    doCaption="One image with a dark variant, picked before paint."
    dontExample={<Image src={sessionSummaryLight} alt="" />}
    dontCaption="A light image alone on a dark surface."
/>

### Leave `alt` empty when nearby text already states the meaning.

`alt` defaults to empty (`""`), which marks the image decorative. Set `alt` to
real text only when the image carries information nothing else on the page
already states.

<DoDontPair
    doExample={<div><Image src={sessionSummaryLight} alt="" /><p>Week 3 attendance, by session.</p></div>}
    doCaption="Empty alt where a caption already says it."
    dontExample={<div><Image src={sessionSummaryLight} alt="Image" /><p>Week 3 attendance, by session.</p></div>}
    dontCaption="Alt text that says nothing, or repeats the caption beside it."
/>

### Size the container, not the image.

Use `fluid` and let the container set the width, so one image works from phone to desktop. Reach for `fixed` only for a picture that must stay at its natural size.

<DoDontPair
    doExample={<FigureStack width="narrow"><Image src={sessionSummaryLight} alt="" /></FigureStack>}
    doCaption="Fluid, so the container sets the width."
    dontExample={<FigureStack width="narrow"><Image src={sessionSummaryLight} alt="" size="fixed" /></FigureStack>}
    dontCaption="Fixed in a narrow container: the picture overflows it."
/>

</div>

## Accessibility

- **Decorative by default.** `alt=""` hides the image from assistive
  technology when a caption or heading nearby already says what it shows.
- **Meaningful images need real alt text.** Describe what the image
  communicates, not what it depicts pixel for pixel.
- **The dark swap has no accessibility impact.** It is a media query on the
  `<picture>` element, not a state change a screen reader needs to track.
