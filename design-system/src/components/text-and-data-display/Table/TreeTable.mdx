## Usage

Use a Tree table for records that nest — a curriculum of units and lessons, a
folder of sessions. For a flat list, use the Static or Dynamic table instead.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Head cell.** A label, as in the other tables.
2. **Chevron.** Leading the title cell of a branch; static today.
3. **Indent.** The title cell's left padding grows with depth, up to three levels.

## Best practices

- **No component yet.** There is no `TreeTable` export. This page composes the
  look from `TableRow` and `TableCell`, the same parts `Table` is built from,
  so a project that needs nesting today builds it the same way.
- **Depth is a left pad**, `--size-table-cell-pad-x` plus `--space-125` per level, on
  the row's title cell.
- **Expand and collapse are unbuilt.** The chevron shown here does not toggle
  anything; building that behavior is open work.

</div>

## Accessibility

- **Depth is visual only.** The rows are plain table rows; the indentation is not announced, so put the level in the label when it matters.
- **The chevron is decorative.** It is `aria-hidden` and does not toggle anything yet.
- **Do not use it to hide required content.** Until expand and collapse are built, every row is visible.
