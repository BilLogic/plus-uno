Universal navigation sidebar — the foundation Sidebar pattern filled with the Specs item list, for tutor and supervisor from one config (`sidebarConfig.js`).

- **Tutor:** Home · Training (Lessons, Onboarding) · Toolkit (Sessions, Students, Slack ↗)
- **Supervisor:** adds Admin (Tutors, Sessions, Students, Groups)

Two code-only items are not in Specs: Toolkit › Reviews and Admin › Compliance. They show only with `showItemsNotInSpecs`, which the demo walkthrough sets.
