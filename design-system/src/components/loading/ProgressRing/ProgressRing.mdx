## Usage

Use `ProgressRing` when a task has a known percent done and sits in an
icon-sized slot, such as an uploading file row where a list of horizontal bars
would crowd the view. A ring is never indeterminate.

### Appearance guidance

<DocsTable>
<thead>
<tr><th>Appearance</th><th>When to use</th></tr>
</thead>
<tbody>
<tr><td>Default</td><td>Standard surfaces: a brand-bold fill on a neutral track, using <code>PROGRESS_RING_SIZES</code>.</td></tr>
<tr><td>Inverse</td><td>On a bold or colored background.</td></tr>
</tbody>
</DocsTable>

</div>

## Alternatives

- For a wait whose duration is unknown, use `Spinner`.
- For progress where a horizontal track fits (such as a card header or a form step), use `ProgressBar`.
- For content loading into a layout that already has a shape, use `Skeleton`.

</div>

## Parts

1. **Track.** The full neutral circle behind the arc, drawn with a `--progress-ring-stroke` stroke.
2. **Fill.** The clockwise brand-bold arc starting at twelve o'clock, rounded at its ends and hidden when `value` is `0`.
3. **Accessible name.** The `label` prop set on the `progressbar` element via `aria-label`.

## Best practices

### Keep `ProgressRing` determinate and reach for `Spinner` when the total is unknown.

A ring with a track promises a known share of completion; spinning or freezing a
half-filled ring when there is no total misleads the tutor about how long is
left.

<DoDontPair
    doExample={<div style={{ display: 'inline-flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Spinner size={16} /><span>Connecting to session</span></div>}
    doCaption="Spinner when the wait has no measurable percent."
    dontExample={<div style={{ display: 'inline-flex', alignItems: 'center', gap: 'var(--inline-md)' }}><ProgressRing value={50} size={16} label="Connecting to session" /><span>Connecting to session</span></div>}
    dontCaption="A fixed ProgressRing faking an unknown wait."
/>

### Pair `ProgressRing` with visible percent text when exact progress matters.

At `PROGRESS_RING_SIZES` diameters (`16`, `20`, `24`), the center of the ring
cannot hold text; put the percent beside it on the row's meta line.

<DoDontPair
    doExample={<div style={{ display: 'inline-flex', alignItems: 'center', gap: 'var(--inline-md)' }}><ProgressRing value={64} label="Uploading recording, 64%" /><span>Uploading · 64%</span></div>}
    doCaption="The percent sits beside the ring."
    dontExample={<div style={{ position: 'relative', display: 'inline-flex', alignItems: 'center', justifyContent: 'center' }}><ProgressRing value={64} size={24} label="Uploading recording, 64%" /></div>}
    dontCaption="A bare ring with no surrounding context."
/>

### Match `size` from `PROGRESS_RING_SIZES` to the icon slot it replaces.

Use `size={20}` in a row's leading slot so swapping between a status icon and
an active upload never shifts the row, and `size={16}` beside compact text.

<DoDontPair
    doExample={<div style={{ display: 'inline-flex', alignItems: 'center', gap: 'var(--inline-md)' }}><ProgressRing value={40} size={20} label="Uploading recording, 40%" /><span>session-recording.mp4</span></div>}
    doCaption="A ring sized to match the row's leading icon slot."
    dontExample={<div style={{ display: 'inline-flex', alignItems: 'center', gap: 'var(--inline-md)' }}><ProgressRing value={40} size={16} label="Uploading recording, 40%" /><span>session-recording.mp4</span></div>}
    dontCaption="An undersized ring that shifts when replaced by the row's icon."
/>

### Use `appearance="inverse"` on bold surfaces.

The neutral track disappears against a bold ground; `inverse` switches the track
and fill to inverse roles that stay legible.

<DoDontPair
    doExample={<div style={{ display: 'inline-flex', padding: 'var(--pad-y-lg) var(--pad-x-md)', borderRadius: 'var(--radius-md)', backgroundColor: 'var(--ds-background-brand-bold)' }}><ProgressRing value={64} appearance="inverse" label="Uploading recording" /></div>}
    doCaption="Inverse appearance on a bold surface."
    dontExample={<div style={{ display: 'inline-flex', padding: 'var(--pad-y-lg) var(--pad-x-md)', borderRadius: 'var(--radius-md)', backgroundColor: 'var(--ds-background-brand-bold)' }}><ProgressRing value={64} label="Uploading recording" /></div>}
    dontCaption="Default appearance lost against a brand-bold fill."
/>

## Accessibility

- **Announced as a determinate progressbar.** Renders `role="progressbar"` with
  `aria-label` set from the required `label` prop, `aria-valuemin="0"`,
  `aria-valuemax="100"`, and `aria-valuenow` clamped to `0`–`100` together with
  the drawn arc.
- **Name each ring distinctly in a list.** When several file rows upload at the
  same time, include the item's name in `label` so screen-reader users can tell
  one progressbar from another.
- **Decorative SVG.** The inner `<svg>` is marked `aria-hidden="true"` and
  `focusable="false"` so assistive technology reads only the progressbar role
  and its value.
- **Reduced motion.** Under `prefers-reduced-motion: reduce`, changes to `value`
  update the arc immediately without animating `stroke-dashoffset`.

- `ProgressBar`: use when there is horizontal space for a full-width track, such as a card header or a multi-step flow.
