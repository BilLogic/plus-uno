# Tutor task board

Build this in `src/`, with the PLUS design system.

A board with three columns, *To do*, *In progress* and *Done*. Each card is a tutor task with a title, a due date and an assignee avatar. Tutors drag cards between columns and reorder them within a column; each column header shows its card count, and a column can be collapsed.

When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
