# Add availability form

Build this form in `src/`, with the PLUS design system.

A tutor adds a weekly availability slot: day of the week (required), start time and end time (required; the end must be after the start), session format (*Online* or *In person*), and an optional note of up to 200 characters. *Save* is disabled until the required fields are filled. On save, show each field's error inline if it is invalid; when everything is valid, show a success confirmation and clear the form. Show every state on screen at least once in the code: empty, filled, invalid, disabled save, saved.

When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
