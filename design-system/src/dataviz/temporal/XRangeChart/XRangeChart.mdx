## When to use

Use `XRangeChart` for who is busy when: tutors' sessions across a week,
blocked-out availability, exam windows per class, or how long each unit of a
lesson plan runs. Gaps between bars are free time; overlapping rows show
clashes.

For milestones in order with no duration, use `TimelineChart`. For low-to-high
ranges across categories with no time axis, use `ColumnRangeChart`. For how
much capacity is used over time as a quantity, use `AreaChart`.

## Data shape

`categories` names the rows, top to bottom. `data` is an array of items, each
`{ start, end, y, name, color }`: `start` and `end` are timestamps in
milliseconds, `y` is the row's index in `categories`, and `name` and `color`
are optional.

```jsx
const day = 24 * 60 * 60 * 1000;
const monday = Date.UTC(2026, 8, 7);

<XRangeChart
    categories={['Maya (Lincoln Middle)', 'Jordan (Roosevelt K-8)', 'Priya (North High)']}
    data={[
        { start: monday, end: monday + day, y: 0, name: 'Lincoln Middle group' },
        { start: monday + day * 2, end: monday + day * 3, y: 0, name: 'Roosevelt K-8 1:1' },
        { start: monday, end: monday + day * 2, y: 1, name: 'North High group' },
        { start: monday + day, end: monday + day * 4, y: 2, name: 'Session prep' },
    ]}
/>
```

`height` defaults to 400.

## Color and accessibility

- **Color follows the row.** Each bar takes the categorical color for its row index, so every bar on a row matches. Rows past the eighth reuse colors. Pass `color` on an item to override it, for example a status color for a cancelled session, and say the status in its `name` too.
- **Position and labels carry the meaning.** The row names who, the bar's ends say when, and the label says what. Row color repeats what the row axis already says, so the chart reads without hue.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`XRangeChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>The schedule could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions scheduled" description="Sessions appear here once tutors are booked." />
    : <XRangeChart categories={categories} data={data} />}
```
