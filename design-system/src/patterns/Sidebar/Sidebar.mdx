It mirrors the Figma `_Sidebar` and `_Sidebar section` in Patterns › Surface container, and `Sidebar` fills it with the PLUS content for each role.

### Anatomy

- **Frame** — fills the Surface container's sidebar panel (`--layout-width-sidebar` 240, padded `--surface-container-pad` 8), its rows `--element-stack-sm` 4 apart.
- **Header** — the logo, padded `--element-pad-y-md` 6 / `--element-pad-x-sm` 8. It sits outside the scroller, so it stays put.
- **Body** — the top-level items, then the sections. Past the frame's height it scrolls inside the sidebar.
- **Section label** — `--heading-xxsmall` (12 semibold, Atlassian's menu section style), padded 6 / 12 (`--element-pad-y-md` / `--element-pad-x-md`). It names a `role="group"`; it is not a heading.
- **Item** — a `SidebarTab`: `--item-height-md` 32, a 16 icon (`--icon-md`), a label that truncates, and the `description`, `elemAfter` and `actionsOnHover` slots.
- **Divider** — optional, after a section: a `Divider` inset 12.

## Usage

- Content is data: pass `items` and `sections`. Which items a role sees belongs in the caller's config, never in a second copy of the markup.
- A section label is a group's name. Never render it as a heading: the sidebar sits beside every page and would add the same headings to each one.
- An external destination is an item with `href` and `external`. It opens a new tab, says so, and is never selected.

## Open tabs

An opened record, such as a session or a student, becomes a temporary tab under the item it belongs to. Several can be open at once, and each one can be closed. They are open records, not nested pages: Toolkit › Sessions and Toolkit › Students use them first.

<DocsCanvasShell description={<>The tutor example: two open sessions, one of them live, and one open student.</>}>
    <DsCanvasQuiet of={SidebarStories.OpenTabs} />
</DocsCanvasShell>

<DocsCanvasShell description={<>None, one, five, twenty and long titles. Past five, "Show N more" expands the rest and takes the thread's elbow.</>}>
    <DsCanvasQuiet of={SidebarStories.OpenTabExtremes} />
</DocsCanvasShell>

- **Parent** — the item turns into an accordion. Its chevron is a disclosure button (`aria-expanded`, `aria-controls`) that hides and shows the tabs, and the list opens on its own when a tab is opened. The label still opens the item's own page. On hover or focus it shows "Close all".
- **Tab** — two parts side by side: a 28 thread column (the parent's `--element-pad-x-md` 12 plus its `--icon-md` 16) and a surface, a `SidebarTab` without an icon, `--item-height-md` 32 high, padded `--element-pad-x-sm` 8, so its label lines up with the parent's at 36. The title truncates. A live session shows the green `Count` dot, named "Live". On hover or focus it shows ×, named "Close" plus the title, and Delete or Backspace closes the focused tab.
- **States** — on the surface only: hover `--color-on-surface-state-08`, pressed `--color-on-surface-state-12`, selected `--color-primary-state-16` with primary text, selected and hovered the hover layer over the selected fill, and focus the ring inside the surface.
- **Overflow** — the 5 most recent tabs show, then a "Show N more" row on the same surface, in secondary text.
- **Thread** — a `--size-element-stroke-sm` line in `--color-outline-variant` under the parent icon's center (x 20), unbroken through the gaps, ending at the last row (which is "Show N more" when it shows) in a `--element-radius-item-sm` 6 elbow whose stub stops at 26, 2 before the surface. It never changes with the row's state.
- **Selection** — opening a record selects its tab. Closing the selected tab selects its parent.
- **Scope** — the tabs live in `sessionStorage`: they survive a reload and clear when the browser session ends. Call `clearOpenTabs()` at sign-out.
- **No routing** — nothing in the model reads or writes the URL. Each record keeps its own route in `href`, and the tab links to it; `onTabSelect` gets a plain click, so an app can show the record without a page load.

```jsx
import PatternSidebar, { useOpenTabs } from '@/patterns/Sidebar';

const tabs = useOpenTabs();
// Wherever a page opens a record:
tabs.open('sessions', { id: 's1', title: 'Hogwarts · Tue, Sep 9', href: '/toolkit/sessions', status: 'live' });

<PatternSidebar
    items={items}
    sections={sections}
    activeId={tabs.selectedId}
    openTabs={tabs.byParent}
    onTabSelect={(tab) => tabs.select(tab.id)}
    onTabClose={(tab) => tabs.close(tab.id)}
    onTabsCloseAll={(item) => tabs.closeAll(item.id)}
/>
```
