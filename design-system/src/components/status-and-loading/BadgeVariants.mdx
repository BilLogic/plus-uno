## When to use

Not in new code. Is it a number? `Count`. Is it the condition something is in,
and can that condition change? `Status`, whether the system calculated it or a
person set it. Otherwise, `Tag`.

`BadgeVariants` keeps working while its calls move. Each variant renders the
component that replaced it:

| This call | Renders |
|---|---|
| `variant="status"` | `Status` with the matching `style` |
| `variant="date"` | `Status type="date"` (neutral, warning or danger) |
| `variant="counter"` | `Count` |
| `variant="custom"` | a read-only `Tag`, with `color` on the swatch |
| `appearance` positive · negative · information | `style` success · danger · info |
| `spacing` default · spacious | Status `size` medium · large |
| `trailingMetric` | Status `count` |
| `iconBefore` | Status `leadingVisual` |
| `isBold` on a counter | Count's bold appearance |

</div>

## Usage notes

### Move a call by copying the warning.

```jsx
// Incorrect — still works, and warns on every render in development.
<BadgeVariants variant="status" appearance="positive" trailingMetric={12}>Complete</BadgeVariants>

// Correct — what the warning names.
<Status style="success" count={12}>Complete</Status>
```

### `custom` becomes a Tag, not a colored Status.

A Status's color is a meaning, and `custom` was the way to give a label a color
that meant nothing. That is a category, so it renders a read-only Tag and the
color moves to the swatch.

```jsx
// Incorrect — a status in a color no reader can learn.
<BadgeVariants variant="custom" color="#7f3fb1">Algebra</BadgeVariants>

// Correct — a category, in a Tag color.
<Tag color="purple">Algebra</Tag>
```

## Accessibility

- **A status is announced as its text**, with no role that suggests it can be
  pressed. A leading icon is hidden; the word carries the meaning.
- **A dot is named.** A counter with nothing to say renders a Count dot named
  by `label`, or "New" when there is none.
- **A clipped status keeps its full text** in a tooltip, and becomes a tab stop
  so a keyboard user can reach it.
- **Contrast is measured, not asserted here.** The a11y ratchet tracks color
  contrast over every story on this page.
