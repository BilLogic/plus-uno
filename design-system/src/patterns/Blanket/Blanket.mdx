<Title />
The Blanket is the full-screen layer that holds the blanket fill and the one layer above it, a modal or a drawer, so that layer is placed, not drawn. It fills with the blanket, pads 16 at the sides and 64 above and below, and centers a modal or holds a drawer at the screen edge. The examples on this page follow the toolbar's Color mode switch.

### Purpose

A Blanket interrupts the page for one task. It dims everything behind it with one fill, so the person sees only the layer on top. It never draws content of its own.

</div>

<div className="sb-ds-doc-section">

### When to use

- Put a **Modal** in a Blanket when one task blocks the page.
- Put a **Drawer** in a Blanket, at an edge, when the task needs the page in view.
- A dialog never opens another Blanket. A follow-up decision inside a modal swaps its content for an inline confirmation in the same Blanket.
- For a menu, popup, flag or tooltip, use the **Popups**. These float with no blanket and never take a Blanket.
- For a floating sidebar, use the **Sidebar**. It takes a shadow and no blanket.

</div>

### One dialog at a time

A dialog never opens a second Blanket. When a follow-up decision comes up
inside a modal — confirming a delete, for example — the modal swaps its
title, body and footer for an inline confirmation in the same Blanket instead
of raising another one on top.

### Rules

- Pad 16 at the sides and 64 above and below. This is the closest a modal gets to the screen edge.
- Use one fill, `--ds-blanket`, under every modal, drawer and overlay Panel.
- A dialog never opens another dialog. A follow-up decision swaps the dialog's content for an inline confirmation in place.
- Opening a modal closes a floating sidebar, so the two never stack.
- A floating sidebar gets a shadow and no blanket.
- Popovers, flags and tooltips never bring a blanket.
- A modal and a confirm cap at the screen height less 2 × pad-y (see Tokens) and scroll their body past it.
- Place a modal in the Blanket. Do not detach it to move things around.

</div>

<div className="sb-ds-doc-section">

### Do and don't

None. The Blanket has no do and don't pairs of its own. The pairs live on the Modal page.

</div>

<div className="sb-ds-doc-section">

### Accessibility

- The Blanket is a layout layer with no role. The Modal or Drawer inside it is the dialog.
- The blanket is a pointer shortcut, not a control. A keyboard closes a dialog from inside it, so the blanket takes no role and no key handler.
- The blanket at `--ds-blanket` keeps the dialog legible in Light and Dark. The toolbar's Contrast switch changes it with the rest of the page.
- A layer wider than a narrow screen keeps its width, and the Blanket scrolls.

</div>

<div className="sb-ds-doc-section">

### For developers

The Blanket draws the layer only. It does not trap focus, close on Escape or count toward the two-overlay limit. For a real dialog, use the core Modal component, which draws the same layers and blanket token. The Drawer pattern brings its own focus handling.

</div>
