Foundations are the tokens, guidelines and visual styles that every pattern and component builds on: color, spacing, typography and more. This page lists all fourteen, grouped as tokens, guidelines, then styles.

- Repo: `design-system/guidelines/foundations/` holds the written guidance for each foundation.

<FoundationSection title="Page anatomy">

Every foundation page follows the same shape, so you can find the same thing in the same place.

- A hero names the foundation, says what it is in one line.
- Contents lists every section, Overview and Related included.
- The foundation's own sections come next, then Accessibility, then Related last.
- Examples are drawn from live tokens, so they follow the toolbar's Color mode and Contrast switches.

</FoundationSection>

<FoundationSection title="Accessibility">

- Every foundation page ends its guidance with the accessibility rules that foundation owns: contrast in Color, heading order in Typography, the focus ring in Border and Radius, reduced motion in Motion.
- The Accessibility page holds the rules that cut across them.
- Test a screen in every color mode before shipping, not only Light.

</FoundationSection>
