## When to use

Use `ScatterChart` to examine how two numeric measures move together across
records, such as weekly tutoring minutes vs. score gain or attendance vs. final
grade. Clarify in surrounding copy when correlation does not imply causation.

For a third measure encoded as size, use `BubbleChart`. When points are dense
enough to overlap heavily, use `HeatmapChart`. For one measure across named
categories, use `BarChart`; for one measure over time, use `LineChart`.

## Data shape

`data` (required) is an array of `{ name, data, color }` series, where `data`
holds `[x, y]` pairs. `height` defaults to 300. Omit `color` to assign one
automatically.

```jsx
<ScatterChart
    xAxisLabel="Tutoring minutes per week"
    yAxisLabel="Score gain (points)"
    data={[
        { name: 'Grade 7', data: [[30, 4], [45, 7], [60, 9], [90, 12], [20, 2]] },
        { name: 'Grade 8', data: [[35, 5], [50, 6], [70, 10], [10, 1], [100, 11]] },
    ]}
/>
```

## Color and accessibility

- **Automatic series color.** One series uses `--ds-chart-brand`; two or more follow the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1 without skipping. Past six series, group the rest or split the chart.
- **Position and marker shape.** Position carries the values, and Highcharts assigns each series a distinct marker shape alongside its color.
- **Overlapping points.** Markers are solid with no transparency prop, so identical points stack into one dot; switch to `HeatmapChart` for dense data.
- **No trend line.** The chart draws points only; state the relationship in the header or description when it is the takeaway.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`ScatterChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <ScatterChart data={data} xAxisLabel="Tutoring minutes per week" yAxisLabel="Score gain (points)" />}
```

## Related

- For a third measure encoded as bubble size, use `BubbleChart`.
- For too many points to read one by one, use `HeatmapChart`.
- For one measure over time rather than two against each other, use `LineChart`.
- For the spread of a single measure, use `HistogramChart`.
