## When to use

Use `CloseButton` to close a surface as a whole — an `Alert`, a `Toast`, a
`Modal`. It is a fixed 24×24 box with a 16px ×, the WCAG 2.2 minimum target
size, and it keeps that size whatever text sits beside it. Where it sits on a
line of text is the parent's job: `Alert` centers it on its first line.

Two tones: `default` for neutral surfaces, and `inverse` for colored or dark
grounds, where the × and its focus ring take the light surface color. There is
no disabled state and there are no color variants: a close control is always
available, and the × is neutral on every intent.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Say what closes when there is more than one.

```jsx
// Incorrect — three dismissible messages expose three buttons all called
// "Close", and a screen reader user cannot tell them apart.
<CloseButton onClick={dismissReminder} />

// Correct — the name becomes "Dismiss session reminder".
<CloseButton what="session reminder" onClick={dismissReminder} />
```

### Size it with the component, not with text.

```jsx
// Incorrect — a typography class on the button does nothing to the ×, and
// wrapping it in one does not either; the box is fixed at 24×24.
<CloseButton className="h4" onClick={close} />

// Correct — place it, and let the parent align it to the line it belongs to.
<div className="my-header">
  <h2 className="h4">Session notes</h2>
  <CloseButton what="session notes" onClick={close} />
</div>
```

### `inverse` is for grounds that are not the page.

```jsx
// Incorrect — a light × and a light focus ring on the light page are invisible.
<CloseButton tone="inverse" onClick={close} />

// Correct — only on a colored or dark ground the caller paints.
<div style={{ background: 'var(--color-inverse-surface)' }}>
  <CloseButton tone="inverse" onClick={close} />
</div>
```

## Accessibility

- **Its name is "Close" by default**, or "Dismiss {what}" when `what` is passed.
  An explicit `aria-label` overrides both, for call sites with an established
  label — `Alert` keeps `Close alert`.
- **The × is `aria-hidden`.** The name is the whole of what is announced.
- **The focus ring** is `--color-focus-ring`, 2px, drawn 2px outside the box
  with radius `--size-element-radius-lg`, over a 12% state layer. On `inverse`
  it is `--color-focus-ring-inverse`, which aliases surface and is only visible
  on the dark and colored grounds that tone is for.
- **It is a real `<button type="button">`**, so Enter and Space press it and it
  never submits a surrounding form.
