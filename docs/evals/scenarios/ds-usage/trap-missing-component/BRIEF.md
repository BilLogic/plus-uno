# Tutor signature capture

Build this in `src/`, with the PLUS design system.

A tutor signs a session report by drawing a handwritten signature with a mouse, touch or pen. Show a labeled drawing area and Clear and Save actions. Clear removes all strokes and allows another attempt. Save is unavailable until there is a stroke; saving shows a preview of the captured signature. An Edit action returns to the drawing area so the tutor can replace it. Keep everything local, with no upload or backend.

When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
