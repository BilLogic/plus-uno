## Usage

Pass the icon's name to the component that shows it. Where no component takes the name, draw it with Icon:

```jsx
import { Icon } from '@/components';

<Icon name="calendar-days" size={16} color="subtle" />
<Icon name="circle-check" size={16} color="success" label="Approved" />
```

Navigation icons are always outlined: a selected row shows a fill, not a filled icon, and brand marks (`fa-brands`) are the only exception. Pass a plain name and set `iconStyle` only when a glyph must be solid outside navigation; never write `fa-solid` or `fa-regular` into the name. Use a glyph's current name: an alias is not in the regular list, so it draws solid. A `fa-brands` name carries its family: `fa-brands fa-figma`.

## Best practices

### Pair it with words, or give it a `label`.

Without `label` the icon is hidden from assistive technology, so the words beside it carry the meaning.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-sm)', font: 'var(--body-default)', color: 'var(--ds-text)' }}><Icon name="calendar-days" size={16} color="subtle" />Tuesday, 4 pm</div>}
    doCaption="The icon beside the words it backs up."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-sm)' }}><Icon name="calendar-days" size={16} color="subtle" /></div>}
    dontCaption="An icon alone with no label, so it has no name."
/>

### Color it with a role, never a picked color.

<DoDontPair
    doExample={<Icon name="circle-check" size={24} color="success" label="Approved" />}
    doCaption="The success role for a success mark."
    dontExample={<Icon name="circle-check" size={24} color="brand" label="Approved" />}
    dontCaption="The brand role on a status mark."
/>

</div>

## Accessibility

- **Labeled or hidden.** With `label` the icon is `role="img"` named by it. Without, it is `aria-hidden`.
- **An icon-only control is named by the control.** Icon button takes a required `label`, and the glyph inside stays hidden.
