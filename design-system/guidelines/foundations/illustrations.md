# Illustrations

The illustrations are hand-drawn characters: five for the SMART areas and seven math characters (`Illustration`, `@/components`).

## Rules

- Use one where a page has room to breathe: empty states, onboarding, completion and SMART area headers. Never in tables, forms, toolbars, inline errors or buttons.
- Sizes are 48, 96, 160 and 240; scale uniformly and never stretch.
- Color comes from tokens: SMART bodies take `--ds-background-smart-<area>-subtle`, math bodies an accent hue (never a SMART hue), line work `--ds-icon-subtle`. Never detach an instance or recolor its parts.
- A character appears only with its own SMART area. One character per moment.
- A low-fidelity illustration of the UI uses basic shapes in mostly gray and never a real screenshot.
- Reuse the existing characters first; a new character is a design lead's call.
- Decorative by default; give a `title` that names the idea when it carries meaning. Never put the only copy of information in an illustration.
