<FoundationSection title="Overview">

Borders mark a boundary, separate neighbors and show state. The width token sets how heavy the line is, and the color token says what it means, so always choose them as a pair. A divider is a border, not a component.

```css
border-width: var(--border-default);
border-width: var(--border-selected);
border-width: var(--border-focused);
```

Figma holds Border/default, Border/selected and Border/focused in `spacing / semantics`, built on Stroke/stroke-1 and stroke-2 in `spacing / primitives`. Pair them with `color/border/*` in `color / semantics`.

<Callout title="Border rules">
A card has no border: its edge comes from elevation. A divider is a border, not a component.
</Callout>

</FoundationSection>

<FoundationSection title="Width tokens">

Three widths cover every border. Pick by what the line says, never by how heavy you want it to look. Values are indicative; the tokens are the contract.

<FoundationSection title="Selected states">

A selected option takes the 2 px selected width in `color/border/selected` on every side, and a second cue such as a check or a fill. An active tab and a selected row use the same pair.

State and emphasis use the whole shape. A selected, active or flagged row, card, banner, quote or nav item shows its state with its fill, text, icon or weight, or with a border or ring on every side.

<FoundationSection title="Dividers">

<Callout title="There is no Divider component">
A divider is a 1 px line in `color/border/default`: a border, not a component.
</Callout>

- Space comes first. Add a line only when spacing alone does not separate two groups.
- A horizontal rule spans the content width of its container. A vertical one sits between controls and takes their height.
- A divider uses Border/default and `color/border/default`. A heavier or colored line is a state, not a divider.
- A card gets its edge from elevation, not from a border: see Elevation.

<FoundationSection title="Accessibility">

- A border that is the only cue for a control's edge is held to 3:1 against its surround (WCAG 1.4.11). Use `color/border/input` for fields.
- The focus ring is the one signal for keyboard focus, clears 3:1 against what it sits on, and is described under Focus ring.
- Selection never rests on color alone: the 2 px width is the second cue beside `color/border/selected`.
- A subtle accent background needs an accent border to reach 3:1 against the surface, because the tint alone is too close to the page.

</FoundationSection>
