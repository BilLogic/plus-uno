# Cancel a session flow

Build this flow in `src/`, with the PLUS design system.

A card shows an upcoming session (student, date, time) with a *Cancel session* action. Choosing it opens a confirmation that names the session and asks for a reason from a short list (*Student unavailable*, *Tutor unavailable*, *Scheduling conflict*, *Other*; *Other* reveals a text field). Confirming shows a brief notice that the session was cancelled, and the card shows a *Cancelled* status. Dismissing the confirmation changes nothing. Keyboard users can complete the whole flow.

When you are done, write `NOTES.md` with one paragraph on what you built and anything you could not build as asked.
