## Usage

Use the Dynamic table where people act on the data: sort a column, filter the

## Parts

1. **Head cell.** A label with an optional type icon; a sortable one holds a button across the whole cell.
2. **Sort arrow.** 12 tall; hidden until hover or focus, kept once sorted.
3. **Row.** Cells in a band, with hover and selected grounds.
4. **Footer.** States the range on a table that pages.
5. **Message row.** The empty, no results, loading and error states, spanning every column.
6. **Checkbox column.** With `isSelectable`: as wide as the row is tall, select-all in the head.
7. **Bulk bar.** `TableBulkActions`, in the Section header's toolbar while rows are selected.
8. **Frozen column.** With `isFrozen`: an opaque first column with a stronger divider while scrolled sideways.

## Best practices

- **A column sorts by its cells' `key`.** Give a date cell a sortable key (`20261024`) and its readable text as `content`.
- **Stateful or stateless.** Leave the sort and page alone and the table holds them. Pass `sortKey` and `sortOrder`, or `page`, and the page owns them: the table reports a press through `onSort` or `onSetPage` and draws what it is given.
- **Server paging.** With `totalRows`, `rows` is the current page only, and the footer counts against `totalRows`.
- **States.** `isLoading` and an empty `rows` pick `loading`, `refreshing` and `empty` on their own. Name `no results` and `error` with `state`, and word them with `noResultsView` and `errorView`.
- **The footer states the range**, `1–25 of 340`, and shows only on a table that pages.
- **Selection reports keys.** `isSelectable` adds the checkbox column, and `onSelectionChange` returns every selected row's `key`. Select-all covers the rows on the current page.
- **The bulk bar is the Section toolbar's selected state.** Swap the Section's `toolbar` for `TableBulkActions` while rows are selected. The table never draws a toolbar of its own.
- **Pin the head row with `stickyHeader` and `maxHeight`.** Only a bounded region scrolls, so the head row needs a height to pin within.
- **Freeze with `isFrozen`.** The first column stays put, and with checkboxes the title column beside them stays put too.

## Accessibility

- **Sorting is announced.** A sortable header carries `aria-sort` (`none`, `ascending` or `descending`) and holds a real button, so a keyboard reaches it with Tab and a press asks for the next sort.
- **Focus is a ring.** The ring is inset in the cell and is at least 3:1 on the surface; focus never changes the fill.
- **The arrow is decorative.** The sort state is in `aria-sort`, so color and the arrow never carry it alone.
- **A disabled row is announced.** It is `aria-disabled` and takes no pointer events.
- **Row selection is named and announced.** Each checkbox is "Select row N" and the head's is "Select all rows", mixed when only some rows are selected; a status says how many are selected, from the first one.
