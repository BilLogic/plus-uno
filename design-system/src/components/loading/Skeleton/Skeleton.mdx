## Usage

Use `Skeleton` while content loads, so the space it will fill is already on
screen and the layout does not jump when it arrives.

- **One label loading on its own** (a status calculated after the row appears, a
  tag list fetched separately): the matching preset.
- **A thumbnail, avatar or header:** a rectangle or circle with its own size.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Bar.** A flat fill in the skeleton color: a rectangle, a circle, a text line or a label shape.
2. **Shimmer.** A band that sweeps across. Off, it is a flat fill.
3. **Group.** Lines and tag groups are columns or rows of bars.

## Best practices

### Shape the placeholder like its content.

A paragraph placeholder promises lines of text; a block promises an image.

<DoDontPair
    doExample={<Skeleton preset="paragraph" width={240} />}
    doCaption="Paragraph preset for a paragraph."
    dontExample={<Skeleton width={160} />}
    dontCaption="A rectangle standing in for text."
/>

### Pair a circle with text for people.

An avatar placeholder is round; a square one misleads about what will load.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Skeleton shape="circle" /><Skeleton shape="text" width={160} /></div>}
    doCaption="Circle beside a text line."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Skeleton width={32} height={32} /><Skeleton shape="text" width={160} /></div>}
    dontCaption="Rectangle beside a text line."
/>

### Keep the shimmer on while loading.

The shimmer tells the person the content is still coming; a frozen skeleton
reads as a broken page. Leave `isShimmering` at its default.

### Use a label preset when one label loads after its row is on screen.

A preset has the label's height and corners, so nothing moves when the value arrives.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><span>Unit 3 review</span><Skeleton preset="status" /></div>}
    doCaption="The status preset, the size of the Status tag it stands in for."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><span>Unit 3 review</span><Skeleton /></div>}
    dontCaption="A free rectangle at its default size, so the row jumps when the status arrives."
/>

### Use plain text bars inside a loading table or card.

The container owns the skeleton. Labels become the same text bars as the rest,
so a loading table does not fill with dozens of label shapes.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Skeleton shape="text" width={120} /><Skeleton shape="text" width={64} /><Skeleton shape="text" width={64} /></div>}
    doCaption="Text bars throughout the row."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><Skeleton shape="text" width={120} /><Skeleton preset="status" /><Skeleton preset="tag-group" /></div>}
    dontCaption="Label shapes inside a loading container."
/>

### Skip the skeleton on a count in a button, tab or nav item.

Show nothing until the number arrives; `CountTag` already renders nothing without a value.

### Skeleton the host, not a count inside it.

For a `CountTag` inside a `StatusTag` or `Tag`, use one `preset="status"` for the whole label.

### Leave flags, modals, menus and spinners out.

They appear when they have something to say. A Tag saving a change keeps its
own spinner (`isLoading`), so saving and loading look different.

## Accessibility

- **Every skeleton is hidden from assistive tech.** It renders `aria-hidden="true"`
  with no role, never takes focus and ignores the pointer, so a screen reader
  does not read a list of empty items and a placeholder cannot be clicked.
- **The loading region carries the busy state.** Set `aria-busy="true"` once on
  the container that is loading, and remove it when the content arrives. The
  component does not set it, because it cannot see the region.
- **Pair the busy state with a live label.** `aria-busy` alone is not announced
  by every screen reader. Render a visually hidden `role="status"` element
  **beside** the busy region, not inside it: content inside a busy region may
  be held back until it is no longer busy. Mount the status **empty** and set
  its text after mount ("Loading students…"), because text a status already
  holds when it mounts is not announced. Keep it mounted, and when the content
  arrives, set its text again ("Students loaded").

```jsx
const [message, setMessage] = useState('');
useEffect(() => {
  setMessage(loading ? 'Loading students…' : 'Students loaded');
}, [loading]);

<div role="status" className="visually-hidden">{message}</div>
<section aria-labelledby="students" aria-busy={loading || undefined}>
  <h3 id="students">Students</h3>
  {loading ? <Skeleton shape="text" lines={3} /> : renderStudents(students)}
</section>
```
- **Reduced motion.** Under `prefers-reduced-motion: reduce` the shimmer stops
  and the fill is flat.
- **Contrast in any theme.** The fill is `--ds-skeleton` and the shimmer
  `--ds-skeleton-subtle`, both theme tokens.
