## When to use

Use `NetworkGraph` for unweighted connections with no fixed order or hierarchy,
such as linked math topics, peer tutoring pairs or tutors who share students.
Filter to roughly 50 or fewer nodes so labels and links stay readable.

For a strict hierarchy, use `OrganizationChart` or `TreegraphChart`. For a small
ordered set, use `ArcDiagram`. For weighted connections or flows, use
`SankeyDiagram` or `DependencyWheel`.

## Data shape

`data` is an array of `[from, to]` node-name pairs. Optional `nodes` is an array
of `{ id, color }` matching names in `data`.

```jsx
<NetworkGraph
    data={[
        ['Fractions', 'Ratios'],
        ['Ratios', 'Percentages'],
        ['Fractions', 'Decimals'],
        ['Decimals', 'Percentages'],
        ['Ratios', 'Proportions'],
    ]}
    nodes={[{ id: 'Fractions', color: 'var(--ds-chart-categorical-2)' }]}
/>
```

## Color and accessibility

- **Default and custom node colors.** Nodes default to `--ds-chart-categorical-1` unless overridden via `nodes` with another [categorical token](?path=/docs/data-visualizations-color--docs). Because there is no legend, explain any color grouping in surrounding text.
- **Labels and links carry the structure.** Every node is named and joined by a visible line, so the graph reads without hue.
- **Non-deterministic positions.** Because the force layout settles dynamically and can vary between renders, never refer to nodes by screen direction.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`NetworkGraph` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={500} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Topic map could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No connections yet" description="Topics connect once lessons reference each other." />
    : <NetworkGraph data={data} />}
```
