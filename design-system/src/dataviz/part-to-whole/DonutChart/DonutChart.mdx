## When to use

Use `DonutChart` for a single headline share — such as modules completed,
sessions against a term target or SMART competencies passed — or a small split
of two to five parts when a total or label belongs in the center.

For a split with labeled slices and a legend, use `PieChart`. For one value
against a target read precisely, use `BulletChart`. For a value on a dial with a
min and max, use `GaugeChart`. For more than five parts, or comparing multiple
donuts, use `BarChart`.

## Data shape

`segments` is an array of `{ value, color, label }` (`value` and `color`
required; `label` names the segment in the tooltip), drawn in array order.

```jsx
import { BRAND, CHROME } from '@/dataviz/palette';

<DonutChart
    value="18/24"
    label="Sessions this term"
    segments={[
        { value: 18, color: BRAND, label: 'Completed' },
        { value: 6, color: CHROME.track, label: 'Remaining' },
    ]}
/>
```

</div>

## Color and accessibility

- **Caller-assigned colors.** `color` is required on every segment. For progress, pair `BRAND` (`--ds-chart-brand`) with `CHROME.track` (`--ds-background-neutral`); for a split of up to five parts, sort from most to least and assign `CATEGORICAL` slots in order without skipping ([Chart color](?path=/docs/data-visualizations-color--docs)).
- **Always print the exact figure in `value`.** Never leave the arc to carry the number alone.
- **Hover-only segment names.** With no legend or slice labels, name splits of three or more parts in surrounding copy or use `PieChart`.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Never wrap it in `aria-hidden` (which hides the keyboard proxies); name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

</div>

## States

`DonutChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's size, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={228} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Progress could not load.</SectionMessage>
    : segments.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="Progress appears after a session is logged." />
    : <DonutChart value={value} label={label} segments={segments} />}
```
