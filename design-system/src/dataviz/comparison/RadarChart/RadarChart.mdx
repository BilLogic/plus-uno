## When to use

Use `RadarChart` to show a profile across a handful of measures on one scale: a
tutor's five SMART competencies, a student's skills across subjects, one tutor
against the cohort average. The shape shows balance and gaps at a glance.

Radars are hard to read precisely: values sit at different angles and the area
grows faster than the numbers. When readers need the values, use `BarChart`.
For two values per measure read as a gap, use `DumbbellChart`. For measures
changing over time, use `LineChart`.

Keep it to roughly three to eight spokes and two or three series, all on the
same scale. Mixed units on one radar make the shape meaningless.

## Data shape

`categories` is an array of strings, one per spoke. `series` is an array of
`{ name, data }`, where `data` holds one number per category in the same order.
A series may carry its own `color`. `height` takes a number of pixels, default
400, or `'100%'` to fill its container. `chartSpacing` is
`[top, right, bottom, left]`.

```jsx
<RadarChart
    filled
    yAxisMax={5}
    categories={['Social-emotional', 'Mastering content', 'Advocacy', 'Relationships', 'Technology tools']}
    series={[
        { name: 'Maya', data: [4, 5, 3, 5, 4] },
        { name: 'Cohort average', data: [3.5, 4, 3.5, 4, 3], dashStyle: 'Dash' },
    ]}
/>
```

## Color and accessibility

- **Color is assigned for you.** One series takes `--ds-chart-brand`. Two or more take the categorical order, slot 1 first. A series' own `color` overrides that.
- **Spoke labels can carry subject color.** `categoryColors` tints each label, as an array in category order or an object keyed by name. For the five SMART competencies, use the `--ds-chart-smart-*` tokens from `SMART` in the palette so each subject wears its own color.
- **Distance from center carries the value.** Color tells series apart, so add a second cue when there are two: `filled` makes the first an area, and `dashStyle` can dash the comparison line.
- **Icons need a nearby name.** With `categoryIcons`, the spoke shows only the icon. Name the categories in the surrounding text so the chart is not icon-only.
- **Data labels always add a percent sign.** Turn on `showDataLabels` only when the values are percentages.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`RadarChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Competencies could not load.</SectionMessage>
    : series.length === 0 ? <EmptyState spacing="compact" header="No ratings yet" description="Competencies appear after a session is reviewed." />
    : <RadarChart categories={categories} series={series} />}
```

- For measures that change over time, use `LineChart`.
- For one score against a target per measure, use `BulletChart`.
