## For developers

- **Caption and validation message are separate props.** <code>caption</code> is standing help. <code>validationMessage</code> appears only while <code>validation</code> is set and takes the caption's place.
- **A neutral line on a field with no caption prop** is text you render. Give it an id and pass <code>aria-describedby</code> to the control.
- **The required marker sets the field required for assistive technology only.** It does not set the native required attribute or block a submit, so your own validation enforces it.

## When to use

Label and caption have no component of their own. Text field, Select, Text area and the other fields render their label and caption, so use the field, not these parts.

- **Label every field.** The label is the field's name for a screen reader and a click target that focuses it. It is always present, short, and does not change.
- **Add a caption only when the field has something to say.** A caption helps, warns or explains, and it carries a state. A placeholder is no substitute, because it vanishes once a person types.
- **Say what the field is, not what to do with it.** Labels appear without context in a screen reader's list of fields. An instruction, if one is needed at all, is a caption.
- **Write the error, not the fact that there is one.** A danger caption says what to do next, such as "Choose a date after today", not "Invalid date". The state colors the line, and the words do the work.
- **Mark required fields with the asterisk alone.** The form explains the asterisk once, in a legend. Fields carry no "(required)" or "(optional)" text.
- **A group of choices is named by its legend**, not by a label. See [Choice group](?path=/docs/components-forms-and-inputs-choice-group--docs).
- **For a message about the whole form rather than one field**, use an alert.

</div>

## Accessibility

- **The label is associated, not merely adjacent.** The field components connect the label to the control. Where you build a field yourself, a label that sits above an input and points at nothing names nothing.
- **A label for a set of controls is not a label element.** For radios or a scale, a label element would point at one control, and clicking it would select that one. Choice group names its set with a fieldset and legend, and Rating names its row by pointing it at a text label.
- **Messages are attached to their fields.** The field points at its message, marks an invalid field as invalid, and reads an error out when it appears. Your own description is kept, not replaced.
- **Standing help is read before a validation message.** A caption on the field is described by the field, so a screen reader reads it with the name.
- **Do not hide the label.** Hiding it with <code>showLabel=false</code> moves pixels and keeps the name. Do not remove the name.
- **State is never color alone.** Caption states carry an icon as well as a color, and the words should stand without either.
- **The asterisk is decoration for sighted people.** It is hidden from assistive technology, which hears the field announced as required instead.

</div>
