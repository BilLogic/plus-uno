## When to use

Use `SunburstChart` when a total breaks down across a shallow hierarchy (root
plus two rings) and readers benefit from drilling into branches, such as session
hours by subject and topic or SMART competencies by skill.

For a single level of parts, use `PieChart` or `DonutChart`. For a flat split
with many parts, use `TreemapChart`. For a hierarchy without sizes, use
`TreegraphChart`. For exact comparisons, use `BarChart`.

## Data shape

`data` is a flat array of `{ id, parent, name, value }`: the root sets
`parent: ''`, other nodes reference their parent's `id`, and leaf nodes carry
`value` (parent totals are summed automatically). Keep depth to the root plus
two rings.

```jsx
<SunburstChart
    data={[
        { id: 'all', parent: '', name: 'Session hours' },
        { id: 'zoom', parent: 'all', name: 'Zoom' },
        { id: 'pencil', parent: 'all', name: 'Pencil Spaces' },
        { id: 'lincoln', parent: 'zoom', name: 'Lincoln Middle', value: 120 },
        { id: 'roosevelt', parent: 'zoom', name: 'Roosevelt K-8', value: 90 },
        { id: 'north', parent: 'pencil', name: 'North High', value: 70 },
        { id: 'south', parent: 'pencil', name: 'South High', value: 110 },
    ]}
/>
```

## Color and accessibility

- **Theme categorical color.** Arcs draw from the theme's [categorical order](?path=/docs/data-visualizations-color--docs); position under each parent, arc length and labels carry the structure without hue.
- **Keep branches few.** Many parts per level make outer arcs too thin to label or click; rely on the tooltip for exact values on narrow arcs.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`SunburstChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Session hours could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No session hours yet" description="Hours appear after a session is logged." />
    : <SunburstChart data={data} />}
```
