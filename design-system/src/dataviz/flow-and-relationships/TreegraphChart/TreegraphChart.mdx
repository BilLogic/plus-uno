## When to use

Use `TreegraphChart` for any parent-child structure that is not a reporting
line: subject to topic to lesson, a prerequisite chain, or a decision path a
tutor follows in a session.

For people and who they report to, use `OrganizationChart`. For the same tree
sized by a value, use `TreemapChart` or `SunburstChart`. For a structure where a
node has more than one parent, or links loop back, use `NetworkGraph`; a tree
cannot draw either.

## Data shape

`data` is a flat array of `{ id, parent, name }`. `id` is required and unique;
`parent` is the `id` of the node above it, left out for a root; `name` is the
label.

```jsx
<TreegraphChart
    data={[
        { id: 'math', name: 'Math' },
        { id: 'fractions', parent: 'math', name: 'Fractions' },
        { id: 'ratios', parent: 'math', name: 'Ratios' },
        { id: 'equivalent', parent: 'fractions', name: 'Equivalent fractions' },
        { id: 'unit-rates', parent: 'ratios', name: 'Unit rates' },
    ]}
/>
```

## Color and accessibility

- **Color marks depth, not identity.** Level 0 takes `--ds-chart-categorical-1`, level 1 `--ds-chart-categorical-2`, level 2 `--ds-chart-categorical-3`. Nodes cannot be colored one by one.
- **Position carries the structure.** Levels and links show the hierarchy and every node is named, so the tree reads without hue.
- **Labels sit on colored boxes.** The label is `--ds-text` with no outline; check that it stays legible on each level's fill in both color modes.
- **Wide trees crowd.** Many siblings at one level squeeze their labels. Collapse a branch into one node, or split the tree.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`TreegraphChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={500} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Topic tree could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No topics yet" description="Topics appear once a subject's lessons are added." />
    : <TreegraphChart data={data} />}
```
