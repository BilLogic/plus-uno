## When to use

Use `SmartTag` wherever training content, a tutor's strengths or a feedback
item is tagged by SMART area. For a category that is not a SMART subject, use
`Tag` directly — `SmartTag` exists only to fix the color and icon per subject,
not to add new behavior.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Older spellings still work.

`socio-emotional` and `relationships` are accepted and map to
`social-emotional` and `relationship`. Write new code with the current
spelling; the aliases exist for content written before it changed.

```jsx
<SmartTag subject="advocacy" />
<SmartTag subject="technology-tools">Tech & tools</SmartTag>
```

### Let the default label stand unless the context needs different words.

Each subject already has a label people recognize. Override it with
`children` or `text` only when the surrounding content needs a shorter or
longer phrasing.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **Inherits `Tag`'s accessibility.** Selection, removal and link behavior
  are unchanged — see `Tag`'s own Accessibility section for the full
  contract.
- **The subject icon is decorative.** It is `aria-hidden`; the subject's name
  is carried by the visible label, not the icon.

</div>

<div className="sb-ds-doc-section">

## Related

- For a category outside the five SMART subjects, use `Tag` directly.
- For a group of tags, including smart tags, use `TagGroup`.
