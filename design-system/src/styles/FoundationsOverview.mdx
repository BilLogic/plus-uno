<FoundationSection title="Overview">

Foundations are the tokens, guidelines and visual styles that every pattern and component builds on: color, spacing, typography and more. This page lists all fifteen, grouped as tokens, guidelines, then styles.

- Repo: `design-system/guidelines/foundations/` holds the written guidance for each foundation.
- Figma: one page per foundation under Foundations, in this order.
- Storybook: one page per foundation under Foundations, in the same order.

</FoundationSection>

<FoundationSection title="Page anatomy">

Every foundation page follows the same shape, so you can find the same thing in the same place.

- A landing opens the page: the foundation's name, what it is in one line, and its hero.
- The right rail lists every section, Overview and Related included.
- The foundation's own sections come next, then Accessibility, then Related last.
- Examples are drawn from live tokens, so they follow the toolbar's Color mode and Contrast switches.

</FoundationSection>

<FoundationSection title="Accessibility">

Each foundation page ends its guidance with the accessibility rules it owns, and the [Accessibility](?path=/docs/foundations-accessibility--docs) page holds the rules that cut across them.

</FoundationSection>
