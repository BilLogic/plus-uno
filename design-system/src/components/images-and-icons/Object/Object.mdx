## Usage

Use an `Object` icon beside the name of the thing it represents — a task in a
list, a bug in a reference, a page in a breadcrumb. For a larger picture of a
thing (a school, a tool, a lesson), use `Tile`. For a bitmap, use `Image`.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Glyph.** A fixed Font Awesome Free glyph for the kind: task, bug, idea, pull request, project or page.
2. **Size.** 12 or 16, in `--ds-icon-subtle`.

## Best practices

### Pick the component for the kind — there is no generic `Object`.

`TaskIcon`, `BugIcon`, `IdeaIcon`, `PullRequestIcon`, `ProjectIcon` and
`PageIcon` each draw a fixed glyph. Reach for the one that names the thing,
rather than a generic component with a glyph prop.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><TaskIcon label="" /><span>Fix the broken sync</span></div>}
    doCaption="The Task glyph beside the task name."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><BugIcon label="" /><span>Fix the broken sync</span></div>}
    dontCaption="The Bug glyph on a task."
/>

### Override `label` only when the default name does not fit.

Each kind defaults its accessible name to its kind ("Task", "Bug", …). Set
`label=""` when the kind is already stated in visible text beside it, so
assistive technology does not hear it twice.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><TaskIcon label="" /><span>Task: fix the sync</span></div>}
    doCaption="An empty label when the kind is written beside it."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><TaskIcon /><span>Task: fix the sync</span></div>}
    dontCaption="Both the default name and the visible kind, so it reads twice."
/>

### Keep the glyph at its kind.

Each kind has one glyph. Do not change the glyph or the color to say a status; show the status in text or a Status tag.

<DoDontPair
    doExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><TaskIcon /><span>Fix the sync</span><StatusTag appearance="success">Done</StatusTag></div>}
    doCaption="The kind stays a Task; the status goes in a Status tag."
    dontExample={<div style={{ display: 'flex', alignItems: 'center', gap: 'var(--inline-md)' }}><TaskIcon /><BugIcon /><span>Fix the sync</span></div>}
    dontCaption="A second glyph to hint at a status."
/>

</div>

## Accessibility

- **Named by default.** Each icon's default `label` makes it `role="img"`
  with that name, read by assistive technology.
- **Decorative with an empty label.** `label=""` sets `aria-hidden="true"`
  and drops the accessible name, for use beside visible text that already
  names the kind.
