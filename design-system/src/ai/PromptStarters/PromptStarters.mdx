## When to use

Use `PromptStarters` on an empty chat or panel, to show what the agent can help
with before anyone has typed. Put them above a `PromptInput`.

## Usage notes

### Starters are suggestions, never auto-send.

A starter puts words in the field for a person to read, change and send. Sending
on press takes the choice away from them.

```jsx
// Incorrect: pressing a starter sends it unread.
<PromptStarters label="Suggested prompts" starters={starters} onSelect={(s) => send(s.text)} />

// Correct: it fills the PromptInput and the person sends.
<PromptStarters label="Suggested prompts" starters={starters} onSelect={(s) => setText(s.text)} />
```

### Keep them short and few.

<DoDont>
    <Do caption="Three or four short labels that each name a task.">
        <PromptStarters
            label="Suggested prompts"
            starters={[
                { id: 'a', label: 'Plan a session' },
                { id: 'b', label: 'Recap last session' },
                { id: 'c', label: 'Set learning goals' },
            ]}
        />
    </Do>
    <Dont caption="Do not fill the room with long sentences. A wall of chips is a menu nobody reads.">
        <PromptStarters
            label="Suggested prompts"
            starters={[
                { id: 'a', label: 'Plan a thirty minute session on fractions' },
                { id: 'b', label: 'Summarize everything we did last month with every student' },
                { id: 'c', label: 'Write a long note to every parent' },
            ]}
        />
    </Dont>

## Accessibility

- **A named group.** The chips sit in `role="group"` named by `label`.
- **Real buttons.** Each is a native button, named by its label and &ldquo;suggested&rdquo;,
  reachable in order by Tab.
- **Wrapping, not scrolling.** The row wraps, so every starter stays visible at
  any width and zoom.
