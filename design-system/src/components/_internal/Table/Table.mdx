## Usage notes

- **Sorting is not built in.** The consuming page owns sort state and passes already-ordered `rows`. To make a header sortable, put a text-fill `Button` in that header's `text`.
- **Per-cell control** — pass `{ content, align, colSpan, className }` instead of a bare value when a cell needs alignment or spanning.
- **Density** maps to the `--size-table-cell-*` token family.

</div>

<div className="sb-ds-doc-section">

## Related

- For a list of records with no columns to line up, use `ListGroup`.
- For splitting a long result set across pages, use `Pagination`.
- For a status or a count inside a cell, use `Badge`.
- For a row-select control, use `Checkbox` with an `aria-label` — the column heading does not name it.
