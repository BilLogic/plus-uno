Image and Figure are the Bootstrap image utilities: a picture in a thumbnail
frame, and a picture with a caption. They place a picture in content such as a
lesson, a help article or a training page. They map to no PLUS component, so
you write them as `img` and `figure` elements with Bootstrap classes.

## What to write

A thumbnail is an `img` with `img-thumbnail`. A figure is a `figure` that holds
an `img` with `figure-img` and a `figcaption` with `figure-caption`. The
thumbnail frame follows the toolbar's Color mode and Contrast switches.

```jsx
<figure className="figure">
    <img src={src} className="figure-img img-thumbnail img-fluid" alt="A number line from 0 to 10 with 7 marked" />
    <figcaption className="figure-caption text-start">A caption for the above image.</figcaption>
</figure>
```

## Anatomy

1. **Thumbnail frame.** The `.img-thumbnail` utility: a 1px outline, 4 of padding and a 4 radius around the picture.
2. **Picture.** The image itself. Figma draws a teal placeholder that marks where the picture goes and states its size. Replace it with the real picture.
3. **Caption.** The `figcaption` with `.figure-caption`, aligned left or right.

</div>

## Properties

Image and Figure have no props. Each choice is a Bootstrap class.

The Bootstrap version in use names the alignment classes <code>text-start</code>
and <code>text-end</code>. Figma still names them <code>.text-left</code> and
<code>.text-right</code>. In this version <code>img-thumbnail</code> already limits
the picture to its container's width, so fixed and fluid look the same in a column wider than the picture.

## States

Image and Figure are static, so they have no states. Wrap a clickable picture
in a link or a button. That wrapper carries the hover and the focus ring.

## Rules

- **Prefer a component when one fits.** Use Tile, or the media slot of a Card or a Jumbotron.
- **Use fluid in responsive layouts.** A picture then never overflows a narrow column. Use fixed only where the picture has a known size.
- **Keep the picture's own ratio.** Never stretch it.

## When to use

Use an Image or a Figure to place a picture in long-form content. Use a Figure
when the picture needs a caption.

- For a small square picture or a logo beside a name, use **Tile**.
- For a person, use **Avatar**.
- For a picture beside a page's main message, use the media slot of **Jumbotron**.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **Describe a picture that carries meaning.** Write alt text that says what it shows.
- **Skip a decorative picture.** Give it an empty alt, `alt=""`, so screen readers pass over it.
- **A Figure's caption is read with its picture.** Keep the alt text from repeating the caption.
- **Keep text that matters out of the picture.** Text in an image cannot be read aloud, translated or resized.
- **A clickable picture takes its name from its wrapper.** The link or button around it also carries the focus ring.

</div>
