## When to use

Use `Sparkline` for a trend beside a stat or in a table row: a student's
average score over the last seven weeks next to today's score, attendance per
week in a tutor's roster row. The number says where things are; the line says
which way they are heading.

For values someone reads off an axis, or more than one series, use
`LineChart`. For a single headline number with no trend, show the number alone,
not a chart.

Always put the current value beside it in text. The line carries only the
shape.

## Data shape

`data` is an array of numbers, oldest first. `label` is required: it names the
line for screen readers and the tooltip. `categories` is an optional label per
value, shown in the tooltip.

```jsx
<span>82%</span>
<Sparkline
    label="Average score, last 7 weeks"
    data={[64, 70, 68, 74, 77, 79, 82]}
    categories={['Sep 1–5', 'Sep 8–12', 'Sep 15–19', 'Sep 22–26', 'Sep 29–Oct 3', 'Oct 6–10', 'Oct 13–17']}
    valueSuffix="%"
/>
```

## Color and accessibility

- **Brand by default, a status when the trend means one.** The line takes `--ds-chart-brand`. Set `tone` to `success`, `warning`, `danger` or `information` only when the trend itself is on track or at risk, and say the status in the text beside it too, as the Overview story does. Color alone never carries it.
- **The marker stands off the line.** The latest-value marker is ringed in `--ds-border-inverse`, so it reads against the line in light and dark.
- **Checked in every color mode.** The `ColorModes` story is a test, hidden from this page: in every color mode it checks that a brand line strokes in `--ds-chart-brand` and a danger line in `--ds-chart-danger`, that only the latest value draws a marker at rest, and that no axis labels render.
- **Name it with `label`.** The chart's screen-reader description and series name come from `label`, since there is no axis or title to describe it. Write what the line shows and over what span.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary, per-point labels, and arrow-key navigation through the values. The chart takes no title of its own, so the stat or row around it must name it.
- **Contrast.** The line follows the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`Sparkline` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the size of the sparkline.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" width={120} height={32} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="A trend appears after a few sessions." />
    : <Sparkline label="Average score, last 7 weeks" data={data} />}
```
