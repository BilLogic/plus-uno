## Usage

Use `ButtonGroup` for a short row of related actions that read as one unit —
view toggles, a set of filters. For mutually exclusive options that pick one
value, consider whether `RadioGroup` fits the data better than buttons
styled to look selected.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Container.** Groups its children with `role="group"` and the `label` as its name. It paints nothing of its own.
2. **Buttons.** Button or Icon button children. Each keeps its own appearance, spacing and state.
3. **Seam.** Inner corners are square and neighbors overlap by one edge, so the row reads as one control.

## Best practices

### Group actions that belong together.

<DoDontPair
    doExample={<ButtonGroup label="Date range"><Button text="Week" /><Button text="Month" /></ButtonGroup>}
    doCaption="Related choices connected in one group, with a name."
    dontExample={<ButtonGroup label="Actions"><Button text="Week" /><Button appearance="danger" text="Delete" /></ButtonGroup>}
    dontCaption="Unrelated actions, one of them destructive, sit side by side as if they were a choice."
/>

### Give every group a `label`.

`ButtonGroup` has no visible title of its own — `label` is the only thing
that tells assistive technology the buttons form one related set.

```jsx
<ButtonGroup label="View options">
    <Button text="List" isSelected={view === 'list'} onClick={() => setView('list')} />
    <Button text="Grid" isSelected={view === 'grid'} onClick={() => setView('grid')} />
</ButtonGroup>
```

### Selection state lives on each `Button`, not on the group.

`ButtonGroup` renders children as given — set `isSelected` on the `Button`
that should read as current, and manage which one that is yourself.

</div>

## Accessibility

- **A named group.** The row is `role="group"` with `label` as its accessible
  name, so assistive technology announces the buttons as one related set.
- **Each button keeps its own accessible name and state.** `ButtonGroup`
  adds no roles or attributes beyond the group wrapper.

</div>

<div className="sb-ds-doc-section">

## Related

- For a single action, use `Button` directly.
- For a group of buttons stacked vertically instead of in a row, use
  `VerticalButton`.
