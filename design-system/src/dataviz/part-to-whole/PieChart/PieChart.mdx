## When to use

Use `PieChart` when one total divides into two to five parts — such as sessions
per subject, students by grade band or library resource types — especially when
one share dominates or matches a simple fraction.

For a headline number in the center, use `DonutChart`. For more than five parts
or close comparisons, use `BarChart`. To compare the same split across groups,
use `StackedBarChart`. For nested parts, use `SunburstChart`.

## Data shape

`data` is an array of `{ name, y, color }` (`name` and raw `y` required;
`color` optional). The chart computes percentages from the sum of `y`. Sort
`data` from most to least before passing it in.

```jsx
<PieChart
    data={[
        { name: 'Math', y: 420 },
        { name: 'Reading', y: 310 },
        { name: 'Science', y: 180 },
        { name: 'Other', y: 90 },
    ]}
/>
```

## Color and accessibility

- **Color by position.** Slices without `color` take the [categorical order](?path=/docs/data-visualizations-color--docs) starting at slot 1 (even for a single slice). Keep to five or fewer slices and group smaller parts into "Other" rather than reaching overflow slots 7 and 8.
- **Labels compensate for angle.** Because angles are hard to compare closely, data labels print each slice's name and percentage so the chart reads without hue; switch to `BarChart` when ranking close shares. Never tilt the pie into 3D.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`PieChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Sessions could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No sessions yet" description="The split appears after a session is logged." />
    : <PieChart data={data} />}
```
