## For developers

Import `UserAvatar` from the `@/components` barrel. The Avatar renders a
`div`, so make it a control by wrapping it.

```jsx
import { UserAvatar } from '@/components';

// In the topbar: 32 high, with the unread count.
<button type="button" aria-label="Account, 2 unread notifications">
    <UserAvatar size="md" firstChar="J" name="Jane Park" counterValue={2} />
</button>
```

The `lg` size is the default and keeps the padded row used in tables. Pass
`size="md"` wherever the Avatar sits in the 32 topbar.

## When to use

Use an Avatar to show who is signed in, in the topbar, or to name a tutor or
a student in a row.

- For a school, a tool or a lesson, use **Tile**.
- For a role or a state beside a name, use **Status**.
- For a count of unread items on its own, use **Count**.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **The pill is decorative.** It is hidden from assistive technology, so the name is the accessible text. Keep the name on wherever the Avatar stands alone.
- **A truncated name keeps its full text.** It shows as a tooltip, so a long name is never lost.
- **The counter is a bare number.** Give the control that holds it a name that says what it counts, such as "2 unread notifications".
- **A clickable Avatar needs a button around it.** The Avatar itself is not focusable and draws no focus ring. Wrap it in a button or a link that carries the accessible name and the focus ring.

</div>
