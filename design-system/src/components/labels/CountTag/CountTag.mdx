## Usage

Use `CountTag` for a number on its own: unread messages on a nav item, results on a
tab, errors in a section header, a notification on a bell.

- **Is it a number?** Count tag.
- **Is it the condition something is in, and can that condition change?** Status tag.
- **Otherwise** (a subject, a person, a category): Tag.

`spacing="compact"` (16) is for use inside a label: Status tag nests it through its
`trailingMetric` prop, and Tag nests it on a selectable tag.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Number.** The count in the body-small size with tabular digits, hidden at 0 unless <code>showZero</code>, capped at <code>max</code> with a <code>+</code>.
2. **Badge.** 20 tall on its own and 16 inside a label, 24 wide at minimum, with a 2 corner, so one digit is a small rectangle and more digits grow it from the trailing edge.
3. **Dot.** Presence without a number: an 8 circle that needs a <code>label</code> for its name.
4. **Ring.** Optional, in the surface color, for a count pinned to the corner of an icon or an avatar.

## Best practices

Use a count for a number on its own, beside the thing it counts or inside a Status tag or Tag. For a condition, use Status tag; for a category, use Tag; for progress toward a total, use Progress bar.

### Keep most counts quiet.

Subtle neutral is the default. Bold asks for action now, so use at most one bold count per area.

<DoDontPair
    doExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><CountTag value={12} /><CountTag value={4} /><CountTag value={3} isBold appearance="danger" label="3 errors" /></div>}
    doCaption="Subtle neutral by default, with bold only where something needs doing now."
    dontExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><CountTag value={12} isBold appearance="danger" /><CountTag value={4} isBold appearance="info" /><CountTag value={3} isBold appearance="warning" /></div>}
    dontCaption="Bold on every item in a list: when every count shouts, none of them does."
/>

### Let the component decide zero and overflow.

It renders nothing at 0 and caps past `max` with a `+`, so pass the raw number.

<DoDontPair
    doExample={<CountTag value={250} label="250 results" />}
    doCaption="Pass the raw number; past 99 it reads 99+."
    dontExample={<CountTag value={0} showZero />}
    dontCaption="Force a zero onto an empty tab, unless the zero is the news."
/>

### Show the bare number, and put the meaning in the label.

The badge shows 4, never "4 unread"; `label="4 unread messages"` tells a screen reader what it counts.

### Use inverse on filled buttons and dark surfaces.

Inverse is a solid white badge with dark text, so it passes contrast on any fill. On a light surface use subtle.

<DoDontPair
    doExample={<div style={{ display: 'inline-flex', padding: 'var(--pad-y-lg) var(--pad-x-md)', borderRadius: 'var(--radius-md)', backgroundColor: 'var(--ds-background-brand-bold)' }}><CountTag value={4} isInverse /></div>}
    doCaption="Inverse on a filled, dark ground."
    dontExample={<CountTag value={4} isInverse />}
    dontCaption="Inverse on a light surface, where it barely separates from the page."
/>

### Give a dot a name.

A dot has no number, so `label` is its accessible name; without one it is announced as nothing.

## Accessibility

- **A dot needs a name.** It has no number, so `label` is its accessible name,
  exposed as an image with that name. Without one it is announced as nothing,
  and the component warns in development.
- **A label turns a digit into information.** "Messages 4" is ambiguous; with
  `label="4 unread"` a screen reader hears "Messages 4 unread", while the badge
  still shows 4.
- **The count is not a control.** It is a `span` that sits inside buttons, tabs
  and nav items; whatever is pressable is the thing around it.
- **Contrast.** Subtle uses each appearance's (Text) color, and bold warning uses the
  Warning Container pair because warning with white text fails AA. Inverse
  is a solid white badge with dark text, so it clears AA on any fill, including
  a primary button.
