## When to use

Use `FunnelChart` for a sequence where each stage is a subset of the one before:
tutor onboarding (applied, trained, matched, first session), student
enrollment (referred, signed up, attended, active), or an assessment (started,
submitted, passed).

For stages that do not have to shrink, use `BarChart`. For flow that splits
into several destinations, use `SankeyDiagram`. For drop-off ranked by cause,
use `ParetoChart`.

Order stages from largest to smallest, in the order they happen. Keep to five
to seven stages.

## Data shape

`data` is an array of `{ name, y }`, one per stage, in process order. `name`
and `y` are required. A stage may carry its own `color`.

```jsx
<FunnelChart
    data={[
        { name: 'Applied', y: 640 },
        { name: 'Completed training', y: 410 },
        { name: 'Matched with students', y: 300 },
        { name: 'Led a first session', y: 260 },
    ]}
/>
```

## Color and accessibility

- **Each stage takes the next categorical color**, starting at `--ds-chart-categorical-1`, unless it carries its own `color`. The colors are not a ramp and say nothing about size; they only separate neighboring stages. Past eight stages the colors repeat.
- **The label carries the value.** Every stage is labeled with its name and count, so the chart reads without hue. Width is only a rough guide: the neck holds the last stages at one width, so read the counts, not the shape, near the bottom.
- **State the conversion yourself.** The chart shows counts, not percentages. If the drop between two stages is the point, say it in the surrounding text.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`FunnelChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Onboarding progress could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState size="compact" header="No applicants yet" description="Stages fill in as tutors apply and complete training." />
    : <FunnelChart data={data} />}
```

## Related

- For stages that do not have to shrink, use `BarChart`.
- For flow that splits and rejoins rather than narrowing, use `SankeyDiagram`.
- For the same drop-off ranked by cause, use `ParetoChart`.
- For quantities ordered largest to smallest without a process behind them, use `PyramidChart`.
