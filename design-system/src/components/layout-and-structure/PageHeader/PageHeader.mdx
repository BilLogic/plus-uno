## Usage

Use `PageHeader` once per page, at the top of the Page pattern's body, to
carry the page's title and the actions that apply to the page as a whole. For
a heading inside a region of the page, use the
<a target="_top" href="./?path=/docs/templates-section-section--docs">Section</a>{' '}
pattern's own header instead — `PageHeader` is reserved for the page level.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Breadcrumbs.** Optional, above the title.
2. **Title.** A level 2 heading, or any node with `disableTitleStyles`.
3. **Actions.** Optional, at the end of the title row.
4. **Bottom bar.** Optional, under the row: tabs, a filter bar or a status line.

## Best practices

Use one page header per page, for the title and the actions that apply to the whole page.

### Show the trail on nested pages.

Breadcrumbs tell the person where they are; on a page two levels down they are the way back.

<DoDontPair
    doExample={<PageHeader breadcrumbs={<Breadcrumb items={trail} label="Breadcrumbs, nested page" />} title="Session notes" />}
    doCaption="Breadcrumbs on a nested page."
    dontExample={<PageHeader title="Session notes" />}
    dontCaption="Nested page with no way back."
/>

### Name the page in a word or two.

The title shares a row with actions, so it has to stay on one line.

<DoDontPair
    doExample={<PageHeader title="Sessions" actions={<Button appearance="primary" text="Schedule" />} />}
    doCaption="A short noun."
    dontExample={<PageHeader title="All of the sessions you have scheduled this semester" actions={<Button appearance="primary" text="Schedule" />} />}
    dontCaption="A title that wraps and pushes actions down."
/>

### Use only the parts the page needs.

Every extra row pushes content down; add a part only when the page uses it.

<DoDontPair
    doExample={<PageHeader title="Session plans" actions={<Button appearance="primary" text="New plan" />} />}
    doCaption="Title and one action."
    dontExample={
        <PageHeader
            breadcrumbs={<Breadcrumb items={[{ text: 'Home', href: '#' }, { text: 'Session plans' }]} label="Breadcrumbs, every part" />}
            title="Session plans"
            actions={<Button appearance="primary" text="New plan" />}
            bottomBar={<Tabs defaultActiveKey="all" spacing="compact"><Tabs.Tab eventKey="all">All</Tabs.Tab><Tabs.Tab eventKey="mine">Mine</Tabs.Tab><Tabs.Tab eventKey="shared">Shared</Tabs.Tab></Tabs>}
        />
    }
    dontCaption="Breadcrumbs, actions and bottom bar all on."
/>

### `title` or `children` — not both.

Pass the title through `title`, or through `children` when that reads more
naturally in the surrounding code; `children` is only used when `title` is
not given.

```jsx
<PageHeader
    title="Session plans"
    breadcrumbs={<Breadcrumb items={trail} />}
    actions={<Button text="New plan" />}
/>
```

### Reach for `disableTitleStyles` only when the title isn't plain text.

The default renders the title in a `Heading`. Turn styling off when the
title itself needs to be something other than text that a `Heading` can
wrap — a custom element already carrying its own heading semantics.

## Accessibility

- **A real heading.** The title renders as an `h2` by default, giving the
  page one clear entry point for assistive technology navigating by
  heading.
- **Breadcrumbs keep their own semantics.** `PageHeader` doesn't wrap
  `breadcrumbs` in extra markup — pass a `Breadcrumb` component, which
  carries its own navigation landmark.
