## One primary AI action per region

Use one AI button per region, only for an action that calls the AI, such as "Generate summary" on session notes. Keep its built-in sparkle and required label. Use default or subtle buttons with an AI <DocsLink id="ai-ui-components-icon">Icon</DocsLink> for other AI actions.

    doExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><Button appearance="ai" text="Generate summary" /><Button appearance="subtle" text="Edit notes" /></div>}
    doCaption="One AI button for the region's main AI action, with the other actions subtle."
    dontExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><Button appearance="ai" text="Generate summary" /><Button appearance="ai" text="Save notes" /></div>}
