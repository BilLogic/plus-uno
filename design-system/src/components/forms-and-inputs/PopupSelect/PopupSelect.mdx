## Usage

Use `PopupSelect` when one pick from one list immediately changes what the page shows, with no field and no Apply button:

- **A view switch** under page tabs, such as "Status: Upcoming" (pass `label` and no `trigger`).
- **One filter** in a section's view bar, such as Subject (pass a `FilterButton` as `trigger`).

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For a value that belongs to a form field, use `Select`.
- For several filter categories staged and applied together, use `FilterMenu`.
- For a menu of actions rather than values, use `DropdownMenu`.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Trigger.** The labeled trigger is a subtle `FilterButton` reading "Label: Value" with a chevron. Any other trigger is the caller's.
2. **Popup.** A `Popup` at `width="auto"`: at least the trigger's width, never under 160, up to 320. It sits 4 from the trigger.
3. **Search** (optional). A compact search field above the list, on by default. Turn it off with `isSearchable={false}` for a short list.
4. **List.** `Select`'s list: the same rows, groups, descriptions and messages. The picked row takes the selected fill and a radio before its label, since the menu picks one value. `marker="check"` draws a check at the row's end instead.

## Best practices

### Line the menu up with its trigger's side.

Start-of-bar triggers open `bottom-start` and end-of-bar triggers open `bottom-end`, so the menu never hangs past its own bar.

### Turn search off for a short list.

Pass `isSearchable={false}` when a list has only a few options that scan at a glance.

### Show the active value on the trigger.

The built-in labeled trigger shows the value automatically; with a custom `FilterButton` trigger, pass the applied count as `trailingMetric`.

### Keep it to one list.

Two lists, or picks that wait for an Apply, are a different menu.

## Accessibility

- **The trigger is a real button** that says a popup opens and whether it is
  open. The labeled trigger's name carries the value: "Status: Upcoming".
- **The popup is named** by `label`, and so is the list inside it.
- **The search field is the list's combobox.** Focus stays in it while the
  arrow keys move the highlighted row (`aria-activedescendant`). Without
  search, focus goes to the list itself.
- **Focus returns to the trigger** after a pick or Escape.
