<FoundationSection title="Overview">

PLUS is all sans. Every heading, metric and body style is Noto Sans, and Noto Sans Mono is for code. Headings are semibold (600). Pick a style by its role on the page, never by how big it looks. Tutors and students read on laptops and desktops, so check each size on a desktop screen from 768 up.

```css
font: var(--heading-md);
font: var(--body-default);
font: var(--metric-lg);
```

Figma holds `Heading/*`, `Body/*`, `Metric/*` and `Code/default`, bound to the typography variables (<DocsLink id="foundations-tokens-typography">Tokens: Typography</DocsLink>).

</FoundationSection>

<FoundationSection title="Type scale">

Every text style binds to a typography variable and is sized in `rem` (1 rem = 16 px) so text scales with browser settings. Never type a raw size or detach a style.

<TypeScaleBlocks />

<FoundationSubsection title="Body, metric and weights">

- **Body/large (16/24):** long-form reading such as lessons, help articles and quotes (quotes use the body family; never add a decorative face).
- **Body/default (14/20):** default interface text and control labels (sets the 24, 32 and 40 control heights). Do not use heading styles inside components; use body with a heavier weight instead.
- **Body/small (12/16):** secondary meta text, tags, statuses, counts and tooltips.
- **Metric (large, medium, small):** featured numbers such as session counts or scores.
- **Paragraph spacing:** space blocks with Section and stack tokens (<DocsLink id="foundations-layout-spacing">Spacing</DocsLink>), never a paragraph-spacing style.

<FoundationSection title="In code">

<FoundationSubsection title="Text-style classes">

Markup without its own stylesheet can use the generated utility classes (`.heading-xxl` to `.heading-xxs`, `.body-lg`, `.body-default`, `.body-sm`, `.metric-lg` to `.metric-sm`), which set `font` and tracking together. The metric classes also set tabular figures. Component stylesheets use `font: var(--…)` directly, and add `font-variant-numeric: tabular-nums` to a metric.

```jsx
<p className="body-default">Helper text</p>
<h2 className="heading-md">Section title</h2>
```

<FoundationSection title="Heading levels">

Headings step down one size per nesting level; containers use a fixed title size. Reserve `Heading/xxlarge` (32) and `Heading/xlarge` (28) for heroes, empty states and metric-heavy dashboards, never a page title. Use a heading style rather than bold text or a size change, because heading styles carry the structure assistive technology reads.

<FoundationSection title="Labels">

Button, tab and menu labels use `Body/default/medium` (`font: var(--body-default); font-weight: var(--type-weight-medium)`), which pairs with icon stroke weight. A Sidebar tab is a navigation row: its label is regular weight at rest and medium when selected.

</FoundationSection>

<FoundationSection title="Code">

`Code/default` (12/16, Noto Sans Mono) sets code samples, token names and property values. In CSS, `var(--code-default)` sets `0.875em` of the parent size so inline code scales with surrounding text.

<Canvas of={TypographyStories.CodeStyle} sourceState="none" />

<FoundationSection title="Truncate and wrap">

Names and titles truncate; primary content wraps. Never shrink font size to fit a long string.

- **Titles and names** truncate to one line with an ellipsis; expose the full text on hover or in the detail view.
- **Descriptions** clamp at 3 lines unless configured to wrap.
- **Session notes and help answers** wrap in full. Table cells truncate by default and opt into wrap per column.

<FoundationSection title="Headings, numbers and mono">

<FoundationSubsection title="Headings">

Every heading level is Noto Sans at weight 600. Size, line height and tracking step down together (sizes are in the type scale above, tracking in the tokens table, and the level for each role in Heading levels).

Semibold at 28 and 32 sits close to bold body text. Keep 600 and do not add a 700 weight.

</FoundationSubsection>

<FoundationSubsection title="Numbers">

Metric styles are Noto Sans 600 with tabular figures. Use the `.num` class, or `font-variant-numeric: tabular-nums`, for numbers that line up vertically: table columns, times in schedules and timelines, and counts in lists. Running text keeps proportional figures. A time or duration ("3:30 to 4:30", "12 min") takes the body or heading style of its context, never mono.

<Canvas of={TypographyStories.MetricNumbers} />

</FoundationSubsection>

<FoundationSubsection title="Mono">

Noto Sans Mono is for code, token names, property values and machine IDs such as a session ID or a URL. Never use it for metrics, times or counts: mono digits are wide and read as a data dump. `Code/default` is 0.875em of its parent, and in a table it pairs with `Body/small`.

<FoundationSection title="Accessibility">

- Keep one `h1` per page and step down one heading level at a time (`h1` → `h2` → `h3`); the HTML tag sets the outline while the token sets the visual size.
- Pair text styles with `color/text/*` tokens to meet WCAG AA 4.5:1 contrast (<DocsLink id="foundations-visual-color">Color</DocsLink>).
- All type tokens use `rem` or `em` so text scales with browser zoom and font-size preferences.

</FoundationSection>
