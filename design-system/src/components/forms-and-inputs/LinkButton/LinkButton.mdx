## Usage

Use a link button to open another page, a site or a place on the page. For an action that stays on the current page, use a Button.

</div>

<div className="sb-ds-doc-section">

## Parts

1. **Container.** An anchor drawn as a button: 32 high at default spacing and 24 at compact.
2. **Icon before** (optional). A Font Awesome Free glyph at 16, before the label.
3. **Label.** Body/default at the medium weight. It describes the destination or purpose.
4. **Icon after** (optional). A Font Awesome Free glyph at 16, after the label, such as the external-link glyph.

Default spacing suits most places. Use compact in table rows and inline toolbars.

## Best practices

### Keep space between link buttons.

Leave a gap so neighboring link buttons read as separate targets.

<DoDontPair
    doExample={<div style={{ display: 'flex', gap: 'var(--inline-md)' }}><LinkButton href="#sessions" text="View sessions" /><LinkButton href="#students" text="View students" /></div>}
    doCaption="A clear gap between link buttons."
    dontExample={<div style={{ display: 'flex', gap: 0 }}><LinkButton href="#sessions" text="View sessions" /><LinkButton href="#students" text="View students" /></div>}
    dontCaption="Link buttons touching."
/>

### Use it to go somewhere, not to act.

A link button navigates to a page or an external address, and assistive
technology announces a link. Actions that save, delete or submit belong on a
Button.

<DoDontPair
    doExample={<LinkButton href="#notes" text="Open session notes" />}
    doCaption="Open session notes goes to the notes page."
    dontExample={<LinkButton href="#notes" text="Delete session" />}
    dontCaption="Delete session acts on the page, so it belongs on a button."
/>

### Let it hug its label.

Keep the natural width. Reserve `shouldFitContainer` for narrow containers,
such as a mobile sheet.

<DoDontPair
    doExample={<LinkButton href="#sessions" text="View sessions" />}
    doCaption="Natural width."
    dontExample={<LinkButton href="#sessions" text="View sessions" shouldFitContainer />}
    dontCaption="Stretched across a wide row."
/>

### Align with the button group.

Right-align in focused tasks and modal dialogs; left-align on full-page forms and content-heavy screens.

## Accessibility

- A link button is an anchor, so assistive technology announces a link. Do not use it for actions.
- It has no disabled state. A disabled link leaves the tab order, gets no focus or hover events and does not say why. Use validation and error messages instead, and never attach a tooltip to a disabled control.
- `target="_blank"` adds `rel="noopener noreferrer"`. Flag the new tab in the label or with the external-link glyph.
- The focus ring is 2px in `--ds-border-focused`. Never remove it.

</div>
