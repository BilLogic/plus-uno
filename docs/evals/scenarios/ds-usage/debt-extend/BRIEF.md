# Monthly reviews: status filter

`src/MonthlyReviews.jsx` is a tutor's list of monthly reviews, carried over from an earlier prototype, and `src/App.jsx` renders it. Extend it in `src/`, with the PLUS design system.

Add a status filter above the table (*All*, *Not viewed*, *Viewed*) that narrows the rows, and keep the "Showing … results" line and the pagination true to the filtered list. When a filter matches nothing, show an empty state with a way to clear the filter. *View* marks a review as viewed, so a *Not viewed* filter loses that row at once. Keep everything else the list already shows and does.
