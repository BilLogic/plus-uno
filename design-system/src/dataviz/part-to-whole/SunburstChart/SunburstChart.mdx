## When to use

Use `SunburstChart` when a total breaks down in levels and the reader needs to
see both the levels and the sizes: session hours by subject, then by topic;
SMART competencies, then the skills inside each. It suits exploration, since a
reader can click a branch to see only its parts.

For a single level of parts, use `PieChart` or `DonutChart`. For a flat split
with many parts, use `TreemapChart`; tiles are easier to compare than arcs.
For the shape of a hierarchy with no sizes attached, use `TreegraphChart`. For
values that must be compared precisely, use `BarChart`.

## Data shape

`data` is a flat array of `{ id, parent, name, value }`. The root has
`parent: ''`; every other node names its parent's `id`. Give `value` to the
leaves; a parent's size is the sum of its children.

```jsx
<SunburstChart
    data={[
        { id: 'all', parent: '', name: 'Session hours' },
        { id: 'zoom', parent: 'all', name: 'Zoom' },
        { id: 'pencil', parent: 'all', name: 'Pencil Spaces' },
        { id: 'lincoln', parent: 'zoom', name: 'Lincoln Middle', value: 120 },
        { id: 'roosevelt', parent: 'zoom', name: 'Roosevelt K-8', value: 90 },
        { id: 'north', parent: 'pencil', name: 'North High', value: 70 },
        { id: 'south', parent: 'pencil', name: 'South High', value: 110 },
    ]}
/>
```

The chart sizes three levels: the root and two rings beneath it. Keep the
hierarchy to that depth.

## Color and accessibility

- **Color comes from the theme.** The chart sets no colors of its own, so arcs draw from the theme's categorical order. Do not rely on color to say which branch an arc belongs to; its position under its parent says that.
- **Position and labels carry the structure; arc length carries the size.** The chart reads without hue, but outer arcs are short and their labels crowd. The tooltip is the reliable place for an exact value.
- **Keep it shallow and short.** More than a handful of parts per level makes outer arcs too thin to read or click.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation through the arcs. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`SunburstChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Session hours could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No session hours yet" description="Hours appear after a session is logged." />
    : <SunburstChart data={data} />}
```
