## When to use

Use `Fieldset` wherever a set of fields shares one label and, often, one
validation message — a group of radios, a group of checkboxes, related text
fields asked together. For a single field with its own label, use the
<a target="_top" href="./?path=/docs/components-forms-and-inputs-form--docs">label and caption</a>{' '}
convention instead.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### One `error` covers the whole group.

Pass `error` on the `Fieldset`, not on each field inside it, when the
validation applies to the set as a whole — "Choose at least one," for
example, rather than a field-by-field message.

```jsx
<Fieldset legend="Notify me by" isRequired error={error}>
    <Checkbox label="Email" />
    <Checkbox label="Text" />
</Fieldset>
```

### Build on `Fieldset` rather than reimplementing it.

`RadioGroup` already composes `Fieldset` with `Radio` children. Reach for
`RadioGroup` directly for radios, and use `Fieldset` on its own only for a
shape it doesn't already cover, like a checkbox group.

</div>

## Accessibility

- **A real `fieldset`/`legend` pair.** The legend is tied to the group
  through native HTML semantics, which every screen reader already
  understands.
- **The error is announced once.** `role="alert"` on the error message means
  assistive technology hears it as soon as it appears, without needing focus
  to move there.
- **`isRequired` is visual and spoken.** The asterisk is `aria-hidden`, and a
  visually hidden "(required)" is added to the legend's accessible name.

</div>
