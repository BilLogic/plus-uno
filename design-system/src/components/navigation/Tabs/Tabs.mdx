## Usage

Use `Tabs` for the tab bar that switches between sibling views on the same page
— a student's Overview / Sessions / Progress, or the sections of an admin page.
Compose it from `Tabs.Tab` children, and declare a `Tabs.Panel` alongside each
one when the tab's content should be owned by the component rather than rendered
separately.

It can be uncontrolled (`defaultActiveKey`) or controlled (`activeKey` plus
`onSelect`). `alignment` covers left, center, right and `justified`, which
stretches the tabs to fill the bar. `appearance` is `default` (an underline) or
`pill` (a filled, rounded selected tab). There is one size: a 32 tab
(`--control-md`). `overflow` is `auto` by default: extra tabs fold into More,
and under 768 an underline strip scrolls sideways while a pill strip becomes
one pill that opens a menu of every view. `collapse`, `scroll`, `menu` and
`wrap` hold one form at every width.

</div>

<div className="sb-ds-doc-section">

## Alternatives

- For navigating to a different page in a hierarchy, use `Breadcrumb` or `Sidebar`.
- For more options than fit on one strip without wrapping, use `Select`.
- For a second-level choice inside a view, use `PopupSelect`.
- For filtering a list rather than switching between views, use `FilterMenu` or `RadioGroup`.

</div>

## Parts

1. **Tab strip.** A `tablist` of buttons, aligned left, center, right or justified.
2. **Tab.** A button whose label names a view, on one line; the selected one is marked by an underline on the strip's baseline (`default`) or a filled pill (`pill`), whose strip has no baseline.
3. **Baseline.** The hairline under an underline strip that the selected bar sits on.
4. **Panel.** The content one tab controls, shown below the strip.

## Best practices

### Pass `onSelect` whenever `activeKey` is controlled.

```jsx
// Incorrect — activeKey pins the bar and nothing updates it.
<Tabs activeKey="overview">
  <Tabs.Tab eventKey="overview">Overview</Tabs.Tab>
  <Tabs.Tab eventKey="sessions">Sessions</Tabs.Tab>
</Tabs>

// Correct.
<Tabs activeKey={tab} onSelect={setTab}>
  <Tabs.Tab eventKey="overview">Overview</Tabs.Tab>
  <Tabs.Tab eventKey="sessions">Sessions</Tabs.Tab>
</Tabs>
```

### Give every `Tabs.Tab` an `eventKey`.

```jsx
// Incorrect — with no eventKey, there is no key to compare against activeKey,
// so the tab never shows as selected and onSelect fires with nothing useful.
<Tabs activeKey={tab} onSelect={setTab}>
  <Tabs.Tab>Overview</Tabs.Tab>
</Tabs>

// Correct.
<Tabs activeKey={tab} onSelect={setTab}>
  <Tabs.Tab eventKey="overview">Overview</Tabs.Tab>
</Tabs>
```

### Keep the labels short and parallel.

Each label is one or two words naming a view of the same subject: Overview, Sessions, Progress. Parallel wording lets people scan the strip without reading it.

<DoDontPair
    doExample={<Tabs defaultActiveKey="0"><Tabs.Tab eventKey="0">Overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions</Tabs.Tab><Tabs.Tab eventKey="2">Progress</Tabs.Tab></Tabs>}
    doCaption="Short nouns for views of the same subject."
    dontExample={<Tabs defaultActiveKey="0"><Tabs.Tab eventKey="0">View the overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions list</Tabs.Tab><Tabs.Tab eventKey="2">Show progress</Tabs.Tab></Tabs>}
    dontCaption="Mixed verbs and phrases that do not scan."
/>

### Choose the appearance by weight, not taste.

The underline suits a strip that sits above page content. The pill suits a strip inside a card or toolbar, where a filled selected tab reads as a control.

<DoDontPair
    doExample={<FigureBox tone="surface"><Tabs defaultActiveKey="0" appearance="pill" overflow="collapse"><Tabs.Tab eventKey="0">Overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions</Tabs.Tab><Tabs.Tab eventKey="2">Progress</Tabs.Tab></Tabs></FigureBox>}
    doCaption="A pill strip inside a card reads as a control."
    dontExample={<FigureBox tone="surface"><Tabs defaultActiveKey="0"><Tabs.Tab eventKey="0">Overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions</Tabs.Tab><Tabs.Tab eventKey="2">Progress</Tabs.Tab></Tabs></FigureBox>}
    dontCaption="The page-level underline inside a card, where it reads as a stray rule."
/>

### Keep labels the same across visits.

A label names a view. A count or status in it changes the name and breaks the parallel wording.

<DoDontPair
    doExample={<Tabs defaultActiveKey="0"><Tabs.Tab eventKey="0">Overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions</Tabs.Tab><Tabs.Tab eventKey="2">Progress</Tabs.Tab></Tabs>}
    doCaption="The label names the view."
    dontExample={<Tabs defaultActiveKey="0"><Tabs.Tab eventKey="0">Overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions (12)</Tabs.Tab><Tabs.Tab eventKey="2">Progress (new)</Tabs.Tab></Tabs>}
    dontCaption="Counts and status in the label."
/>

### Let a tab label longer than its cap end in an ellipsis with a Tooltip.

The Tooltip is on only while the label is clipped. Tabs that do not fit fold into a More tab that opens a menu of them; `overflow="wrap"` lets them flow onto more rows instead. Under 768 nothing folds: underline tabs scroll and pill views become one menu. A `justified` strip shares the row and never folds or narrows. See [Overflow](?path=/docs/patterns-states-overflow--docs).

### Keep one tab system per page and use `PopupSelect` for a second-level choice.

A `pill` strip is a fixed set of views of one subject, decided when the page is designed, so it has no add-view control and people cannot create, rename, reorder or remove a tab. A strip that must grow with the data is a list or a `Select`, not tabs. A page has one tab system: the underline strip under the page header switches the page's sections, and a pill strip inside a card switches that card's views, without stacking two strips of the same kind. For a second-level choice inside a view, use the labeled trigger of `PopupSelect` ("Status: Upcoming") in the view's toolbar.

<DoDontPair
    doExample={<FigureStack><Tabs defaultActiveKey="0"><Tabs.Tab eventKey="0">Overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions</Tabs.Tab><Tabs.Tab eventKey="2">Progress</Tabs.Tab></Tabs><PopupSelect label="Status" defaultValue="upcoming" options={[{ value: 'upcoming', label: 'Upcoming' }, { value: 'past', label: 'Past' }]} /></FigureStack>}
    doCaption="One strip for the sections; a labeled PopupSelect for the choice inside one."
    dontExample={<FigureStack><Tabs defaultActiveKey="0"><Tabs.Tab eventKey="0">Overview</Tabs.Tab><Tabs.Tab eventKey="1">Sessions</Tabs.Tab><Tabs.Tab eventKey="2">Progress</Tabs.Tab></Tabs><Tabs defaultActiveKey="0" appearance="pill" overflow="collapse"><Tabs.Tab eventKey="0">Upcoming</Tabs.Tab><Tabs.Tab eventKey="1">Past</Tabs.Tab></Tabs></FigureStack>}
    dontCaption="A second strip under the first, so two tab systems compete."
/>

### Swap content in place without sliding.

Switching tabs is a frequent action. The selected marker transitions quickly, and the content under the strip swaps in place with no slide or fade-through. Reduced motion removes the transition and the marker changes at once.

## Accessibility

- **A real tab widget, always.** `role="tablist"` on the strip, `role="tab"`
  and `aria-selected` on each tab, `aria-controls` pointing at the panel when
  one is declared, and roving tabindex: one stop for the whole strip, with
  Left, Right, Home and End moving selection and focus together. Tabs are real
  `<button>` elements, so activating one pushes no history entry and moves no
  scroll position.
- **A disabled tab stays reachable by the arrow keys**, so its existence is
  discoverable, but is never selected — `isDisabled` keeps it out of
  `activeKey` contention without removing it from the strip's keyboard path.
- **`aria-controls` is omitted rather than dangled.** A `Tabs.Tab` with no
  matching `Tabs.Panel` gets no pointer at all.
- **Narrow pill views are a menu button.** The selected pill carries
  `aria-haspopup="menu"` and `aria-expanded`, and is named from the strip's
  `aria-label` and the selected view ("Views: Active"). It opens from Enter,
  Space or a click with focus on the checked row; each view is a
  `menuitemradio` row, the selected one `aria-checked`, and each panel is
  labeled by the trigger. Underline tabs that scroll stay a tablist, and the focused
  tab's ring is drawn inside it so the strip's edge never clips it.
