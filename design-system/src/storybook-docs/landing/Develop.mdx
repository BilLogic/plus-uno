<FoundationSection title="Start here">

- Run Storybook locally: the steps are on <DocsLink id="get-started-about">About</DocsLink>.
- Check that a component exists before you use it: `design-system/agent-views/components/index.md` is the generated list.
- Import public components from the `@/components` barrel, never from a component's own folder.
- Style with `--ds-*` tokens, never literal values: <DocsLink id="foundations-tokens">Tokens</DocsLink> explains the names.
- Build new interactive behavior (open and closed state, focus, keyboard) on Base UI, styled on the tokens.

</FoundationSection>
