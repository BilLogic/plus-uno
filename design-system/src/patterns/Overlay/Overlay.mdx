<Title />
The Overlay is the full-screen layer that holds a scrim and the one layer above it, a modal or a drawer, so that layer is placed, not drawn. It fills with the scrim, pads 16 at the sides and 64 above and below, and centers a modal or holds a drawer at the screen edge. The examples on this page follow the toolbar's Color mode switch.

### Purpose

An Overlay interrupts the page for one task. It dims everything behind it with one scrim, so the person sees only the layer on top. It never draws content of its own.

</div>

<div className="sb-ds-doc-section">

### When to use

- Put a **Modal** in an Overlay when one task blocks the page.
- Put a **Drawer** in an Overlay, at an edge, when the task needs the page in view.
- Raise a confirm from a modal in a second Overlay above the first.
- For a menu, popup, flag or tooltip, use the **Popover family**. These float with no scrim and never take an Overlay.
- For a floating sidebar, use the **Sidebar**. It takes a shadow and no scrim.

</div>

### Rules

- Pad 16 at the sides and 64 above and below. This is the closest a modal gets to the screen edge.
- Use one scrim, `--ds-blanket`, under every modal and drawer.
- Stack at most **two overlays**: Overlay 1 for a modal, Overlay 2 for a confirm raised from it.
- Opening a modal closes a floating sidebar, so the two never stack.
- A floating sidebar gets a shadow and no scrim.
- Popovers, flags and tooltips never bring a scrim.
- Both layers cap at the screen height less 128 and scroll their body past it.
- Place a modal in the Overlay. Do not detach it to move things around.

</div>

<div className="sb-ds-doc-section">

### Do and don't

None. The Overlay has no do and don't pairs of its own. The pairs live on the Modal page.

</div>

<div className="sb-ds-doc-section">

### Accessibility

- The Overlay is a layout layer with no role. The Modal or Drawer inside it is the dialog.
- The scrim is a pointer shortcut, not a control. A keyboard closes a dialog from inside it, so the scrim takes no role and no key handler.
- The scrim at `--ds-blanket` keeps the dialog legible in Light and Dark. The toolbar's Contrast switch changes it with the rest of the page.
- A layer wider than a narrow screen keeps its width, and the Overlay scrolls.

</div>

<div className="sb-ds-doc-section">

### For developers

The Overlay draws the layer only. It does not trap focus, close on Escape or count toward the two-overlay limit. For a real dialog, use the core Modal component, which draws the same layers and scrim tokens. The Drawer pattern brings its own focus handling.

</div>
