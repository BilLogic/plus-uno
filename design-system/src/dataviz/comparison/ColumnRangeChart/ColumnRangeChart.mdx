## When to use

Use `ColumnRangeChart` for a minimum and a maximum per category: a tutor's
available hours each day, the shortest and longest session per subject, the
lowest and highest score per class.

For one value per category, use `BarChart`. For two distinct moments, such as
before and after, use `DumbbellChart`. For spans placed on a timeline rather
than across categories, use `XRangeChart`. For the full spread of a
distribution, with quartiles and outliers, use `BoxPlotChart`.

The chart is vertical by default. Set `horizontal` for long category labels.

## Data shape

`categories` is an array of strings. `data` is an array of `{ low, high }`,
both required, one per category in the same order. `height` defaults to 400;
`horizontal` defaults to `false`.

```jsx
<ColumnRangeChart
    yAxisLabel="Session length (min)"
    categories={['Math', 'Science', 'Reading', 'Writing']}
    data={[
        { low: 25, high: 60 },
        { low: 30, high: 55 },
        { low: 20, high: 45 },
        { low: 30, high: 50 },
    ]}
/>
```

## Color and accessibility

- **One color for every column.** The chart draws a single series in categorical slot 1 and takes no per-column color.
- **Position carries the values, and the labels repeat them.** Both ends sit on a shared axis and print their numbers, so the chart reads without hue.
- **The ends carry no unit.** The labels print bare numbers. Put the unit in `yAxisLabel`, as in "Hour" or "Session length (min)".
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. There is no legend, and the series is named only "Range", so the axis title and the surrounding header have to say what is measured. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`ColumnRangeChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Availability could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState size="compact" header="No availability set" description="Hours appear once a tutor sets their availability." />
    : <ColumnRangeChart categories={categories} data={data} yAxisLabel="Hour" />}
```
