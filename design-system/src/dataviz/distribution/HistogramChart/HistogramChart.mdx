## When to use

Use `HistogramChart` for the spread of one continuous measure: test scores
across a class, session lengths across a week, minutes to first message across
new students. It answers "what is typical, and how far do values stray".

For counts of named categories, use `BarChart`; a histogram bins a continuous
number, a bar chart does not. For the spread of several groups side by side,
use `BoxPlotChart`. For a distribution across two dimensions, use
`HeatmapChart`.

## Data shape

`data` is a flat array of numbers, one per record; the chart does the counting.
`height` defaults to 400.

```jsx
<HistogramChart
    xAxisLabel="Session length (min)"
    yAxisLabel="Session length (min)"
    binWidth={10}
    data={[22, 28, 30, 31, 35, 38, 40, 41, 44, 45, 45, 48, 52, 55, 58, 60, 62, 75]}
/>
```

Pick a `binWidth` that matches how readers think about the measure (5 points,
10 minutes). Too wide hides the shape; too narrow turns it into noise.

</div>

## Color and accessibility

- **One color.** Bins take `--ds-chart-brand`; there is only ever one series, so there is no legend to read.
- **Height carries the count.** Bins are positioned and sized by value, so the chart reads without hue. The count axis starts at zero.
- **Uneven samples mislead.** A handful of records makes a ragged shape that looks meaningful. Say how many records are behind the chart.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

</div>

## States

`HistogramChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <HistogramChart data={data} xAxisLabel="Score" yAxisLabel="Score" />}
```

## Related

- For comparing several distributions at once, use `BoxPlotChart`.
- For counts of named categories rather than binned values, use `BarChart`.
- For the distribution across two dimensions, use `HeatmapChart`.
- For the individual records behind the bins, use `ScatterChart`.
