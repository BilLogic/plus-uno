## When to use

Use `DumbbellChart` when the gap between two values is the story: pre-test vs.
post-test score per student, starting vs. current skill level, or first-week vs.
latest attendance per school. Sort by gap size to surface the biggest movers.

For one value per category, use `LollipopChart`. For a continuous span without
two distinct moments, use `ColumnRangeChart`. For two values as side-by-side
bars, use `BarChart` with two series. For more than two points per category, use
`LineChart`.

Horizontal by default to fit names; set `horizontal={false}` for short labels
in columns.

## Data shape

`categories` is an array of strings. `data` is an array of `{ low, high }` (both
required) in `categories` order. `lowLabel` and `highLabel` name the two ends.
`height` defaults to 400; `horizontal` defaults to `true`.

```jsx
<DumbbellChart
    lowLabel="Pre-test"
    highLabel="Post-test"
    yAxisLabel="Score"
    categories={['Maya', 'Jordan', 'Priya', 'Luis']}
    data={[
        { low: 45, high: 82 },
        { low: 65, high: 92 },
        { low: 58, high: 78 },
        { low: 80, high: 88 },
    ]}
/>
```

## Color and accessibility

- **Fixed end colors.** The high dot and connector use categorical slot 1; the low dot uses slot 2. Colors cannot mark a gain vs. a loss.
- **Single-swatch legend.** The legend prints `"Pre-test → Post-test"` with one swatch, so state which end is which in surrounding text or rely on the tooltip.
- **Position carries the values.** Both dots sit on a shared axis, so the gap reads as a length without hue.
- **Keep `low` and `high` consistent.** Put the same measure in the same field for every row (for example, pre-test in `low`). Because only dot color order indicates a decline, call declines out in surrounding text.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`DumbbellChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a post-test is logged." />
    : <DumbbellChart categories={categories} data={data} lowLabel="Pre-test" highLabel="Post-test" />}
```
