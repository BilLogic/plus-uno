# ADR-038: Every size, type and motion family is a repo plan (2026-11-03)

> **Superseded for motion** by [ADR-041](041-motion-is-springs-on-four-tiers.md) (2026-11-12): springs only, no durations or bezier easings. The rest of this ADR stands.

**Decision.** Extends ADR-035's pattern — a plan this repo owns, generated into SCSS and a Figma variables payload, Figma downstream of code — from color to every other token family: space, size, radius, border width, typography and motion. PLUS ×16 numbering stays (`--space-100` is 16px, per Bill 2026-11-03); nothing here renumbers the primitive ladder. Container roles are keyed to density, not `sm`/`md`/`lg`: `--{card|section|modal|page}-pad[-x|-y]-{default|compact|spacious}`. Element roles: `--element-{pad|gap|radius}-{default|compact}`. Motion gets duration and easing roles, with reduced motion handled once at the token layer rather than once per component.

**What this ticket (#1704) actually ships.** `scripts/lib/tokens/plan.mjs` is the plan; `scripts/generate-design-tokens.mjs` renders it into `design-system/src/tokens/deep/`: `_roles.scss` (container and element roles), `_motion.scss` (duration/easing roles plus one `prefers-reduced-motion` block that zeroes every duration), `_legacy-size-aliases.scss` (old names pointed at their role-token replacement, value-exact — see below) and `figma-spec.json` (the Figma variables payload — **written, not pushed**; pushing it is a separate, one-writer-queue step #1698 leaves to Phase D). `npm run regenerate` runs it.

**Primitives are not re-generated here.** The `--space-*` / `--radius-*` / `--stroke-*` ladder already exists, already on ×16 numbering, in `design-system/src/tokens/_scales.scss`, generated by `scripts/generate-all-tokens.js` from a manual Figma JSON export. This plan reads that ladder by name rather than re-declaring it: re-deriving ~200 already-consuming components' primitive source today, with no value change to gain, is risk with no payoff. Flipping the primitive ladder's own generator onto a plan (so it, too, stops reading Figma) is a follow-up ticket, not this one.

**Old names, and why only six are aliased.** Three size vocabularies already coexist in this repo: `_spacing_semantics.scss`'s `--size-element-*`/`--size-card-*`/`--size-section-*`/`--size-modal-*`/`--size-surface-*`, `_frame_layers.scss`'s bare `--card-*`/`--section-*`/`--modal-*`/`--surface-*`, and `_scales.scss`'s `--element-*`. They do not agree with each other — `_spacing_semantics.scss` has `--size-element-radius-sm` at 4px where `_scales.scss` has `--element-radius-sm` at 2px — which is exactly the debt #1698 describes. An alias can only be value-exact where ONE of the old vocabularies names the value unambiguously; `LEGACY_ALIASES` in `plan.mjs` lists the six names that qualify (element pad, card pad), each proven value-exact in `scripts/check-legacy-size-aliases.test.mjs` by compiling `main.scss` and resolving both sides' `var()` chains. `--page-pad` is excluded even though it is unambiguous: `_frame_layers.scss` overrides it inside a `@media (min-width: 1440px)` block, and a flat `:root` alias would silently drop that step. Gap and radius old names stay off the alias list for the reason above — aliasing one would mean picking which disagreeing legacy vocabulary is "right," which is a per-component call, not a generator's.

**The rest of the old names are a ratchet, not a guess.** `npm run check:old-size-tokens` counts `var()` uses of the exact declared old-name set (not a bare prefix — `--card-` is also the new role tokens' prefix) per file, may only fall, and a family PR lowers it with `-- --update` the same cycle it moves a component's callers to role tokens. `npm run generate:old-size-token-list` writes the same scan into `design-system/guidelines/foundations/spacing.md`'s "Still on old size tokens" table — the to-do list a family PR works from, the same shape `color-migration.md`'s legacy-color list already is for color (ADR-035).

**Deleted.** `scripts/sync-figma-tokens.js`, the Figma-to-code sync script: it wrote to `new tokens/`, a path the generator it fed never read, and resolved only one alias level. It was dead, not merely broken — nothing in CI or `npm run regenerate` called it. `npm run sync:tokens` is gone with it; every doc that pointed at either is updated to say the export is a manual step until the primitive generator's own follow-up flips it.

**Consequences.** `check:design-tokens` fails on drift between `tokens/deep/` and the plan. `check:old-size-tokens` and `check:old-size-token-list` fail on a rise or a stale regenerate. Neither check requires a component to move — #1698's scope line holds: this ticket does not migrate a single caller, and every family PR owns its own rows on the ratchet it inherits. — uno (agent), Nov 2026, recording the decision Bill settled in the grill round for #1704

## Addendum: the four-tier ladder (#1756, 2026-11-04)

Bill, 2026-11-04: "clean up both token on figma and in code and fully align the two." `plan.mjs` grows one more export, `TOKEN_LADDER`, that extends this ADR's "Figma downstream of code" decision from role/motion tokens to the whole spacing, size and radius surface, organized as one plan with four tiers, most general to most specific:

- **Primitives** (`spacing / primitives`) — `--space-*` / `--radius-*` / `--stroke-*` / `--size-*`, unchanged; still generated from the Figma JSON export by `generate-all-tokens.js`, for the same risk-reduction reason this ADR already gave for not re-deriving them.
- **Semantics** (`spacing / semantics`) — Pad, Stack, Inline and Radius replace the Element layer as the safety net, on steps only (`xs`/`sm`/`md`/`lg`), no density words; plus Border, Focus, Grid, Screen, Content (dissolved out of `spacing / layout`), and the Size dimension roles.
- **Patterns** (`spacing / patterns`) — Frame (with Topbar and Sidebar), Page, Section, Card, Table, Blanket (renamed from Overlay), Modal, Popover, Drawer, Focused page. Density (`default`/`compact`/`spacious`) lives only where a `spacing` prop lives: here and in Components.
- **Components** (`spacing / components`) — a value exactly one component needs that no shared tier covers: Button radius, Calendar day sizes, Checkbox/Radio control sizes, Listbox limits, Join row and Option menu widths, Tile radii.

`layers` becomes its own non-spacing, code-only family (`--layer-*`), carrying the z-index scale this ADR's generator already wrote as `CODE_ONLY_LAYERS`. `design-system/figma/variables-payload.json` is the one combined Figma variables payload for every tier, superseding `tokens/deep/figma-spec.json`; `architecture/token-tiers-name-map.md` is the full old-to-new name list.

This ticket (#1756, PR1 of its sequence) is additive only, the same cycle this ADR's six `LEGACY_ALIASES` already used: every new-tier name is generated as `var(--old-name)` beside the untouched old declaration, so no caller moves and no pixel changes. Caller migration by area (components, then patterns/styles, then specs, then prototypes/src) is PR2+; deleting the old declarations and zeroing `check:old-size-tokens` is the final PR in the sequence, the same shape this ADR's own "rest of the old names are a ratchet, not a guess" section already describes.

## Addendum: the old vocabulary is deleted (#1756 part 2, 2026-11-04)

The final PR of the sequence deletes what the ladder replaced. The retired names (`RETIRED_TOKENS` in `plan.mjs`) lose their declarations: `generate-all-tokens.js` still reads the Figma exports, which carry them, and drops them on the way out, so a regenerate cannot write one back. Every ladder row now declares its own value, with its responsive overrides under the media query the plan names, rather than aliasing an old name. `check:old-size-tokens` counts uses of the retired set and is held at zero.

Bill's ruling the same day removes the "roles" concept. The container pad roles split into the patterns tier (`Card/pad-compact`, `Section/pad-x-default`, `Modal/pad-y-spacious`, `Page/pad-x-compact`, and the rest), the `--element-*` roles are gone, and callers read the semantics Pad / Stack / Radius steps. Motion keeps its tokens and becomes its own `motion` collection. The spec name never appears in a token or collection name: `tokens/deep/` is `tokens/ladder/`, and `design-system/figma/variables-payload.json` holds `spacing / semantics`, `spacing / patterns`, `spacing / components`, `layers` and `motion`. A guard test in `scripts/generate-design-tokens.test.mjs` fails on `deep`, `roles` or `element` in any of those names.

Two values the old Figma element vocabulary held have no semantic step — a 4px vertical pad and a 10px gap — so their callers read `--space-025` and `--space-0625` directly. Adding a step is a design call, left open.
