## When to use

Use `AiIcon` to mark an action that PLUS AI performs. For any other action, use a Font Awesome Free glyph. Stop generating has no sparkle on purpose, because stopping is not generative.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Pair it with visible text, or give it a `label`.

Without `label` the icon is hidden from assistive technology.

```jsx
<AiIcon name="summarize" label="Summarize" />
```

### Pick `name` from the set.

`generate`, `ask`, `rewrite`, `summarize`, `plan`, `suggest` and `stop-generating`.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **Labeled or hidden.** With `label` the icon is `role="img"` named by it. Without, it is `aria-hidden`.
- **Color follows the text.** It fills with `currentColor`, so it keeps contrast with its surroundings.

</div>

<div className="sb-ds-doc-section">

## Related

- For any non-AI icon, use a Font Awesome Free glyph.
- For the border that shows generation in progress, use `GenerativeBorder`.
