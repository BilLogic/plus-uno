Every component page has four tabs below its title:

- **Examples:** live stories for each appearance, state and size, followed by the interactive playground.
- **Code:** the barrel import line and props table, generated from the component source.
- **Usage:** when to use the component, alternatives, best practices, accessibility, parts, content guidelines and related components.
- **Harness:** the generated markdown file that coding agents read, with copy and issue links.
