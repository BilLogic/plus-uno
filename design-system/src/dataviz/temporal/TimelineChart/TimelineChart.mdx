## When to use

Use `TimelineChart` for a handful of milestones in order: a student's path from
application through assessment, enrollment and midterm review to completion; a
tutor's onboarding steps; the phases of a program term.

Events sit at even spacing, in array order, with no time scale. When the gaps
between events or the length of each one matter, use `XRangeChart`. For a
measured value over time, use `LineChart`. For stages people drop out of
between, use `FunnelChart`.

## Data shape

`data` is an array of events in the order they happened, each
`{ name, label, description }`. Only `name` is required; `label` defaults to
`name` and `description` to empty.

```jsx
<TimelineChart
    data={[
        { name: 'Matched', label: 'Matched with tutor', description: 'Placed in a Math group' },
        { name: 'First session', label: 'First session', description: 'Baseline SMART check-in' },
        { name: 'Midpoint', label: 'Midpoint review', description: 'Goals revisited with the tutor' },
        { name: 'Wrap-up', label: 'Term wrap-up', description: 'Final progress report shared' },
    ]}
/>
```

`height` defaults to 400.

## Color and accessibility

- **Color follows event order and means nothing.** Each event takes the next categorical color, slot 1 first, and the order wraps after the eighth. There is no `color` field, so color cannot mark a status or a type of event.
- **Position and text carry the meaning.** Order along the line is the sequence, and each label and description says what the event is. The chart reads the same without hue.
- **Keep labels short.** Labels that would collide are hidden rather than moved, so a long description or a crowded timeline loses text. Keep to a handful of events, or raise `height`.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-point labels, and arrow-key navigation through the events. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`TimelineChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Milestones could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No milestones yet" description="Milestones appear as the student moves through the program." />
    : <TimelineChart data={data} />}
```
