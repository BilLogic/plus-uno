## When to use

Use `GaugeChart` sparingly for one or two headline figures on a known scale,
such as course completion rate, tutor attendance share or average satisfaction
out of 100.

For several figures at once, use `BarChart`. For a value against a target read
precisely, use `BulletChart`. For a completion share with a centered label, use
`DonutChart`. For change over time, use `LineChart`.

## Data shape

`value` is a single number (printed as given with no automatic unit), `min` and
`max` set the scale, and `label` names the measure and its unit.

```jsx
<GaugeChart value={82} min={0} max={100} label="Sessions attended (%)" />
```

</div>

<div className="sb-ds-doc-section">

## Color and accessibility

- **Brand by default, status when meaningful.** The fill uses `--ds-chart-brand` unless `color` is set (it does not change dynamically with `value`). When encoding status with `STATUS.success`, `STATUS.warning` or `STATUS.danger`, state the status in `label` or surrounding copy.
- **Arc length and printed value.** Because `value` is always printed under the arc, the gauge reads without hue.
- **Keep the scale honest.** Setting `min` above zero exaggerates small values; use a non-zero `min` only when the scale genuinely starts there.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type, a per-point label, and keyboard navigation to the value. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting ([Chart color](?path=/docs/data-visualizations-color--docs)).

</div>

## States

`GaugeChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Attendance could not load.</SectionMessage>
    : value == null ? <EmptyState spacing="compact" header="No sessions yet" description="Attendance appears after a session is logged." />
    : <GaugeChart value={value} label="Sessions attended (%)" />}
```
