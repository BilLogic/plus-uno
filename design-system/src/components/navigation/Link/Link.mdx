## When to use

Use `Link` for navigation inside a sentence or a block of text — "see the
session report," "read more." For a standalone action styled like a button,
use `Button` or `LinkButton` instead; `Link`'s appearances are for text, not
for a control that stands on its own.

</div>

<div className="sb-ds-doc-section">

## Usage notes

### Pick the appearance for the surface it sits on, not for emphasis.

`default` is for a link on the page's own background, `subtle` for one on a
muted surface where less contrast reads better, and `inverse` for a link on a
dark or colored fill. None of the three changes the link's meaning.

### Let `isOpenInNewWindow` manage `target` and `rel` together.

Setting `isOpenInNewWindow` adds the external-link glyph, appends spoken text
to the accessible name, and defaults `target="_blank"` with
`rel="noopener noreferrer"` — pass `target`/`rel` directly only when the
default pairing doesn't fit.

```jsx
<Link href="/report" isOpenInNewWindow>View the full report</Link>
```

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **A real anchor.** `Link` renders an `<a>`, reachable with Tab and
  activated with Enter, with no extra role needed.
- **New-window links say so.** The glyph is decorative, but the accessible
  name gains "(opens in a new tab)" through visually hidden text, so a screen
  reader announces the behavior before it happens.
- **`children` is required.** A link always needs visible or accessible text
  — there is no icon-only mode.

</div>
