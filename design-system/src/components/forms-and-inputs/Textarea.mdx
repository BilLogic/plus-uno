## For developers

- **Validation works as on Text field.** The message sits in the caption on the left. With <code>maxLength</code>, a count sits on the right, such as "55 / 120", and neither replaces the other.
- **subtle keeps the editor open.** A click elsewhere mid-paragraph should not publish half a thought, so a subtle text area saves only through its Save button or Ctrl or Cmd with Enter, and stays open when it loses focus. Cancel or Esc puts the saved text back. A failed save, thrown or rejected from <code>onSave</code>, keeps the field open and invalid.
- **One row, not a short variant.** Pass <code>rows=1</code> for a single-line text area.
- **The id is derived** when you do not pass one. Pass <code>id</code> only when something outside the component needs to point at the control.

## When to use

Use Text area when the answer may run past one line and is prose the person writes in their own words: session notes, a reflection, feedback, a reason for canceling.

- **Size it to the usual answer.** Set the number of rows so a typical answer fits without scrolling. The field is 80 high at least and grows from there.
- **Label it like any field.** Give it a visible label and, where it helps, a caption with the expected length.
- **For a name, an email or a short phrase**, use [Text field](?path=/docs/components-forms-and-inputs-text-field--docs).
- **For formatted text**, use [Rich text editor](?path=/docs/components-forms-and-inputs-rich-text-editor--docs).
- **For a number**, use [Number input](?path=/docs/components-forms-and-inputs-number-input--docs).

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **The label is associated with the field.** Give every Text area a label. Hiding it with <code>showLabel=false</code> clips it out of sight and keeps the name for assistive technology.
- **An error is announced.** An invalid field is marked invalid, points at its message, and the message is read out when it appears. The count is described too.
- **Required is marked once.** An asterisk shows beside the label and the field is announced as required. Explain the asterisk once, in the form's legend.
