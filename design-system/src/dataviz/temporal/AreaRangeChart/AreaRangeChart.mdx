## When to use

Use `AreaRangeChart` when spread over time matters, such as weekly lowest and
highest session scores, an expected score band across a term or daily earliest
and latest session starts. Because the chart draws only the band and no
midpoint line, state the average in surrounding text if needed.

For a single value over time, use `LineChart`. For a fill down to zero, use
`AreaChart`. For low-to-high ranges across categories, use `ColumnRangeChart`.

## Data shape

`data` is an array of `[x, low, high]` triples in `x` order. Because there is
no `categories` prop, index periods numerically and name the unit in
`xAxisLabel`. `height` defaults to 400.

```jsx
<AreaRangeChart
    xAxisLabel="Week of term"
    yAxisLabel="Session score (%)"
    data={[
        [1, 52, 78], [2, 55, 80], [3, 58, 84], [4, 61, 85], [5, 60, 88],
    ]}
/>
```

## Color and accessibility

- **Fixed brand color.** The band always uses `--ds-chart-brand` with no `color` prop or second series.
- **Position carries the values.** Top and bottom edges mark the high and low without hue; rely on the tooltip for exact readings, and state what the bounds represent in the surrounding header or caption.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`AreaRangeChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Score ranges could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Ranges appear after a week of sessions is logged." />
    : <AreaRangeChart data={data} yAxisLabel="Session score (%)" />}
```

## Related

- For the level alone, as a line, use `LineChart`.
- For a fill down to zero rather than between two bounds, use `AreaChart`.
- For low-to-high ranges across categories rather than time, use `ColumnRangeChart`.
- For the full spread of values in each group, with quartiles, use `BoxPlotChart`.
