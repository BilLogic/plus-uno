# AI Compliance Monitor Prototype

A supervisor-facing dashboard for reviewing AI compliance flags on tutoring
sessions, built with the PLUS design system for a supervisor usability study.
All tutors, students, sessions and transcripts are fictional.

- **Location**: `prototypes/compliance-dashboard/`
- **Port**: 3031 (default)
- **Branch**: `feat/compliance-dashboard-prototype` (branch experiment; do not merge to `main`)

## Run locally

From the **project root**:

```bash
npm run dev:compliance-dashboard
```

## Build

```bash
npm run build:compliance-dashboard
```

Outputs to `dist/prototypes/compliance-dashboard/`, served on the Deploy
Preview at `/prototypes/compliance-dashboard/`.
