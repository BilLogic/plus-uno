<FoundationSection title="Lookup tools">

The `ds` CLI and the `plus-ds` MCP server (`npm run ds:mcp`, or `/mcp/ds` when hosted) expose five tools over the design system (`docs/connectors/ds-mcp.md`):

- `ds_find`: search components, patterns, tokens and icons by name, alias or task.
- `ds_get`: read a component's import line, props, usage rules, accessibility and Figma mapping.
- `ds_tokens`: list the token steps for a role with their tier, value and intent.
- `ds_guide`: read a foundation or composition guideline by topic or rule ID.
- `ds_check`: check JSX or SCSS code against design-system usage rules.

While `npm run storybook` runs, `localhost:4200/mcp` also serves the Storybook MCP endpoint (`docs/connectors/storybook-mcp.md`).

</FoundationSection>

<FoundationSection title="Files an agent reads">

- `AGENTS.md` at the repo root: the routing table, loading contract and hard rules.
- `design-system/agent-views/`: generated indexes of components, tokens, motion and pages.
- `design-system/src/components/<group>/<Name>/index.md`: the generated single-file reference for each component, also shown in its **Harness** tab.
