<Title />

The AI register has three kinds of token: a bold ground, an edge and a glyph. It
is shaped like Atlassian's
<a href="https://atlassian.design/rovo-ui/color"> Rovo color</a> tokens, which are one
bold ground plus accents that only ever mark an edge or an icon, and it is built
from tokens PLUS already has, so there is no new palette.

<div className="sb-ds-doc-section">
### Elevation

An AI panel uses the core elevation pairs. Atlassian adds one overlay token for
Rovo opening over another app (<C>elevation.rovo.surface.overlay</C>) and says menus and
dropdowns use the core levels. PLUS has no such overlay yet, so
<C>--ds-surface-overlay</C> applies; a separate AI overlay is a follow-up if a case needs it.
</div>
