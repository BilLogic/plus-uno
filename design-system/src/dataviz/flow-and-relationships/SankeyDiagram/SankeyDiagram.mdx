## When to use

Use `SankeyDiagram` when an amount splits, merges and moves between stages:
students moving from referral source to first session to a subject, session
hours flowing from tutors into subjects, or where students go after a module.

For stages that only ever narrow, with nothing splitting off sideways, use
`FunnelChart`. For connections that carry no amount, use `NetworkGraph` or
`ArcDiagram`. For a plain comparison of totals, use `BarChart`.

Keep the flow moving one way. A link that loops back to an earlier stage turns
the diagram into a tangle; show that relationship with `DependencyWheel`
instead. Five to seven stages is the readable range.

## Data shape

`data` is an array of `[from, to, weight]` rows. `from` and `to` are node names;
`weight` is the amount flowing between them. Nodes are created from the names,
so spell a name the same way everywhere it appears.

```jsx
<SankeyDiagram
    data={[
        ['School referral', 'First session', 120],
        ['Family referral', 'First session', 60],
        ['First session', 'Math', 110],
        ['First session', 'Reading', 50],
        ['First session', 'No second session', 20],
    ]}
/>
```

</div>

## Color and accessibility

- **Color tells nodes apart.** Nodes take the categorical colors in order, starting at `--ds-chart-categorical-1`, and each link takes its source node's color. There are eight categorical colors, so past eight nodes the colors repeat; keep the node count low or label every node.
- **Width carries the amount.** Link width and node height are the reading; color only groups a link with where it came from. The tooltip gives the exact number.
- **Labels carry identity.** Every node is named in place, so the diagram reads without hue.
- **Thin links are hard to see and hard to hover.** Fold very small flows into an "Other" node rather than drawing slivers.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`SankeyDiagram` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Student flow could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState size="compact" header="No sessions yet" description="The flow appears after students book their first session." />
    : <SankeyDiagram data={data} />}
```

## Related

- For stages that only ever narrow, use `FunnelChart`.
- For relationships with no amount attached, use `NetworkGraph` or `ArcDiagram`.
- For flows that run both ways between a set of items, use `DependencyWheel`.
- For composition at one moment rather than flow between stages, use `TreemapChart`.
