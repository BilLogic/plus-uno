## When to use

Use `BubbleChart` when three measures of the same records belong together, such
as weekly sessions vs. average rating sized by student count, or attendance vs.
grade average sized by class size. Because area is read roughly, use the third
measure for relative size rather than exact comparison.

For two measures with nothing to size by, use `ScatterChart`. For sizes without
axes, use `PackedBubbleChart`. When the third measure needs exact comparison,
give it its own `BarChart`.

## Data shape

`data` is an array of series `{ name, data, color }`, where `data` holds
`[x, y, z]` triples. Axis labels default to `"X Axis"`, `"Y Axis"` and
`"Size"`, so always set `xAxisLabel`, `yAxisLabel` and `zAxisLabel`. `height`
defaults to 400. Omit `color` to assign one automatically.

```jsx
<BubbleChart
    xAxisLabel="Sessions per week"
    yAxisLabel="Average rating"
    zAxisLabel="Students"
    data={[
        { name: 'Math tutors', data: [[6, 4.6, 12], [9, 4.2, 18], [4, 4.8, 7]] },
        { name: 'Reading tutors', data: [[5, 4.5, 9], [8, 4.7, 15], [3, 4.1, 5]] },
    ]}
/>
```

## Color and accessibility

- **Automatic series color.** One series uses `--ds-chart-brand`; two or more follow the [categorical order](?path=/docs/data-visualizations-color--docs) from slot 1 without skipping. Keep to two or three series so bubbles do not crowd.
- **Position and size carry the values.** Color only separates series. Because readers can rank bubble areas but cannot judge exact ratios, rely on the tooltip (`zAxisLabel`) for exact values.
- **No size legend.** State what bubble size represents in the header or description.
- **Overlap.** The 70% fill shows overlapping bubbles, and drag-to-zoom separates dense clusters, but many large bubbles still occlude each other.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`BubbleChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Tutor stats could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No tutor stats yet" description="Stats appear after a tutor's first week of sessions." />
    : <BubbleChart data={data} xAxisLabel="Sessions per week" yAxisLabel="Average rating" zAxisLabel="Students" />}
```

## Related

- For two measures with no third to size by, use `ScatterChart`.
- For sizes grouped into clusters with no axes, use `PackedBubbleChart`.
- For density rather than individual points, use `HeatmapChart`.
- For a weight shown as column width instead of bubble area, use `VariwidthChart`.
