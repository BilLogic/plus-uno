## Usage

Use `InlineMessage` for a note that explains or qualifies something right
beside it, such as why a field is required or what a score means, without
taking up space until someone asks. It is built on `Popup`, so placement,
dismissal and focus return are shared with every other popup in the system.

For a message that belongs to a whole page or section and should always be
visible, use `Banner` or `SectionMessage` instead. `InlineMessage` is for
detail that most people will never need to open.

## Best practices

### Match the tint to the meaning.

Info for a neutral note; danger only when something failed. The icon is a
second cue, not a style choice.

<DoDontPair
    doExample={<OpenPreview appearance="info" label="About this setting" title="Heads up">This setting applies to new sessions only.</OpenPreview>}
    doCaption="Info for a neutral note."
    dontExample={<OpenPreview appearance="danger" label="About this setting" title="Heads up">This setting applies to new sessions only.</OpenPreview>}
    dontCaption="Danger for a neutral note."
/>

### Keep it to one short line.

It sits beside a field; long copy pushes the form around.

<DoDontPair
    doExample={<OpenPreview appearance="warning" label="About availability" title="Limited availability">Only 2 slots left this week.</OpenPreview>}
    doCaption="One short sentence."
    dontExample={<OpenPreview appearance="warning" label="About availability" title="Limited availability">Only 2 slots left this week. Slots open each Monday for the following week, and a slot is held for ten minutes while you book, so the count can change while this page is open.</OpenPreview>}
    dontCaption="A paragraph beside a field."
/>

### Show one message per field.

Two messages on one field leave no clear next step.

<DoDontPair
    doExample={<div inert aria-hidden="true" style={fieldRow}><span>Session length</span><InlineMessage appearance="info" label="About session length" title="Heads up">This setting applies to new sessions only.</InlineMessage></div>}
    doCaption="A single message."
    dontExample={<div inert aria-hidden="true" style={fieldRow}><span>Session length</span><InlineMessage appearance="info" label="About session length" title="Heads up">This setting applies to new sessions only.</InlineMessage><InlineMessage appearance="warning" label="About availability" title="Limited availability">Only 2 slots left this week.</InlineMessage></div>}
    dontCaption="An info note and a warning together."
/>

### Write the label as the question the popup answers.

The trigger is an icon button with no text of its own, so `label` carries its
accessible name and its tooltip. Write "Why this field is required", not
"info" or "more".

## Accessibility

- **The trigger is a real button.** It is reached with Tab and opens with
  Enter or Space, same as any `IconButton`.
- **`label` is required.** It is the trigger's only accessible name; a vague
  label like "info" tells a screen reader nothing about what the popup holds.
- **Focus and dismissal follow `Popup`.** Opening moves focus into the popup;
  Escape or a click outside closes it and returns focus to the trigger.
