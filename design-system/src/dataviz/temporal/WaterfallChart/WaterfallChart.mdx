## When to use

Use `WaterfallChart` for roughly ten or fewer ordered steps that add up between
two totals, such as term start enrollment → sign-ups → withdrawals → current
enrollment, or budget → expenses → remaining balance.

For totals without intermediate steps, use `BarChart`. For a continuous running
value, use `LineChart` or `AreaChart`. For an unordered breakdown of one total,
use `TreemapChart`.

## Data shape

`categories` names each step. `data` holds one entry per category in the same
order: a number (negative for a loss) or `{ y, isSum, isIntermediateSum, color }`.
Totals compute `y` automatically; `height` defaults to 400.

```jsx
<WaterfallChart
    yAxisLabel="Enrolled students"
    categories={['Start of term', 'New sign-ups', 'Transfers in', 'Withdrawals', 'Graduated', 'Current']}
    data={[
        { y: 420, color: 'var(--ds-chart-brand)' },
        85,
        12,
        -30,
        -18,
        { isSum: true, color: 'var(--ds-chart-brand)' },
    ]}
/>
```

## Color and accessibility

- **Override color on start and total bars.** Gains default to `--ds-chart-success` and losses to `--ds-chart-danger`. Pass `color: 'var(--ds-chart-brand)'` on starting and total bars so they do not take a status color.
- **Direction and labels carry the reading.** Every bar prints its value and steps up or down from the previous bar's end, so the chart reads without hue.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`WaterfallChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Enrollment changes could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No changes yet" description="Sign-ups and withdrawals appear here as they happen." />
    : <WaterfallChart categories={categories} data={data} yAxisLabel="Enrolled students" />}
```
