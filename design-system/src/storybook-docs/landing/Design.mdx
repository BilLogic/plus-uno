<FoundationSection title="Start here">

Storybook holds the usage rules for every foundation, component, template and pattern. The Figma library holds the visual layer: component sets, anatomy, redlines, variants and a link back to each Storybook page.

- <DocsLink id="foundations-overview">Foundations</DocsLink>: color, typography, spacing, grid, motion, sound and tokens.
- Components: UI building blocks grouped by job, starting with <DocsLink id="components-forms-and-inputs-button-button">Button</DocsLink>.
- <DocsLink id="templates-overview">Templates</DocsLink>: page shells and containers with named slots, from <DocsLink id="templates-frame">Frame</DocsLink> and <DocsLink id="templates-page">Page</DocsLink> down to <DocsLink id="templates-section">Section</DocsLink>, <DocsLink id="templates-modal">Modal</DocsLink>, <DocsLink id="templates-panel">Panel</DocsLink> and <DocsLink id="templates-popup">Popup</DocsLink>.
- <DocsLink id="patterns-overview">Patterns</DocsLink>: guidance that holds across two or more templates.
- <DocsLink id="ai-ui-about-ai-ui">AI UI</DocsLink>: how AI features look and behave.
- <DocsLink id="data-visualizations-overview">Data visualizations</DocsLink>: choosing and coloring charts.

</FoundationSection>
