<FoundationSection title="Guidance">

The content guidance lives in the repo, under `design-system/guidelines/foundations/content/`:

- `overview.md`: the index, which file answers which question.
- `voice-and-tone.md`: how PLUS sounds.
- `language-and-grammar.md`: the house rules for grammar, capitalization and punctuation.
- `message-design.md`: errors, warnings, success messages and empty states.
- `date-and-time.md`: how to write dates and times.
- `inclusive-language.md`: writing for everyone.
