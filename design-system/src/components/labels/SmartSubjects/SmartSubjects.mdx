## For developers

`StaticBadgeSmart` takes the subject as its key. `CompetencyBadge` takes the
same subject as people write it, such as "Mastering Content", and turns it into
the key. An unknown value becomes social-emotional.

`SMART_TAG_COLORS` maps each key to the Tag color its tokens alias, and
`TAG_COLOR_OF_CURRICULUM` holds the same pairing by token name. Both must name
the same accent as the tokens.

## When to use

Use a SMART subject to name which of the five areas a competency or a piece of
content belongs to. The subject colors belong to these five areas.

- **A category that is not a SMART subject:** use Tag, with one of its ten colors.
- **A condition that can change:** use Status.
- **A number:** use Count.

Each subject takes the color of an accent that no state role uses. A subject
therefore never reads as information, success, warning, danger or discovery.

</div>

<div className="sb-ds-doc-section">

## Accessibility

- **The words name the subject.** Color is never the only carrier: each subject says its name, so a reader who cannot tell the colors apart still knows the area.
- **Not a control.** A subject is a read-only tag, so it takes no focus and has nothing to press.
- **Contrast.** The ink is the token made for the subject's ground, so the words stay readable on the fill.
- **Decoration.** The swatch is hidden from assistive technology.

</div>
