## When to use

Use `LineChart` for a trend over evenly spaced time: average score across a
semester, sessions completed per week, active students per month. Several lines
compare trends, such as two cohorts or one student against the class average.

For separate categories with no order between them, use `BarChart`. When the
quantity under the line matters, or parts stack into a total, use `AreaChart`.
For two units on one chart, use `ComboChart`. For a trend beside a number with
no axes, use `Sparkline`.

Keep it to four or five lines. Past that the lines tangle and no one can follow
a single trend.

## Data shape

`data` is an array of series, each `{ name, data }`, where `data` holds one
number per period. There is no separate `categories` prop: put the period
labels on the first series as `categories`.

```jsx
<LineChart
    xAxisLabel="Week"
    yAxisLabel="Average score (%)"
    yDomain={[0, 100]}
    yTicks={[0, 25, 50, 75, 100]}
    data={[
        { name: 'Cohort A', data: [62, 66, 71, 74, 78], categories: ['Wk 1', 'Wk 2', 'Wk 3', 'Wk 4', 'Wk 5'] },
        { name: 'Cohort B', data: [58, 60, 65, 70, 72] },
    ]}
/>
```

A series may carry its own `color`; leave it out and the chart assigns one.
`height` defaults to 300.

## Color and accessibility

- **Color is assigned for you.** One line takes `--ds-chart-brand`. Two or more take the categorical order, slot 1 first, never skipping a slot. Past six series, group the smallest into "Other", or split the chart.
- **Position carries the value.** Color only tells lines apart, and every line uses the same solid stroke and circle marker, so where lines cross, color is the only thing separating them. Keep the count low enough that the legend can name each one, and say which line is which in the text around the chart when it matters.
- **Set the domain on purpose.** Without `yDomain` the axis fits the data, which can make a small change look steep. For scores and percentages, pass the full range.
- **Screen readers and keyboard.** The chart is a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation through the data. The chart takes no title of its own, so name it in the Section or Card header around it.
- **Contrast.** Chart colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens.

## States

`LineChart` draws what it is given and has no empty, loading or error state of its own. The caller chooses what to mount in its place:

- **Loading:** a `Skeleton` the height of the chart.
- **Empty:** a compact `EmptyState` saying what data belongs here.
- **Error:** a `SectionMessage` with `appearance="danger"` and a way to retry.

```jsx
{isLoading ? <Skeleton shape="rect" height={300} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="Scores appear after a session is logged." />
    : <LineChart data={data} />}
```
