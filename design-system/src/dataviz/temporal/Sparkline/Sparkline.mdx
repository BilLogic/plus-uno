## When to use

Use `Sparkline` for a compact trend beside a stat or inside a table row, such as
a student's seven-week score trend next to today's score or weekly attendance in
a roster row. Always print the current value beside it in text.

For values read off an axis or multiple series, use `LineChart`. When there is
no trend to show, render the number alone.

## Data shape

`data` is an array of numbers, oldest first. `label` (required) names the series
for screen readers and the tooltip; `categories` optionally labels each period
in the tooltip.

```jsx
<span>82%</span>
<Sparkline
    label="Average score, last 7 weeks"
    data={[64, 70, 68, 74, 77, 79, 82]}
    categories={['Sep 1–5', 'Sep 8–12', 'Sep 15–19', 'Sep 22–26', 'Sep 29–Oct 3', 'Oct 6–10', 'Oct 13–17']}
    valueSuffix="%"
/>
```

## Color and accessibility

- **Brand by default, status when meaningful.** Defaults to `--ds-chart-brand`. Set `tone` to `success`, `warning`, `danger` or `information` only when the trend carries that status, and state the status in adjacent text as well ([Chart color](?path=/docs/data-visualizations-color--docs)).
- **Mode-verified rendering.** The latest-value marker is ringed in `--ds-border-inverse`, and the hidden `ColorModes` story test verifies token strokes (`--ds-chart-brand`, `--ds-chart-danger`), resting marker visibility and hidden axes across every color mode.
- **Descriptive `label` and surrounding context.** Because there are no axes or title, write what the line shows and over what span in `label`, and name the metric in the surrounding stat or table row. Renders a labeled group with a screen-reader summary, per-point labels, and arrow-key navigation.
- **Contrast.** The line follows the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`Sparkline` has no empty, loading or error state. Mount a `Skeleton` matching the sparkline's size, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" width={120} height={32} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Scores could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No scores yet" description="A trend appears after a few sessions." />
    : <Sparkline label="Average score, last 7 weeks" data={data} />}
```
