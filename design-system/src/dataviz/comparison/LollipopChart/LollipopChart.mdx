## When to use

Use `LollipopChart` to rank many categories on one measure, such as scores by
student, average rating by tutor or views by lesson. Sort data from most to
least before passing it in; the chart preserves input order.

For a few categories or multiple series, use `BarChart`. For two values per
category, use `DumbbellChart`. For a low-to-high span, use `ColumnRangeChart`.

Horizontal by default to fit long names; set `horizontal={false}` for short
labels in columns.

## Data shape

`categories` is an array of strings. `data` is an array of numbers in
`categories` order. `height` defaults to 400; `horizontal` defaults to `true`.

```jsx
<LollipopChart
    yAxisLabel="Average rating"
    categories={['Maya', 'Jordan', 'Priya', 'Luis', 'Ana', 'Sam']}
    data={[4.9, 4.7, 4.6, 4.4, 4.1, 3.8]}
/>
```

## Color and accessibility

- **Single series color.** Every dot uses categorical slot 1 with no per-point color override. Highlight notable items in surrounding text instead.
- **Position carries the value.** Dots and stems trace each value to its label without hue.
- **Screen readers and keyboard.** Renders a labeled group with a screen-reader summary of its type and axes, per-series and per-point labels, and arrow-key navigation. Because there is no legend, `yAxisLabel` is the only name for the measure; name the chart in its surrounding Section or Card header.
- **Contrast.** Colors follow the page's color mode and increased-contrast setting; the tooltip uses the Popup pattern's background and text tokens ([Foundations](?path=/docs/data-visualizations-foundations--docs)).

## States

`LollipopChart` has no empty, loading or error state. Mount a `Skeleton` matching the chart's height, a compact `EmptyState` naming the missing data, or a `SectionMessage` (`appearance="danger"`) with a retry action:

```jsx
{isLoading ? <Skeleton shape="rect" height={400} />
    : error ? <SectionMessage appearance="danger" dismissible={false} actions={[{ text: 'Retry', onClick: retry }]}>Ratings could not load.</SectionMessage>
    : data.length === 0 ? <EmptyState spacing="compact" header="No ratings yet" description="Ratings appear after students review a session." />
    : <LollipopChart categories={categories} data={data} yAxisLabel="Average rating" />}
```
